## 二、知识是否真的有用：同题盲评

短剧知识用同一命题做盲评验证：三位评委（商业爽感、作者导演、技术完成度）和创作模型不同族，不知道哪份是哪一版。无技能裸写 73.2 分，第一版知识 85.0 分。第二版同时改了多个变量反而退步，这条教训写进了「复刻与变体方法论」的单变量纪律。

## 三、怎么读

1. **想直接写短剧** → 先读「开场钩子」和目标片种卡，写完对照「评分标准与三评委」自查
2. **想做广告、宣传片、科普等其他片种** → 读「编导分镜」对应的片种卡 +「导演审片标准」
3. **想照着爆款做、或要出多个版本测试** → 读「复刻与变体方法论」+「爆款拆解与带货测试」
4. **想搭批量出片的生产线** → 读「AI 视频产线工作流」+「AI 短剧制作手法」，分镜表两头对接
5. **想做内容/图文** → 读「写作与内容方法论」，选题 → 框架 → 成稿 → 去 AI 味一条线

## 四、样本与证据口径
