# 镜头语法：特写 → 拉远

每个镜头从一个小物件的特写开始，停留片刻，加速拉远，最后缓停在远景上。引擎在 `assets/template/src/cameras.js`。

## 节奏（7 秒一个镜头时）

| 段 | 时长 | 动作 |
|---|---|---|
| 停留 | 0 – 1.0s | 几乎不动（只推进 1.2%），让观众看清特写 |
| 加速 | 1.0 – 3.1s | 二次方加速 |
| 缓停 | 3.1 – 7.0s | 四次方减速，最后 1.5 秒只走总路程的约 1.4% |

两段曲线在 k=0.35 处值和斜率都连续，所以没有顿挫。镜头长度改了就改 `SHOT_LEN`，`HOLD` 按比例调。

## 为什么用指数距离

相机到焦点的距离是 `d0 · (d1/d0)^p`，不是线性插值。从 0.3m 拉到 100m 时：
- 线性插值：p=0.1 时已经离物件 10m，特写在第一秒后就没了。
- 指数距离：p=0.1 时约 0.54m，p=0.5 时约 5.5m，画面的缩放感是匀速的。

## 写一个镜头

```js
makeShot({
  name: '3 望柱 → 桥里桥全貌',
  close: { pos: [-16.25, 6.45, 1.25], target: [-15.65, 6.35, 0.78], fov: 38 },
  wide:  { pos: [-48, 5.5, 2],        target: [-10, 2.5, -8],       fov: 46 },
  focusEase: [0.35, 1],  // 焦点在 p=0.35 之后才开始移向远景目标
  arcUp: 0,              // 路径中途抬高多少米（越过屋顶时用）
  focusOffset: (t, p) => new THREE.Vector3(...),  // 焦点跟运动物体，比如船
})
```

### 起幅（close）

- 距离 0.3 – 1.5m，fov 38 – 42。离得越近，物件越要经得起看。
- **相机放在物件和远景机位的同一侧。** 起幅方向和落幅方向相反时，方向插值会绕半圈，扫进旁边的房子。
- **看背景**：逆光镜头的物件背后要是天空或开阔水面，不能是房子。
- **看受光**：傍晚低太阳下，背光面的特写是黑的，选朝太阳那面的物件。
- 要读的字（招牌、旗、匾）起幅就得完整可读。

### 落幅（wide）

- fov 45 – 52。最后一镜（航拍）可以朝太阳方向，拍剪影和逆光。
- 落幅机位不能在房子里，也不能紧贴墙。用 `check-cameras.mjs` 查。

### 常见问题和对应参数

| 现象 | 原因 | 处理 |
|---|---|---|
| 拉到一半相机进了墙 | 焦点先走了，相机被“焦点 + 方向 × 距离”带进去 | `focusEase: [0.4, 1]` |
| 拉远时横扫进旁边的房子 | 起幅、落幅方向夹角太大 | 把起幅机位挪到物件的另一侧 |
| 擦过屋檐或桥面 | 路径太低 | `arcUp: 3 ~ 6` |
| 运动物体（船）跑出画面 | 焦点没跟着 | `focusOffset` 返回物体相对起始时刻的位移，乘 `(1 - smoothstep(0.2, 0.9, p))` 让它在落幅时回到固定构图 |

## 检查顺序

1. `node scripts/check-cameras.mjs`：逐帧查相机是否进到 `CHECK.volumes`。会有误报（比如穿过拱洞），在 volume 上加 `open()` 开口函数，不要靠调大阈值掩盖。
2. `node scripts/contact.mjs`：每个镜头取 u = 0, 1, 3, 7 秒四帧拼成接触表，用 Read 看图。黑帧、背光、切字、构图都在这一步看。
3. 两项都过了再出片。

## 时间轴上的光照

全片的光照只由全局 t 决定（太阳高度、发光物亮度一起推进），和镜头顺序无关。所以安排镜头时，**需要暗场的特写（灯笼倒影、亮窗）放在后面，需要阳光的特写放在前面**。
