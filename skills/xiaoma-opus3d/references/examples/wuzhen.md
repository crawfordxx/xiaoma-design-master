# 例子：乌镇西栅 · 日落到华灯初上（完整实战）

先做成了 70 秒视频，后来按用户要求改成可嵌入网页的交互模型。两种产物都在项目里：

| 产物 | 路径 | 怎么重新生成 |
|---|---|---|
| 交互模型（单文件） | `dist/wuzhen.html`（862 KB） | `node scripts/build.mjs` |
| script 挂载版 | `dist/wuzhen-embed.js` | 同上 |
| 嵌入演示页 | `dist/embed-demo.html` | 同上 |
| 视频 | `out/wuzhen.mp4`（70 秒，135 MB，未放进仓库） | 删掉 `out/frames` 后 `node scripts/render.mjs` |

交互模型参数：光照固定在 t=55（太阳约 2°、灯笼约 85% 亮），初始视角 `pos [95,55,85] → target [-10,0,-5]`（东南高处朝西北，远处是白莲塔），最近 1.5m、最远 420m。M5 Pro 上三档都是约 120fps，加载约 1.3–3.5 秒。

完整源码在仓库的 `examples/wuzhen/`（在线演示见仓库 README）。遇到同类问题时直接去读那里的源码，比读这份摘要更准。

## 参数

| 项 | 值 |
|---|---|
| 范围 | 240m × 160m 的十字河口街区（不做整个景区） |
| 时段 | 太阳 6° → 1°，方位 260°（顺着主河），灯笼亮度 0.25 → 1 |
| 视频 | 70 秒，10 镜 × 7 秒，1920×1080，30fps |
| 规模 | 88 栋民居 + 作坊、11 处水阁、4 座桥、3 条船、23 棵树、约 900 栋远景低模；约 700 万三角形 |

## 区块（6 个子 Agent）

| 区块 | 负责 | draw call / 三角形 |
|---|---|---|
| terrain | 地面、驳岸、河床、河埠头 | 6 / 9.4 万 |
| water | 反射水面（Reflector + 自写 shader）、3 条摇橹船、橹的水花 | 23 / — |
| bridges | 通济桥、仁济桥（桥里桥）、两座平桥，望柱头雕刻 | 8 / 20.8 万 |
| houses-north | 北岸 45 栋 + 临水灯笼、晾衣竿、竹帘、私家石阶 | 116 / 90 万 |
| houses-south | 南岸 43 栋 + 廊棚、美人靠、58 盏灯笼、招牌、酒旗 | 71–79 / 190 万（含阴影） |
| landmarks | 染坊晒布架（140 条布）、白莲塔、20 棵柳树、远景 | 29 / 169 万 |

主 Agent 写的公共件：`layout.js`、`rng.js`、`geom.js`（米制 UV、瓦垄屋面）、`materials.js`、`house.js`（参数化民居）、`paths.js`、`sky.js`、`lighting.js`、`main.js`、`cameras.js`，以及全部 scripts。

## layout 的结构

- `rivers`：主河 12m 宽东西向，支河 8m 宽南北向，十字相交。
- `ROWS`：8 排民居的定义（沿哪条轴、哪几段、进深、朝向、是否临水、水阁概率），`fillRow` 用固定种子展开成 88 条记录，每条带 `footprint`。
- `bridges`：拱桥写跨径和拱顶离水高度，平桥写桥面高。
- `corridors`、`waterSteps`、`dyeYard`、`pagoda`、`trees`、`boats`、`backdrop.fillRects`。
- 乌镇版的 check-layout 是专用的（早于通用版的 `CHECK` 结构），规则包括：水阁不能挡航道、桥两端落在岸上、船线整段在水里且不撞水阁。

## 这次的改动轨迹（看 pitfalls.md 的对应条目）

- 平面图检查抓出 3 个重叠，加了 4 块后排填充区。
- house.js 先自测：修了俯视被雾吃掉、亮窗过亮、墙脚霉斑成条码、观音兜过大。
- 物理天空换成自写渐变天空；修了 `pow` 负数导致的 NaN 黑屏。
- 根据 Agent 报告：瓦面降采样、滴水瓦改小、灯笼改深红、水阁挂点外移、水阁侧面开窗、廊棚点光源对齐灯笼、店铺内景贴图、composer 开 MSAA、小窗改用均匀发光材质。
- 接触表抓出：水面 shader 在部分机位出 NaN（退回水 Agent 修，同时加了 NaN 保护 pass）、镜头 3/6 穿墙、镜头 5 背光、镜头 9 切字、镜头 10 不逆光（和镜头 8 对调柳树）。
- 改成交互模型：主入口拆成 scene.js（场景核心、画质分级）/ main.js（截图测试）/ viewer.js（交互）/ embed.js（打包入口）；区块改成静态注册；修了高像素比下画布撑出容器的 bug。
