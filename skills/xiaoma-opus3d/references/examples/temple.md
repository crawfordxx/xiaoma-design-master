# 例子：黄昏寺庙（原版提示词）

这套流程最早来自一段 4 步提示词（实际只给了 3 段，“截图对比”那段缺失）。这里把它映射成 skill 的参数，演示怎么把一个新主题套进来。

## 原始要求

- three.js 做一座黄昏时刻的寺庙，输出 70 秒视频，不准用任何 3D 模型、贴图或照片。
- 先出平面图 layout.js：主殿、五重塔、拱桥、莲花池、山门，单位米。
- 6 个子 Agent：地形、池塘（莲花、锦鲤）、主殿、五重塔、拱桥、树木。
- 全局材质：朱漆、金箔、青铜、屋瓦、木头。固定种子。
- 10 个镜头 × 7 秒，从灯笼、莲花、风铃、佛像面部等特写拉远；最后一镜从逆光枫叶拉到整座寺庙的航拍。
- （现在本 skill 默认交付可嵌入的交互模型；原版要的是视频，按 SKILL.md 附录导出。这些特写物件在交互模型里就是“值得近看的细节”。）
- 太阳在西南偏西，地平线上方约 7°，暖色光。

## 映射到 skill 的参数

| 参数 | 值 |
|---|---|
| 时段 | `sunBearingDeg: 250`（西南偏西），7° → 2°；交互模型固定在灯笼刚亮的一刻 |
| ZONES | `terrain, pond, main-hall, pagoda, bridge, trees` |
| 公共生成器 | 寺庙建筑各不相同，`shared.js` 可以只放“歇山顶 / 斗拱 / 栏杆”这类构件生成器，供主殿、塔、山门共用 |
| 材质 | `vermilion`（朱漆）、`gold`（金箔，metalness 1）、`bronze`、`roofTile`、`wood`、`stone`；发光物：灯笼、殿内烛光 |
| CHECK.keepOut | 莲花池（只允许 `bridge` 前缀进入） |
| CHECK.paths | 锦鲤游动路径，`mustStayIn: ['pond']` |
| 特写物件 | 灯笼（trees 或 main-hall 区块挂）、莲花（pond）、塔檐风铃（pagoda）、佛像面部（main-hall，要做殿内）、枫叶（trees） |

## 要提前想到的

- 佛像面部特写要做殿内，主殿区块的工作量会明显大于别人，可以拆成 `main-hall` 和 `hall-interior` 两个区块。
- 五重塔高、细，航拍和逆光剪影里最显眼，轮廓（层层收分、翼角起翘）比细节重要。
- 金箔在 ACES 下容易过曝成白色，金色材质的 roughness 别太低，环境贴图强度要压。
- 锦鲤和莲花在水面上：如果用反射水面，锦鲤要放在水下并让水有透明度，否则看不见。
