# 审美标准

商用 PPT 的读者是领导、客户、评委。他们不会夸「好看」，但会一眼看出「这页不像我们公司的」「这页字太多」「这个数字在哪」。所以标准按重要性排：**一致 > 清楚 > 好看**。

## 1. 模板一致性（最重要）

- **颜色**：只用 profile 里的令牌：`primary`（品牌主色，用于数字、图标底、重点色块）、`secondary`（辅色，用于第二组数据、渐变终点）、`dark`/`body`/`muted`（文字三级灰）、`surface`/`tint`（卡片底和浅底）。不引入新颜色。
- **字体**：标题用模板标题字体，正文用模板正文字体。一份 PPT 最多两种中文字体。
- **形状语言**：模板是直角的，卡片就是直角加一条主色顶边；模板是圆角的，卡片就是圆角。`radius` 由 inspect 自动判断。
- **页眉页脚、logo、页码、背景图**：原样保留，位置不动。
- **深色页**：文字自动反白；主色和深底撞色时，这一页自动换用辅色做强调。
- 品牌名、口号这类模板原文会自动保留；示例字（标题、XXXX、请输入……）一定替换或删除。

## 2. 层级

一眼要能看出先读什么。字号（16:9、13.33 英寸宽）：

| 层级 | 字号 | 颜色 |
|---|---|---|
| 页面标题 | 模板原字号 | 模板原色 |
| 关键数字 | 46–88（按列宽自适应） | 主色 |
| 一句话结论 `lead` | 20 | 标题色，加粗 |
| 小标题（卡片、步骤） | 18（空间大时放大到 25） | 标题色，加粗 |
| 正文说明 | 14（空间大时放大到 19） | 正文色 |
| 注释、来源 | 10–12 | 弱化色 |

正文不小于 12pt，任何字不小于 10pt（lint 会报）。

## 3. 密度（每页字数上限）

| 版式 | 上限 |
|---|---|
| `cards` | 2–6 张；每张小标题 ≤12 字、说明 ≤40 字 |
| `bullets` | ≤5 条单列，6–10 条自动两列；每条 ≤30 字 |
| `stats` | ≤4 个数字；标签 ≤10 字、说明 ≤20 字 |
| `process` / `timeline` | 3–6 步；每步说明 ≤30 字 |
| `compare` | 每边 ≤5 条，每条 ≤20 字 |
| `chart` | 类目 ≤12 个，系列 ≤3 个 |
| `table` | ≤7 行 × 5 列 |
| `quote` / `statement` | ≤40 字 |
| 整页 | ≤200 字（lint 超过 260 报警告） |

超了就拆页或删字。build 输出「字号从 X 缩到 Y」时，说明内容超了，**删字优先于接受缩字**。

## 4. 版面

- 内容只画在 `area` 里；内容少时引擎会放大（最多 1.4 倍）并上下居中，不要手动把东西挤到顶部。
- 同一组卡片结构一致：有一张带图标/数字，其他也留出同样的位置。
- 主色面积控制在 10% 左右：数字、图标底、一条结论条、一根高亮柱子。不要整页铺主色卡片。
- 图表：去掉网格和坐标轴线的噪音，数据标签直接标在柱子上；要讲哪一项就 `highlight` 哪一项，其余自动变淡。
- 相邻两页不要用同一种版式超过 3 次，节奏要有变化（数字页 → 卡片页 → 图表页 → 金句页）。

## 5. 文字

- 上屏的字从 md 原文删减、拆分得到，不改写、不扩写、不编数据。完整原文放演讲者备注。
- 标题说结论，不说话题：「OEE 逐月提升」好于「OEE 情况」。（如果 md 原标题是话题式的，可以把结论放进 `lead`。）
- 句末不加句号（金句除外）；数字带单位；同一份 PPT 里同类数字的小数位一致。

## 6. 目视打分（能读图的模型逐张看拼图，每项 1–10 分，都 ≥ 8 才交付）

| 项 | 8 分的样子 |
|---|---|
| 模板一致 | 盖住页眉看内容区，也能认出是这家公司的 PPT；没有模板外的颜色和字体 |
| 层级 | 3 秒内知道这页讲什么、关键数字是多少 |
| 密度 | 没有缩到很小的字；没有一页塞两件事 |
| 对齐 | 卡片等高等宽、左边缘对齐标题、上下留白均匀 |
| 数据可读 | 图表一眼看出趋势或对比；数字有单位 |
| 节奏 | 翻 5 页不会觉得每页都一样 |

修改最差的 3 处，重新生成、重新看，直到全部 ≥ 8。
