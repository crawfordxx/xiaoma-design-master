# 文章封面（gen-cover）

一张让读者停下来的封面。三个创意方向，平台规格锁死，标题位永远留着。

## Onboarding

> ✅ **封面生产线已就绪！**
> 贴文章（或标题+一段摘要），说明发哪个平台。
> 我会出三个创意方向（直接冲击/氛围/信息可视化），选一个后 draft→final。

## Usage

- 贴文章全文 + "做封面"
- 给标题 + "小红书封面"（3:4）
- "氛围感的，别太直白" —— 指定方向倾向

## Pipeline

下文 `S=<本技能目录>`（直接用安装路径，不必解 symlink）；`$S/toolkit/gen` 是生成能力的唯一入口。

**Step 1 文章分析**：提炼核心概念（一句话）、情绪基调（理性/温暖/锐利/史诗）、目标读者。封面 = 概念的视觉隐喻 + 情绪的色调。

**Step 2 平台规格锁定**：
- 公众号：2.35:1（1280×544），**中心 1:1 安全区**会被裁成缩略图——关键元素居中，标题叠加位留左或留中
- 小红书：3:4（1080×1440），大字标题卡思路（背景生图+排版叠字）
- 通用/社媒：16:9

**Step 3 三创意方向**：按 [`shared/visual-prompts.md`](shared/visual-prompts.md) 的 A/B/C 模板各出一稿提示词：
- **A 直接冲击**：核心概念的视觉隐喻（适合数据/方法/干货）
- **B 氛围**：情绪场景+电影光（适合故事/观点/情感）
- **C 信息可视化**：数据/结构的图形化（适合对比/清单/趋势）

三个方向的提示词都给用户看，说明各自适合的读者心理。

**Step 4 draft 三方向**：
```bash
$S/toolkit/gen image --prompt "<方向A>" --ratio 2.35:1 --tier draft
# B、C 同理（如需视觉对比）
```

**Step 5 选定+迭代**：选定方向后一次一变量微调。检查：缩略图尺寸下还看得清主体吗？标题叠加位干净吗？

**Step 6 final + 交付**：
```bash
$S/toolkit/gen image --prompt "<锁定提示词>" --ratio 2.35:1 --tier final --out workspace/projects/<slug>/images/cover.png
```
交付：封面图 + 三个方向的提示词存档（下次同系列可复用）+ 结果链接区。

## 执行模式

auto：三方向 draft 出齐后停一次等选择（这是必停点）。interactive：Step 3 提示词先过目。

## 弹性规则

生成失败 → 三方向提示词包交付（排版工具可直接用）。系列文章 → 复用已选定方向，只换概念隐喻，保持视觉系统一致。

## Gotchas

- **缩略图失明**：2.35:1 的图在信息流里是 1:1 小方块——主体必须中心可辨
- **标题位被占**：生图主体怼满全图 = 排版没地方放标题，留白是功能不是浪费
- **方向跟风**：干货文硬凹氛围感封面 = 点击率和内容错配，跟着内容类型走
- **系列不锁风格**：同系列封面换风格 = 读者认不出你，四件套锁死
