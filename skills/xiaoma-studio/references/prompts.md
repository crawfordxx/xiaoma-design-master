# 可直接抄的 prompt

这些 prompt 可以给用户，也可以交给子 agent。全部默认已经加载本 skill，也就是说流程、规矩、渲染合约不用在 prompt 里重复，prompt 只写「拍什么」。

## 一句话类（让模型自由发挥，适合高 effort）

样本里最火的几条都是一句话起手。一句话 prompt 好用，靠的是这三点：
1. **借一个体裁**，它自带规则：showreel、Apple 发布会、纪录片、官方 MV、儿童绘本。
2. **给主角一个身份**，让模型去「展示」而不是「解释」：「你是一个很厉害的 motion designer」。
3. **短到一次能做完**：15–30 秒。

```
做一条 15 秒的动效视频，展示你是多厉害的 motion designer，就像简历里的 showreel。全力以赴。
```
```
用博物馆纪录片的风格，做一条 60 秒的《XX 的形状》：从人类第一次遇到这个问题讲到今天，每个年代一个会动的实验，纯音乐 + 双语字幕。
```
```
给这首歌做一支官方 MV，只用动效图形，2D、3D 或两者都行；我在乎的是有创意、独一无二。从头做到尾，中途不要停下来问我。
```
（最后这条来自 Devarf 的 effort 对比实验：同一句话，low 档出 2D，medium 到 max 档出 3D，耗时从 42 分钟到 3 小时不等。）

## 导演分镜类（要精确控制时用）

结构照抄 Andy Lo 的《霍金辐射》纸偶剧场 prompt，分 5 段：

```
STYLE（每个镜头都适用）：
手工纸片拼贴动画，儿童绘本风。每个元素都像从带纹理的纸上剪下来，用干水粉和蜡笔上色：看得见笔刷痕、纸纤维，边缘略不规则，外加一圈细白纸边。扁平 2D 分层，轻微视差；轻微定格抖动（每隔几帧形状轻轻晃一下）；柔和的纸片投影。色板：芥末黄、珊瑚粉、青绿、奶油、牛皮纸米色，太空场景用深海军蓝和紫。整片框在一个小纸偶剧场里：两侧是珊瑚粉纸幕，四周牛皮纸边框，底部木质舞台地板。

MAIN CHARACTER：
一个好奇的小女孩，黑色波波头，黄色发夹，简单的点状眼睛，小小的「o」形嘴，粉色圆脸蛋，青绿色毛衣配白领子。她拿着一支蓝色蜡笔，担任旁白和向导，嘴型和旁白同步。

TRANSITIONS：
所有转场都无缝衔接：一个连续的镜头运动，没有硬切。用匹配剪辑和纸的形变：形状折叠、展开、滑动、重塑成下一个场景；镜头穿过纸层滑行；舞台背景像卷轴一样卷起，露出下一张画好的背景。一直保持轻微的运动，永远不停顿、不闪切。

SCENES：
SCENE 1（0:00–0:10）想法。画面：…… 旁白：「……」 TRANSITION：镜头推进纸做的太阳，太阳的橙色光芒向内卷曲……
SCENE 2（0:10–0:22）……
……

SOUND & TECH：
旁白：温暖、好奇的年轻女声，绘本式的语速，留出小停顿让人惊叹。友好、略带俏皮，不赶。
配乐：轻柔奇幻的原声，钢片琴、钟琴、拨弦、毛毡钢琴，偶尔加八音盒。
音效：每次移动和转场都有纸张的沙沙声和褶皱声，线条自己画出来时配蜡笔涂画声……
技术：16:9，24fps，定格动画质感，总长 1:40；画面上不放文字，除了第 1 场可选的手写蜡笔标题。
```

## 发布片类（品牌 / 产品）

结构照抄 twoclipping 的发布片 prompt（14 万播放，零外部工具）：

```
<inputs>
先问我要：一个单词的品牌名（动词最好）、9–12 张高清产品图或截图、一首 120 BPM 左右、有 drop 和安静 breakdown 的免版税音乐。
</inputs>

<direction>
Apple 发布会风格的发布片，只用 2D，一镜到底。每个场景都由上一个场景变出来：不淡化、不模糊、不硬切。用物体变形代替：文字从遮罩线升起，图标弹簧弹出，进度条画过去，页面推入，一个黑色形状泛洪铺满全屏，再收缩成下一个场景。暖白画布、黑色 UI、照片上覆液态玻璃。一个光标驱动每一次变化，都是真实的点击、拖拽、长按。镜头像 Screen Studio 一样跟着缩放，让每个瞬间都占满画面。
禁止：交叉淡化、模糊入场、亮度显影、3D 翻转、粒子、发光、超过 1 秒的停顿、任何看起来像模板的东西。
</direction>

<structure>
120 BPM，54 拍，每一拍都有事发生。
开场：……  功能 1：……  功能 2：……  收尾：回到字标，最后一帧 = 第一帧。
</structure>

<start>
先问我要素材，然后给我看拍点表和 4 张关键帧，再写整片。
</start>
```

## 知识讲解类（本 skill 的标准输入）

```
主题：沉没成本
时长：45–60 秒，16:9
受众：普通人，不需要经济学基础
形态：纯音乐 + 中英双语字幕，不要旁白
风格：自选一个最合适的原型
要求：开头 2 秒用一个具体物件当钩子；用一个生活场景（电影票 / 排队 / 学了一半的课）讲清楚；中间要有一个会动的「证据」（图表或天平）；结尾回到开场那个物件，给出一句可以带走的结论。
交付：mp4 + 同主题的 HTML 幻灯片（可演讲、可导出 PDF）。
```

## 给子 agent 的派活模板

```
读 <skill>/SKILL.md，严格按工作流 1–7 做。
主题：___  时长：___  画幅：___  声音：___
交付到 ___/：STORYBOARD.md、index.html、cues.json、out/video.mp4、out/sheet.jpg（最后一轮拼图）。
完成后报告：选了哪个原型、为什么；拼图自检每轮的 6 项分数；qa.py 的输出。
```

## prompt-motion.com 热门榜的规律（2026-10 抓取前 16 名）

[prompt-motion.com](https://prompt-motion.com/) 收录了数百条 Opus 5.5 动效视频及其 prompt / skill，分类数量本身就是热度信号：Product UI 100、Kinetic type 97、Music 50、Shapes 44、Particles 43、Charts 33、Diagrams 31、Characters 27。

- **前 16 名里有 7 条是同一句话**：「15 秒 showreel，go all out」。品牌变体同样排得很靠前：
  ```
  先研究 <品牌/产品>。做一条 40 秒的动效视频，展示你是多厉害的 motion designer，像你的 showreel 一样，主题是 <品牌>。风格和它的落地页一致。全力以赴。
  ```
- **结构化长 prompt 的固定五段**：`<inputs>`（先问要什么素材，给出缺省值）→ `<direction>`（体裁、色板角色、字体、镜头语言 + Banned 清单）→ `<structure>`（BPM × 小节，逐拍写事件）→ `<build>`（seek(t) 合约、闭式弹簧、音频测拍、子帧运动模糊、先逐拍出静帧）→ `<start>`（先给拍点表和关键帧再写整片）。
- **一个形状贯穿所有状态**（twoclipping UI 形变）：按钮 → 加载 → 对勾 → 灵动岛 → 播放器 → 进度条 → 音量 → 开关 → tab 指示器 → 图表 → ⌘K → toast → 回到按钮。指示器两条边用不同的弹簧，前沿跑在后沿前面，有拉伸感。
- **概念 × 风格切换**（Ethan Mollick）：
  ```
  做一个解释「递归」的视频，每一段解释都换一种截然不同的视频风格，让它自我指涉、聪明、节奏快。
  ```
- **参考视频驱动**（LexnLin）：附一段 5 秒参考，要求研究它的流畅度、节奏、镜头时长、字体和元素，借鉴技法但整体重新设计，「看起来像是你凭自己的品味做的」。
- **常见附加约束**：「no beige artsy look, no eyebrow labels」（不要米色文艺风、不要眉标小字）、「屏幕文字不带句号」、「Feel free to work 10+ hours」（给足时长预算）。
