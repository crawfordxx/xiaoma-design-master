# 网页：官网、落地页、展厅大屏

规则来自一个真实上线的官网（三个业务场景页 + 分屏入口，同时跑在展会大屏上），经过五轮领导和品牌方的修改意见、一轮 9 条走查反馈。视频的规矩大多仍然成立（一底一字一强调、首尾呼应、一次只让人读一件事），这里只写网页特有的部分。

起步：`node engine/init.mjs <目录> web`，复制 `templates/web/`（Vite + GSAP + Lenis）。

**和视频最大的区别**：网页是实时的，不是 `f(t)`。访客想停多久就停多久，想跳到哪就跳到哪。所以网页不靠「节奏」留住人，靠的是**每一屏都在演示，而不是在描述**。

## 1. 信息结构：先演示，再讲道理

一个场景页的骨架，顺序按访客的疑问排：

| 版块 | 回答访客哪个问题 | 写法 |
|---|---|---|
| ① 首屏 | 这是什么、给谁用 | 场景主视觉（图或 5–15 秒循环视频）+ 四字口号两行 + 一句「它替你做哪几件事」+ 两个按钮：主按钮「一键试一下」跳到演示，次按钮「它还能做什么」 |
| ② 痛点 | 跟我有什么关系 | 「过去 / 现在」对照：三张卡，上面一行划掉的旧做法（具体到人和时间），下面一行新做法（写结果，不写功能名） |
| ③ 核心演示 | 它真的能做吗 | 访客自己选条件 → 数字员工一步步做（思考 → 调工具 → 自查）→ 出一个能拿走的产物（手册、方案、视频）。这一节是整页的重心，花一半的工夫在这 |
| ④ 能力格 | 还能做什么 | 便当格（bento）：大小格交错，一格一个能力，一张图 + 一句话结果 |
| ⑤ 工作流 | 落到我手上怎么用 | 3–6 步，**全部一屏排开**，每步一张图 + 动词标题 + 一句话 |
| ⑥ 收尾 | 下一步做什么 | 深色底，回到首屏那句口号（首尾呼应），预约 + 下载两个按钮 |

- 多个业务场景时，加一个**分屏入口页**：三扇门并排，悬停的那扇变宽（`flex 1 → 1.5`，1.2 秒 ease-out），其余收窄，门里是各自的循环视频。场景顺序一旦定了，入口、每页的切换器、页脚互链、演示模式轮播、SEO 标题**全部同步**，漏一处就会被指出来。
- 版块角标写成「01」小圆圈 + 衬线大标题 + 一行灰色副标题。导航只放页内锚点，最多 6 个。
- 演示里用的数据一律是示例，页脚写「演示内容为示意」；涉及事实（营业时间、票价）查不到就标「待核」，不编。演示边界写在按钮下面一行小字里，并告诉访客真实使用去哪（下载、登录、预约）。

## 2. 视觉：一底一字一强调，层级靠透明度

`templates/web/css/base.css` 有三套主题，换 `<body>` 的类就行。每套只有十来个变量：

| 主题 | 适合 | 底 / 字 / 强调 | 标题字体 |
|---|---|---|---|
| `t-paper` 纸墨编辑 | 文化、文旅、品牌故事 | 暖纸 `#f2ede3` / 墨 `#16130f` / 朱砂 `#b23a27` | 中文衬线 900（宋体感） |
| `t-signal` 深空信号 | 科技、出海、数据 | 冷近黑 `#05070c` / 白 `#eef1f7` / 一个高亮橙 `#ff7a3d` 只给 CTA | 黑体 |
| `t-light` 亮色编辑 | B2B 平台、服务 | 纸白 `#f4f2ed` / 墨 `#1d1c19` / 低饱和鼠尾草绿，只用在小标记 | 中文衬线 |

- **文字层级靠透明度**：正文 `.68`、次要 `.46`、分隔线 `.1–.14`。不要为了区分层级换颜色。
- **强调靠字体，不靠颜色**：衬线 vs 黑体、粗细对比、意大利斜体拉丁副标题（`Cormorant Garamond`）。全大写英文小字 + `letter-spacing .2em+` 是最便宜的高级感。
- 一页一个强调色，面积小：当前选中、主按钮、角标圆圈、划掉旧做法的删除线。场景页之间可以换主题，同一页里不换。
- 圆角：按钮胶囊，小卡 `.5rem`，大图卡最多 `1.2rem`。投影只用很淡的长投影，不用发光。
- 质感：全局胶片颗粒 `.grain`（亮底 `.03`、暗底 `.05–.07`）。图片和视频统一降饱和（`saturate(.75–.85)`），悬停或选中时回到 1。
- **点缀只放在「此刻该点的那一个」**：流光描边（BorderBeam 式 `.beam`）只给主 CTA 和正在工作的数字员工面板，演示跑完就摘掉。全局常亮的点缀会变成噪音。

**一眼「AI 模板味」的东西，不要用**（被点名过）：渐变填充的文字、霓虹青绿 / 琥珀发光阴影、脉冲光点、遮罩网格背景、毛玻璃卡片堆叠、彩色左边框卡片、彩色半透明底的标签气泡、大圆角（1.2rem 以上的小卡）、通篇中文 900 粗黑、圆圈里写一个首字当头像、页面角落写「画面由 AI 生成」。

## 3. 排版与适配

- 根字号按 1920×1080 设计，跟着视口宽、高中**较小**的一边缩放：`html { font-size: clamp(11px, min(.8333vw, 1.55vh), 40px) }`。矮屏不挤压，4K 大屏等比放大不留白；≤900px 固定 14px，改单列。
- 标题字号写 rem，不写 vw，否则手机上会失控。手机上标题降到 2–2.6rem。
- 中文 web font 自托管时用 Google Fonts 的 unicode-range 分片。只打包用到的字重（常见 400/500/700/900），写 600 会被渲染成 700。**每次换字体都跑 `python3 engine/fontcheck.py <fonts.css> --chars <页面上的字>`**：分片缺一个文件，或者某一片是被冻结成单一字重的静态字，表现就是一句话里个别字突然变粗（这个真实发生过：「跨」「山」两个字在两个页面上变成了 Black）。
- 验收宽度：390（手机）、1024、1280、1440、1920，展厅再加 3840。导航加了项以后最容易在 1024 溢出。

## 4. 动效：三层，别混

| 层 | 什么时候播 | 写法 |
|---|---|---|
| 入场 | 页面加载完，只播一次 | 口号逐字从遮罩下升起（`yPercent: 110 → 0`，每字间隔 .035 秒，`power4.out`），其余元素依次上浮淡入。可选一个加载页，加载页的标记只用口号或品牌正式标识 |
| 滚动触发 | 版块进入视口 15%，只播一次 | 标题拆字升起、卡片依次上浮（`y: 60`，间隔 .08 秒）。`once: true`，不跟着滚动来回倒放 |
| 交互 | 用户点了才动 | 选项切换、演示开跑、悬停放大。所有演示的等待都经 `Run`（可取消），用户换条件时整条链立刻停 |

- 平滑滚动用 Lenis（`lerp .085`），ScrollTrigger 跟着它更新；所有「滚到某处」走 `scrollToEl`，演示脚本才能 `await`。
- 缓动只用两条：`cubic-bezier(.16,1,.3,1)`（出）和 `cubic-bezier(.76,0,.24,1)`（进出）。磁吸按钮用弹性（`elastic.out(1,.4)`），除此之外 UI 不弹跳。
- 图片的标准动作：默认 `scale(1.06)` + 降饱和；悬停 / 选中时 1.2 秒回到 `scale(1)` 并恢复饱和。展开型卡片（入口三扇门、目的地卡）用 `flex` 增长 1 秒。
- 自定义光标：小圆点即时跟随，外圈带阻尼，`mix-blend-mode: difference`；悬停到 `data-cursor="开始"` 的元素外圈放大并显示两个字。只在精确指针设备上启用。
- 导航：下滚收起、上滚出现；压到 `data-theme="dark"` 的版块时反白（logo 换反白版）。
- 3D（three.js）只放在一处、有意义的地方：首屏的墨晕着色器、一个可拖动的场景沙盘、点阵地球。不自动旋转（被否过：「别转」），不做全站粒子背景。
- 一律尊重 `prefers-reduced-motion`：关掉平滑滚动、颗粒动画、拆字入场。

**演示台的写法**（整页最值钱的部分）：
1. 左边选条件（胶囊单选），右边是数字员工面板：名字 + 状态（待命 / 工作中 / 完成）+ 计时器。
2. 每一步写成「动词 + 对象 + 结论」，结论带一个具体数字或名字（「查资料：找到 12 条，3 条标待核」）。逐字打出，打完打勾。
3. 最后出产物：能翻的手册、能播的视频、能导出的 PDF（浏览器打印 A4 满版即可）。产物下面放「换个条件再来」。
4. 演示的规则要经得起较真：条件之间的约束（天数、人群、距离）写成数据规则并用脚本把所有组合跑一遍，不能靠演示时运气好。

**展厅自动演示**：`?autoplay=1` 打开才启用（记在会话里，普通访客永远不会被自动滚动）。无人操作 45 秒后按页面脚本自动滚动、自动点演示、跑完切到下一个场景页，循环；任何触摸、点击、按键、滚轮立即交还控制，底部有「自动演示中」提示条。导航上可以再放一个「演示模式」按钮，给讲解员用。

## 5. 品牌与对外信息

- **logo 只用品牌方的正式文件**：浅底用彩色版，深底用反白版，就这两种。不要自己改色、描边、做「深色适配版」，也不要拿公司名做一个假印章当装饰——三个页面三种 logo 配色、首屏一个用公司简称做的印章，都被品牌方在走查里点了名。拿到的是 .ai 源文件时，它其实是 PDF：`pdftocairo -svg` 把每页转成 SVG，再用 `python3 engine/split-logo.py 页.svg 输出.svg x y 宽 高` 按 logo 的矩形裁成独立文件（只留矩形内的图形和用到的渐变 / 裁剪路径，自动去掉整块底色）。矩形坐标先用 `pdftocairo -png -r 72` 出图量出来（72 dpi 下 1px = 1pt）。
- 公司全称、电话、地址、备案号从正式资料复制，不凭记忆写（公司全称多写了一个字，被指出过）。
- 对外的物料里不出现地图、行政区轮廓、线路示意图（在国内需要送审）。需要表达「流向」「分布」时改成流向图谱、名单、按天分栏的看板。
- 第三方平台的图标用 simple-icons（CC0）；不用其他软件的商标做界面外观。

## 6. 反馈过的坑（照着查一遍）

| 现象 | 原因 | 做法 |
|---|---|---|
| 「工作流第四步只能看到一部分」 | 用了滚动钉住的横向轨道，首屏只露出三张半，访客以为是被截断了 | 步骤全部一屏排开（≤1280 三列）；手机用原生横滑 + `scroll-snap`，并露出下一张的边 |
| 「找不到登录按钮」 | 展示页只有预约，没有通往真正使用的入口 | 每个场景页导航都放「下载客户端 / 登录」；演示里提示「真实使用请下载」 |
| 「换个方案后不知道在哪输入自己的目的地」 | 演示只有预置选项，没说明边界 | 在选项下面写清：演示只带这几个，想要别的去哪里做 |
| 「提交预约后回不到首页」 | 成功态只有一行字 | 成功态给「返回首页」，从哪个场景页来的再给「回到 XX」 |
| 「下载页第三张卡在首屏外」 | 网格写死两列，首屏留白太多 | 三张卡宽屏一行；首屏上下留白收紧 |
| 个别字变粗 | 字体分片里混进了静态 Black | `fontcheck.py` |
| 视频播完画面卡住 | 素材不循环 | 首尾交叉淡化做成无缝循环；或者三段叠化 |
| 深色底上黑字看不清 | 字色跟着全局走了 | 深色版块整体重设 `--fg-2 / --mute / --line` |

## 7. 验收

```bash
python3 engine/fontcheck.py site/public/fonts/fonts.css --chars 页面上所有标题文字
node engine/webcheck.mjs http://localhost:5173/ --widths 390,1024,1280,1440,1920
```

`webcheck` 每个宽度、每个版块截一张图，生成 `report.html`，同时不看图也能查：横向溢出、导航溢出、文字出界、请求失败（字体 / 图片 404）、坏图、控制台报错。全绿之后，**能读图就逐张看**，按下面 6 项各打 1–10 分，每项 ≥ 8 才交付：

1. 首屏 3 秒内能说出「这是什么、给谁用」
2. 每一屏都有一个在演示的东西，而不是一段介绍
3. 一底一字一强调，没有上面清单里的 AI 模板味
4. 品牌信息（logo、公司名）和正式资料一致
5. 手机上能读、能点，没有被截断的内容
6. 演示经得起较真：换任何条件都对，失败有出口
