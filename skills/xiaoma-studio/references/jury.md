# 独立评审：另开一个评委，再按评委意见改

自己做的片子自己评，分数一定偏高：制作者知道每个镜头想表达什么，观众不知道。所以拼图自检过了之后，再派一个**不带制作上下文**的评委打分，按它的意见改，最多改 3 轮。

实测数据：22 支 10 秒风格片，独立评委第一轮平均 6.95 分，按意见改两轮后 7.81 分（最终单片 7.57–8.21）。这个水平大约是「业余顶级、准商业作品的边缘」，和人看下来的感受一致。所以第一轮 6 到 7 分是正常的，不要因为分低就怀疑评委。

## 怎么派评委

- **独立**：新开一个子 agent 或新会话，不继承制作过程的对话。只给它三样东西：成片路径、风格卡或分镜里的风格和规格段落、下面的评审提示词。不要给它 STORYBOARD.md 的读点说明，评委就该像观众一样第一次看。
- **能看图的模型当评委**。看不了图的模型不能当评委，只能跑 `qa.py` 和 `lint.mjs`，并在报告里写明「未经独立目视评审」。
- **过线**：7 个维度每项 ≥ 7.5，且没有致命问题。到了 3 轮还没过，停下来把评审表和剩下的问题交给用户决定，不要无限循环。

## 第一步：评审提示词（发给评委）

```text
你是一名资深动态设计评委，标准对标 Motionographer 编辑、Buck / ManvsMachine 创意总监；中文风格（综艺花字、贴纸人科普等）对标抖音 / B 站头部设计账号。这支片子不是你做的。请严格、具体地评，目标是让它达到获奖入围 / 高端商用水准。客气没有用，具体才有用。

成片：<video.mp4 路径>
风格与规格：<贴风格卡的「视觉特征」「关键技法」和输出规格；没有风格卡就贴分镜里的风格、画幅、时长>

1. 认真看片：每 0.5 秒抽一帧拼成大图；在最快的动作和高潮附近抽连续帧；再取 5–8 个关键时刻的原尺寸帧，放大看边缘、字距、锯齿、色带、纹理、出画裁切。
2. 查规格：时长是否精确、分辨率和帧率是否符合、有没有音轨、响度约 −14 LUFS（±1）、真峰值 ≤ −1 dBTP、有没有非预期的黑帧和静止段、画面的重拍是否对上音频起音。
3. 按 7 个维度各打 1–10 分。刻度：5 = 合格的学生作业，6 = 像样的模板 / 剪映水平，7 = 扎实的专业水准，8 = 高端广告公司，9 = 获奖入围，10 = 世界顶级。多数第一版应在 5–7 分，不要抬分。
   - 风格还原：内行一眼认得出是这种风格；每个标志特征和技法都在，而且做对了
   - 创意与惊艳：有一个清楚的想法；0.5 秒内有钩子；有一个让人记住的高潮；结尾画面让人满足
   - 动效手艺：缓动、间距、重叠、预备与跟随、弧线、转场、运动模糊；没有死板或抖动的运动
   - 设计与排版：构图、层级、网格、字体排印（含中文）、配色、留白
   - 质感与完成度：光、纹理、颗粒、辉光和细节符合风格；没有色带、锯齿和瑕疵
   - 声音与同步：音乐性、曲风是否对、音效设计、声画同步、混音与母带
   - 技术：规格达标、字体加载正确、没有闪烁、裁切和跳帧
4. 按对整体观感的影响从大到小，给 5–10 条修改。每条写：时间码、看得见的问题、为什么要紧、具体怎么改（技法加数值：缓动曲线、帧数、像素、色值、字体、版式调整）。宁可几条大改，不要一堆小毛病。至少一条要提升惊艳度，而不只是打磨。
5. 单独列出致命问题：任何看起来通用、像 AI 模板的地方；不自然的中文文案；字体回退或豆腐块；任何规格不达标。

返回：评分表、致命问题、修改清单。
```

## 第二步：修改提示词（贴回制作的会话）

```text
一位独立评委看了你的片子，下面是完整评审：
<贴评审结果>

把片子提到获奖水准（每项目标 ≥ 9）：
- 先把当前的视频和源码另存为第 N 版。
- 落实每一条致命问题和每一条高影响修改。如果你有把握某条有更好的解法，可以替换，但要说明理由。看到更大的提升空间就超出清单去做，尤其是惊艳度。评委列为优点的地方不许改坏。
- 全分辨率重新渲染，重跑规格检查，看帧，直到修改真的落地。
- 报告哪些改了、哪些没改，以及原因。
```

## 记录

每轮的 7 项分数、致命问题和改动写进 STORYBOARD.md 末尾的修改记录，和拼图自检的记录放在一起。交付时报告最后一轮评委分，不报自评分。
