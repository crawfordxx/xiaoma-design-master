# 分镜与节奏

## 为什么先写分镜

prompt 只决定 10%，剩下 90% 靠工作流（Lukas Margerie，53 万播放教程）。高赞作品的作者都是先拿到分镜或拍点表、看过几张关键帧，才让模型写整片。twoclipping 的 prompt 最后一句是：「先问我要素材，然后给我看拍点表和 4 张关键帧，再写整片。」

## STORYBOARD.md 格式

模板在 `templates/STORYBOARD.md`。

```
Logline：一句话。主角/主题 想要 ___，但是 ___，所以 ___。
原型：theme-xxx    画幅：1920×1080    时长：24s    BPM：80
钩子（0–2s）：哪个物件在动？
母题：贯穿全片、最后会回来的那个东西（一枚金币 / 一个红点 / 一句问话）
色彩弧线：开头什么色调，结尾什么色调（冷夜 → 暖晨）

镜头：
  A  0.0–5.6   [入：物件落下]  看到什么 · 发生的事件 · 镜头运动
     读点  0.0–1.0  金币落地（观众的眼睛在画面中央）
           1.0–1.8  一分为二
           2.4–5.6  标题 + 第一句字幕
  B  5.6–20.4  [转：标题模糊退场，坐标轴描出]  ...
  ...
  [出：回到开场标题卡，副标题换成答案]

声音：纯音乐 / 歌曲 / 旁白；音效清单（时刻 + 类型）
修改记录：每轮拼图自检的分数和改动
```

## 读点（reads）：最容易做错的地方

观众只看一遍，而且是全速看第一次。模型自己写的代码，自己当然知道发生了什么；观众不知道。（这条来自 ClaudeAnimationBase 的动画指南，作者说这是模型最常犯的错。）

- 每个镜头列出观众必须依次看懂的东西，每一条就是一个「读点」，写上开始和结束时间。
- 一个读点需要的时间 = 眼睛找到它 + 看懂它 + 停一下。小的、远的、快的、微妙的东西更耗时间。
- 一次只给一个读点。两件事同时发生，观众只会看到一件。因和果要错开，不要叠在一起。
- 快动作，慢意义：动作本身可以很快（先给预备动作，让眼睛知道往哪看），但它的意思要留够停顿。
- 引导视线：重要读点出现前，先让它动一下、亮一下，或者让角色看向它，然后给眼睛留时间过去。
- 镜头长度由读点决定。最后一个读点之后，至少再留 0.8 秒才结束。

## 节奏数字（来自样本）

| 类型 | 时长 | 新事件间隔 | 硬切 / 分钟 |
|---|---|---|---|
| 15 秒 showreel | 12–15s | 每 1–2 拍（0.5–1s） | 0–20，全部落拍 |
| 知识短片（纪录片 / 数据） | 60–130s | 2–4s | 0 |
| 发布片 | 15–60s | 每拍都有事 | 0（一镜到底） |
| 歌词 MV | 跟歌走 | 每句歌词一个画面 | 3–30 |
| 角色短片 | 15–30s | 每个镜头一个事件 | 0–6，只在动作中切 |

## 叙事结构（选一个）

**A. 编年纪录片**（运气的形状 / 复利的形状 / Can Machines Think?）
物件钩子 → 标题卡 → 年代 1 的实验 → 年代 2 → … → 「此刻 · 你」（2026）→ 回到标题卡，副标题换成答案 → 参考文献。每个年代一种视觉手法，但配色和字体不变。bridgemindai 那条更进一步：每个年代用那个年代的视觉语言（1943 打字机、1973 雪花、1997 绿色终端、2012 粒子），年份大数字始终放在左下角。

**B. 反常识数据**（新鲜感的魔咒）
具体场景（358 天没联系的老朋友）→ 抛出问题 → 常见解释 → 亮底翻转「这只说对了一半」→ 数据（点阵 73% vs 28%）→ 隐喻（两杯水的水位）→ 新的结论。

**C. 闯关**（生物必修一）
「检测到新玩家」→ 通关条件 3 个 → 任务一 / 二 / 三，知识点 = 碎片 / 装备 / Boss → 判定规则 → 通关。适合有人声旁白的教育内容。

**D. 15 秒 showreel**（ajith_io，一句 prompt）
单点（0.5s）→ 分裂 → 泛洪进第一种颜色 + 大字 → 每 2–4 拍换一种技法 → 字标 + 一个点（呼应开场）。prompt 要点：「showreel for a résumé」设定了一个有既定规则的体裁；「你是多厉害的 motion designer」让模型展示技法，而不是讲产品；15 秒足够一次跑完，又能塞下 6–8 个镜头；「go all out」相当于再加一档 effort。

**E. 发布片一镜到底**（twoclipping）
字标挤压进句号 → 句号长成黑色胶囊 → 光圈开合切到照片 → 网格展开 → 点击放大落在 drop 上 → 功能 1 / 2 / 3 依次由上一个形状变形而来 → 回到字标，最后一帧 = 第一帧。所有变化都由光标真实点击驱动。

**F. 歌词 MV**（Simulation's Ending / 我不难过 / 每天每天）
先分析歌（BPM、段落、哪里安静哪里炸、歌在讲什么），每句歌词配一个视觉隐喻，副歌回到同一个场景并加强，安静段（breakdown）给最空的画面。慢歌：一个角色、一个世界、色彩随情绪走（雨夜冷蓝 → 回忆暖黄 → 雨停彩虹）。

**G. 角色科普**（Hawking 辐射纸偶剧场，Andy Lo）
固定一个讲解员角色和一个舞台（纸偶剧场的幕布），7 个场景，每个场景写清楚：时间段、画面、旁白台词、进入下一场景的转场。转场全部用纸的形变（太阳光芒卷进黑洞、彩纸屑变成粒子、背景像卷轴一样卷起）。

## 自查清单

- [ ] 0–2 秒有物件在动，不是标题淡入
- [ ] 每个镜头都有一个「事件」：首帧到末帧之间有东西变了
- [ ] 每个读点都有时间被找到、被看懂；没有两个重要读点重叠
- [ ] 每 2–4 秒有新东西（`qa.py` 静止段 = 0）
- [ ] 每一处接缝都有转场；硬切只出现在拍点或动作中途
- [ ] 结尾呼应开头
- [ ] 全片只用一个原型的色彩和字体
- [ ] 字幕在手机上读得清（≥ 40px，≤ 18 字 / 行）
