# 审美规则

## 选型表：题材 → 原型

一条片只用一个原型。想混搭，就「一个原型为主，另一个只出现在一个镜头里」（例：纪录片里插一个数据图镜头，配色仍然沿用纪录片的）。

## 通用规则

**色彩**
- 一底 + 一前景 + 一强调色。强调色只给「这一秒最重要的东西」：当前数字、关键词、主角。整片强调色面积不超过画面的 10%（瑞士风 reel 整屏换色除外）。
- 暗底不用纯黑 `#000`，用带色相的近黑：暖黑 `#0b0a08`、冷黑 `#0a0a0a`、紫黑 `#0b080b`。亮底不用纯白，用纸色 `#f2f2ef`、`#ece4d4`、`#f4f2ee`。
- 第二强调色只用于「对立面」：对手、错误、警告（纪录片里的红 `#b0412e`）。
- 亮暗翻转是一种节奏工具：在章节转折时整段换成亮底（《新鲜感的魔咒》在「这只说对了一半」那一刻翻成白底）。

**字体**
- 标题 1 个 + 正文 / UI 1 个，可再加 1 个等宽体放元信息（时间码、编号、坐标）。
- 中文标题：衬线（宋 / 明）营造纪录片和文学感，黑体营造信息和科技感。英文副标题 / 引文用意大利斜体衬线（Cormorant / Garamond）。
- 小字一律加字距（`letter-spacing: .2em–.45em`），全大写英文小字是「高级感」最便宜的来源。
- 数字用等宽数字（`font-variant-numeric: tabular-nums`），滚动时不会抖。

**版式**
- 左上：时间 / 章节 / 年代（大号数字 + 小字地点）。右上：出处 / 引注（斜体拉丁文 + 中文书名 + 一个红色小印章）。底部居中：字幕。右下角：极淡的署名水印。这是纪录片原型的固定骨架，其他原型也可以借用「四角放元信息、中间放证据」的思路。
- 正中央永远是「证据」：会动的图、物件、数据，而不是一段文字。
- 安全边距：16:9 左右 ≥ 96px、上下 ≥ 70px；9:16 上下各留 ≥ 220px 给平台 UI。

**手机可读性（按 1080p 画布）**
- 字幕 ≥ 40px；正文 ≥ 30px；元信息 ≥ 16px（只放可以读不清的东西）。
- 一屏中文不超过 2 行字幕加 1 个标题；一行字幕 ≤ 18 个汉字。
- 细线（1px）只用于装饰性网格；承载信息的线 ≥ 2px。

**质感**
- 胶片颗粒：`.grain`，暗底用 0.06–0.1，亮底用 0.03–0.05。暗角：`.vignette`，纪录片 / 电影用 0.5–0.7。
- 光：只给主角发光（金币、曲线头、粒子核心），UI 和文字不发光。
- 一切都在动：镜头 1%–3% 的缓推，背景粒子 / 网格缓慢漂移，手绘线条每秒抖 12 次（boil）。

## 10 个原型的配方

token 定义在 `engine/themes.css`，`<div id="stage" class="theme-xxx">` 即可启用。

### 1 博物馆纪录片 `theme-museum`
样本：《运气的形状》60 万赞、《Opus 家族史》17 万赞。
- 暖黑底，金色强调，红色只给对立面；衬线中文 + 斜体拉丁文。
- 结构：按年代推进。左上年份大数字滚动（1494 → 1620 → 1654 → 2026），右上文献引注，正中放「当年的那个实验」（骰子、帕斯卡三角、高尔顿板、布丰投针），底部双语字幕。
- 片头片尾用同一张标题卡：拉丁文小标题 + 金色渐变大标题 + 一条手绘曲线 + 一行副标题。片尾加参考文献列表。
- 实现：canvas 画证据，DOM 放文字；参见 `examples/museum-compound`。

### 2 编辑部数据叙事 `theme-editorial`
样本：《新鲜感的魔咒》41 万赞。
- 黑白灰加一个蓝，正文左对齐，在画面左 1/3 一句一句出现。
- 证据：点阵（73% vs 28%）、水杯水位、聊天气泡流、柱状 / 折线。关键词在句子里用强调色。
- 节奏：先抛反常识问题，再给常见解释，然后亮底翻转（「这只说对了一半」），最后给新的解释。

### 3 宇宙电影感 `theme-cosmic`
样本：Immanuelle 9.7 万赞。
- 纯黑加 2.39:1 遮幅，粒子星系、黑洞透镜，发丝线标注（细线 + 小字坐标），超宽字距英文（`A N D  T I M E`）。
- 数字是主角：光年、时间膨胀系数实时滚动。
- 片尾用亮底标题卡反打一下（白底 + 红色星标），再回到黑底署名。

### 4 瑞士风 motion reel `theme-swiss`
样本：ajith_io 64 万播放（一句 prompt 生成）。
- 整屏原色按拍切换：黑、红、奶白、蓝、黄。粗黑体大字、发丝线 HUD 取景框（四角 + 顶部元信息 + 底部时间码 + BAR x/8 · BPM）。
- 每 2–4 拍换一种「技法」：点、形变、点阵波、粒子球、线框、跑马灯文字、环形文字。最后落到衬线字标加一个红点。
- 运动模糊（`--subframes 2–4`）是这种风格的灵魂。参见 `examples/swiss-reel`。

### 5 产品发布（亮）`theme-launch`
样本：Shipper 发布片 14 万播放，twoclipping 发布片 14 万播放。
- 暖白画布、黑色 UI、单一强调色、iOS 液态玻璃、真实截图。光标驱动一切：点击、拖拽、长按。
- 镜头像 Screen Studio：跟着光标缩放，让每个动作都占满画面。
- 一个黑色形状不断变形，串起所有状态：已下单 ✓ → 打印中 % → 配送中 → 已送达 ✓。
- 禁用：交叉淡化、模糊入场、3D 翻转、粒子、发光、停顿超过 1 秒。

### 6 纸艺绘本 `theme-paper`
样本：孙燕姿《我不难过》MV 44 万赞、《每天每天》MV、Sweet Tooth 17 万播放。
- 纸张底色、扁平 2D 分层视差、手绘描边每秒抖 12 次（boil）、水彩填色、柔和投影；整片固定一个 3–5 色的色板（例：芥末黄、珊瑚粉、青绿、奶油、深海军蓝）。
- 一个固定的主角（一把黄伞、一个方块小人），所有镜头都围着它转。没有文字，用画面讲；MV 的歌词放底部，字小、色淡。
- 角色动画遵守 12 条原则（见 `motion.md`）：预备动作、挤压拉伸、弧线、跟随、夸张。

### 7 霓虹终端歌词 `theme-neon`
样本：The Simulation's Ending 9.7 万播放、Run It Again 5.3 万播放。
- 近黑底加洋红，偶尔插一段米白纸面镜头做呼吸。动态排版：每句歌词都配一个视觉隐喻（终端、图表、地图、手机 UI、进度条）。
- 边角铺满等宽微型元信息（`step 157,587 / 412,000`、`EVAL CONSOLE`），营造「系统内部」的感觉。
- 唱到哪个字就点亮哪个字（卡拉 OK），英文混排粗黑体、意大利斜体和等宽体。

### 8 新粗野主义 UI `theme-brutal`
样本：Ignore Previous Instructions MV 4.2 万播放。
- 奶白、克莱因蓝、洋红，窗口边框（标题栏 + □□□），粗黑描边，贴纸（GREAT JOB TOO），超大粗体字压满整屏。
- 适合讽刺、梗、安全话题：用「系统弹窗 / 权限勾选 / 结账单」承载叙事。

### 9 工程爆炸图 `theme-blueprint`
样本：SpaceX 爆炸图 15 万播放（/anatomy skill）、Nvidia Blackwell 从机房缩放到原子 23 万播放。
- 浅灰蓝底、等轴测线稿、窄体大写标题（`INSIDE A MERLIN`）、规格表（参数名小字灰色 + 数值黑色）、编号 `07 / 12`。
- 连续推镜：从整体到零件、从机房到晶体管，右侧放一把对数刻度尺显示当前视野（`≈ 43.0 cm → 4.44 mm → 8.1 nm`）。
- 部件一个个拆开再合上（take apart / put together）。

### 10 游戏关卡 HUD `theme-hud`
样本：生物必修一「细胞城」2.4 万赞。
- 黑底加警示红，雷达圈、任务清单、「叮！检测到新玩家」。知识点就是关卡、碎片和装备。
- 适合考试复习、系列课，有人声旁白时最好用这个。

## 反例（看到就改）

- 标题居中压在紫蓝渐变上：换原型骨架。
- 每个元素都是 0.5 秒的同一种淡入：按 `motion.md` 换成遮罩升起、弹簧弹出、描边或打字机，并错开时间。
- 四角塞满不读的科技标签（HUD 原型除外）：删掉，留白。
- 字幕 28px 白字压在亮图上：加大到 40px 以上，底部加渐暗。
- 三种以上颜色同时抢眼：降成一个强调色。
