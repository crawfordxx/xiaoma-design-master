# 经典动效风格卡（15 种）

`aesthetics.md` 的 10 个原型是按**题材**选的（讲历史用纪录片、讲数据用编辑部）。这里的 15 张卡是按**动效风格**分的：用户点名要「等轴 2.5D」「像素风」「综艺花字」，或者要一支展示某种风格的片子时用。每张卡都经过实测：按卡做 10 秒片，再经独立评委两轮评审，终评在 7.6–8.2 分之间。

## 怎么用

1. 选一张卡，整片只用这一种风格。卡上的「认得出」和「关键技法」是评委对照打分的依据，**不能删，也不能弱化**。
2. 故事、品牌名、文案和配色可以全换成自己的，但必须保持这种风格最经典、一眼认得出的样子。品牌名一律虚构。
3. **配色和字体按卡自己定义**：`engine/themes.css` 的主题是给 10 个题材原型用的，和风格卡不一一对应。用风格卡时在项目里按卡上的色值写一组 CSS 变量。
4. **风格卡优先于 SKILL.md 的禁用清单**。Synthwave 要透视网格地板和霓虹辉光，HUD 要四角括号和科技小字，VHS 要 RGB 分离。这些是标志特征，选了这张卡就照做；没选这张卡时，禁用清单照常生效。
5. 做完走 `jury.md` 的独立评审，评委拿到的风格说明就是这张卡。
6. 想要一份能直接发给模型的完整提示词：`mg-prompts/` 里每张卡都有对应的一份（如 `mg-prompts/02-isometric.md`），含通用工作流、规矩、自评和交付要求，原片终评 7.6–8.2 分。换掉 `Creative seed` 就能做自己的片。

**提示词里要写上质量标尺**（这一句决定模型对标几分）：

```text
你是这支片子的导演、动态设计师、工程师和声音设计师。目标是这种风格最经典、同时最惊艳的样子，达到获奖入围 / 高端商用定制水准；干净但像模板的结果算失败。对标：Buck、ManvsMachine、Ordinary Folk、Giant Ant、Territory Studio、Apple 发布会动效、Pentagram 动态识别，以及抖音 / B 站头部设计账号。
```

**通用规格**（每张卡默认）：1920×1080（综艺花字为 1080×1920），10.000 秒，H.264 + 48 kHz 立体声 AAC，−14 LUFS，真峰值 ≤ −1 dBTP。交付前跑 `qa.py out/video.mp4 --duration 10`。

## 01 逐帧手绘 / 线条沸腾

- **用在**：反数字精致感的品牌片、角色小片；也常作为矢量动画上的点缀层（烟、水花、速度线）
- **认得出**：线条每隔几帧轻微抖动（line boil），一拍二 / 一拍三的节奏，快动作有拖影帧，手绘烟火水花，纸纹底
- **关键技法**
  - 24 fps 下以一拍二（实际 12 fps）为主，快动作切一拍一，静止镜头一拍三
  - 线条沸腾：同一条线备 3–4 个轻微抖动的版本，每 2 帧换一个循环
  - 拖影帧：快速位移的中间帧把物体拉长到 150–300%，只留 1 帧
  - 矢量主体 + 手绘逐帧特效层（烟、水花、闪电）
  - 整片叠纸纹，正片叠底 10–15%
- **技术路线**：Canvas2D 自写变宽笔刷（中心线 + 压力 → 轮廓多边形），沸腾版本按 2 帧轮换
- **声音**：俏皮的爵士拨弦 / 木琴 + 卡通音效（擦火柴、呼、啵、噗、闪光），逐帧对齐

## 02 等轴 2.5D

- **用在**：科技公司架构图、App 功能演示、微缩城市 / 办公室 / 机房
- **认得出**：30° 等轴投影，没有透视灭点，微缩场景，楼房生长，整组平移式运镜
- **关键技法**
  - 真等轴相机：正交投影，仰角 35.264°、方位角 45°
  - 2D 造等轴面：纵向缩到 86.6% → 斜切 ±30° → 旋转 ∓30°，三个面分别做再拼合
  - 假 3D 靠图层排序：Z 序 = 画面 y 坐标；物体只沿两条网格轴移动，斜率和投影保持一致（真等轴是 30°；像素画常用的 2:1 斜率是 26.57° 的二等角，两种别混用，用真 3D 正交相机时按 30° 做）
  - 楼房生长：底面先落位，立面 scaleY 从 0 拉起带过冲，顶面晚 2–3 帧盖上
  - 运镜只平移不旋转，前中后景视差速度 1 : 0.8 : 0.6
- **技术路线**：Three.js 正交相机 + 柔和阴影 + AO 后处理；或 SVG 按上面的公式造面
- **声音**：明亮的拨弦科技旋律（FM 马林巴），每块地砖、每栋楼落地一声轻响，拉远时一声空气感 whoosh

## 03 扁平矢量

- **用在**：SaaS 产品宣传、科普解说、企业年报。动效设计最主流的基本盘
- **认得出**：纯色大色块，几何化角色，不用或极少用渐变，干净留白，高饱和品牌色，元素弹性入退场
- **关键技法**
  - 弹性缓动是灵魂：过冲用 `cubic-bezier(0.34,1.56,0.64,1)`；入场走「预备 → 冲出 → 回弹」三段
  - 错峰入场间隔 2–4 帧，同一时刻只让一个主体动
  - 位移带约 10% 的挤压拉伸
  - 角色四肢用锚点旋转做骨骼，父子层级控制
  - 转场用色块擦除，或让一个元素飞出、带动整场切换
- **技术路线**：SVG + GSAP（CustomEase / MorphSVG），快动作加运动模糊
- **声音**：120 BPM 左右的轻快流行，每次入场配啵 / 嘣 / whoosh

## 04 线条动画

- **用在**：奢侈品、金融、建筑品牌片，logo 动画
- **认得出**：等宽细线，单色或双色，大量负空间，线条连续生长，「线变面」的一瞬间
- **关键技法**
  - 描线：SVG `stroke-dasharray` / `stroke-dashoffset`，路径长度用 `getTotalLength()`
  - 线宽全片恒定 2–4 px，圆头端点；转角处描线减速，`cubic-bezier(0.65,0,0.35,1)`
  - 一笔画叙事：上一个图形的尾线就是下一个图形的起线，路径事先连好
  - 线变面：描完轮廓后，用同一路径的填充从锚点向外铺开
  - 虚拟相机跟着笔尖走，走过的旧线段压暗到约 35%，结尾拉远成一张完整海报
- **技术路线**：SVG 路径 + GSAP + 跟随笔尖的虚拟相机
- **声音**：极简毛毡钢琴 + 柔和弦乐铺底；笔划纸面的沙沙声随笔尖速度变响；填充时一声轻铃

## 05 3D 渲染（C4D / Blender 质感）

- **用在**：高端产品片（手机、饮料、球鞋）、品牌 ident
- **认得出**：PBR 真实材质，浅景深，柔和棚拍布光，克隆阵列，软体碰撞，糖果色软胶
- **关键技法**
  - 克隆阵列 + 效果器做群体波浪运动
  - 质感三件套：次表面散射（软胶感）+ AO + HDRI 布光
  - 长尾缓动：前 20% 的时间走完 80% 的路程，收尾极慢，配运动模糊
  - 24 / 25 fps 电影帧率 + f/1.8 感的浅景深，和 2D 的 30 fps 利落感区分开
  - 以产品为轴心，粒子 / 流体 / 布料围着它做物理编排
- **技术路线**：Blender 命令行脚本（Cycles + 降噪）出 PNG 序列 → ffmpeg；文字可用网页叠加层另渲。这是 15 张卡里唯一不走网页渲染的
- **声音**：解压系的软闷响、挤压声、气泡声 + 空灵电影感铺底，撞击逐帧对齐

## 06 形变动画

- **用在**：图形叙事、发布会动效、高端 explainer 里最见功力的段落
- **认得出**：轮廓连续过渡没有跳变，有中介形状桥接，形变同时带位移和旋转，变形瞬间挤压拉伸
- **关键技法**
  - 两个形状顶点数一致、首顶点方位对应，否则会打结；每次形变都看中点静帧
  - 复杂的 A→B 不直接变：先收成圆或胶囊再展开，A→圆、圆→B 各 8–12 帧
  - 全程叠 10–15% 挤压拉伸和轻微旋转，掩盖插值的机械感
  - 速度曲线中段最快 `cubic-bezier(0.7,0,0.3,1)`，起止各留 3 帧缓冲
  - 子部件同步形变（蒸汽 → 太阳光芒 → 波浪）；每次形变换一次背景色块
- **技术路线**：SVG + flubber 或 MorphSVG（调 shapeIndex 做顶点匹配）
- **声音**：有节奏的拨弦琶音，每次形变一声带音高的 whoosh，落在拍上

## 07 粗描边贴纸人科普

- **用在**：知识区硬核科普、财经、跨学科解说、企业宣传片
- **认得出**：照片抠图加粗白描边变成「贴纸」，蓝灰 / 米白冷静底色，扁平图标 + 精确图表，大画布上镜头平移缩放，节拍化的高密度信息
- **关键技法**
  - 照片抠图 + 8–12 px 白描边 + 柔和投影，统一不同来源素材的质感
  - 一张超大画布（如 6000×3000），相机层做长曲线的平移和缩放，一镜串起多个信息点
  - 图表动效：柱子生长、数字滚动计数、路径描边生长；图表必须按比例、数字前后一致
  - 每一句解说或每一拍都有一个新元素入场
  - 配色克制（2–3 色 + 1 个强调色），等线无衬线字体，保持严肃感
- **技术路线**：一张大 canvas + 相机变换，SVG 图表，贴纸照片
- **声音**：干净的科技解说铺底，UI 点击声，计数时滴答，镜头移动时轻 whoosh

## 08 赛博朋克 HUD / FUI

- **用在**：数码测评、游戏剪辑、军事航天科普、AI 产品演示的「科技感」皮肤
- **认得出**：青色 / 橙色霓虹线框，锁定框和十字准星，雷达扫描循环，等宽小字数据流和打字机文字，六边形网格与辉光
- **关键技法**
  - 线框按层级错帧描出（stroke-dashoffset）
  - 雷达：圆锥渐变扇区旋转 + 目标点闪烁
  - 数字先随机跳 3–5 帧再落定真实值；打字机文字带闪烁光标
  - 锁定框：四角括号从 1.4 倍收到 1.0 倍吸附目标，快出缓入
  - 全局外发光 + 轻微色差 + 扫描线；常态青色，锁定瞬间整体翻成警报橙
- **技术路线**：SVG / Canvas 界面层 + Three.js 线框全息物体 + 辉光扫描线后处理；随机数一律用种子
- **声音**：暗黑合成器脉冲 + HUD 提示音、扫描声、上升的锁定音，锁定时警报

## 09 拼贴剪贴

- **用在**：音乐类、街头潮流类短视频，杂志风包装
- **认得出**：照片剪影带白边，半调网点，报纸纹理，比例失衡的超现实拼装，定格式抽帧
- **关键技法**
  - 抠图加 2–4 px 白边（剪刀剪出来的感觉）+ 半调网点滤镜
  - 关节在肩、肘、下颌，分段旋转像木偶；嘴巴用两三张替换帧开合
  - 刻意降帧：渲染 30 fps，但主体运动落在 12 fps 甚至 6 fps 的格子上，位置加 ±2 px 手摆抖动
  - 图层：纸纹 → 大色块 → 照片剪影 → 手写涂鸦 / 胶带贴纸 → 颗粒
  - 转场用「手把元素拍上来」或整页翻纸、撕纸
- **技术路线**：DOM / Canvas + 抠好的 PNG（只用 CC0 / 公有领域照片），SVG 滤镜做白边和半调
- **声音**：黑胶噼啪声 + 爵士 boom-bap 铺底，纸张沙沙、剪刀咔嚓、拍打声，揭开时一声卡通「啵」

## 10 弥散渐变 / 玻璃拟态

- **用在**：AI 产品发布、科技品牌片。气质是慢、透、高级
- **认得出**：大色斑高斯模糊后缓慢漂移，磨砂玻璃卡片，1 px 高光描边，邻近色低对比，呼吸感节奏
- **关键技法**
  - 底层 3–5 个纯色大圆，模糊 80–150 px，各自沿贝塞尔路径慢漂，融成网格渐变
  - 玻璃卡片：背景模糊 20–40 px + 5–10% 白色填充 + 1 px 30% 白色内描边 + 大圆角
  - 只用 2–3 个邻近色（紫蓝青 / 橙粉红），撞色会脏；暗底比亮底出效果
  - 全局叠 3–5% 噪点防色带
  - 缓动接近线性或正弦呼吸，一切都慢；文字入场只用透明度 + 8 px 上移
  - 惊艳点：一枚真折射的液态玻璃透镜滑过，边缘有色散
- **技术路线**：WebGL 网格渐变着色器 + SDF 透镜折射；卡片用 CSS backdrop-filter
- **声音**：氛围电影感铺底，柔和闪光声，极轻的 UI 提示音

## 11 几何构成 / 包豪斯

- **用在**：动态海报、音乐节视觉、和节拍强相关的片子
- **认得出**：圆、三角、矩形，红黄蓝黑限定色，严格网格对齐，节拍驱动的模块化运动
- **关键技法**
  - 一切运动锚定网格：位移 = 网格模数的整数倍，落点必在网格线上
  - 缓动克制：easeInOutQuad 或匀速，**禁用过冲**，机械感是特征不是缺陷
  - 一拍一个动作：四分之一圆绕角旋转 90°、半圆滑一格、三角翻转、方块分裂
  - 旋转轴心在「自身中心 / 边缘顶点 / 画面中心」三种之间交替，制造韵律
  - 高潮用三角函数相位差驱动整片阵列，形成一道波
- **技术路线**：SVG / Canvas + GSAP，模数网格（如 240 px），120 BPM 拍点网格
- **声音**：极简 techno，每次翻转一声带音高的点击，四分音符上底鼓

## 12 复古 80s Synthwave / VHS

- **用在**：音乐视频、潮流品牌片、怀旧营销
- **认得出**：霓虹辉光，透视网格地平线，扫描线与 RGB 色偏，镀铬金属字，条纹落日
- **关键技法**
  - 三件套：一点透视网格向镜头滚动、多层渐变的条纹落日、双层辉光（内层 4 px 高亮 + 外层 30 px 低透明）
  - VHS 做旧链：红蓝通道各偏 1–2 px → 2 px 间隔 10% 黑条扫描线 → 每秒 1–2 次随机抖动抽帧
  - 镀铬字：高对比多段金属渐变 + 斜角高光 + 一道星光扫过
  - 关键段落故意抽帧到 15 fps，或倒放 2 帧，模拟磁带卡顿
- **技术路线**：WebGL（透视网格、落日、山脉）+ canvas 镀铬字 + 辉光 + VHS 后处理
- **声音**：门限混响军鼓、琶音锯齿贝斯、厚铺底，标题砸下时大和弦 + 镲

## 13 像素风

- **用在**：游戏区内容、8-bit 音乐 MV、品牌怀旧营销
- **认得出**：大颗粒像素、硬边缘，有限色板（8–32 色），8–12 fps 精灵动画，抖动渐变，可选 CRT 扫描线
- **关键技法**
  - 内部分辨率 320×180，整数倍（×6）最近邻放大，杜绝抗锯齿
  - 精灵逐帧循环：走路 6–8 帧、呼吸 2–4 帧，约 10–12 fps
  - 精灵动画用阶梯时序，不用平滑缓动；所有坐标取整
  - 远中近三层视差卷轴，按整像素平移
  - CRT 后处理（扫描线 + 桶形畸变 + 磷光）不能把像素糊掉；中文用像素字体
- **技术路线**：Canvas，精灵直接在代码里写成像素数组，限定色板
- **声音**：芯片音乐（方波主旋律、三角波贝斯、噪声鼓）+ 跳跃 / 金币 / 宝箱音效

## 14 液态流动

- **用在**：音乐视频、食品饮料广告、转场包装
- **认得出**：波浪边缘转场，拉丝与滴落，融球融合，次级液滴跟随，有机曲线永远不直
- **关键技法**
  - 融球：高斯模糊 20 px 以上 → 收紧 alpha 阈值，两球靠近自动粘连；或着色器里 smooth-min 求场
  - 拉丝 → 断裂 → 回弹：主形离开时留一条细颈，断开瞬间两端各回弹 2–3 帧
  - 缓动前快后慢 `cubic-bezier(0.22,1,0.36,1)`，液体是被甩出去的，不会匀速
  - 次级液滴晚主体 2–3 帧跟随，落地压扁
  - 液态转场：波浪前沿扫过画面，带 3–5 个错开相位的凸起
  - 用场的梯度做法线，加高光和菲涅尔边缘光，让它读起来像厚的 3D 液体
- **技术路线**：WebGL2 片元着色器，2D SDF 融球 + 假 3D 光照，logo 用文字 SDF 和液体融合
- **声音**：咕嘟气泡、倾倒、飞溅、滴落，低频鼓胀垫在光亮的合成器铺底下

## 15 综艺花字（竖屏）

- **用在**：vlog、萌宠、访谈、搞笑二创的通用包装
- **认得出**：多层描边圆体 / 胖体字，高饱和撞色 + 白边 + 投影，弹性 pop 入场，和音效一起出现，手绘装饰符号（爆炸框、汗滴、闪光）
- **关键技法**
  - 字分三层：填充色（可渐变）+ 粗白描边 + 彩色外描边 / 投影
  - 入场 scale 0 → 1.15 → 1.0，约 8 帧；或逐字弹跳，错开 2 帧
  - 情绪对应：吐槽用歪斜手写体，惊讶用放射线爆炸框，尴尬用汗滴
  - 出现时机比笑点或音效晚 2–3 帧，更自然
  - 停留较久的花字加轻微晃动，保持活性
  - 底层要像实拍素材：慢推拉、轻微手持晃动、在笑点上猛推近
- **技术路线**：DOM / SVG 多层描边花字组件 + 弹簧 pop + SVG 装饰；底层用 CC0 照片做推拉，照片太弱就画风格化场景
- **声音**：弹跳的综艺铺底（拨弦、贝斯、拍手）+ 嘣、啵、叮、滑哨、唱片搓碟

## 写一张新风格卡

照下面五段写，其余（质量标尺、通用规格、工作流、渲染合约）沿用本 skill。

```text
# 风格
<中文名 English name>

# 用在 / 认得出
<来源和用途一两句>；认得出：<逗号分隔的标志特征>

# 关键技法（评委按这个打分）
<每条一行，可执行、可检验：曲线参数、帧数、像素、层结构>

# 技术路线
<SVG / Canvas / WebGL / Three.js / Blender……以及关键实现手段。有更好的路线可以换，但要说明理由>

# 创意种子
<一句话片名 + 按秒的节拍：钩子 → 升级 → 高潮（约 60–75% 处）→ 结尾画面；3–6 个具体色值；字体气质；音乐风格和关键音效>
```

写好的关键：
- **技法要可检验**：写「过冲用 `cubic-bezier(0.34,1.56,0.64,1)`，错峰 2–4 帧」，不写「动效要有弹性」。
- **创意种子要有节拍**：按秒写出钩子、升级、高潮和结尾，模型才不会做成平铺直叙的模板。
- **先做一批，再挑**：实测时先做了 22 种风格各一支，评审后留下最好的 15 支。新风格也先多做几个方向，留分高的。
