# 片头 / 活动开场片

## 判定信号与相邻片种

- 信号：片头、开场视频、大会开场、发布会开场、晚会开场、年会开场、倒计时、栏目片头、栏目包装、节目 ID、论坛主视觉动画
- 和 **品牌片** 的区别：品牌片要讲完一个人和一个主张，以分钟计；开场片 15–60 秒，不讲故事，只做三件事：让全场安静、亮出主题、把舞台交给下一位
- 和 **MG 动画** 的区别：MG 负责讲清楚（流程、数据、政策）；开场片不解释，只宣告和造势
- 和 **预告片** 的区别：预告片让人「以后去看」，要埋悬念；开场片放给已经坐在现场的人，要的是当下的注意力和情绪
- 和 **活动纪实** 的区别：活动纪实在活动之后用真实素材回顾；开场片在活动开始那一刻播，画面是设计出来的
- 和 **产品宣传片** 的区别：发布会上揭幕产品用产品片的「发布会揭幕」变体；开场片只亮活动，不讲产品

## 默认规格

| 项 | 15 秒版（栏目片头 / ID） | 30 秒版（大会开场） | 60 秒版（晚会 / 发布会开场） |
|---|---|---|---|
| 镜数 | 5–10 | 10–18 | 18–35 |
| 平均镜长 | 1–2s | 1.5–3s | 1.5–3s |
| 文字 | 主标题 + 关键词 0–1 个 | 主标题 + 主题语 + 关键词 ≤ 3 个 | 主标题 + 主题语 + 关键词 ≤ 5 个 |
| 音乐 | 一个重音 + 收尾 | 一首 110–128 BPM、有 drop 的曲子 | 两段式：铺垫 + 爆发 |
| 画幅 | 16:9 出分镜；主屏常是超宽 LED（如 32:9），先要屏幕分辨率，安全区写进 `notes` | 同左 | 同左 |

## 结构模板

先定**主视觉母题**：一个贯穿全片、最后变成主标题或 KV 一部分的元素（光标、一条线、一粒种子、一个几何形）。再按音乐小节排节拍（30 秒版、120 BPM，一小节 2 秒）：

| 节拍 | 占比 | 小节 | 做什么 |
|---|---|---|---|
| 引燃 | ~13% | 1–2 | 黑场 + 一个声音或一个光点，让全场安静下来，母题第一次出现 |
| 母题生长 | ~27% | 3–6 | 母题从一个元素长成一个世界，尺度越来越大；不出字或只出一个词 |
| 加速 · 关键词 | ~27% | 7–10 | 卡点快切到全片最密，2–3 个关键词各占一小节 |
| 汇聚 | ~13% | 11–12 | 所有元素收回中心，组成主视觉 KV，音乐 drop |
| 定版 | ~13%（至少 3 秒） | 13–14 | 主标题 + 主题语 + 日期地点，稳定可读 |
| 交接 | ~7% | 15 | 母题最后出现一次，留一拍给灯光和主持人 |

其他常用结构：
- **倒计时**：10 → 0 每秒一个画面，数字就是母题；归零就是交接点，和灯光、主持人口令对齐。长倒计时（24 个、60 个数）分两段：前段每个数字是一张约 3 秒的数字卡加 3–6 个内容镜，一个数字约 11 秒；最后 8–10 个数字一数一镜、等长（约 2.7 秒），最后一个数停 5–8 秒交给现场
- **回顾 + 展望**：前半用往届活动的真实素材快剪，后半切到今年主视觉；适合年会、第 N 届大会
- **人物群像**：嘉宾、员工、用户的面孔卡点快切，最后汇成主标题；适合年会、晚会
- **一镜到底穿越**：摄影机连续穿过母题构成的空间，终点就是主标题；适合科技大会，制作量最大。剧集开场可以把长镜拉到 90–130 秒，末尾接 15–25 秒快切收束，再落 3 秒片名；这一类在 `project.asl` 里另写平均镜长区间

15 秒版：引燃 → 母题 → 汇聚 → 定版，四拍。

## 信息层级与节拍

开场片放在几十米外的大屏上，观众只看一遍。字要分层，要踩拍，要给够读的时间。

**文字三层**

| 层 | 内容 | 出现 | 停留 | 屏幕占比 |
|---|---|---|---|---|
| L1 主标题 | 活动名，如「2026 开发者大会」 | 全片一次，只在定版 | ≥ 3s | 画宽 40–70% |
| L2 主题语 | 一句话，≤ 10 字 | 1–2 次 | ≥ 2s | 画宽 15–30% |
| L3 关键词 / 信息 | 议题词、日期、地点 | 每个一次 | 每个 1–2s | 画宽 5–12% |

- 同一画面只有一个最大的字；定版时三层可以同屏，但字号梯度要拉开
- 读字时间：2–4 个字的关键词至少 1 秒，10 个字的主题语至少 2 秒，主标题定版至少 3 秒
- 字踩重拍出现，提前半拍开始消失，不要在字刚读完时硬切
- 面向陌生观众（国际活动、首次亮相）时，也可以一段只讲一个意思、压到 3 个左右镜头；一段 7–9 秒塞 8 个 0.5–1.5 秒的镜头，观众看不懂

**节拍表先于分镜**

先定音乐和 BPM，再把镜头排进小节：

- 120 BPM：一拍 0.5 秒，一小节 2 秒；镜长尽量取 0.5 秒的整数倍，节拍时长取整小节
- 引燃、母题段按小节切（一镜 2–4 秒）；加速段的关键词镜也按小节切，给够读字时间，关键词之后到 drop 前按拍切（一镜 0.5–1 秒）；汇聚和定版回到小节
- drop 落在汇聚段的第一拍，主标题落在定版段第一小节的第一拍
- 全片时长取整小节，结尾留一拍空给现场

| 情况 | ❌ | ✅ |
|---|---|---|
| 议题多 | 30 秒滚 8 个议题名，每个 0.5 秒，谁都看不清 | 挑 3 个关键词各占一小节，其余交给议程页和主持人 || 主标题 | 第 1 秒就挂在画面上，到定版时已经不新鲜 | 只在定版出现一次，前面全用母题铺垫 |
| 母题 | 每一镜换一种特效：粒子、液体、玻璃、故障风轮着来 | 一个母题从头长到尾，最后变成 KV 的一部分 |
| 卡点 | 切点和字跟音乐错开半拍 | 切点、字、音效、灯光 cue 都在节拍表上对齐 |

## 节奏基准

- 开头 2–5 秒是「静场」：黑场或单个光点，声音比画面先到，这是全片最安静也最要紧的一刻
- 速度一路往上走：母题段一镜 2–4 秒，加速段 0.5–2 秒，最密处放在 drop 前的那一小节
- drop 前抽空半拍到一拍，drop 后突然变慢：汇聚和定版用全片最长的镜头，形成落差
- 白闪、黑场这类大转场全片不超过 2 次，留给 drop 和交接
- 出彩镜头两到三成：母题点题、尺度揭示、汇聚成 KV、首尾呼应

## 招牌镜头

- **黑场光点**：纯黑里一个点亮起来，配低频或一个单音
- **母题生长**：一个元素复制、延展，长成网络、城市、星系
- **尺度揭示**：从一个微小元素急速拉远或升高，揭示它是一个巨大结构的一部分
- **穿越镜头**：摄影机高速穿过母题构成的空间，速度线、光流向中心汇聚
- **关键词卡点**：一个词踩重拍弹出，背景同时变化
- **汇聚成 KV**：所有元素从四面八方飞回中心，咬合成主视觉
- **定版呼吸**：主标题定住，背景缓慢流动，保持现场感但不抢字
- **双重曝光人像**：人物剪影当窗口，里面是他所处的风景，素材慢放到原速的 10–20%，约一小节一镜

## 扩展列

- `文字层级`：本镜出现哪一层字、原文是什么。例：「L3 · AI 原生」「L1+L2+L3 · 定版」「无字」。用来逐字核对和排读字时间
- `音乐节拍`：本镜落在第几小节、踩什么拍点、音乐在做什么。例：「第 7 小节第 1 拍 · 鼓组进，字落」「第 11 小节第 1 拍 · drop」。剪辑、现场灯光和音响都按这列对点

## 画风

默认 `motion-design`，`allow_text: true`；人物群像、回顾类开场用 `realistic-cinema` 或 `documentary-natural`，只在定版加字。

`prompt_prefix` 参考：高端科技大会开场视觉画面，抽象几何与粒子光效，深色背景上的冷色霓虹光线，三维图形与体积光，标题字体现代简洁，构图居中对称

- 主视觉母题建 `refs`（type: prop），设定图写清形状、颜色、发光方式；母题有两种形态（单独出现 / 组成 KV）时分建两条
- 反复出现的空间（光流城市、隧道、舞台）建场景 `refs`（type: location）
- 字直接写进 `frame_prompt` 并加引号，一格最多一两处；定版的第三层小字写进 `notes` 后期加；主办方 logo 不画进图

## 声音

- 音乐先于画面定：时长、BPM、drop 位置定了，分镜才能排
- 开头用一个「静场声」：低频心跳、单音、一下键盘敲击，让现场安静
- 音效跟着母题和字走：光点出现「叮」、字落「咚」、汇聚「轰」，一一对应
- 低频按现场音响设计，drop 处给足超低频；交接处留一拍空，接主持人或灯光 cue
- 旁白可有可无：最多 2–3 句，或只在定版念一遍活动名

## 常见坑

- 特效大杂烩：粒子、液体、玻璃、故障风全用上，没有一个母题
- 字太多太快：议题、嘉宾名单、赞助商全塞进来
- 主标题出得太早，或者出了好几次
- 不踩拍：画面切点和音乐错开，现场听起来是乱的
- 不问屏幕：按 16:9 做完，现场是 48:9 的异形屏，主标题被切掉
- 定版太短：主标题一闪就交接，后排观众没看清
- 结尾没留空：音乐最后一拍和主持人开口撞在一起

## 变体

- **倒计时片**：数字就是母题，每秒一镜；最后 3 秒放慢，归零时全场灯光、音乐同时切换；24 个以上的长倒计时按结构模板里的两段式排
- **栏目片头 / 节目 ID**：5–15 秒，每期重复播，母题和音乐动机要短、可识别，定版就是栏目名
- **电影 / 剧集片头**：片名是 L1，主创署名是 L3，按署名顺序排读字时间；画面用正片的影调和母题。母题按「生成 → 变形 → 转折或毁灭」走，不必汇聚成 KV；也可以把片名压到最后 10–15% 再出。每集都播的片头少放细节，按剧情可做 3–4 个版本；惊悚类可以故意不卡拍，用闪帧和抖动的手写字
- **晚会 / 年会开场**：人物群像 + 年度关键词，情绪比信息重要，两段式节奏，结尾接主持人开场口令
- **异形大屏**：先按屏幕实际比例画安全区，分镜按 16:9 出图，在 `notes` 里写清主体和字在超宽画面里的位置

## 顶尖范本

写分镜前挑一部最接近的范本，照它的排法走。实测镜长和来源见 `references/benchmarks.md`。

| 范本 | 导演 / 创作者 | 学它怎么排 |
|---|---|---|
| 《迷魂记》《惊魂记》片头 | Saul Bass | 一个图形母题概括全片（螺旋、切开文字的线条），片头和海报用同一母题；字本身参与运动 |
| 《七宗罪》片头 | Kyle Cooper | 微距拍凶手的手在做笔记本，黑底手刻署名卡和插入镜交替；四段越剪越密（约 1.7→1.0 秒），故意不卡拍 |
| 《真探》第一季片头 | Patrick Clair | 人物剪影里装风景的双重曝光，约一小节一镜（2 秒）切在小节线上；从明到暗到火，片名在 85–95% 处出现 |
| 《权力的游戏》片头 | Angus Wall / Elastic | 约 90 秒一次连续飞行掠过机械地图，按每集到访地点做 4 个版本，浮雕从 5 块减到 3 块 |
| 北京冬奥会二十四节气倒计时 | 张艺谋团队 | 17.7 秒字卡交代规则；每个节气 = 3 秒数字卡 + 几个内容镜（约 11 秒）；最后 8 个数字一数一镜 2.73 秒 |
| 《长安十二时辰》第一集开场 | 曹盾 | 127 秒长镜从屋顶降进西市、穿过人群、上望楼看全城，接 25 秒快切，落 3 秒书法片名和 6.5 秒时辰卡 |

## 节奏审核参数

`review.py` 按下面的参数做节奏机检，规则见 `references/director-review.md`。项目属于本卡里的某个子类型（例如竖屏短版、一镜到底、长版）时，在 `project.asl`、`project.hook` 里写那个子类型的平均镜长区间和钩子时限。

```pace
asl = 1-3
cps = 3
slack = 0.8
hold = 4
hook = 5
```

asl 平均镜长区间（秒）· cps 台词旁白舒适语速（字/秒）· slack 有台词镜头的余量（秒）· hold 无台词镜头的停留上限（秒）· hook 钩子最晚结束（秒，0 表示不查）
