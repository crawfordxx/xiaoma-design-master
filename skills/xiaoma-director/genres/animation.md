# 动画短片

## 判定信号与相邻片种

- 信号：动画、动画短片、2D / 3D 动画、手绘、绘本动画、定格、黏土、剪纸、毕业设计动画、剧情动画
- 和 **MG 动画**的区别：MG 是信息驱动，图形、图标、数据跟着解说走；动画短片是角色驱动，角色有目标、有情绪变化。判断方法：关掉解说还看得懂故事，是动画短片；画面在图解一段话，是 MG
- 和**知识科普**的区别：科普里的卡通角色是讲解员，为知识点服务；动画短片里的角色自己就是故事
- 和**实拍微电影**的区别：结构方法相同，但动画每一秒都要画或渲染出来，没有「多拍几条备用」，分镜基本就是最终剪辑，镜头数直接决定成本
- 和**游戏 PV / CG 预告**的区别：PV 卖世界和期待，不讲完；动画短片讲完一个故事
- 动画 MV（画面跟着歌走）按 MV 做，画风借本卡

## 默认规格

| 项 | 1–2min | 3–5min |
|---|---|---|
| 镜数 | 20–40 | 50–100 |
| 平均镜长 | 3–4s | 3.5–5s |
| 主要角色 | 1–2 个 | 2–3 个 |
| 场景 | 1–3 个 | 3–6 个 |
| 台词 | 少或无 | 少 |
| 画幅 | 16:9 | 同左 |

全片超过 1 分钟时，可先做开头 60 秒的完整段落，`scope` 写 `segment`。

## 结构模板

短动画按「世界 → 角色 → 麻烦 → 尝试 → 高潮 → 余韵」排节拍（全片占比）：

| 节拍 | 占比 | 做什么 |
|---|---|---|
| 世界 | ~10% | 一个和现实不同的设定，用一两个大远景立住它的规则（纸鹤会送信、云是可以收割的） |
| 角色 | ~15% | 主角做一件体现性格的事，观众先喜欢上他 |
| 麻烦 | ~20% | 规则带来的问题，或主角的缺点惹的祸 |
| 尝试 | ~25% | 两三次尝试，一次比一次大，前几次失败 |
| 高潮 | ~20% | 主角用自己的方式解决，常常要付出代价 |
| 余韵 | ~10% | 世界或角色的新状态，可回到开头的画面做对照 |

- 好用的出发点：一个简单规则推到极致；「如果这个东西有感情会怎样」；先让人笑，再让人哭
- 尽量用动作讲故事，台词能删就删；关掉声音也要看得懂
- 也可以把同一个动作重复三遍，每遍变一处（一个和尚挑水 → 两个抬水 → 三个没水喝 → 合力），结尾回到开场的动作、换成新状态

## 媒介判定与夸张表演

### 先定媒介，写进 `assumptions`

| 媒介 | 适合 | 代价与限制 |
|---|---|---|
| 2D 手绘 | 抒情、写意、绘本感、水彩背景 | 画量大；大角度转镜要重画背景，镜头运动靠平移、推画面和多层视差 |
| 3D | 复杂运镜、群戏、大尺度、精确接戏 | 建模绑定贵，镜头多才划算；不用心打光会有塑料感 |
| 3D 角色 + 手绘背景 | 想要手绘质感又要控制成本 | 要分开声明角色和背景各自的画风 |
| 定格 / 黏土 | 手工质感、童趣 | 慢，动作量少，镜头运动受限 |
| 剪纸 / 有限动画 | 图形化、民俗风、低成本 | 动作偏硬，靠造型设计和节奏取胜 |

2D 的镜头运动写成画面横移、竖摇、推画面、多层视差、背景急拉；`frame_prompt` 里不写焦段、光圈、景深，写了画面容易漂成实拍或伪 3D。日式、迪士尼式、剪纸式是不同传统，时间和阴影逻辑不同，不要混用。

### 表演要夸张，并写成可执行的描述

动画角色没有真人演员的微表情，情绪靠姿势和时间被读出来。模型和画师默认给的都是「平均幅度」，夸张要写明。

| 原则 | 在分镜里怎么写 |
|---|---|
| 预备 | 起跳前先往下蹲半拍；出手前先往回收 |
| 挤压拉伸 | 落地时身体压扁约四分之一，再弹回略过头 |
| 跟随 | 角色停下后，围巾、尾巴、头发晚半拍才落定，回摆一次 |
| 剪影 | 关键姿势只看剪影也认得出在做什么 |
| 停顿 | 关键姿势停 0.5–1 秒，让观众读到 |
| 夸张 | 动作幅度比真人大三分之一，夸张放在脸、手和个别部位，身体结构保持可信 |

- ❌ 小鹤很开心地飞起来
- ✅ 小鹤先把身体缩成一团，猛地张开翅膀，整个身体向上拉长，在最高点停住半拍，再一扇冲出画面
- 写关键姿势（起点、顶点、落点），不写一串流水过程；一格分镜图只画动作最饱满的那个姿势

### 对白戏

- 以双人中景长镜做骨架（10–20s），单人近景只给情绪落点；口型越多画量越大，台词密的段落用双人、背影、远景、画外音压成本
- 对白语速按每秒 4 字写，情绪戏放慢到 3 字左右

## 节奏基准

- 平均镜长 3.5–5s（无对白喜剧、自然题材 5–7s）：动作镜 1–2s；开场世界观镜头 6–20s，可叠片名；情绪顶点后停 10–17s；结尾大远景可到 20–40s。超过 10s 的镜头标「停留」；无对白喜剧的长镜标「停留」并写 `pace_note`
- 第一版几乎总是太快：关键信息落定后再停 1 秒以上，开场主体动作给足 3 秒
- 留「沉默的动画」：角色发呆、看风景、等待，不要剪掉，这是动画的呼吸
- 日式有限动画常用一拍二（每秒 12 张）、一拍三（每秒 8 张，日式主流），快动作才一拍一；全片都一拍一会显得「AI 式丝滑」，没有动画味。帧率也是表演参数，可以按角色区分（生手一拍二、老手一拍一）
- 作画量不平均：最重的一段常占全片画量四成以上，排期按镜头难度算，不按时长平分
- 出彩镜头一成半到三成，开头和结尾略多；视觉奇观全片 1–2 次，前面要有铺垫

## 招牌镜头

- **世界观大远景**：多层视差慢慢横移，前景、中景、远景各走各的速度
- **角色亮相**：先剪影或局部，再一个清楚的全身姿势，停住
- **夸张表情特写**：眼睛放大、五官位移，停半拍
- **视觉隐喻**：角色做了一件事，不拍反应，切到一个有寓意的画面
- **变形转场**：前一镜的形状长成下一镜的东西（一片云变成一只纸鹤）
- **天气与光的情绪镜**：雨、雪、窗外的光斑，替角色说心情
- **静帧慢推**：画好的一张图慢慢推近，省画量又稳，适合情绪段和过场
- **喜剧固定全景**：一个固定全景 10–20s，让进出画、探头这些喜剧动作在镜内完成，不切五个近景
- **高点一刀**：冲击动作用 1–1.5s 连切落在最狠的那一下，紧接 10s 以上的停留
- **留白开场**：第一镜几乎空白，主角慢慢从画里冒出来，走起来观众才认出环境

## 扩展列

`作画要点`：每镜写「关键姿势 · 时间 · 层与复用」。关键姿势写起点、顶点、落点；时间写停顿长度或拍数；层写视差层数、哪些背景可复用。例：「缩身 → 张翅拉长 → 顶点停 0.5s → 冲出画；一拍二；三层视差，背景同 s02」。空镜写「无角色 · 」加画面里会动的元素（「无角色 · 只有云层和光斑在动，静帧慢推」）。

## 画风

默认 `animation-2d`；3D 动画自写前缀（如「三维动画电影画面，柔和的全局光照，风格化的角色比例，细腻的材质」），不要借 `cg-game` 的写实游戏质感。

`prompt_prefix` 参考：日系手绘 2D 动画电影画面，水彩质感手绘背景，干净的线条与赛璐璐上色，温暖柔和的色调

- 光线描述按段落固定，逐镜原样复用（比如「傍晚暖橙色斜阳，长影子」），别每镜换天气换时间；剧情需要变天，只在一个明确的节点换一次，写进 `assumptions`
- 角色必建 `refs`，设定图写清发色、瞳色、服装色块和比例（几头身），全身正面
- 非人角色（纸鹤、猫、机器人）也建 `refs`，写清形状、颜色、标志性部位
- 背景能复用就复用：同一场景的多个镜头，`notes` 里写「背景同 sNN」

## 声音

- 拟音比现实大，分层叠加；最响的一下对在冲击帧上
- 情绪段用「间」：刻意近乎静音，只剩一两个细小的声音（纸张摩擦、风声）
- 音乐和动作精确同步（每一步踩一个音）只用在喜剧段或少数强调点，全片都这样会显得幼稚
- 没有台词的镜头也要写清声景，不要只写「无对白」
- 有台词时，混音优先级是对白 > 冲击音效 > 音乐
- 分镜阶段就排 story reel：声音列写 temp 曲风格和临时台词，节拍按音乐小节对；第一版允许超时，删的单位是镜头
- 高潮可以删掉台词，让配乐接管；无对白片可以一个角色配一件乐器

## 常见坑

- 动作只写结果（「他跳过去」），画出来像人偶
- 全片都一拍一、匀速运动，像幻灯片动画
- 2D 镜头写摄影参数，或设计大角度绕人转的运镜
- 第一版节奏太快，情绪还没落就切走
- 角色每镜换样：没建设定，或每镜描述的服装颜色不一样
- 把 MG 当动画：画面在图解解说，角色没有自己的目标
- 台词太多，动画变成配音的广播剧
- 角色第一版设计得太搞笑，整片的情绪就立不起来

## 变体

- **绘本动画**：以静帧慢推、平移为主，旁白讲故事，作画量最小
- **3D 动画短片**：镜头运动可以更自由，但要先做预演把动作和机位定死；角色表演同样要夸张
- **定格 / 黏土**：镜头少、每镜长，运镜以固定和慢推为主，质感镜头（指纹、布料纤维）是招牌

## 顶尖范本

写分镜前挑一部最接近的范本，照它的排法走。实测镜长和来源见 `references/benchmarks.md`。

| 范本 | 导演 / 创作者 | 学它怎么排 |
|---|---|---|
| 《中国奇谭·小妖怪的夏天》 | 於水 | 开场 18 秒大远景叠片名；母子戏用 18 秒双人侧面中景做骨架；结尾 37 秒大远景 |
| 《三个和尚》 | 阿达 | 23 秒留白长镜开场；挑水动作重复三遍渐变；无对白，一个和尚一件乐器 |
| 《鹬》（Piper） | Alan Barillaro | 喜剧段用 19–20 秒固定全景；小鸟客观镜浅景深，主观镜深焦大全景 |
| 《包宝宝》（Bao） | 石之予 | 先拍和面的手；崩溃段 1–1.5 秒连切到一口吞，接 17 秒长镜；结尾全家包包子各停 11–13 秒 |
| 《蜘蛛侠：平行宇宙》 | Persichetti、Ramsey、Rothman | 同场戏按角色混用一拍一和一拍二；每帧按单格漫画构图 |

- 范本共性：开场给 6–23 秒的世界观或留白镜，结尾回到开场的动作。

## 节奏审核参数

`review.py` 按下面的参数做节奏机检，规则见 `references/director-review.md`。项目属于本卡里的某个子类型（例如竖屏短版、一镜到底、长版）时，在 `project.asl`、`project.hook` 里写那个子类型的平均镜长区间和钩子时限。

```pace
asl = 3-7
cps = 4
slack = 4.5
hold = 10
hook = 0
```

asl 平均镜长区间（秒）· cps 台词旁白舒适语速（字/秒）· slack 有台词镜头的余量（秒）· hold 无台词镜头的停留上限（秒）· hook 钩子最晚结束（秒，0 表示不查）
