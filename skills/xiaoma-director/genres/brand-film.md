# 品牌形象宣传片

## 判定信号与相邻片种

- 信号：企业宣传片、品牌片、形象片、品牌故事、企业文化片、招聘片、周年片、官网首页片、展厅片
- 和 **TVC** 的区别：TVC 卖一个产品或一次活动，以秒计，前 5 秒就要看出品类；品牌片讲「这家企业是谁、凭什么值得信」，以分钟计，logo 可以留到最后
- 和 **产品宣传片** 的区别：产品片的主角是产品，按卖点逐个证明；品牌片的主角是人（员工、用户、创始人），产品只作为证据出现，不给环绕英雄镜
- 和 **文旅片** 的区别：文旅片推一个地方，靠只有那里才有的东西；品牌片推一个组织，靠价值观和做事的人
- 和 **纪录片** 的区别：纪录片跟着事件走，结论在拍摄中形成；品牌片先有主张句，每一镜都替它作证，结尾落 logo。用户要「真员工、不摆拍」时用本卡的纪实变体，不改纪录片
- 和 **片头 / 开场片** 的区别：开场片 15–60 秒，任务是点燃现场、亮出活动名；品牌片要讲完一个人和一个主张

## 默认规格

| 项 | 60 秒版 | 90–120 秒版 | 180 秒版 |
|---|---|---|---|
| 镜数 | 20–30 | 36–75 | 75–110（宣言混剪可到 140） |
| 平均镜长 | 2–3s | 1.6–2.5s | 1.6–2.5s |
| 主角 | 1 人或一组群像 | 1–2 人 | 1–2 人 + 一段群像 |
| 旁白字数 | 80–150 | 150–300 | 按类型：叙事体 100–150，独白体 350–400，演讲宣言体 600–700 |
| 画幅 | 16:9；展厅大屏按屏幕实际比例；招聘片社媒版另出 9:16 | 同左 | 同左 |

超过 120 秒的片子默认先做开头 90 秒（`scope: segment`），把人物和难题立住再往后写。

## 结构模板

先写一句**主张句**（品牌想被记住的那句话，必须能拍），再按「一个人的一件事 → 更多人」排节拍（180 秒版占比）：

| 节拍 | 占比 | 做什么 |
|---|---|---|
| 引子 | ~8%（前 10–15 秒） | 一个具体的人在一个具体的时刻，抛出全片的问题；不先放 logo、大楼、航拍 |
| 人物与难题 | ~19% | 主角是谁、在跟什么较劲（技术、自然、时间、偏见）；把难题落到一个普通用户身上；情绪最低点放在这段，全片前 1/4 内 |
| 行动与坚持 | ~23% | 全片 25–35% 处一句话或一个意象完成转折；价值观落成动作：反复试、失败、再来 |
| 突破与证据 | ~15% | 一次看得见的成功；可核实的数据，或一个真实用户的变化 |
| 升华 | ~25% | 从一个人拉到更多人：用户、城市、行业，景别跨度变大，音乐全开 |
| 主张落版 | 8–12 秒（~4–7%） | 先回到开头的人或意象，首尾呼应；再拆 2–3 张：一个字或主张句 2.5–3.5 秒 →（网址 / 活动）→ logo 2.5–4.5 秒 |

其他常用结构（按企业和用途选一种）：
- **群像蒙太奇**：多岗位、多城市的人做同一类动作，一句主张串起来；适合企业文化片、周年片
- **用户视角**：企业不出镜，只拍被它服务的人；适合 ToC 品牌、公共服务属性强的企业
- **时间物件**：一个物件（同一台机器、同一个工位、同一本手册）穿过几十年；适合周年片，用来替代大事记
- **宣言体**：旁白是一段宣言，画面是一组对应的意象；适合品牌焕新，60 秒以内。3–4 分钟的演讲版：主讲人近景长镜 8–14 秒做锚点，中间 0.5–0.8 秒素材逐词对位，三段用大字卡分章
- **社会实验型**：交代规则 → 过程（自述、手部、五官特写三类镜头循环）→ 全片约 50% 处揭晓，揭晓镜停 7 秒 → 反应 → 主张句；分镜只写节拍和镜头类型，不写台词

60 秒版：引子 → 一个人做一件事 → 一个结果 → 主张落版，四拍就够。

## 把价值观翻译成人和行动

价值观词（创新、专业、责任、匠心）拍不出来。每个词都要翻成「谁 · 在做什么 · 付出了什么 · 留下了什么痕迹」：

| 价值观 | ❌ 空镜 + 口号 | ✅ 人 + 行动 + 痕迹 |
|---|---|---|
| 专业 / 严谨 | 实验室全景，字幕「严谨求实」 | 工程师把同一组数据第三遍抄进本子，用红笔圈出小数点后第三位 |
| 创新 | 粒子光效、蓝色线条流动 | 白板上划掉的六版方案，第七版只写了半行 |
| 以客户为中心 | 西装握手、会议室里的微笑 | 售后工程师夜里蹲在客户车边，手电咬在嘴里 |
| 长期主义 | 「十年磨一剑」大字 | 同一个工位，墙上贴的照片从一张变成一排 |
| 责任 | 植树、捐赠合影 | 巡检员在零下的风里拧紧一枚松掉的螺栓，再用记号笔画一道线 |

三条规矩：
- **一个价值观配一个人、一个动作**：一段戏里不要同时证明三个词
- **留痕迹**：动作做完要留下看得见的结果（数字、划痕、磨白的边角、一直亮着的灯），痕迹比动作更有说服力
- **主张句要能拍**：「让每一度电走得更远」能拍（车、路、远处亮起的灯）；「赋能美好生活」拍不出，回去和客户改，改不了就找它背后最具体的一件事

翻译不出人和行动的价值观，删掉。180 秒讲透一个就够，最多两个。

## 节奏基准

- 两种主节奏选一：**人物叙事 / 独白 / 纪实型** 平均镜长 1.8–2.5s，每分钟 24–33 镜；**宣言 / 演讲混剪型** 平均镜长 1.5–1.8s，每分钟 33–40 镜，靠主讲人长镜和素材快切做长短对比。升华段加速到 0.5–1s 一镜
- 开头 10 秒内出现主角的脸或手：人是品牌片的钩子；独白型可以先用 15–20 秒空间和物件铺氛围
- 6 秒以上的长镜全片 2–5 个，只放在四处：主讲人锚点、开场氛围、揭晓与反应、升华后的凝望
- 升华段节奏最快、景别跨度最大；落版前收住，给最后一句主张留 2 秒空；落版前放 5–8 秒无旁白的释放镜（群像、日出、拥抱）
- 组接也可以照这几条：先交代空间再上近景；同类人物三镜一节拍；特写留 1–1.5 秒；推镜放在一组第一镜；同景别同角度、固定接大运动不要直接接；不要全片变速
- 出彩镜头占两到三成，集中在开场、中点、升华、落版四处，不要扎堆

## 招牌镜头

- **手部工作特写**：手、工具、材料三者同框，配真实现场声
- **工作中的侧脸**：人物不看镜头，专注手上的事，浅景深把环境隔开
- **尺度跳切**：大特写直接切大远景（一片极片 → 一片雪原），把个人和世界连起来
- **群像横移**：一排工位、一条产线、一群人，用平移串成一个集体
- **物件叙事**：一本笔记、一张照片、一件旧工服，承载时间和情感，首尾可以呼应
- **对镜一句话**：真员工看着镜头说一句话（不超过 10 字），全片最多一次，放在升华段
- **首尾呼应**：结尾回到开场的人、地点或意象，但状态变了；开头抛一个问题，落版用一个字或一句话作答
- **真实故事改编字卡**：真实事件改编的片子，开场黑底字卡停 3–4 秒
- **意象转折镜**：用一个画面完成转折，比如车队冲出黑暗隧道迎上强光

## 扩展列

`价值落点`：每镜写这一镜在替主张或哪个价值观作证、用什么方式证明（人物 / 动作 / 痕迹 / 用户 / 意象 / 环境）。例：「较真 · 痕迹：笔记本里一行行手写数据」「为人 · 用户：冬天在充电桩边等车的司机」「主张「更远」· 意象：车灯在雪原上拉出一条线」。一镜写不出价值落点，就问它为什么还在片子里。

## 画风

默认 `realistic-cinema`；纪实变体用 `documentary-natural`。

`prompt_prefix` 参考：企业品牌形象片剧照，真实摄影，电影级自然光布光，人物质感真实不修饰，浅景深，克制的低饱和调色，细腻胶片颗粒

- 主角建角色 `refs`；反复出现的工作场景（实验室、产线、门店）建场景 `refs`；产品作为证据出现时也建产品 `refs`
- 关键道具（笔记本、工牌、旧照片）跨镜出现就建 `refs`，它常常是首尾呼应的载体
- 主角有两套服装（工装和便装）时，设定图用出镜最多的那套，其余在 `frame_prompt` 里写清
- 工牌、厂区标识、logo 不画进图，后期贴

## 声音

- 旁白先定人称：人物叙事型用主角第一人称（真实、可信），宣言体用品牌第三人称；全片不混用
- 旁白和画面互补，不复述：画面在拧螺丝，旁白不说「他在拧螺丝」，说为什么拧；演讲 / 宣言体例外，可以逐词对位配素材
- 旁白每秒 3–3.5 字，句子短，一句一个意思；覆盖率按类型定：叙事体 15–20%（句与句之间留 3–6 秒纯画面），独白体 55–60%，演讲体 85–90%
- 现场声是质感来源：机器、键盘、风、脚步，在旁白之间让它们出来
- 音乐一条走到底：钢琴或弦乐起 → 行动段加节奏型 → 中点抽掉 → 升华段全编制 → 落版收在一个长音上

## 常见坑

- 「楼、厂、人、奖」四件套：大楼航拍、产线全景、领导讲话、荣誉墙，看完记不住任何一个人
- 价值观词直接打字幕，画面配空镜
- 主角太多：180 秒里出现 6 个人各说一句，谁都没立住
- 旁白太满，从头念到尾，没有一处呼吸
- 摆拍的握手、假笑、指着大屏开会
- 大事记年表：「2008 年成立，2012 年……」按时间念流水账
- 编造数据、荣誉、客户名称；真实员工、客户出镜没拿肖像授权
- logo 太早太多：开头就是 logo 动画，中间每段都打一次；logo 首次出现压在最后 3% 以内（宣言体开头的黑底署名字卡不算）

## 变体

- **招聘片**：主角是和目标候选人同龄的员工，拍真实的一天和成长路径；节奏更快，可出 9:16，结尾给投递方式
- **周年片**：用「时间物件」结构串起过去和现在，老照片、老物件与今天同构图对比；不做大事记
- **企业文化 / 内部片**：群像蒙太奇 + 员工原声，可以有内部梗，对外版要删掉
- **纪实风品牌片**：真员工、真现场，不排练；画风换 `documentary-natural`，旁白改为人物采访原声
- **展厅 / 大屏循环片**：无旁白、首尾帧接得上可循环，按屏幕实际比例构图，信息放在画面中下部

## 顶尖范本

写分镜前挑一部最接近的范本，照它的排法走。实测镜长和来源见 `references/benchmarks.md`。

| 范本 | 导演 / 创作者 | 学它怎么排 |
|---|---|---|
| 大众银行《梦骑士》 | 台湾奥美 / Thanonchai Sornsriwichai | 1.8 秒问「人为什么活着」；低谷放前 1/4，45 秒一句台词转折；骑行段 0.5–1 秒快切；落版只答一个「夢」字 |
| B站《后浪》 | SG 胜加 / 何冰 | 何冰近景长镜 8–14 秒做锚点，中间 0.5–0.8 秒素材逐词对位；三段大字卡分章；结尾 8 秒无旁白群像 |
| New Balance《致匠心》 | 李宗盛 / Verawom | 前 20 秒纯画面再进独白；吉他与制鞋两条手艺线平行剪；成品鞋到全片 95% 处才完整出现 |
| 多芬《真美素描》（Real Beauty Sketches） | John X. Carey / Ogilvy Brazil | 1.4 秒交代实验规则；自述、手部、五官特写三类循环；第 91 秒两画并排揭晓，停 7 秒 |
| 苹果《非同凡想》（Think Different） | TBWA\Chiat\Day | 17 位人物黑白档案影像依次出现，每人不到 3.5 秒；收尾一个小女孩睁开眼 |
| 宝洁《最难的工作》（Thank You, Mom） | Alejandro G. Iñárritu / W+K | 四大洲母亲清晨叫醒孩子 → 多年训练 → 奥运赛场，多线并行，结尾一句字幕致谢 |

## 节奏审核参数

`review.py` 按下面的参数做节奏机检，规则见 `references/director-review.md`。项目属于本卡里的某个子类型（例如竖屏短版、一镜到底、长版）时，在 `project.asl`、`project.hook` 里写那个子类型的平均镜长区间和钩子时限。

```pace
asl = 1.5-3
cps = 3.5
slack = 1.5
hold = 6
hook = 0
```

asl 平均镜长区间（秒）· cps 台词旁白舒适语速（字/秒）· slack 有台词镜头的余量（秒）· hold 无台词镜头的停留上限（秒）· hook 钩子最晚结束（秒，0 表示不查）
