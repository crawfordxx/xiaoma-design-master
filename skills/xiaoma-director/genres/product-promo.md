# 产品宣传片

## 判定信号与相邻片种

- 信号：产品片、新品发布视频、功能展示、产品介绍、官网产品视频、电商主图视频、详情页视频、众筹视频、开箱质感、产品 3D 展示
- 和 **TVC** 的区别：TVC 用一个创意概念卖产品，15/30 秒只讲 1–3 个卖点；产品片让产品自己当主角，按卖点逐个证明，30–90 秒，信息量是 TVC 的两三倍
- 和 **品牌片** 的区别：品牌片讲企业和人，产品只是证据；产品片的每一镜都围着产品转，人是用产品的人
- 和 **达人口播** 的区别：产品片是官方视角，没有人对着镜头讲体验；有人拿着产品说「我用了一周」就是达人口播
- 和 **教程** 的区别：教程教怎么一步步操作；产品片只拍操作带来的结果和那一下的手感，不讲步骤
- 和 **MG 动画** 的区别：产品还没有实物、主要靠图表和流程讲原理时用 MG；产品片的主体是实物（实拍或 CG 实物）
- 和 **开场片** 的区别：发布会开场片亮的是活动名；揭幕产品那一刻用本卡的「发布会揭幕」变体

## 默认规格

| 项 | 30 秒版 | 60 秒版 | 90 秒版 |
|---|---|---|---|
| 镜数 | 17–23 | 24–40 | 36–60 |
| 平均镜长 | 1.3–1.8s | 1.5–2.5s | 1.5–2.5s |
| 卖点数 | 2–3 | 3–4 | 4–6 |
| 旁白 | 可无；有则 ≤ 60 字 | 可无；有则 ≤ 120 字 | ≤ 180 字 |
| 画幅 | 16:9（官网、发布会）；电商主图 1:1，信息流 9:16 | 同左 | 同左 |

## 结构模板

先列卖点清单并排序：**最强的卖点放第一组**（观众注意力最高），**最好拍的放最后一组**（情绪最好收）。再按下表排节拍（60 秒版占比）：

| 节拍 | 占比 | 做什么 |
|---|---|---|
| 悬念开场 | 4–10 秒 | 产品局部、轮廓光、剪影，不给全貌，先让人想看 |
| 英雄亮相 | 3.5–5 秒 | 产品第一次完整出现：环绕或缓推，暗场或纯色背景，名字和产品同时出 |
| 卖点证明 ×3 | ~50% | 每个卖点 2–4 镜、5–10 秒，按「原理 → 体验 → 数字」证明（见下节） |
| 设计细节 | ~10% | 材质、工艺、结构、配色，微距滑轨 |
| 生活方式 | ~10% | 产品回到人和场景里，给观众一个「我用它」的画面 |
| 落版 | 5–10 秒 | 逐张出：主张句 → 英雄镜 + 名称 → 上市信息或 CTA（开售日期单独一张）→ logo，每张 1.5–3 秒 |

分镜里可以把「卖点证明」拆成「卖点①×× / 卖点②××」几个节拍，方便对时长。

其他常用结构：
- **一天的使用线**：早到晚跟着一个用户，卖点按出场时间嵌入；适合日用品、穿戴设备
- **拆解 → 组装**：从零件爆炸图开始，每个零件对应一个卖点，最后合成整机；适合硬件、工艺型产品
- **对比型**：旧方式的麻烦 vs 新产品的轻松，同构图前后对比；适合升级换代产品
- **发布会揭幕**：只做悬念 + 亮相 + 一个核心卖点 + 名字，用在发布会现场揭幕那一刻
- **名人叙事型**：人物第一人称旁白讲一段经历，产品当道具入画，后半程才完整展示；卖点只用一个动作隐喻（如「开合」）
- **材质起源型（30 秒单卖点）**：用卖点的来历占七成篇幅，成品最后几秒才完整亮相，口号拆两张字卡把两段接上

30 秒版：悬念 → 亮相 → 2 个卖点 → 落版，落版可占 20–25%。

## 卖点三段证明

TVC 的卖点拍得到一次就算数；产品片的观众是来了解产品的，每个卖点要经得起追问，按三层证明：

| 层 | 回答什么 | 拍什么 |
|---|---|---|
| 原理 | 它凭什么做到 | 先拍测试实拍（喷淋、跌落、机械臂、实物燃烧）；拍不到再用剖切、爆炸图、CG 可视化（声波、气流、光路、热量），一镜讲清一个机制 |
| 体验 | 用起来是什么样 | 真实场景里的使用瞬间 + 人的反应，最好是同构图的前后对比 |
| 数字 | 到底有多好 | 官方参数做成小字，叠在对应部件上或放角标，和体验镜同屏或紧跟其后；一个卖点只出一次 |

| 卖点 | ❌ 只喊 | ✅ 三段证明 |
|---|---|---|
| 主动降噪 | 字幕「深度降噪」+ 人闭眼微笑 | 原理：杂乱的声波遇上反向波被抹平 · 体验：婴儿就在身后哭，戴耳机的人闭着眼 · 数字：降噪深度（官方值） |
| 快充 | 「充电快人一步」 | 体验：咖啡机出一杯咖啡的工夫插上线，指示灯换了颜色 · 数字：充电时长对应的续航（官方值） |
| 防水 | 水花特效 | 体验：手表跟着手腕扎进泳池，水下屏幕还在计圈 · 数字：防水等级（官方值） |
| 轻 | 「轻若无物」 | 原理：同体积的旧材料和新材料放在天平两端 · 体验：戴着它侧躺睡着 |

规矩：
- 三层不必每个卖点都齐，**体验层必须有**；原理拍不清就跳过，数字没有就不写
- 参数只用官方给的；拿不到时字幕写成「○○」参数位，在 `notes` 标明，并列进 `open_questions`，绝不编
- 一个卖点只用一个最强的画面证明，不要换三个场景重复同一件事
- 原理可视化要能回到真实产品：剖开的结构、发光的位置必须和外观对得上
- 爆炸图只在要解释机构或装配时用

## 节奏基准

- 悬念开场 4–10 秒、2–10 个短镜（0.3–2s），暗调、局部、材质或光，不出完整产品；也可以先出一个产品的声音再出画面
- 英雄亮相给 3.5–5 秒的停留，60 秒以上的片子放在第 4–10 秒：全片第一次让观众看清它，也是全片最长的镜头之一
- 卖点组内先快后慢：引子镜 1.5–2s，原理镜 2–4s，体验镜 2–4s，数字字幕至少停 1.5 秒
- 每组卖点之间换一次环境或色温，让观众知道「下一个了」
- 设计细节段放慢，配合微距滑轨的匀速运动
- 落版 5–10 秒，每张 1.5–3 秒；发布会现场版末张多停，留给掌声
- 每镜一句大花字的电商写法会把平均镜长压到 1.4 秒左右，只适合参数型受众；高端调性的卖点字一个卖点只出一次
- 出彩镜头两到三成，放在亮相、最强卖点的原理镜、生活方式收束

## 招牌镜头

- **轮廓光局部**：暗场里一道光沿产品边缘划过，只露线条
- **英雄环绕**：产品悬浮或立在转台上，摄影机环绕 90°–180°，背光勾边
- **爆炸图 / 剖切**：零件沿轴线分开再合拢，或半透明剖开露出内部结构
- **微距滑轨**：材质纹理、按键行程、缝线、接口，匀速滑过
- **原理可视化**：把看不见的（声音、气流、信号、热）画成线、波、粒子，和产品同框
- **测试实拍**：实验室里的喷淋、跌落、机械臂测试，配工程师一句话，证明耐用比特效可信
- **使用瞬间**：按下、折叠、插入、戴上，配一个清脆的动作声
- **前后对比**：同构图同人物，用前和用后
- **落版 packshot**：产品 + 配件或包装，三分构图，留足字的安全区

## 扩展列

- `卖点`：本镜证明哪个卖点、在哪一层（原理 / 体验 / 数字 / 外观）。例：「卖点①降噪 · 原理可视化」「外观 · 悬念局部」「落版」
- `产品状态`：本镜产品的配色、形态（展开 / 折叠 / 佩戴 / 剖切）、指示灯和配件状态。例：「雾银 · 佩戴中 · 灯灭」「雾银 · 折叠平放 · 充电中」。道具组按这列备样机，CG 组按这列出模型，前后镜不穿帮

## 画风

默认 `realistic-studio`；生活方式镜头占一半以上时改用 `realistic-cinema`。

`prompt_prefix` 参考：高端消费电子产品宣传片画面，商业产品摄影，影棚级布光，柔光箱与轮廓光勾边，材质与反光细节清晰，商业精修质感

- 产品必须建 `refs`（type: product），设定图写清外形、配色、材质、接缝、按键和接口位置、指示灯位置
- 有多个配色时选一个主配色贯穿全片，其他配色只在落版出现
- 原理可视化镜头只挂产品设定，不挂人物设定；有用户角色跨镜出现就建角色 `refs`
- 机身和包装上的字、logo 不画进图，后期贴

## 声音

- 音乐要分段清楚：悬念段只有低频和细碎音效，亮相落在第一个重拍，卖点段稳定律动，落版收住
- 每个使用瞬间配一个干净的拟音（折叠「咔」、插入「嗒」、按键「哒」），这是产品片的手感
- 旁白可有可无；有的话每秒 3–4 字，只说画面说不出的那半句（原理、数字），不念画面
- 降噪、音质这类听觉卖点，用声音本身做证明：环境声从满到空、乐器从糊到清
- 产品名和口号与音乐最后一拍同时落

## 常见坑

- 参数大字报：满屏数字、图标、对勾，画面只是背景
- 只有棚拍没有人：产品转了 60 秒，观众不知道自己什么时候会用它
- 原理特效脱离产品：粒子和光线很炫，看不出和哪个部件有关
- 一个卖点拍三遍：换了三个场景证明同一件事，后面的卖点没时间了
- 产品状态穿帮：上一镜折叠、下一镜展开，配色和指示灯前后对不上
- 编造参数、跑分、认证；用竞品出镜或暗贬竞品
- 英雄亮相太晚：60 秒以上的片子过了第 10 秒还没见到完整产品（材质起源型 30 秒片除外）

## 变体

- **电商主图 / 详情页视频**：1:1 或 9:16，前 3 秒必须出完整产品，卖点字幕加大，静音也能看懂，结尾停在主图同构图
- **发布会揭幕片**：悬念 + 亮相 + 一个核心卖点 + 名字，45–60 秒，落版留 5 秒给现场
- **CG 全三维产品片**：无人物，全部原理可视化 + 英雄镜，产品数模必须来自客户
- **众筹片**：前面加 15–30 秒创始人讲「为什么做它」，后面接本卡结构，结尾给支持方式
- **软件 / SaaS / AI 产品片**：没有实物可拍时，「英雄亮相」换成界面或工作台的完整亮相，卖点按「用户的一个任务 → 界面里发生了什么 → 结果」一卖点一段；旁白密、以界面和数据为主的，结构和节奏改按 `motion-graphics` 卡，画风按用户的品牌或官网定，可以是实拍场景叠界面面板。界面里的数据一律标「演示」

## 顶尖范本

写分镜前挑一部最接近的范本，照它的排法走。实测镜长和来源见 `references/benchmarks.md`。

| 范本 | 导演 / 创作者 | 学它怎么排 |
|---|---|---|
| 《Introducing iPhone 11 Pro》 | Apple | 前 10 秒约 10 个暗场光条和局部短镜，第 9.8 秒完整亮相 3.8 秒；耐用靠喷淋、跌落实拍证明 |
| 《钛金属》（iPhone 15 Pro「Titanium」） | Apple / TBWA\Media Arts Lab | 前 19 秒只拍钛从宇宙到边框的来历，成品第 22.5 秒才露出；口号拆两张字卡衔接 |
| 《Introducing Osmo Pocket 3》 | DJI | 4 秒微距局部接黑底英雄镜 4.5 秒；13 个卖点各 2–4 镜：手持使用 → 特写 + 角标卖点 → 拍出的画面 |
| 华为 Mate XT《开合间 见非凡》 | 上海动观 | 刘德华第一人称旁白；产品第 15 秒以静物入画，第 93 秒才完整展开；卖点只用「开合」一个动作 |
| 小米 14 Ultra 功能片 | 小米 | 第 0 秒产品名压在第一镜，2.4 秒已在手；每镜一句卖点花字，平均 1.4 秒；开售日期单独一张卡 |

- 范本都不用 logo 开场，前 3 秒 1–2 刀，第一镜是局部、材质、光或产品名

## 节奏审核参数

`review.py` 按下面的参数做节奏机检，规则见 `references/director-review.md`。项目属于本卡里的某个子类型（例如竖屏短版、一镜到底、长版）时，在 `project.asl`、`project.hook` 里写那个子类型的平均镜长区间和钩子时限。

```pace
asl = 1.3-3
cps = 3.5
slack = 1
hold = 4
hook = 10
```

asl 平均镜长区间（秒）· cps 台词旁白舒适语速（字/秒）· slack 有台词镜头的余量（秒）· hold 无台词镜头的停留上限（秒）· hook 钩子最晚结束（秒，0 表示不查）
