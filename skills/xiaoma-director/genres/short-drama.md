# 竖屏短剧

## 判定信号与相邻片种

- 信号：短剧、竖屏剧、红果 / 抖音 / 快手短剧、爽剧、霸总、逆袭、重生、赘婿、退婚、打脸、单集、付费卡点、漫剧
- 和**微电影**的区别：短剧一集 1–2 分钟，每集至少一个爽点，集尾必须卡在悬念上，冲突外放、台词直给；微电影一次讲完一个故事，靠潜文本和留白成立。观众要「爽到、追下一集」是短剧，要「看完回味」是微电影。靠留白成立的故事硬改成短剧，两头不讨好
- 和**达人口播**的区别：口播是一个人对着镜头讲；短剧是演员之间演戏，不看镜头
- 和**剧情 TVC** 的区别：剧情广告的故事为产品服务、结尾落品牌；短剧里的植入只能是道具露出，不能打断剧情

## 默认规格

| 项 | 单集 60s | 单集 90–120s |
|---|---|---|
| 镜数 | 20–28 | 30–45 |
| 平均镜长 | 爽剧 2.3–3s；甜宠、精品 3.5–5.5s | 同左 |
| 画幅 | 9:16 | 同左 |
| 腰部以上单人（中近景及更近）占比 | 爽剧 ≥ 60%；精品向 ≥ 45%，全景留给关系和空间 | 同左 |
| 爽点 | 1 个 | 1–2 个 |
| 集尾卡点 | 1 个 | 1 个 |
| 同框人数 | 主体不超过 3 人，群演做背景 | 同左 |

## 结构模板

单集按「钩子 → 压迫 → 翻盘 → 余波 → 卡点」排节拍（90 秒占比）：

| 节拍 | 占比 | 做什么 |
|---|---|---|
| 钩子 | ~5%（前 3–5 秒） | 接上集最后一拍，或直接给画面里正在发生的危机、反常：当众受辱、身份反差、倒计时、证据亮出 |
| 压迫 | ~30% | 对手施压，主角处境压到底；同时埋下翻盘要用的证据或身份线索（观众看到了，对手没看到） |
| 翻盘 | ~35% | 主角用看得见的证据或行动翻盘，对手付出可核对的代价 |
| 余波 | ~20% | 旁观者分层反应，人物地位重新排序 |
| 卡点 | ~10%（最后 8–10 秒） | 停在新危机或新揭示的前一秒，峰值后不加余韵 |

- 每 15–20 秒一个转折：一句冲突台词、一个改变局面的动作、一条新信息，1 分钟约三个爆点；甜宠向可放宽到 20–35 秒。重复说明和客套不算
- 第 1 集的大爽点不能拖到第 2 集；付费卡点那一集，卡点前不要刚兑现完大回报
- 其他常用结构：**身份揭示型**（受辱 → 埋证据 → 亮身份 → 对手失势）· **误会虐恋型**（甜 → 误会 → 心碎 → 卡在真相前）· **悬疑型**（异常 → 追查 → 半揭示 → 卡点）

## 钩子—爽点—卡点与站位连续性

### 三个点都要拍得到

| 环节 | ❌ 拍不到 / 不成立 | ✅ 拍得到 |
|---|---|---|
| 钩子 | 黑屏旁白「她的人生从今天改变」 | 请柬被当众撕成两半，碎片落在她鞋面上 |
| 爽点 | 主角说「你们会后悔的」，众人震惊 | 她把房产证推到桌子中间，对方伸手去拿，被律师一把按住 |
| 卡点 | 黑屏加「未完待续」 | 手机亮起，来电显示「爸」，可她爸三年前就过世了 |

- **钩子**：第一镜就要有运动的主体，静物特写开场是死画面；首屏交代「出了什么事、谁倒霉、该看哪」中的两件。可以用 2–3 秒的大环境建立镜或证据特写打头，但第二镜必须上人和冲突
- **爽点**是一条五环链：先前状态 → 主角行动 → 可见证据 → 对手的代价 → 新状态。代价落在看得见的权力变化上：签字被驳回、门禁亮红灯、名字被划掉、原本坐着的人站起来
- 用证据揭身份，不靠报头衔：「我是董事长」不如门禁亮绿灯、保安把挡路的手收回去
- 爽点必须有**承受者的反应镜**：对手的脸僵住、手松开、退半步。比旁观者齐声惊呼有力
- **卡点**停在峰值或峰值前一秒：门推开一半、录音刚放出第一个字、一句没说完的问话。优先选能启动下一集压力的那一刻
- 也可以卡在对话中途，下一集开头用不同语气把上一句重说一遍接上

### 站位、轴线、视线、持物

- **每场先写站位**，写进该场第一镜的 `notes`：锚点（门、桌、台阶）、每人位置和朝向、轴线在哪一侧、本场谁会移动
- 用锚点写站位（「站在茶几后、背对落地窗」），不写「画面左侧」，换机位就失效
- **竖屏多人戏靠纵深，不靠横排**：主导者中景居中，对手分在前景边缘和后景门口。三人横排一字站，竖屏会把两边的人切掉
- 正反打两镜屏幕方向互补：A 看画右，B 就看画左；身高差对应一俯一仰
- 要越轴：用骑在轴线上的正面或背面镜过渡，或让人物走位把轴线带过去；越轴的那镜在 `notes` 标「越轴」
- 持物写清在谁手里、哪只手、什么时候转手，前后镜对得上
- 权力关系先用距离和高低（坐与站、台阶上下）表达，再动机位俯仰。竖屏里俯仰的效果比横屏强得多，留给翻盘那一下
- 精品向用纵深补环境：门窗、廊柱、枝叶做前景，人物在中景演，背景放氛围；按天地纵向选景，用光影切开空间，不要只拍大头对切

## 节奏基准

- 平均镜长 2.3–3s：反应镜 1–2s，证据特写 1.5–2s（要让观众看清），台词镜按每秒 4–4.5 字算，单镜不超过 5 字/秒
- 台词约占全集时长的一半；台词密的段落，画面负责给反应和证据，不再把台词演一遍
- 无台词镜多数 2–2.5s，一般不超过 5.5s；揭示后的承受者反应要停更久时标「停留」
- 长台词拆到说话者和听者两个镜头上，不要压快语速
- 一场的景别走法：先开宽一档交代关系 → 落到中景、中近景对切 → 特写留给要落地的那句台词或那件证据 → 场尾退回中景。不要一路收紧，到中段就没余量了
- 翻盘前留 0.5–1 秒的「静」：环境声抽空、所有人停住，然后再翻
- 每一次切镜，景别、角度、人物关系至少变一项，否则并成一镜
- 出彩镜头一成到两成，集中在钩子、翻盘、卡点三处

## 招牌镜头

- **延迟亮相**：先给脚步、背影、手、门缝或逆光剪影，再给脸，用在身份揭示
- **证据特写**：文件、手机屏、工牌、钥匙，停够 1.5 秒；屏幕和纸上的字后期贴
- **冲击重复**：打脸或翻盘的关键动作从 2–3 个角度各给一次，状态只变一次，全集只用一次
- **背后仰拍**：低机位从主角身后仰拍他走向对手，观众感觉「他在变大」
- **承受者反应**：对手僵住、松手、后退半步
- **旁观者分层**：近处的人先静、远处的人后知后觉，不给每个路人一个惊讶特写
- **卡点定格**：停在动作完成前的那一帧，配一个悬念音
- **冷开场闪前**：把后面最强的一场剪 10–12 秒放在开头，再回到故事起点

## 扩展列

`情绪钩子`：每镜写这一镜让观众留下来的东西，用「压 / 扬 / 悬」三类加一句具体内容。压是委屈、愤怒、不公；扬是翻盘、打脸、出气；悬是问题、未知、危险。例：「压 · 前任当众撕请柬」「扬 · 对手的手被律师按住」「悬 · 来电显示已故的父亲」。连续三镜以上同一类要有意图，整集要能看出「压 → 扬 → 悬」的走向。

## 画风

默认 `realistic-vertical`；漫剧改用 `animation-2d`，前缀里写清漫画分镜感。

`prompt_prefix` 参考：竖屏短剧剧照，真实摄影，人物是画面主体，明亮清晰的布光，色彩饱满，竖构图

- `frame_prompt` 一律写「竖构图」，主体放在画面中上部，下方约四分之一给字幕留空
- 关键证据和手部动作不要落在画面最底部和右侧，那里会被字幕和平台按钮遮住
- 跨镜出现的角色都建 `refs`，服装要有一眼能认出的色块；关键道具（房产证、戒指、工牌）也建 `refs`（type: prop）

## 声音

- 台词是主轴；字幕默认硬烧，单行不超过 12 字，长句拆条
- 每个重点音效都要有功能：新信息、权力变化、兑现钩子。翻盘的声音锚定在可见结果上（录音放出、手被按住），不是每个冲突都砸一下重低音
- 身份揭示可以反着做：杯盘声渐停，近处的人先静、远处后静，只剩底噪和一次吞咽
- BGM 写相对位置：压迫段低频长音铺底，翻盘那一下进节奏型音乐，卡点前骤停或换成一个悬念音
- 集尾最后一个声音要和卡点画面同时落，别让音乐在卡点后继续抒情

## 常见坑

- 前 10 秒在交代人物关系和背景，没有事发生
- 爽点不讲理：无因扇耳光、对手突然降智、群众齐声惊呼、证据凭空出现
- 用报头衔代替证据；「受辱—亮牌」循环用到第三次还没换花样
- 每句台词切一个大头近景，景别不动；或者连续三句都是大特写加推
- 横屏构图直接裁成竖屏：多人横排被切掉，关键道具落在底部被字幕盖住
- 集尾靠黑屏、「未完待续」或一声无来由的尖叫
- 台词爆仓：3 秒的镜头塞 20 个字

## 变体

- **漫剧 / AI 短剧**：平均镜长放到 3 秒，表演和表情更外放，画风用 `animation-2d`
- **付费卡点集**：一般在第 10–15 集前后（之前免费）。卡点要比普通集更强（身份即将曝光、生死、不可撤销的选择），卡点前一场先小兑现，不要把大回报用完
- **甜宠 / 情感向**：转折间隔 20–35 秒，平均镜长 3.5–5.5s（`project.asl` 写 3.5-5.5）；全景多用来交代关系。集尾也可以把揭示放在倒数约 20 秒，用 10–15 秒承受者反应收尾，标「停留」并写 `pace_note`
- **横屏短剧（16:9）**：节奏和结构照本卡，构图按微电影的横向调度来

## 顶尖范本

写分镜前挑一部最接近的范本，照它的排法走。实测镜长和来源见 `references/benchmarks.md`。

| 范本 | 导演 / 创作者 | 学它怎么排 |
|---|---|---|
| 《一品布衣》 | 红果出品 | 3 秒古城远景后切哭喊的弟弟；前 90 秒 35 镜，每 13–30 秒抛一条新信息（卖妻、穿越） |
| 《盛夏芬德拉》 | 穆裕 | 12 秒闪前冷开场再回到相亲；茶室用剪影侧面和手部特写，揭示后给 11 秒转身反应收尾 |
| 《冒姓琅琊》 | 汪帅 | 不拍大头对切，按天地纵向选景，用光影切开人物之间的空间 |
| 《我的亿万富翁丈夫的双重身份》（The Double Life of My Billionaire Husband） | ReelShort | 99 秒 42 镜，单人中近景正反打为主；50 秒抛出「替嫁」，最后 8 秒一句「我嫁」就切 |
| 《Beneath Crimson Sails》 | Steven Kammerer | 约七成是特写；头顶留空比横屏多，双人镜不按 50/50 摆 |

- 范本共性：开头 5 秒内给出冲突台词或冲突画面，之后每 15–20 秒一个转折。

## 节奏审核参数

`review.py` 按下面的参数做节奏机检，规则见 `references/director-review.md`。项目属于本卡里的某个子类型（例如竖屏短版、一镜到底、长版）时，在 `project.asl`、`project.hook` 里写那个子类型的平均镜长区间和钩子时限。

```pace
asl = 2-4
cps = 4.5
slack = 4
hold = 5.5
hook = 5
```

asl 平均镜长区间（秒）· cps 台词旁白舒适语速（字/秒）· slack 有台词镜头的余量（秒）· hold 无台词镜头的停留上限（秒）· hook 钩子最晚结束（秒，0 表示不查）
