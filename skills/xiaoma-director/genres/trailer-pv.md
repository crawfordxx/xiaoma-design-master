# 预告片 / 游戏 PV

## 判定信号与相邻片种

- 信号：预告片、先导预告、正式预告、teaser、trailer、游戏 PV、CG PV、首曝、角色 PV、实机演示、上线宣传片
- 和 **TVC** 的区别：TVC 卖产品，产品早露出，结尾给口号和答案；预告卖期待和一个没解决的问题，片名放到最后，结尾不给答案
- 和 **MV** 的区别：MV 的结构跟着歌的主歌副歌走；预告的音乐服从剪辑的升级，需要骤停和静默。音乐本身是主角时走 MV
- 和**片头 / 开场片**的区别：片头是「片子已经开始」，视觉识别优先，可以不讲因果；预告必须有触发、阻碍、升级、悬念，最后落片名和发布信息
- 游戏 PV 先分清三种：**首曝 / CG PV** 卖世界观和核心幻想；**实机 PV** 证明玩法，界面要可见；**角色 PV** 卖一个角色。本卡默认首曝 CG PV 和剧情预告，其余见变体

## 默认规格

| 项 | 先导 / 首曝 PV（60–90s） | 正式预告（90–120s） |
|---|---|---|
| 镜数 | 30–50 | 50–95（每分钟 32–48） |
| 平均镜长 | 2–3s | 1.2–2s |
| 字卡 | 2–4 张 | 3–5 张 |
| 片名卡停留 | 3–5s；做成揭示动画时 8–14s | 同左 |
| 画幅 | 2.39:1；平台另出 16:9 和 9:16 | 同左 |

## 结构模板

三幕式预告，能量一路往上推，最后在最高点骤停、落片名（90 秒占比）：

| 节拍 | 占比 | 做什么 |
|---|---|---|
| 冷开场 | ~5% | 黑场里的一个声音，或一个一眼记住的画面，打断注意力 |
| 第一幕 · 世界 | ~25% | 世界的常态和规则、主角是谁；镜头偏长，音乐只有质感没有鼓 |
| 第二幕 · 冲突 | ~30% | 打破常态的事件、威胁出现、赌注抬高；中段插一个安静拍，放一句台词 |
| 第三幕 · 高潮蒙太奇 | ~25% | 全片最快的剪辑和最大的奇观，在最高点骤停 |
| 片名 | ~8% | 片名卡，停住 |
| 发布与彩蛋 | ~7% | 发布信息卡，接一个 button（彩蛋镜：一个笑点、威胁或谜团） |

第二幕的每一镜都要回答「所以呢」或「但是」，不能只是「还有」。只加快切速不加码赌注，不算升级：景别、运动、威胁、声音、色光至少同时推两条。

## 三幕式预告与信息克制

### 只许一个承诺

整支预告只卖一个东西：一个核心幻想（「驾船在星海里航行」）、一个核心问题（「船上的人去哪了」）或一个人物困境。其余镜头都在证明它、抬高它。

| 给 | 不给 |
|---|---|
| 世界的规则和尺度 | 世界的全部设定和历史 |
| 主角是谁、想要什么 | 主角最后有没有得到 |
| 冲突和威胁的样子 | 反派的真面目、威胁的来源 |
| 高潮的一瞬（动作做到一半） | 高潮的结果 |

先导只给一个画面或一个问题；正式预告讲清前提和冲突，仍然不讲结局。

### 字卡

- 每张不超过 12 字，一张只说一件事，落在一个 hit 或一段静默上
- 字卡要有画面背书：说「最后一艘船没有回来」，前后就得有那艘船
- 分散在三幕里，按「钩子卡 → 前提卡 → 赌注卡 → 片名 → 发布卡」的层级递进，不要全挤在最后
- 出品、导演身份卡（「来自《××》导演」）放在第一幕末尾，黑底，每张约 3 秒；主创名字卡做成黑场字卡穿插在第二、三幕，每张 1–1.8 秒；一句标语可以拆成几张分散出现
- ❌「命运开启」「史诗降临」「未来已来」，放进哪部片都成立 → ✅「三百年前，那艘船没回来」，具体但不说全

### 游戏首曝的边界

- CG 画面不能冒充玩法；容易被误认成实机的地方，片尾加「CG 宣传影像，非实机画面」
- 首曝 CG PV 全程不放界面；平台、日期、价格必须由发行方确认，没确认就只写「敬请期待」或留空
- 「开放世界」「首款」「无氪金」这类说法，没有发行方确认不写

## 节奏基准

- 镜长随幕递减：第一幕 1.6–2.5s（世界观 CG PV 约 3s），第二幕 1.2–2s，第三幕蒙太奇 0.9–1.3s
- 加速分两轮，不走一条直线：两轮快切之间用一个长镜或一段对白把速度放下来；也可以在第二幕里用 1–2 次短黑场或骤停把能量放下再起
- 只有观众已经看懂画面类型之后才快切；第三幕的快切镜头，前两幕里要先出现过它的「慢版本」
- 第二幕中段的安静拍 3–6 秒：音乐退到只剩一个长音，一句台词或一个人物的脸
- 高潮蒙太奇之后骤停：0.5–1.5 秒的静默或黑场，再砸片名
- 每一个重击（braam、hit、骤停后的第一声）都要落在切点上，误差不超过 2 帧；其余切点跟着乐句走，不锁拍，也不要每拍都切
- 出彩镜头两成到三成：开场、第二幕、高潮至少各一个，片名揭示本身也可以是出彩镜头

## 招牌镜头

- **世界观大远景**：三层同框，前景人物作尺度，中景是这个世界的规则，远景是巨物
- **角色亮相**：让角色通过完成一个动作被认识（拔刀、掌舵、回头），不摆姿势排队看镜头
- **动作定格**：重预备 → 一帧极快的动作 → 停在命中或接触的瞬间
- **慢动作英雄镜**：在正常速度的混战里突然切进一个慢镜头，全片一到两次
- **黑场字卡**：黑底白字，前后各留半拍静默
- **片名揭示**：由前面立过的母题交出片名（光从门缝里透出、星图拼成片名的轮廓），后期合成字
- **button 彩蛋**：片名或发布卡之后 2–4 秒，一个让人想转发的画面；游戏长版 PV 也可以在日期、平台卡之后放一场 20 秒以上的完整小戏

## 扩展列

`信息释放`：每镜写「给：本镜新交给观众的信息 · 藏：本镜刻意不交代的东西」。给的信息归到世界、角色、冲突、赌注、片名、发布中的一类。例：「给：星槎能在星海里航行（世界）· 藏：船为什么是空的」。整片排下来，要能看出信息一层层递进，而且最后仍然藏着一个问题。

## 画风

游戏 PV 用 `cg-game`；实拍电影预告用 `realistic-cinema`；动画电影预告用 `animation-2d`。

`prompt_prefix` 参考（`cg-game`）：3A 游戏 CG 过场动画质感，电影级三维渲染，体积光与大气雾，史诗感构图，高细节材质，2.39 宽银幕构图

- `allow_text` 保持 false：片名、字卡、发布信息写进 `on_screen_text`，后期合成；字卡镜的 `frame_prompt` 写干净的底图（黑场、大片暗部或天空）
- 主角、主要载具、关键道具都建 `refs`；角色设定写清脸型、发型轮廓、服装结构、标志物和主色
- 强调色只给一个含义（比如只有「星槎」发青光），全片别到处都是这个颜色

## 声音

- 音乐三段式：铺垫（质感、脉冲，不上鼓）→ 推进（鼓进来，riser 往上推）→ 爆发（全编制）→ 骤停 → 片名 hit → 收尾的 sting
- braam、大 hit 只留给 2–3 处；要显得巨大，靠前面的对比：冲击前先静半拍
- 台词碎片放在安静拍里，一句话重新定义赌注；旁白比解说少，不替画面解释没拍到的东西
- 音乐要有头有尾：开场立一个两三个音的动机，片名处到最高点，用一个明确的终止收住
- 不要给每个切点都配 whoosh

## 常见坑

- 把预告做成缩短版正片，剧透了结局
- 第二幕变成平铺的清单：一个接一个的奇观，彼此没有因果、赌注没涨
- 前半段把奇观用完，后半段只剩大字和同一个慢镜头
- 每个切点都有 whoosh 和 boom，音乐没有动机也没有终止
- 字卡套话，或者全部挤在片尾
- 游戏 PV 里 CG 冒充实机、编造平台和日期
- 让出图模型直接画片名和字卡，字错了没法改

## 变体

- **实机 PV**：保留界面，结构改成「钩子 → 玩家做什么 → 核心玩法证明 → 系统和敌人升级 → 英雄时刻 → 平台与日期」，玩法镜头要看得清操作；也可以让相邻镜头的视觉焦点留在画面同一区域，每一刀换一个新地点、新敌人或新机制，裁掉 HUD、保留音效
- **角色 PV**（30–60s）：一个角色，「钩子 → 亮相 → 能力或情绪展开 → 高潮动作 → 定版」，卖点在角色魅力、技能、剧情三选一
- **剧情片正式预告**：第二幕加长，用台词碎片串起前提；镜数按 1.2–2 秒均长算
- **竖屏版（9:16）**：前 2 秒放最强的画面，主体放画面中上，字卡加大

## 顶尖范本

写分镜前挑一部最接近的范本，照它的排法走。实测镜长和来源见 `references/benchmarks.md`。

| 范本 | 导演 / 创作者 | 学它怎么排 |
|---|---|---|
| 《社交网络》正式预告 | Mark Woollen & Associates | 7 秒黑场先进合唱版 Creep；前三成只用界面、照片、单词蒙太奇立母题，再进对白；三段镜长 1.6→1.2→0.9 秒 |
| 《盗梦空间》预告 #3 | 华纳兄弟（配乐 Zack Hemsey） | 第一幕末两张黑底导演身份卡；重击处都有切点；5 秒慢镜高潮→0.9 秒黑场→碎片拼片名→4 秒 button→日期 |
| 《深海迷航》（Subnautica）预告 | Derek Lieu | 12 秒高强度冷开场后放慢讲玩法，旁白交代核心循环；升级段堆生物和建造，一句不祥台词后上 logo |
| 《黑神话：悟空》最终预告 | 游戏科学 | 6 秒黑场 logo 接 14 秒山崖运镜立世界；两轮加速中间插 10 秒长镜；水墨片名生长约 14 秒，日期后接 25 秒剧情 button |
| 《流浪地球2》终极预告 | 郭帆团队 | 两张黑场字卡后接 8.7 秒长镜压旁白；主创名字卡做成 1–1.8 秒黑场书法卡穿插；片名后再用 6 镜收旁白 |

- 冷开场都不靠快切（前 3 秒 0–2 刀），靠一个声音加一个慢画面：黑场里先进歌声、一句旁白压在长镜上、一个立世界的运镜

## 节奏审核参数

`review.py` 按下面的参数做节奏机检，规则见 `references/director-review.md`。项目属于本卡里的某个子类型（例如竖屏短版、一镜到底、长版）时，在 `project.asl`、`project.hook` 里写那个子类型的平均镜长区间和钩子时限。

```pace
asl = 1.2-3
cps = 3.5
slack = 1
hold = 6
hook = 6
```

asl 平均镜长区间（秒）· cps 台词旁白舒适语速（字/秒）· slack 有台词镜头的余量（秒）· hold 无台词镜头的停留上限（秒）· hook 钩子最晚结束（秒，0 表示不查）
