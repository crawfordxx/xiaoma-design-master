# 达人口播 / 带货种草

## 判定信号与相邻片种

- 信号：口播、种草、带货、好物分享、测评、开箱、探店、UGC、KOC / KOL、达人视频、挂车、小红书 / 抖音带货
- 一句话判断：**有一个具体的人对着镜头，用自己的体验推荐一样东西**
- 和 **TVC** 的区别：TVC 没有人对镜说话，靠创意、画面、旁白和音乐讲，追求完美；口播靠这个人的真实体验和信任感，「像朋友推荐」，允许生活化的乱和小瑕疵
- 和**产品宣传片**的区别：产品片是品牌视角，棚拍、讲参数、不说缺点；口播是使用者视角，在真实生活里用，会说缺点
- 和 **Vlog** 的区别：Vlog 记录生活，产品顺带出现；口播是为这个产品拍的，最后要有行动引导
- 和**教程**的区别：「三个技巧」如果主角是一个产品、结尾挂链接，是口播；不卖东西、每步完整可复现，是教程
- 和**竖屏短剧**的区别：「剧情种草」算口播的变体——剧情只占前半段，后半段达人出戏推荐产品

## 默认规格

| 项 | 15s | 30s | 60s |
|---|---|---|---|
| 镜数 | 8–11 | 13–21 | 24–40 |
| 平均镜长 | 1.3–2s | 1.4–2.3s | 1.5–2.5s |
| 画幅 | 9:16 | 9:16 | 9:16 |
| 口播字数 | 65–75 | 130–150 | 260–300 |
| 卖点数 | 1 个 | 2–3 个 | 3–4 个 |

分镜按口播 4.5–5 字/s 排，单镜不超过 5 字/s。真人实拍时头部达人会说到 5.5–6.5 字/s，分镜按 5 排是给现场留余量。口播里的说话人名字也计入字数，画外口播写进 `vo`，不用写名字。

## 结构模板

30 秒版占比：

| 节拍 | 占比 | 做什么 |
|---|---|---|
| 黄金 3 秒 | ~10%（0–3s） | 一句戳中处境的话 + 一个有信息的画面，同时出现 |
| 痛点 | ~15% | 达人自己的具体处境：几点、在哪、狼狈在哪；段末（第 8–12 秒）一句留存钩，承诺看完能得到什么：「这条一定要看完，教你怎么挑」 |
| 产品登场 | ~12% | 产品出现在达人手里，进入她的真实生活 |
| 真实体验 | ~40% | 2–3 个卖点，每个一次真实使用 + 一个看得见的结果 + 一句第一人称感受 |
| 信任补强 | ~13% | 主动说一个缺点或使用限制；或者给一个对比、一个细节 |
| 行动引导 | ~10%（2–4s） | 谁适合 + 去哪买，达人看镜头、指向购物车的位置 |

15 秒版：黄金 3 秒 → 一个卖点的真实使用 → 行动引导，三拍就够。

其他常用结构：
- **测评**：结论先说 → 按维度一项项测（同一测试条件，每个维度一句标准 + 一个手上测试动作，4–8 秒）→ 适合谁、不适合谁 → 1–3 张总结卡（每张 2–3 秒）
- **开箱**：包装 → 第一眼 → 细节 → 第一次用 → 一句评价
- **探店**：门头和排队 → 招牌菜上桌 → 第一口的反应 → 价格 → 地址和营业时间
- **剧情种草**：一个小冲突（前 40%）→ 产品解决 → 达人出戏推荐
- **清单体**：「通勤包里的三样东西」，每样 8–10 秒，同一个版式；测评清单可以压到 1 秒一款，后面用总结卡兜底

## 黄金 3 秒 + 真实体验 + 行动引导

口播卖的是「这个人信得过」。观众划走只要 1 秒；留下来，是因为开头戳中了自己；下单，是因为看见了真实的使用，而不是听到了形容词。

**黄金 3 秒**：第一句话和第一个画面同时成立，各自都带信息。
- 能用的开法：结果先行（举着一杯刚打好的果昔）、痛点正在发生（地铁上干啃面包）、反差（嘴上说「榨汁机」，手里是巴掌大的杯子）、直接给答案（「通勤早饭，我只用这一个」）
- 不要的开法：「哈喽大家好我是 xx」「今天给大家分享一个好物」、产品静物空镜、片头 logo
- 前 3 秒（约 15 字）内说出钩子核心词（价格反差、痛点、数字），整句可以到 25–35 字、7 秒内说完；第一镜可到 4 秒，但镜内 1–2 秒要跳出花字或贴纸；首帧就要有人或产品，叠一行钩子花字
- 品牌名不放在第一句，产品入画时再说

**真实体验**：每个卖点拆成「一个动作 + 一个看得见的结果 + 一句第一人称感受」。
- 卖点用达人自己的话说，不念品牌文案
- 主观感受用「我觉得」「我每天」；硬指标（时长、容量、续航）只说品牌方给了实测、达人自己复现过的
- 在真实生活空间里用：玄关、地铁、工位、厨房，不进影棚

**真人信任感**：
- 达人的脸清楚出镜、眼神看镜头；建角色 `refs`，每镜造型一致
- 主动说一个缺点或限制（「一次只够一人份」「打的时候有声音」），比十句夸更可信
- 口语：短句、停顿、语气词，允许不完整的句子；不用排比和金句
- 手持轻晃、跳切都可以，那是在场感，不是粗糙

**行动引导**：说清「谁适合」+「去哪买」。
- 和平台的挂车方式一致（左下角购物车、评论区置顶）；没有确定的优惠就不说优惠
- 最后一镜回到达人的脸，看着镜头说完再收
- 不挂车的种草内容收在「总结 + 点赞收藏 + 转发给某个具体的人」（天天旅行的朋友、闺蜜），或一句「产品没有好坏，只有合不合适」

| | ❌ 像广告 | ✅ 像朋友推荐 |
|---|---|---|
| 开场 | 「哈喽大家好，今天给大家推荐一款榨汁杯」 | 扶梯上从包里掏出一个小杯子：「我每天背着榨汁机上班。」 |
| 卖点 | 花字「强劲动力 · 极速破壁」 | 按下按键，手机凑近收音：「你听，三十秒就打好了。」 |
| 信任 | 「真的超级好用，闭眼入」 | 「缺点也说下：打的时候有声音，地铁上别用。」 |
| 引导 | 「赶紧去买吧」 | 「没空吃早饭的，链接在左下角。」 |

**合规**：不用「最」「第一」「100%」这类绝对化用语；食品、个护不说功效（「排毒」「瘦身」「美白」）；不编造销量、好评和第三方证言；商业合作按平台要求标「广告」或合作标识。

## 节奏基准

- 前 3 秒说出钩子核心词；第一镜不超过 4 秒，镜内要有花字或贴纸变化
- 口播主镜（A-roll）1.5–4 秒一刀跳切，讲原理的长句最长 5.5 秒；每 1–2 秒画面要有变化：跳切换一级景别、花字、贴纸、插产品特写、切手部操作、插示意图
- 跳切剪掉停顿和口误，前后两镜景别差一级，避免跳帧感
- 测评型体验段 B-roll 占一半以上：口播说到哪个动作，就给到那个动作的特写；知识型口播 A-roll 可占七八成，靠花字、贴纸、示意图保持变化
- 花字跟着口播关键词蹦出来，一屏一个关键词
- 行动引导 2–4 秒，达人看镜头，手指向购物车所在的位置
- 30 秒里出彩镜头 2–3 个：反差开场、一个强证明动作、和开头呼应的结尾

## 招牌镜头

- **对镜口播**：中近景，手机前置或支架，人物在画面中上部，眼神看镜头
- **怼脸展示**：达人把产品举到镜头前，产品占画面 1/3 到 1/2，脸在后面
- **第一视角**：手部操作，模拟观众自己在用
- **声音证明**：凑近收音，开盖、研磨、气泡、咔哒
- **强证明动作**：倒过来不洒、摔一下没事、一擦就干净，一个动作顶十句形容词
- **第一口反应**：喝第一口、尝第一口的表情
- **场景串联**：同一个产品在家、路上、工位三个场景里出现
- **收尾指向**：达人看镜头，手指向左下角
- **常驻导航条**：顶部或侧边写章节（材质 / 轮子 / 把手）或「产品名 + 适合谁」，整段不撤
- **总结卡**：测评和清单体结尾 1–3 张，每张 2–3 秒

## 扩展列

- `素材`：这一镜是 A-roll（对镜口播）还是 B-roll（产品特写、手部第一视角、生活场景），以及机位。例：「A-roll · 手机前置自拍 · 手持」「B-roll · 手机支架放在台面 · 固定」。达人照这一列分两轮拍：先一口气录完 A-roll，口播才连贯自然；再补 B-roll
- `卖点证明`：这一镜在证明哪个卖点、用什么可见的动作证明；铺垫镜写痛点，收尾写行动引导。例：「卖点『不漏』· 杯子倒过来晃，一滴不洒」「痛点 · 早饭只能干啃面包」。整列扫一遍，就知道每个卖点有没有真的被拍到

花字写在 `on_screen_text`，注明位置（顶部大字、跟随口播的关键词、左上角合作标识）。

## 画风

默认 `realistic-vertical`。

`prompt_prefix` 参考：竖屏达人视频截图，手机拍摄的真实生活画面，人物是画面主体，自然明亮的环境光，色彩清新，竖构图

- 前缀里写「手机拍摄」「真实生活」「环境光」，避免画成棚拍广告
- 达人必须建角色 `refs`（type: character），写清发型、眼镜、衣服、包这类一眼认人的东西；产品必须建 `refs`（type: product），写清材质、颜色、按键位置
- 竖构图，人物和产品放画面中上部，下方三分之一留给字幕和购物车
- 花字、产品上的字和 logo 都不画进图，后期贴

## 声音

- 分镜按口播 4.5–5 字/s 排；30 秒全片口播 130–150 字
- 同期声为主：A-roll 收达人原声，保留一点环境声（地铁报站、办公室键盘），在场感比干净重要
- 产品的声音凑近收：开盖、按键、电机、倒水
- BGM 是背景：轻快、音量压低，产品声音出来时让开半拍
- 口播先写成一段完整的话通读一遍，像一个人连续在说，再拆到各镜

## 常见坑

- 开头自我介绍、寒暄，或者用产品空镜开场
- 念品牌文案：「采用 xx 科技」「高效破壁」，一听就是广告
- 只说不演：卖点全靠嘴，画面一直是达人的脸
- 一条片塞五六个卖点，每个一句带过
- 完美得不真实：影棚光、精修脸、不说任何缺点
- 夸大功效、用绝对化用语，或编造销量和评价
- 没标合作标识，或者说了并不存在的优惠
- 结尾没有行动引导，或者手指的方向和平台挂车的位置对不上

## 变体

- **测评对比**：同一测试条件下拍，结果放进同一画面；说清测试方法，不贬低具名竞品
- **探店**：门头、招牌菜、第一口、价格、地址五样不能少；店名和地址用字幕写清
- **剧情种草**：前 40% 演一个小冲突，产品出来解决，达人出戏对镜推荐；剧情台词同样按每秒 5 字算
- **无脸口播**：只露手和产品，第一视角 + 画外口播；信任感靠手部的真实操作和声音
- **横屏长测评（3–10min）**：按维度分章，每章结论先行，片尾一张总结表
- **横屏长视频赞助段**：放在全片 1/3 前后，或开头预告、片尾正式段；45–90 秒；用正片话题双关或剧情关卡接入，不要「接下来介绍一下赞助商」硬切；8 秒内点名赞助方；CTA 约 10 秒、只给一个动作，然后回正片

## 顶尖范本

写分镜前挑一部最接近的范本，照它的排法走。实测镜长和来源见 `references/benchmarks.md`。

| 范本 | 导演 / 创作者 | 学它怎么排 |
|---|---|---|
| 骆王宇 #好物day | 骆王宇 | 第一句价格反差问句（50 块对 500 块）；1–2 秒一刀跳切，每镜一个关键词花字加贴纸；单品段顶部常驻产品名条 |
| 《贵的行李箱就一定好吗》 | 老爸评测 | 1.9 秒问句 → 四宫格痛点 → 第 9 秒留存钩；5 个维度各一句标准加一个手上测试；总结卡后点名转发给谁 |
| 《20 款面霜 60 人实测》 | 老爸评测 | 开头 4 个数字字卡快切；20 款产品每款 1 秒红绿灯评分；「太快了看不清？」接 3 张总结卡 |
| MrBeast 赞助段（CoD Mobile） | MrBeast | 赞助放在全片 39% 处做成剧情关卡，开始约 8 秒就点名赞助方；卖点句穿插在对战画面里，约 85 秒 |
| Linus Tech Tips 赞助段（boot.dev） | Linus Tech Tips | 开头用话题双关接 30 秒预告小剧，正式段放片尾约 80 秒；最后 10 秒只给链接加优惠码 |

- 范本都给观众一个看完的理由：留存钩、常驻导航条或总结卡，至少用一样

## 节奏审核参数

`review.py` 按下面的参数做节奏机检，规则见 `references/director-review.md`。项目属于本卡里的某个子类型（例如竖屏短版、一镜到底、长版）时，在 `project.asl`、`project.hook` 里写那个子类型的平均镜长区间和钩子时限。

```pace
asl = 1.3-3
cps = 5
slack = 0.8
hold = 3
hook = 3
```

asl 平均镜长区间（秒）· cps 台词旁白舒适语速（字/秒）· slack 有台词镜头的余量（秒）· hold 无台词镜头的停留上限（秒）· hook 钩子最晚结束（秒，0 表示不查）
