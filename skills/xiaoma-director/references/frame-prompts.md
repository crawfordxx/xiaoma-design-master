# 分镜图提示词

默认面向 GPT Image（gpt-image 系列），中文提示词效果好。用 Midjourney 等以英文为主的模型时，可以在自定义出图命令里先把提示词译成英文。`frames.py` 拼出的最终提示词是：

```
{style.prompt_prefix}，景别：{shot_size}，角度：{angle}，{frame_prompt}，{文字限制}
```

所以 `frame_prompt` 里不用重复画风和景别，专心写这一格画面。

## frame_prompt 写法

按「主体 → 动作 → 环境 → 构图位置 → 光线」写一句到三句：

- ✅ 二十多岁的短发女生站在地铁车厢门边，右手握着一瓶琥珀色冷萃咖啡贴在脸颊，窗外是飞速后退的城市高楼，人物在画面左三分之一，清晨侧逆光勾出发丝轮廓
- ❌ 女生很开心地喝咖啡，体现青春活力（「体现」画不出来）

要点：
- 只写看得见的东西；情绪写成表情和动作（「嘴角压着笑」「攥紧了拳头」）
- 写清主体在画面里的位置（左三分之一、居中、前景虚化的门框后）
- 竖屏（9:16）写「竖构图」，主体放在画面中上部，下方给字幕留空
- 有设定的角色或产品，`frame_prompt` 里用设定的固定称呼并带上 1–2 个关键外观词（如「穿墨绿冲锋衣的男主」），同时把设定 id 写进本镜 `refs`
- 运镜画不出来：推拉摇移写进 `movement`，`frame_prompt` 只画这一镜最有代表性的那一帧（通常是起幅或动作最饱满的瞬间）
- 一格只画一个瞬间，不要「先……然后……」

## 一致性

- 跨镜出现的角色、产品、关键场景建成 `refs`。`frames.py` 先出设定图，再让引用它的镜头带着设定图改图，人物脸、服装、产品外形会稳很多
- 每个镜头最多带 4 张设定图；空镜、环境镜头不挂设定，走文生图更快
- 产品设定图 prompt 写清材质、颜色、外形、标签位置；角色设定图写清年龄、发型、服装、体态，用全身正面
- 全片共用一个 `prompt_prefix`，不要在单镜里另换画风

## 画风库（`style.frame_style` → `prompt_prefix`）

片种卡会指定默认画风，可按项目调整前缀里的具体词。

| frame_style | 适用 | allow_text | prompt_prefix 参考 |
|---|---|---|---|
| `realistic-cinema` | TVC、品牌片、微电影、文旅、MV、实拍预告 | false | 电影剧照质感，真实摄影，电影级布光与调色，浅景深，细腻胶片颗粒，2.39 或 16:9 宽银幕构图 |
| `realistic-studio` | 产品宣传片、电商主图视频 | false | 高端商业产品摄影，影棚布光，柔光箱与轮廓光勾边，干净背景，材质与反光细节清晰，商业精修质感 |
| `realistic-vertical` | 竖屏短剧、达人口播 | false | 竖屏短剧剧照，真实摄影，人物是画面主体，明亮清晰的布光，色彩饱满，竖构图 |
| `documentary-natural` | 纪录片、vlog、活动纪实 | false | 纪实摄影，自然光，真实环境，不摆拍，略带手持的不完美构图，柔和颗粒，色彩自然克制 |
| `ui-screen` | 软件教程、产品演示 | true | 软件教程录屏画面，清晰的扁平化界面，界面文字清楚可读，带鼠标指针和高亮框标注，干净的桌面背景 |
| `animation-2d` | 2D 动画短片 | false | 日系手绘 2D 动画电影画面，水彩质感手绘背景，干净的线条与赛璐璐上色，温暖柔和的色调 |
| `cg-game` | 游戏 PV、CG 预告 | false | 3A 游戏 CG 过场动画质感，电影级三维渲染，体积光与大气雾，史诗感构图，高细节材质 |
| `illustration-info` | 知识科普、解说 | true | 扁平插画科普风格，简洁的几何造型角色与物件，清晰的信息图元素和简短标注，柔和统一的配色，浅色背景 |
| `flat-mg` | MG 动画、数据可视化 | true | 扁平矢量 MG 动画画面，几何图形与图标，数据图表元素，统一的品牌配色，干净留白，构图规整 |
| `motion-design` | 片头、活动开场 | true | 高端动态视觉设计画面，抽象几何与粒子光效，深色背景上的霓虹光线，科技感三维图形，标题字体现代简洁 |

`allow_text: true` 时，图里需要的字直接写进 `frame_prompt` 并用「」标出，如：界面左上角菜单栏写着「插入」。字越短越稳，一格最多一两处文字。

界面、数据面板类画面（软件演示、深色 UI 风格）里，模型会自己往按钮、表格、步骤条里补中英文小字，而且常和设计对不上。除了用「」标出的那一两处，其余文字写成「灰色占位条，不出现可读文字」。

## logo 和品牌标识

生图模型画不准 logo，没写清楚时还会自己编一个标志。凡是出现 logo 的镜头：
- `frame_prompt` 里写「画面里不要画任何 logo、商标或品牌字」，并写清给 logo 留的空位（位置、大小、背景要干净平整，例如「画面中上方留出约一半画宽的纯深色空位」）
- 出图后用用户给的 logo 文件后期合成到空位上；深色画面用白字版，浅色画面用原版，按原比例缩放，不拉伸变形
- 这一镜的 `notes` 写「logo 为真实素材后期合成」。用户没给 logo 文件时，在 `open_questions` 里要
- 第三方平台（亚马逊、TikTok 等）同样不画官方 logo，用通用图标加平台名字幕

只有用「」标出的字会被放行：`frame_prompt` 里没有「」的镜头和所有设定图，`frames.py` 仍会加「不要出现任何文字」。不这样做的话，模型会在空白处自己编会名、标语和英文标题，再经由设定图传到后面每一镜。
