# 视频制作路线:按片种筛选

分镜表只是中间产物,最终要成片。本页回答:**这个片种的视频该怎么产出来,哪条路线真的有用**。配置见 README「配置视频模型」,出片流程见 SKILL.md 第 8、9 步。

## 三条路线

| 路线 | 做法 | 适用条件 |
|---|---|---|
| **A 全生成** | 每镜直接用视频模型出片段(`video_render.py`),拼接收尾 | 画面虚构或难以实拍:剧情、动画、概念、空镜质感 |
| **B 混合** | 实拍 / 录屏为主体,视频模型只补空镜、B-roll、转场、难拍镜头 | 主体必须真实:真人、产品实物、界面操作、现场素材 |
| **C 图板动效** | 只出分镜图(现有流程),动效在剪辑 / 动效软件里做 | 设计驱动、矢量图形为主,视频模型收益低 |

## 17 片种路线表(筛选结论)

| 片种 | 路线 | 理由与要点 | 状态 |
|---|---|---|---|
| 竖屏短剧 | **A** | 逐镜生成 + 跨镜一致性靠设定图;先用低档模型出小样再换高档 | ✅ 全链实测 |
| 动画短片 | **A** | 同短剧;画风锁写进 prompt_prefix | 链路就绪 |
| 微电影 / 剧情短片 | **A** | 片长较长,按段落分段出片;先做 60–90s 段落(同 scope 逻辑) | 链路就绪 |
| MV | **A** | 歌词对位分镜已有扩展列;生成片段按 beat 长度切 | 链路就绪 |
| 预告片 / 游戏 PV | **A** | 三幕递进节奏已有基准;高光镜用高档模型 | 链路就绪 |
| 片头 / 开场片 | **A** | 短、密、风格化,生成收益最高的一类 | 链路就绪 |
| TVC 广告 | **A/B** | 概念段生成;**产品实物必须参考图模式**(带产品图出镜),logo 留空后期合成 | 链路就绪 |
| 产品宣传片 | **A/B** | 同 TVC;功能演示若拍实物更可信 | 链路就绪 |
| 品牌宣传片 | **A/B** | 情绪段生成 + 实拍人物素材混合 | 链路就绪 |
| 文旅宣传片 | **B** | **地标实景有版权与真实性问题,生成只做氛围空镜与转场**,主体用实拍素材 | 链路就绪 |
| 知识科普 | **A/C 混** | 讲解画面用生成镜头打底,图表数据仍靠图示设计 | 链路就绪 |
| MG 动画 | **C** | 矢量设计驱动,视频模型不擅长,走分镜图 + 动效软件 | 不建议生成 |
| 教程 | **B** | 录屏为主体;补开场钩子镜头与转场空镜 | 链路就绪 |
| 达人口播 / 带货 | **B** | 真人口播为主;生成只做开箱质感镜头、场景空镜 | 链路就绪 |
| 纪录片 | **B** | 纪实素材不可生成替代;补历史再现、空镜、氛围段 | 链路就绪 |
| Vlog | **B** | 个人素材为主;开场片头可用 A 路线 | 链路就绪 |
| 活动纪实 | **B** | 现场素材为主;开场倒计时与回顾混剪段可用 A | 链路就绪 |

**状态口径**:✅ 全链实测 = 竖屏 3×5s 样片从分镜到成片完整跑通(真实模型出片、质检、拼接字幕);链路就绪 = 代码与协议就位,未做整片实测,首片时先小样验证。

## 剧情类片种的剧本层

短剧、微电影、动画这类**多集 / 长片**,直接写分镜会失焦。在片种卡和 storyboard 之间加一层剧本(对话完成,不写代码):

1. **剧本摘要**:创意 → 结构化摘要(集数、人物小传带成长弧「A -> B -> C」、一句话主线+最大反转、200–400 字梗概)
2. **分集大纲**:严格按目标集数出「集名(4–12 字,概括冲突)+ 每集钩子」,相邻集要有因果衔接
3. **分集正文**:按场写(场号 / 日·内外·景 / 出场人物 / △动作 / 台词(情绪·vo·os)),每集 2–4 场
正文通过导演审核后,每场拆成分镜进 storyboard.json。其余 14 个片种不需要这层,直接进分镜。

## 出片与质检

1. `python3 $SD/video_render.py <dir>/storyboard.json` 干跑,先看每镜提示词
2. 确认后 `--live` 真出片(默认只出缺的镜头,换模型自动全部重出)
3. `python3 $SD/video_qa.py <dir>/storyboard.json --scores '{...}'` 七维打分写回
4. 判决即修复路由:**repair(75–60)→ 局部修改**(原片+指令,只改问题点);**fail(<60)→ 整镜重出**

## 成本与安全

- 先低档出小样,满意再换高档 `--shots` 逐镜升级
- 真出片前过一遍片种卡的合规要点;生成片段同样遵守「画面里不要文字」
- 上游内容审核可能拦具名 IP 角色、名场面——剧情类先做去 IP 化改写再出片
