# 镜头语言速查

写分镜时按需查。只在 storyboard.json 里写术语本身，不要把这里的解释抄进表格。

## 1. 景别（`shot_size`，一镜只写一个）

| 景别 | 画面范围 | 什么时候用 |
|---|---|---|
| 大远景 | 人小到几乎看不清，环境压倒一切 | 开场定地点、规模感、孤独感、片尾抽离 |
| 远景 | 人能辨认，环境仍占大半 | 交代人与环境的关系、行进路线 |
| 全景 | 人物全身完整入画，头脚留空 | 交代动作全貌、站位关系、场景建立 |
| 中全景 | 膝盖以上 | 走动、两三人互动，兼顾动作和表情 |
| 中景 | 腰部以上 | 对话主力景别、日常动作 |
| 中近景 | 胸部以上 | 对话里需要更多表情时 |
| 近景 | 肩部以上 | 情绪、反应、关键台词 |
| 特写 | 脸部或一个物件占满画面 | 情绪顶点、产品卖点、关键道具、细节信息 |
| 大特写 | 眼睛、指尖、材质纹理 | 冲击点、悬念、质感（水珠、纤维、齿轮） |

**连接规律**
- 约六成切镜在相邻一级景别之间完成，观众不觉得跳。
- 跨两级以上的跳切（全景→特写）是武器：用在惊讶、翻转、情绪断裂的点上，不要平均撒。
- 场景内常见走向：推近（远→近，从环境进入人物）；拉远（近→远，抽离、揭示更大空间，适合收尾）；弹跳（中→特→中，先强调细节再回到关系）。
- 同景别连续超过 4 镜要有明确意图（压抑、平静、对峙），否则就是单调。

## 2. 角度（`angle`）

平视 · 俯拍 · 仰拍 · 顶拍（正上方垂直向下）· 低机位（贴地）· 荷兰角（倾斜）· 主观镜头（角色视点）· 过肩 · 侧面 · 背面

- 仰拍让主体显得强大、压迫；俯拍让主体显得弱小、被审视；顶拍适合展示布局、桌面、人群图案。
- 荷兰角只用在失序、眩晕、危险，全片一两次。
- 主观镜头后面通常接一个看的人的反应镜头（视点剪辑）。
- 同一主体前后两镜，机位角度变化不到 30° 又是同景别，会像跳帧：要么换景别，要么换角度超过 30°。

## 3. 运镜（`movement`）

| 运镜 | 效果 | 常见用法 |
|---|---|---|
| 固定 | 稳、客观、让画面内的动作说话 | 对话、产品定格、纪实观察 |
| 推 / 缓推 | 聚焦、逼近、情绪加压 | 进入人物内心、强调卖点 |
| 拉 / 缓拉 | 抽离、揭示 | 结尾、揭示环境或反转 |
| 摇（横摇 / 竖摇） | 扫视空间、交代两点关系 | 从人摇到物，从楼底摇到楼顶 |
| 移（横移 / 平移） | 并行陪伴、展示一排事物 | 跟着人物走过街道、货架 |
| 跟拍 | 沉浸、紧迫 | 人物行进、运动、纪实跟随 |
| 升 / 降（摇臂） | 情绪上扬或沉落、开合空间 | 开场升起俯瞰、结尾降到人物 |
| 环绕 | 突出主体、仪式感 | 产品展示、人物高光时刻 |
| 手持 | 真实、不安、在场感 | 纪实、vlog、冲突 |
| 稳定器跟随 | 流畅的长距离运动 | 穿越空间、一镜到底 |
| 航拍 | 尺度、地理、壮阔 | 文旅开场、城市、赛事 |
| 变焦推拉 | 刻意、复古或纪实感 | 新闻感、真人秀感 |
| 甩镜 | 速度、转场 | 两镜之间做快速连接 |
| 希区柯克变焦（推轨变焦） | 眩晕、顿悟 | 全片最多一次 |
| 微距滑轨 | 材质、精密感 | 产品、食物、工艺 |

运镜要有动机：人物没动、信息没变时，镜头不要无理由游动。

## 4. 转场（`transition`）

硬切（默认）· 叠化（时间流逝、情绪延续）· 匹配剪辑（形状、动作、色彩相似的两镜相接）· 动作剪辑（在动作中途切）· J-cut（下一镜声音先进）· L-cut（上一镜声音延续）· 遮挡转场（主体或前景挡满画面）· 甩镜转场 · 白闪 · 黑场（段落结束、留白）· 跳切（同一机位时间跳跃，vlog、口播常用）· 卡点切（踩音乐节拍）

同类场景切换在全片里用同一种转场，保持一致。

## 5. 连续性

- **轴线（180°）**：两人对话时，摄影机始终在两人连线的同一侧。要越轴，先用一个骑在轴线上的镜头（正面、背面）或让人物移动带过去。
- **视线匹配**：A 看向画右，下一镜被看的 B 就该看向画左。
- **方向一致**：人物从画左走出，下一镜从画右走入，方向才连得上。
- **道具与状态**：杯里的水量、衣服、手里拿的东西，前后镜一致。一场多人戏先写清站位（谁在左、谁在右、锚点是什么），再逐镜写变化。

## 6. 镜头时长与信息量

- 一镜只承担一个职责：交代一件事、一个反应、一个卖点。
- 观众读懂画面需要的时间：大远景、全景信息多，2–4 秒以上；特写信息单一，1–2 秒即可。
- 有台词或旁白的镜头，时长至少要够把话说完（中文约每秒 4–5 字）。
- 快节奏不等于每镜都短：在快切段落里放一个长停留，那一镜会被记住。克制也不等于匀速：再慢的片子也要有一段变奏。

## 7. 动作-反应与 7:3 配比

镜头设计的基本单位是**一个动作 + 一个反应**：一句话 → 对方的表情；门打开 → 门里的人；产品亮出 → 使用者的笑。

- 七成以上的镜头用常规手法（标准正反打、动作→反应、蒙太奇并置、递进）撑起骨架，清晰、可靠、不抢戏。
- 一到三成留给出彩镜头：视觉隐喻、揭示反转、首尾呼应、反差并置、留白省略、视觉奇观。出彩镜头要嵌在常规镜头中间，连续出彩就不出彩了。
- 叙事驱动的片子出彩比例一成左右就够，作者性强、概念型的片子可以到三成。

## 8. 叙事目的（`purpose`）怎么写

回答「这一镜为什么必须存在，删掉会少什么」。写功能和对观众的效果，不写形容词堆砌：

- ✅ 交代早高峰的拥挤，给后面「一瓶在手的从容」做对比
- ✅ 让观众先看到结果（满地碎片），再回头看原因
- ❌ 画面很美，氛围感拉满
- ❌ 体现了品牌的温度与情怀

## 9. 画面内容（`visual`）怎么写

只写镜头拍得到的东西：谁、在哪、做什么动作、画面里有什么、光线和空间位置。

- 不写心理活动（意识到、内心、心想、感到）：改写成可见的动作和表情。「她意识到迟到了」→「她看了一眼手机，抓起包冲向门口」。
- 不写括号暗示（「其实是在掩饰紧张」）。
- 竖屏画面写清主体在画面里的上下位置。
