# 交付前自检清单

在内部过一遍，有问题直接改，不用把清单贴给用户。

## 片种与规格
- [ ] 片种判定有依据；用户说过的时长、画幅、平台、受众都照办了
- [ ] 推断出来的规格写进了 `assumptions`
- [ ] 取段落的长片种写清了 `segment_note`（全片多长、取哪一段）

## 结构与节奏
- [ ] 节拍结构用的是片种卡里的模板（或有理由地改了），节拍时长和镜头时长都对得上总时长
- [ ] 开头几秒有钩子（广告、短视频、短剧尤其要）
- [ ] 镜头长短有变化：快切段落里有停留，慢片子里有变奏
- [ ] 出彩镜头一到三成，分散在开头、转折、结尾，没有扎堆

## 每一镜
- [ ] 一镜一个职责，`purpose` 写的是功能而不是形容词
- [ ] `visual` 只写拍得到的；没有心理描写和括号暗示
- [ ] 景别、角度、运镜有动机；相邻镜头没有无意义的重复
- [ ] 台词和旁白在本镜时长内说得完
- [ ] 片种扩展列每镜都填了，内容有用，不是凑字

## 连续性
- [ ] 对话没越轴；视线、运动方向前后接得上
- [ ] 角色服装、道具、产品外观前后一致；跨镜出现的都建了 `refs` 并挂到对应镜头

## 声音
- [ ] 台词、旁白、音效、音乐分开写；音乐的进入、卡点、收尾标在对应镜头
- [ ] 结尾的品牌露出、口号、CTA（如有）和声音同步

## 出图
- [ ] `prompt_prefix` 符合片种画风；需要界面文字或图表时 `allow_text` 设为 true
- [ ] 每张图和该镜的景别、画面内容对得上；不对的用 `frames.py --only sNN` 重出
- [ ] `validate.py --frames` 通过，HTML 已渲染

## 事实与授权
- [ ] 没有编造产品功效、数据、奖项；健康、金融类表述克制、可核验
- [ ] 不冒用真实品牌、名人的形象和名义；用户提供的素材标注了授权状态（未知就写进 `open_questions`）
