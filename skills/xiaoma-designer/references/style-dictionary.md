# 表现层：风格词典

> 摄影接管"像"之后，视觉的价值转向"表现"。流派是前人验证过的视觉词汇表——选一个，比发明一个稳。

## 使用方法

1. 拿策略层的「基调关键词」在下表"情绪适配"列匹配 1-2 个候选流派
2. 读该流派"视觉特征"，转写成提示词/设计规则
3. 提示词里**必须**包含：流派名 + 媒介质感 + 2-3 个特征词；禁用空泛词（精美/高级/大气）

## 媒介质感词（叠加用，去 AI 味的关键）

丝网印刷颗粒 / 纸张纹理 / 版画肌理 / 胶片颗粒 / 水彩晕染边缘 / 粗糙铅笔线 / 孔版印刷
→ screen-print grain, paper texture, film grain, risograph

## 像与表现

- AI 生图的默认倾向是"像"（讨好眼睛的平均脸），必须用流派 + 质感词把它拽向"表现"
- 一张图只属于一个流派世界；混搭仅限"主风格 + 媒介质感"

## 人文底蕴检查（AI 味排除清单）

- [ ] 有明确的流派/媒介，而非"高清、唯美、梦幻"
- [ ] 有可说出的"想法"（一个视角、一个并置、一个瞬间），而非元素堆砌
- [ ] 有不完美（笔触、颗粒、留白），而非无菌感
- [ ] 画面元素彼此讲同一个故事

## 四重境界（自我表达成熟度，供自评）

1. 不知道自己不知道：套模板，感觉良好
2. 知道自己不知道：能看出差距，说不出原因
3. 知道自己知道：能拆解任何作品的层次与手法
4. 忘掉套路：规范内化后的自由表达，从心所欲不逾矩
