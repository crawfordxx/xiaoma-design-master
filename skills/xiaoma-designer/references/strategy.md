# 策略层：想清楚再动手

> 设计不是装饰，是传达。画面上每一个元素都要回答："它帮传达了吗？"

## 1. 通信模型（底层框架）

```
信源(生产者) ──编码──> 信道 ──解码──> 信宿(消费者)
                            ↑ 噪音&干扰
```

- 设计行为 = 编码；观看理解 = 解码
- 一切设计决策只服务两个指标：**噪音↓，精准&高效↑**
- 解码发生在对方的认知里（生理感知 + 文化经验），不是你的认知里

## 2. 移情：委托方 ≠ 受众

- 委托方想说的 ≠ 受众想听的。先列"受众最想了解什么"，再排布信息优先级
- 三个自测：
  - 刷到这张图的人，0.5 秒内会停下吗？
  - 3 秒内明白它是什么吗？
  - 10 秒后记得住什么？

## 3. 受众三问（信息优先级排序）

| 问 | 对应诉求 | 视觉权重 |
|---|---|---|
| 你是干嘛的？ | 功能 | 必须最先被看到 |
| 跟我有什么关系？ | 相关 | 决定是否停留 |
| 我为什么要用/去/买？ | 身份 | 决定是否行动 |

## 4. 修辞三角（诉求选型）

- **Logos 逻辑**：数据、参数、对比、证明 → 适合 B 端、工具、性价比沟通
- **Pathos 共情**：情绪、氛围、故事、美 → 适合文旅、生活方式、品牌
- **Ethos 信誉**：权威、口碑、历史、名人 → 适合教育、医疗、老字号
- 主诉求只选一个，副诉求最多一个。全都要 = 全都没有。

## 5. 马斯洛定位

生理 → 安全 → 归属 → 尊重 → 认知 → 审美 → 自我实现

- 越底层越刚需（美食/住宿/出行），越高层越溢价（审美/身份/自我实现）
- 文旅、奢侈品打高层；工具、电商打底层；同一张图只主打一层

## 6. 故事钩子

- 人脑为故事而进化：把卖点接进微型故事，而不是罗列功能
- 极简叙事测试（六词故事原则）：一句话能否让人生出画面感？
  例："出售：婴儿鞋，全新未穿。"
- 公式：具体的人/物 + 意外的关系 + 未说完的余味
- 名句/典故是现成钩子（自带 Ethos + 集体记忆），但必须与主题强相关

## 7. 差异化

- 同类题材都往东，你往西（生态位来自避开竞争，不是打败竞争）
- 蓝海四动作，对着同类作品逐项过一遍：**砍掉 Eliminate / 减少 Reduce / 加强 Raise / 创造 Create**
- 终极检验：遮住 logo，这张图还能被认出是"你"吗？

## 8. 克制（K.I.S.S.）

- 增之一分则太长，减之一分则太短
- 每加一个元素问：删掉它，核心信息受损吗？不受损就删
- 一张图只留一个记忆点

## 9. 基调定义（策略层产出模板）

```
主题：
受众：
受众三问：功能=…，相关=…，身份=…
主诉求：Pathos（副：Ethos）
马斯洛层级：
故事钩子：
基调关键词（3-5 个形容词）：
核心信息（一句话）：
差异化动作：砍掉…，减少…，加强…，创造…
```
