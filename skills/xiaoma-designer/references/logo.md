# Logo / 品牌标识：从提示词到可用标志

> Logo 不是一张好看的图，是一个**缩到 32px 仍能认出来**的符号。
> 现在的生图模型做简单排版、低复杂度的 Logo 已经能一两抽直出；难点从"出得来"转成"选得对、用得上"。

## 1. 先做三个判断（写提示词之前）

| 问题 | 为什么 | 答不出的后果 |
|---|---|---|
| 这个品牌**一句话是什么**？ | 图形要替这句话说话（品类 + 气质） | 画面可爱但与品牌无关 |
| 图形与文字**谁主谁辅**？ | 决定构图：图形在上文字在下，还是图文一体 | 两者抢第一落点 |
| 主要用在**哪**？ | 头像 / 门头 / 包装 / 印章，决定要不要单色版 | 只能在白底大图里好看 |

差异化先于美化：同品类 Logo 都走精致几何时，走手绘、版画或涂鸦，反而更容易被记住。

## 2. 提示词七段结构

按顺序写，每段一到两句，`[ ]` 为待填项。这个顺序是验证过的：先锁风格世界，再逐个落实主体，最后用否定清单收口。

1. **风格 + 品类 + 介质**：`[国家/流派]风格的[品类]品牌 Logo，[介质质感]，纯白（或指定色）背景，纯平面`
2. **主体构成**：`主体是[角色/物件]，共 [N] 个，[排列方式]，彼此[重叠/并列/搭肩]`
3. **逐个落实细节**：每个角色的姿态、表情、配饰、朝向各写一句；表情用具体五官词（点状眼睛、W 形嘴），别用"可爱"代替
4. **线条与笔触**：`线条粗细不均、带抖动和毛边，像[马克笔/蜡笔/刻刀/毛笔]直接画出来，不要精致、不要专业插画感`
5. **颜色锁定**：`仅使用[色 A]/[色 B]/[色 C] [N] 种颜色，所有色块平涂`，并写明背景色
6. **品牌名处理**：`图形下方居中排版[品牌名]，字体为[手写体/粗圆体/复古绘本体]，字母圆润略不规则`——品牌名逐字写进提示词
7. **否定清单 + 留白**：`无渐变、无阴影、无高光、无 3D、无写实质感、无复杂背景；整体居中，四周留足安全区`

> 写"粗细不均、抖动、毛边"比写"精美"有用得多：模型的默认倾向是平均脸，必须用笔触词把它拽向手作感。

## 3. 四类风格的写法差异

| 类型 | 适合 | 关键词重点 | 容易翻车 |
|---|---|---|---|
| 儿童涂鸦 · 黑白线稿 | 独立咖啡、杂货、亲子 | 极简点状五官、"像小朋友用马克笔画"、字体像铅笔涂写 | 线条太匀、太像专业插画 |
| 日式手绘 · 彩色平涂 | 餐饮、宠物、社群 | 2–4 色锁定、深色蜡笔感轮廓、内部平涂、童趣稚拙 | 颜色超限、出现渐变 |
| 版画 / 橡皮章 | 复古、手作、茶咖 | 黑白双色、活版印刷肌理、毛边、刀口缺口、大面积黑块、白色负形刻痕 | 太光滑、变成矢量剪影 |
| 黑白矢量 · 潮牌 | 街头、工作室、个人 IP | 粗黑描边均匀、正负形对比、逐部位写造型、注册商标符号 | 细节过多，小尺寸糊成一团 |

选型沿用 `style-dictionary.md`：先按基调关键词选流派，再叠加本表的介质词。

## 4. 品牌名与文字

- **中文店名必须逐字写进提示词**，并写"零错字、笔画完整"；出图后**逐字校对**，不信肉眼一瞥。
- 手写体 / 变形字体错字率高：要么多抽，要么把图形和文字分开做，文字用真实字体重新排版再合成。
- 多语言并排（中 + 英 + 日）时，主语言写粗体、副语言写小一号细体，层级写进提示词。
- 装饰性小元素（®、©、"Est."、色带）是点缀，不要让它们进入"必须正确"的清单。

## 5. 小尺寸与应用验证（交付前必做）

| 检查 | 通过标准 |
|---|---|
| 32px / 64px 缩放 | 图形轮廓仍可辨认，文字可不要求可读 |
| 方形头像裁切 | 图形居中不被裁，纯色底上依然成立 |
| 单色 / 反白 | 转黑白后主体不糊；彩色版的色块在单色下仍有区分 |
| 白底 + 浅色底并置 | 色块不与背景同明度 |

可以让模型再出一版"同一图形缩小放在方形底色上的应用示意"，用来提前暴露这些问题。

## 6. 变体与迭代

- **一两抽不满意，先改提示词，不要靠抽卡**：超过三抽还不对，说明某一段写得不够具体（多半是第 3、4 段）。
- 想要同一品牌的多个变体：保持第 1、4、5、7 段不变，只替换第 2、3 段。
- 想要随机变体（换造型、换配饰）：在提示词末尾写"保持以上风格不变，随机修改人物的形象与配饰"。
- 先出白底大图确认图形，再出方形底色版和单色版；不要一次性要求全部输出。

## 7. 评审要点（Logo 专属，追加到 review-rubric 之上）

- [ ] 3 秒内说得出"这是什么品类、什么气质"
- [ ] 32px 下仍可辨认
- [ ] 颜色数量不超过提示词锁定值（>锁定值即不合格）
- [ ] 无渐变、阴影、高光（平面性）
- [ ] 品牌名零错字
- [ ] 图形与文字的第一落点唯一

## 8. 使用边界

- AI 生成的图形**不等于可注册商标**：用于正式商用前，需做商标检索，避免与已有标识近似。
- 不要在提示词里指名某个现有品牌或在世设计师的风格，容易生成近似侵权的图形；用"流派 + 介质 + 特征词"描述即可。
- 生成物的著作权归属各地规则不一，用于正式品牌资产前请自行确认。
