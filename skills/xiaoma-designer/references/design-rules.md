# 规范层：五元素决策表

> 规范不是限制，是把"感觉不对"变成可检查的参数。

## 1. 色彩

### HSB 三通道调色法
- **色相 Hue**：颜色身份。主色相 1 个 + 邻近色辅助 + 至多 1 个对比点缀
- **饱和度 Saturation**：越高越强烈也越廉价，越低越高级沉着。大背景低饱和，小点缀可高饱和
- **亮度 Brightness**：与饱和度反向协同——降饱和时提亮或压暗，制造层次
- **色板 ≤5 色**：主色 / 辅助色 / 点缀色 / 背景色 / 文字色
- 文字可读性：正文对比度至少 WCAG AA（4.5:1）；拿不准就眯起眼看
- 文化差异速查（先查受众文化再定色）：
  - 红 = 喜庆（东亚）/ 危险警示（西方）
  - 白 = 纯洁（西方）/ 传统丧仪联想（部分东亚语境）
  - 绿 = 环保自然 / 中文俗语中有忌讳语境，人物服饰慎用
  - 金 = 尊贵（东亚）/ 贪婪（西方叙事）

## 2. 形状

- 圆角大 → 亲和柔软；直角锐角 → 锐利、专业、警示
- 曲率连续（G2）比简单圆角更"贵"：转面无高光断点
- 形状要有家族相似性：主视觉、图标、图框用同一套圆角/角度语言

## 3. 字体

| 场景 | 选择 | 理由 |
|---|---|---|
| 正文/界面 | 无衬线（黑体系） | 屏幕可读性 |
| 标题/文化感 | 衬线（宋体系/书法体） | 风格化表达 |
| 数字/代码 | 等宽 | 对位整齐 |

- **正文标准化，标题才允许风格化**——铁律
- 字重造层级：同一字体家族用 2-3 个字重拉开层级，比换字体更安全
- 字距：大标题可加字距，正文别动
- 对齐：同一版面只允许 1 种主对齐方式（左对齐适合阅读流，居中适合仪式感）
- 中文避坑：美术字标题逐字校对；生僻字检查字体覆盖

## 4. 版面

### 阅读顺序
- 拉丁文 Z 型，扫描页 F 型；竖排中文右上 → 左下；RTL 语言镜像布局
- 先定"第一眼落点"（全图最大的对比处），再定视觉动线

### 格式塔两定律（最常用）
- **接近律**：相关的靠近，无关的远离——分组全靠它，不靠框线
- **相似律**：同属性元素视觉一致（同色/同形/同字重），观众自动归组

### 对比（层次的来源）
- 字号阶梯用比例不用感觉：斐波那契数列 34/55/89/144，或黄金比 ≈1.618
- 图文比：主视觉 ≥ 60% 版面；文字总量能砍则砍
- 一屏只允许一个最大对比点（第一落点唯一）

### 三段式（海报/封面万能骨架）
上：标题区（钩子 + 主标）｜中：主视觉（情绪承载）｜下：信息带（时间地点行动指令，成组紧凑）

## 5. 风格（统一性）

- 全元素一个声音：色板、圆角、字体、笔触、光感来自同一个"世界观"
- 从风格词典选一个流派起步（见 style-dictionary.md），比自由发挥稳
- 交付前最后一问：把画面任意一个元素换成别家风格，违和吗？违和 = 统一性成立

## 6. 五元素检查清单（评审速用）

- [ ] 色板 ≤5 色，文字对比度过 AA
- [ ] 圆角/形状语言全局一致
- [ ] 字体 ≤2 个家族，字重层级清晰
- [ ] 第一落点唯一；分组靠距离不靠框
- [ ] 图文比健康，留白有呼吸感
- [ ] 文化安全（色彩/符号/手势无冒犯）
