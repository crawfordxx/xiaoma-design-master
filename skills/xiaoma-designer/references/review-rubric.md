# 评审：三层评分与迭代

## 三级成熟度

| 级别 | 标准 | 判定问题 |
|---|---|---|
| L1 及格（不跑题） | 主题正确、核心信息 3 秒可读 | 遮住文字，画面还指向主题吗？ |
| L2 良好（有规范） | 五元素检查清单全过、无硬伤 | 有对比度/对齐/分组/错字问题吗？ |
| L3 优秀（有表现） | 风格成立、有记忆点、有共鸣 | 遮住 logo 还认得出是谁吗？一周后记得住什么？ |

**输出要求：总分（0-100）+ 分层诊断 + 改进清单。**
- <60：先解决 L1，别谈风格
- 60-79：列 L2 硬伤清单，按性价比排序
- 80+：给 1-2 个 L3 迭代方向（A/B 对比建议）

## 评审输出模板

```
总分：82/100（L2+）
L1 策略：主题传达 ✓/✗，3 秒测试 ✓/✗，钩子：…
L2 规范：硬伤清单（位置 + 问题 + 修法）
L3 表现：当前风格：…，记忆点：…，短板：…
改进（按性价比排序）：
1. …（预期提分 +N）
2. …
A/B 建议：…
```

## 高频扣分点（按命中率排序）

1. 文字对比度不足（灰底灰字、花底字）
2. 分组失败：相关元素距离过远，靠框线补救
3. 第一落点不唯一：处处大 = 处处不大
4. 色板失控（>5 色，或全图同一明度）
5. 字体超 2 个家族 / 正文用装饰字
6. 图文比失衡：文字挤占主视觉
7. 生图文字错字（中文尤其要逐字校对）
8. 文化符号误用（色彩/手势/宗教符号）
9. 元素堆砌：不知道说什么，就全放上去
10. "AI 味"：无流派、无菌感、塑料质感

## 场景专属检查（按类型追加）

- 活动/日期类：时间地点信息零错字，缩到 400px 宽仍可读
- 产品类：产品形体无变形走样（用参考图保真），参数零错字
- 界面内插画：与 UI 同色系，抢不过按钮
- 音频/书籍封面：缩略图（100px）测试
- 借势/节气类：符号正确性（别把端午过成冬至）

## A/B 迭代法

- 每次只改一个变量（色彩/构图/风格/文案），并排出图对比
- 用评审模板分别打分再合并结论，避免"感觉 B 好像好一点"
- 3 轮不收敛 → 回到策略层重推，别在规范层死磕
