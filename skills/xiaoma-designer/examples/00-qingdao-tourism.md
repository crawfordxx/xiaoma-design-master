# 00 城市文旅宣传海报（✅ 端到端验证案例）

> Brief：为一座海滨城市做文旅宣传主视觉（竖版海报，社媒与灯箱两用）。
> 本案例经过真实生图验证，成图见 `qingdao-poster.png`。

## L1 策略推演

| 项 | 决策 |
|---|---|
| 受众 | 想"夏日出逃"的都市人群 |
| 受众三问 | 功能=海滨度假地；相关=逃离高温与忙碌；身份=去过=松弛浪漫的夏日记忆 |
| 主诉求 | Pathos 共情（向往感），副 Ethos（城市百年名句背书） |
| 马斯洛 | 审美 + 归属 |
| 故事钩子 | 城市经典名句「红瓦绿树 · 碧海蓝天」（自带集体记忆） |
| 基调关键词 | 松弛、清新、怀旧、向往 |
| 核心信息 | 这座城市 = 夏天该有的样子 |

差异化：同类文旅海报多用实景摄影 → 本作走插画化复古路线，避开同质竞争。

## L2 规范决策

- 色板（5 色）：深海蓝 / 天空青 / 红瓦橙 / 啤酒金 / 奶油白
- 版面：三段式——顶部竖排大字标题 + 名句副标；中部主视觉（俯瞰湾景）；底部窄信息带
- 字体：标题书法感宋体（风格化），信息带无衬线小字（标准化）
- 取舍（K.I.S.S.）：砍掉啤酒杯等具象元素——画面拥挤会稀释"碧海蓝天"主记忆点，啤酒只在文案层保留

## L3 风格选择

风格词典命中：**复古旅行海报**。
理由：扁平色块 + 几何化 + 丝网颗粒，天然规避 AI 摄影味；"向往感"是该流派百年验证的情绪。

## 最终提示词（城市文旅通用模板）

> 竖版复古旅行海报设计，1930 年代 Art Deco 经典旅游海报风格。
> 视角：从[制高点]俯瞰[城市老城]，成片[地域标志建筑元素]层层叠叠延伸向[水体]，[地标建筑]位于画面视觉中心，[点缀动态元素：帆船/飞鸟]。
> 配色严格限制五种：[五色]；扁平色块、几何化造型，轻微丝网印刷颗粒质感。
> 顶部竖排两个醒目大字『[城市名]』（书法感宋体），旁注小字副标『[名句/口号]』，标题旁一枚红色方形印章。
> 底部一条窄信息带，居中一行小号无衬线英文『[城市英文名 · slogan]』。
> 三段式经典旅游海报版式，构图克制、留白充分，明亮光线，怀旧、高级、充满向往感。文字要求零错字。
