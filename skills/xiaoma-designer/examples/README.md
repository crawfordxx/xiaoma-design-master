# 案例索引：10 个视觉设计场景

每个案例都是完整的「策略 → 规范 → 风格 → 提示词 → 评审」决策链，
且**全部经过真实生图验证**（成图即各案例文内图片，评审已通过 L2）。
遇到相似需求，先找同类案例作起点，再按新需求修改决策（不要照抄提示词）。
