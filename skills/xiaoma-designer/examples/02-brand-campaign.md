# 02 品牌形象宣发海报

> Brief：户外装备品牌形象海报，不卖具体产品，只为品牌气质。

## L1 策略推演

| 项 | 决策 |
|---|---|
| 受众 | 25-40 城市中产，身体在工位、心在山野 |
| 受众三问 | 功能=记住品牌；相关=我想要那种生活；身份=用它=走进山野的人 |
| 主诉求 | Pathos（向往）+ Ethos（品牌格调沉淀） |
| 马斯洛 | 自我实现 + 审美 |
| 故事钩子 | 「山里没有信号，才终于收到了自己」 |
| 基调关键词 | 辽阔、克制、真实、自由 |
| 核心信息 | 自然是最终的奢侈 |

差异化：竞品海报都在拍产品特写 → 本作完全不出现产品，只拍人与山的关系。

## L2 规范决策

- 色板（4 色）：雾灰蓝 / 岩石灰 / 苔原绿 / 暖白
- 图文比 9:1：大面积自然场景 + 一句话文案（12-20 字）+ 极小 logo
- 字体：细字重衬线中文 + 小号无衬线英文，双语言弱化存在感
- 版面：地平线置于下 1/3，文案落在天空负空间（左对齐），logo 右下角 5% 大小
- 系列化预留：同一版式换山体剪影 = 四季系列

## L3 风格选择

风格词典命中：**极简主义** + 胶片颗粒介质。
理由：克制本身就是户外伦理（无痕山林）；大留白让"向往"有呼吸空间；胶片质感规避数字感。

## 提示词模板

> 横版/竖版极简主义品牌形象海报。
> 画面：[自然场景：山脊线/湖泊/森林峡谷]，一个很小的人物剪影[动作：行走/静坐]，占比不足画面 5%。
> 大面积留白天空占上 1/3，暖白色调，胶片颗粒质感，光线为清晨/黄昏低角度柔光。
> 天空负空间处一行细衬线小字『[一句话文案]』，右下角极小品牌标识。
> 色彩限制四种：[四色]。辽阔、克制、真实、自由。文字零错字。

## 评审要点（本场景专属）

- [ ] 品牌露出是否克制（logo ≤5% 版面，禁止水印式铺满）
- [ ] 有具体场景细节（天气/地形/光线时刻），而非空泛"唯美风景"
- [ ] 文案 ≤20 字且有未说完的余味，禁止口号式喊话
- [ ] 系列延展测试：换一个场景，版式是否依然成立
