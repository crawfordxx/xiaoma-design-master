# 04 公益倡导海报

> Brief：濒危物种保护公益海报，用于地铁灯箱与社媒。

## L1 策略推演

| 项 | 决策 |
|---|---|
| 受众 | 通勤中的公众（视线预算 2 秒） |
| 受众三问 | 功能=知道这个议题；相关=物种消失与我有关；身份=行动=善意的人 |
| 主诉求 | Pathos（共情冲击，靠概念不靠惨图） |
| 马斯洛 | 归属（善意认同） |
| 故事钩子 | 一个负空间双关：象群剪影的负形是一头象牙梳子——「美丽不该以消失为代价」 |
| 基调关键词 | 肃穆、克制、刺痛、留有希望 |
| 核心信息 | 它们的消失，是我们审美的代价 |

差异化：公益海报惯用实拍惨状 → 本作用概念双关，刺痛但不消费苦难。

## L2 规范决策

- 色板（3 色）：米纸白 / 墨黑 / 一点朱砂红（唯一的情绪色）
- 负空间 ≥50%：一个概念只说一次，画面主体唯一
- 字体：细宋体竖排文案（肃穆感），行动指令（捐赠/转发渠道）极小放右下角
- 图文比 8:2，禁元素堆砌——堆砌 = 概念死亡
- 伦理红线：不使用真实血腥/惨状图像

## L3 风格选择

风格词典命中：**手绘线稿**（单线勾勒 + 纸纹）承载负空间概念。
理由：线稿的"未完成感"暗示物种正在消失；纸纹带来请愿书般的郑重。

## 提示词模板

> 竖版公益海报，极简单色概念设计。
> 米纸白底带纸张纹理，画面中央用连续细墨线勾勒[主体物]，其负空间/缺口处形成[概念物：相关第二意象]的轮廓，一个视觉双关。
> 唯一颜色：一处朱砂红[点睛元素]。
> 右侧竖排细宋体文案『[一句话主张]』，右下角极小行动信息『[参与方式]』。
> 大面积留白，肃穆、克制、刺痛但留有希望。文字零错字。

## 评审要点（本场景专属）

- [ ] 概念 3 秒可懂（双关太隐晦 = 自嗨，先给 3 人盲测）
- [ ] 有"希望出口"（行动入口），不许灰暗到底——绝望不产生行动
- [ ] 未消费真实苦难（无惨状实拍、无猎奇）
- [ ] 主体唯一：出现第二视觉焦点即打回
