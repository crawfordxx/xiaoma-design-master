# 05 餐饮美食海报

> Brief：新开面馆开业海报（门贴 + 社群转发）。

## L1 策略推演

| 项 | 决策 |
|---|---|
| 受众 | 门店 3 公里内的午餐决策人群 |
| 受众三问 | 功能=卖什么+在哪+价格带；相关=这碗面看起来就好吃；身份=懂吃的本地人 |
| 主诉求 | Pathos（食欲，生理层最刚需） |
| 马斯洛 | 生理（饿） |
| 故事钩子 | 「这碗面，先喝汤」——用动作暗示汤底自信 |
| 基调关键词 | 烟火气、温热、真实、市井 |
| 核心信息 | 一碗值得先喝汤的面 |

差异化：餐饮海报惯用"高清精修棚拍" → 本作追求"油的、冒气的"纪实烟火感。

## L2 规范决策

- 色板（5 色）：汤色琥珀 / 辣油红 / 葱花绿 / 面瓷白 / 深棕（文字）
- 食欲三要素：热气（动态）、光泽（油润高光）、特写（占版面 60%+，筷子入画制造"够得着"）
- 版面：第一落点=面碗特写；手写感标题『开业』+ 价格/地址信息带按接近律成组
- 字体：标题手写书法体（风格化），信息黑体（标准化）
- 信息带红线：开业日期/地址/优惠必须缩图可读

## L3 风格选择

风格词典命中：**写实质感摄影流**（胶片颗粒 + 纪实光线）。
理由：棚拍精修产生"塑料距离感"，纪实逆光 + 蒸汽 = 妈妈做饭的记忆通路。

## 提示词模板

> 竖版餐饮开业海报，纪实美食摄影风格。
> 画面：一碗[招牌面名]的 45° 特写，占版面 60% 以上，筷子提起面条带出热气，汤面油润高光，[配料]清晰可见，背景深色虚化。
> 光线：侧逆光暖光，蒸汽在光束中可见，胶片颗粒质感，真实烟火气（拒绝塑料感精修）。
> 顶部手写书法体大字『[店名]』+ 小字『[slogan]』。
> 底部信息带黑体排出『[开业日期] [地址] [优惠]』。
> 色彩限制五种：琥珀/辣油红/葱绿/瓷白/深棕。温热、真实、市井。文字零错字。

## 评审要点（本场景专属）

- [ ] 食物渲染检查：出现蜡感/塑料感即打回（热气、油光是硬指标）
- [ ] 构图距离感：特写要"够得着"，俯拍全景会拉远食欲
- [ ] 食材新鲜度视觉线索（绿意、光泽、汤的清亮度）
- [ ] 信息带三要素齐全：日期/地址/钩子优惠
