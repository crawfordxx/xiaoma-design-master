# 07 书籍封面

> Brief：一部城市题材长篇小说的封面（纸书 + 电商列表）。

## L1 策略推演

| 项 | 决策 |
|---|---|
| 受众 | 文学读者（书店与线上列表双重场景） |
| 受众三问 | 功能=这是什么类型/气质；相关=这故事里有我；身份=读它=有品位 |
| 主诉求 | Pathos（文学氛围）+ Logos（类型信号清晰） |
| 马斯洛 | 审美 + 自我 |
| 故事钩子 | 一个意象而非剧情梗概：城市群楼之间悬停的一只白鸟 |
| 基调关键词 | 隐喻、都市、疏离、余味 |
| 核心信息 | 在密集的城市里，有人想飞 |

差异化：小说封面惯用"剧照式"场景 → 本作用超现实单一意象 + 字体驱动排版。

## L2 规范决策

- 色板（4 色）：雾霾灰蓝 / 楼群炭灰 / 白鸟纯白 / 纸米白
- 字体驱动：书名是最大视觉元素之一（与意象并列第一落点），衬线宋体 + 局部笔画断开处理
- 版面：竖排书名置右上（中文阅读动线起点），意象居中偏下悬于负空间，作者名小字底部
- 腰封/底部：推荐语最多一条（克制），出版信息标准化小字
- 印刷安全：四边 3mm 出血 + 关键元素离边 5mm

## L3 风格选择

风格词典命中：**超现实主义**（逼真物象的错误并置）+ 哑光纸感。
理由：城市与飞鸟的并置即主题本身；超现实的"真实感错位"正是文学隐喻的视觉语法。

## 提示词模板

> 竖版小说封面，超现实主义极简风格，哑光纸质纹理。
> 深雾霾灰蓝的天空下，密集的城市楼群剪影沉在画面下 1/3（炭灰色），楼群之间的负空间中悬停一只纯白色的[意象物：鸟]，是全图唯一纯白与唯一光源。
> 右上角竖排书名『[书名]』（衬线宋体，笔画末端轻微断开处理，米白色），底部小字『[作者名] 著』。
> 大面积留白与克制配色：雾霾灰蓝/炭灰/纯白/纸米白。隐喻、疏离、有文学余味。文字零错字。

## 评审要点（本场景专属）

- [ ] 书名字体气质与文本匹配（都市文学 ≠ 武侠书法体）
- [ ] 电商缩略图测试（列表 80px 高度）：书名与意象仍可辨
- [ ] 意象唯一：一个隐喻说透，第二个意象即噪音
- [ ] 印刷安全边检查；系列书预留统一版式（换意象不换骨架）
