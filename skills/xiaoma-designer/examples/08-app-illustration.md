# 08 App 功能插画 / 引导页

> Brief：记账 App 的空状态与新手引导插画（界面内嵌使用）。

## L1 策略推演

| 项 | 决策 |
|---|---|
| 受众 | App 当前用户（已在界面内，注意力属于产品） |
| 受众三问 | 功能=这个页面干嘛；相关=帮我省事；身份=亲切但不幼稚 |
| 主诉求 | Logos（引导清晰）+ Pathos（降低空页面焦虑） |
| 马斯洛 | 安全（一切尽在掌控） |
| 故事钩子 | 无文案，纯插画——文字交给 UI 层，插画只做情绪 |
| 基调关键词 | 轻盈、友好、干净、可信 |
| 核心信息 | 记账这件小事，很轻松 |

差异化：工具类插画惯用"商务人物 + 图表"套路 → 本作用"小抽屉/存钱罐"等生活物件的戏剧化小场景。

## L2 规范决策

- **必须从产品设计系统取色**：主色 + 2 个中性色 + 1 个点缀色，禁止另开色板
- 形状语言与 UI 同族：UI 圆角 12px → 插画圆角同比例
- 无文字（本地化友好）；构图居中悬浮，重心稳定（安全感的视觉来源）
- 尺寸双版本：深色模式 + 浅色模式（背景透明 PNG 或双底色）
- 层级红线：插画永远不许比页面按钮更抢眼（面积 ≤ 内容区 60%，对比度低于 UI 主色）

## L3 风格选择

风格词典命中：**等距 2.5D**（科技、系统、说明）或扁平插画；界面内取**扁平**更轻。
理由：等距适合"系统感"页面，扁平适合情绪页；记账是生活化场景 → 扁平 + 微弹跳的圆润感。

## 提示词模板

> 界面内空状态插画，扁平风格，圆角几何造型，无描边或极细描边。
> 画面：[生活物件隐喻：存钱罐/小抽屉/天平]的小场景，一枚金币正落入[物件]，带轻微下落动态感。
> 配色仅使用：[产品主色]/浅灰/[点缀色]/白，背景透明。
> 构图居中，物体悬浮稳定，圆角与 12px UI 组件同族，风格轻盈友好不幼稚。
> 不含任何文字。提供浅色与深色两个版本。

## 评审要点（本场景专属）

- [ ] 与 UI 截图并置检查：违和即重做（色板/圆角/密度三项对齐）
- [ ] 200px 与 1024px 两个尺寸下构图都成立
- [ ] 深浅色双版本均通过对比度检查
- [ ] 插画对比度低于页面主按钮（层级红线）
