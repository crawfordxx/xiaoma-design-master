# 03 新品发布海报

> Brief：无线降噪耳机新品发布，主视觉海报（发布会 + 电商 + 社媒）。

## L1 策略推演

| 项 | 决策 |
|---|---|
| 受众 | 每天通勤 1h+ 的都市人、差旅频繁者 |
| 受众三问 | 功能=降噪深度+续航+连接；相关=地铁上的一份安静；身份=效率人群的装备审美 |
| 主诉求 | Logos（参数可信）+ Pathos（安静的奢侈） |
| 马斯洛 | 安全（降噪=秩序感）+ 尊重（品位） |
| 故事钩子 | 「给世界按下静音」 |
| 基调关键词 | 精密、安静、高级、科技 |
| 核心信息 | 一键隔绝噪音 = 夺回注意力 |

差异化：数码发布海报滥用蓝紫渐变"科技感" → 本作用深色材质光影 + 单一强调色表达精密。

## L2 规范决策

- 色板（4 色）：石墨黑底 / 钛灰 / 产品本色 / 单一强调色（琥珀橙，只给 CTA 与产品高光）
- 版面：产品英雄位占 50-65%（微俯 15° 角展示耳罩曲率），底部信息带放参数组
- 接近律：参数成组（降噪 dB / 续航 h / 蓝牙版本），三列对齐，禁止散落
- 字体：几何无衬线家族，参数数字用等宽字重，标题字距 +8%
- 形状语言：全图圆角/曲率与产品 G2 曲率同族，禁直角框

## L3 风格选择

风格词典命中：**瑞士国际主义**（网格、冷静、专业）+ 精密 3D 渲染质感。
理由：参数型诉求需要秩序感背书可信度；网格排版让"精密"从文案变成画面事实。

## 提示词模板

> 竖版新品发布海报，瑞士国际主义排版风格。
> 深石墨黑背景，产品[产品名]悬浮于画面中心偏上（占版面约 60%），[角度：微俯15°/侧45°]，精密工业渲染：钛金属哑光质感、曲率连续的边缘高光、单一琥珀色轮廓光。
> 产品下方网格化参数区：三列无衬线小字『[参数1] [参数2] [参数3]』，数字等宽对齐。
> 顶部大字距无衬线标题『[slogan]』，底部窄信息带『[上市时间] [渠道]』。
> 色彩限制：石墨黑/钛灰/[产品色]/琥珀橙。精密、安静、高级。文字与数字零错字。

## 评审要点（本场景专属）

- [ ] 产品形体零变形（色相/比例/曲率与实物一致，必要时用参考图生图保真）
- [ ] 参数数字逐字校对（发布物参数错误 = 信任事故）
- [ ] 光影方向全局统一（主光/轮廓光不矛盾）
- [ ] "科技感"检查：出现了蓝紫渐变即打回，用材质与光影重做
