# 09 节气节日借势图

> Brief：生活方式品牌借势冬至的营销图（公众号头图 + 微博）。

## L1 策略推演

| 项 | 决策 |
|---|---|
| 受众 | 品牌既有粉丝 + 信息流路人 |
| 受众三问 | 功能=今天冬至（提醒）；相关=该吃饺子/汤圆了；身份=有文化质感的生活方式 |
| 主诉求 | Pathos（时节情绪）+ Ethos（品牌文化感） |
| 马斯洛 | 归属（共同的文化时间） |
| 故事钩子 | 「冬至，白昼最短，思念最长」 |
| 基调关键词 | 温暖、诗意、传统、克制 |
| 核心信息 | 和你一起，把冬天过成节 |

差异化：借势图惯用"元素大杂烩"（饺子+梅花+灯笼全上）→ 本作一个符号说透：九九消寒图的"一笔"。

## L2 规范决策

- 色板（4 色）：黛蓝 / 朱砂 / 米白（纸）/ 描金（细节）
- 符号唯一性：只取「九九消寒图」一笔朱砂（填完 81 笔即出九）——符号自带"等春天"的叙事
- 版面：竖排文字右起（传统动线），符号居左下负空间，品牌 logo 小置左上角
- 字体：细宋竖排 + 描金小字节气注（标准化小字）
- 发布策略也是策略：节气当日 0 点前后发布（时效即信息的一部分）

## L3 风格选择

风格词典命中：**水墨写意**（留白、笔触浓淡）+ 纸张纹理。
理由：冬至的主题是"藏与等"，水墨的留白即冬天；朱砂一笔 = 寒冬里的人情温度。

## 提示词模板

> 横版节气借势图，水墨写意风格，米白纸纹底。
> 画面：大面积留白的冬日，左下一枝[冬季意象：枯梅/残荷]淡墨勾勒，枝头一点朱砂红，旁置[节气符号：一碗热汤/九九消寒图的一笔]极简呈现。
> 右侧竖排细宋体两行『[节气名]』『[一句诗意文案]』，描金小字注『[节气注：如"数九第一天"]』，左上角极小品牌标识。
> 色彩限制四种：黛蓝/朱砂/米白/描金。温暖、诗意、克制。文字零错字。

## 评审要点（本场景专属）

- [ ] 符号正确性：节气物候/食俗对应无误（冬至 ≠ 粽子）
- [ ] "新中式"检查：一个符号说透 = 及格；元素叠加 = 打回
- [ ] 品牌露出 ≤5%：借势图的主人是节气，不是品牌
- [ ] 发布时间策略确认（节气当日 0 点窗口）
