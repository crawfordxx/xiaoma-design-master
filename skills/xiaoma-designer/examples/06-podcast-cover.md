# 06 播客/专辑封面

> Brief：都市夜谈类播客栏目封面（小宇宙/Spotify 等平台）。

## L1 策略推演

| 项 | 决策 |
|---|---|
| 受众 | 通勤与睡前收听的都市青年 |
| 受众三问 | 功能=这是什么节目；相关=聊的就是我的生活；身份=订阅=懂得生活的人 |
| 主诉求 | Pathos（亲密陪伴）+ 身份 |
| 马斯洛 | 归属（有人陪着说话）+ 自我 |
| 故事钩子 | 栏目名即概念：「深夜便利店」——把谈话节目比作深夜亮灯的小店 |
| 基调关键词 | 亲密、松弛、都市、微醺 |
| 核心信息 | 每周更，陪你走夜路 |

差异化：谈话播客封面滥用"话筒+人像" → 本作用一个隐喻物（深夜亮灯的便利店/小店）替代。

## L2 规范决策

- **正方形 1:1**（平台规范）
- 缩略图第一：手机列表里 100px 也要能认出——主体占画面 ≥50%，对比拉满
- 文字 ≤ 两行：栏目名（大）+ 一句副标（小）；正文文字一律不放
- 色板（4 色）：夜蓝 / 暖灯黄 / 象牙白 / 一点霓虹粉
- 系列化：每期换霓虹色相，版式与主体恒定

## L3 风格选择

风格词典命中：**概念极简**（借极简主义原则）+ 霓虹夜色氛围。
理由：隐喻物在极简构图中成为"记忆钩子"；暖灯黄与夜蓝的对比 = "夜路与陪伴"的情绪结构。

## 提示词模板

> 正方形播客封面，极简概念插画。
> 深夜蓝背景，画面中央一个发光的[隐喻物：深夜小店/电话亭/路灯]剪影，暖黄灯光是全图唯一光源，占据画面 50% 以上，窗内一个微小的人影。
> 霓虹粉作少量点缀光。上方栏目名『[名称]』（圆体，大而清晰），下方一行小字『[一句副标]』。
> 色彩限制四种：夜蓝/暖灯黄/象牙白/霓虹粉。亲密、松弛、都市深夜感。
> 要求在 100px 缩略图下依然可辨识。文字零错字。

## 评审要点（本场景专属）

- [ ] 100px 缩略图测试（平台列表真实尺寸）：主体轮廓与栏目名可辨
- [ ] 概念命名 > 描述命名（"深夜便利店" 优于 "都市情感谈话节目"）
- [ ] 禁话筒/耳机/人像剪影三件套（同质化重灾区）
- [ ] 深浅色平台背景（白/黑）下都成立
