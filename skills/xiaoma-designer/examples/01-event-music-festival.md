# 01 活动海报（音乐节）

> Brief：周末草地音乐节，两天，需主视觉海报（线上传播 + 现场物料）。

## L1 策略推演

| 项 | 决策 |
|---|---|
| 受众 | 18-30 岁音乐爱好者，找周末出口 |
| 受众三问 | 功能=日期+地点+购票；相关=周末就该狂欢；身份=懂生活方式的年轻人 |
| 主诉求 | Pathos（现场能量），信息层 Logos 必须清楚 |
| 马斯洛 | 归属（一起狂欢）+ 自我表达 |
| 故事钩子 | 「把音量开到没有天花板」 |
| 基调关键词 | 炽热、自由、躁动、年轻 |
| 核心信息 | 两天 × 音乐 × 旷野 = 值得奔赴 |

差异化：同档活动海报常用暗黑电音风 → 草地场景反走白日糖果色，一眼区分。

## L2 规范决策

- 色板（5 色）：奶油底 / 草绿 / 落日橙 / 电光粉 / 墨黑（文字）
- 字体：主标题可做异形字（风格化），日期/地点/阵容用同一无衬线家族三档字重（标准化）
- 版面：第一落点=活动名异形大字；日期地点+购票指令按接近律成一个块放底部信息带；阵容名单中置
- 对比：主标题字号与信息带比例 ≈ 144:34（斐波那契档），确保唯一第一落点
- 户外物料红线：缩到 400px 宽，日期与购票指令必须仍可读

## L3 风格选择

风格词典命中：**孟菲斯**（活泼、年轻、潮流）+ 丝网印刷颗粒。
理由：糖果几何的错位感 = 音乐节的失重快乐；与"暗黑电音"竞品形成色域级差异。

## 提示词模板

> 竖版音乐节海报，孟菲斯设计风格：奶油色底，草绿/落日橙/电光粉的几何色块与波浪线条错位组合，黑色粗轮廓线。
> 顶部超大异形艺术字『[活动名]』（英中双语，字体像跳动的音符），带轻微丝网印刷颗粒质感。
> 中部[场景意象：草地/舞台剪影/人群剪影]用几何色块表达。
> 底部信息带：无衬线字体排出『[日期] [地点]』，其下小字『[购票渠道/二维码占位]』。
> 整体快乐、躁动、年轻，构图克制但色彩饱和，文字零错字。

## 评审要点（本场景专属）

- [ ] 阵容/日期/地点零错字（致命伤，逐字校对）
- [ ] 信息块不抢主视觉（信息带高度 ≤ 版面 15%）
- [ ] 400px 宽缩图测试：日期可读、二维码占位可替换
- [ ] 现场物料延展：同版式换主色 = 预售/正赛/返场系列
