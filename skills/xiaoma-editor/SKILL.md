# 小马剪辑（xiaoma-editor）

把一堆逐镜生成的 `sNN.mp4` 拼成一条能交付的成片。

## 定位

**素材是既成事实，节奏不是。** AI 视频工具给出的片段有三个毛病，本技能专门治它们：

1. **一段里自己切了镜**：4–10 秒的素材里模型偷偷切了两三个镜头，整段用就会出现剪点两侧重复画面和 0.1 秒闪帧 → 检测内部切点，只取包含人声（或最长）的那一段
2. **时长不由你定**：最短生成约 4 秒，台词不一定从第 0 秒开口，配音语速约 3 字/秒（比分镜假设的慢）→ 按人声定位选入出点，对白镜整句说完才出点，无台词镜严格按分镜时长
3. **声音是空的**：素材只有同期声，静场段（上楼、等人开口、时间跳变）死寂 → 三层声音自动混音，响度归一到 −16 LUFS

不负责：生成片段、写分镜、调色、精修特效。片段本身不对（脸变了、道具漂移、屏幕上有乱码）→
写进报告交回上游重出，**不要在剪辑台上救**。

## 目录与变量

下文 `S=<本技能目录>`（直接用安装路径，不必解 symlink）。技能目录里有三个软链接：

| 路径 | 是什么 | 本技能用它做什么 |
|---|---|---|
| `studio/` | 小马动效工作室技能 | 只借 `studio/engine/audio.py` 的合成音色（九种音效、pad、低通、放置） |
| `shared/` | 仓库共享规则 | 运行时规则、工作区约定 |
| `toolkit/` | 生成能力入口 | 本技能不生成东西，留着是为了和其他技能一致 |

项目目录约定（`assemble.py` 按这个找文件，全都可以用参数改）：

```
<项目目录>/
├── storyboard/storyboard.json      分镜（也接受 <项目目录>/storyboard.json）
├── clips/sNN.mp4                   片段，镜号两位：s01.mp4、s02.mp4…
├── sound/                          声音素材，可选，缺了自动合成兜底
│   ├── beds/<场景 id>.wav          环境底噪
│   ├── sfx/<类型>.wav              音效
│   ├── music/<情绪>.wav            BGM 长音
│   └── vo/sNN.wav                  逐镜旁白 / 播报
└── edit/<成片名>/                  中间文件 + edl.json + 报告（自动创建）
```

## 环境依赖

```bash
ffmpeg -version          # 必需：ffmpeg 与 ffprobe 都要在 PATH 里
python3 -c "import numpy, PIL; print('ok')"    # 必需：numpy + Pillow
```

可选：

- **本地转写库**（用来定位人声、核对台词有没有被剪断）。没装时全链路降级，不中断：
  对白镜改成按分镜时长剪，并在 `flags` 和报告里明写「没定位到人声，检查是否切掉半句」。
  当前支持的实现和模型写在 `scripts/asr.py` 顶部，可用环境变量 `XIAOMA_ASR_MODEL` 换模型
- **中文字体**：按系统探测（macOS 自带黑体 / 苹方；Linux 的 Noto CJK / 文泉驿；再退回 `fc-list`）。
  找不到会**报错并给安装建议**，不会静默用英文字体渲染出豆腐块。指定用 `--font <路径>` 或环境变量 `XIAOMA_FONT`

只有 ffmpeg、numpy、Pillow 三样是硬依赖。检测、选点、排版、混音全部在 numpy / Pillow 里做，
ffmpeg 只负责解码、拼接和编码。

## 流程

```
体检素材 → 选入出点 → 粗剪拼接 → 声音层混音 → 字幕字卡 → 成片体检 → 剪辑报告
   ①          ②          ③           ④           ⑤          ⑥         ⑦
```

①②③④⑤⑥⑦ 由 `assemble.py` 一次跑完（内部就是这七步，会打 `1/5`…`5/5` 的进度）。
①也可以单独先跑，用来决定哪些镜头要在剪辑前就重出。

### Step 0 · 先体检素材（强烈建议，剪之前跑）

```bash
python3 $S/scripts/check.py clips <项目目录>
```

逐镜输出时长、规格、**内部切点**、画面突变、尾部黑场、人声区间、转写文本。看三件事：

- `internal_cuts` 非空 → 这一镜素材自己切镜了，剪辑会自动只取一段，但最好回上游在提示词里补
  「单一连续镜头，从头到尾同一机位，不切换镜头、不剪辑」后重出
- `dialogue: true` 但 `speech: null` → **这一镜会被按分镜时长硬剪，很可能切半句**。先解决转写，或人工听一遍
- `heard` 和分镜台词对不上 → 模型念错或漏词，重出

### Step 1 · 粗剪到成片（一条命令跑完 ①–⑦）

```bash
python3 $S/scripts/assemble.py <项目目录> \
    --out <项目目录>/ep01.mp4 \
    --label "AI 生成 · 纯属虚构" \
    --tail-black 1.0 --lufs -16
```

常用参数：

| 参数 | 默认 | 什么时候改 |
|---|---|---|
| `--out` | `<项目目录>/final.mp4` | 一定要改成分集名 |
| `--storyboard` / `--clips` / `--sound` / `--work` | 按上面的目录约定 | 项目结构不一样时 |
| `--label` | `AI 生成 · 纯属虚构` | 空字符串 `--label ""` 关掉角标 |
| `--tail-black` | `1.0` | 集尾卡点后的黑场秒数，**上限 3.0**，超了会被截到 3.0 并警告 |
| `--lufs` | `-16` | 交付要求别的响度时 |
| `--font` | 系统探测 | 要用指定字体时 |
| `--no-asr` | 关 | 明确不要人声定位（快，但对白镜按分镜时长剪） |
| `--keep-stray-voice` | 关 | 无台词镜里模型生成的人声**不要**压低（比如那就是你要的群杂声） |
| `--no-check` | 关 | 只要成片不要报告（几乎不该用） |

产物：成片、`edit/<成片名>/edl.json`（剪辑单）、`edit/<成片名>/review/{report.md,report.json,sheet.jpg}`、
`edit/<成片名>/png/`（每张字卡的透明 PNG）、`<成片名>.report.md`（报告副本，和成片放一起）。

渲染 32 镜约 2–5 分钟：**放后台跑，等 `ffprobe` 能读出时长再验收**，别在文件写完之前就去跑体检。

### Step 2 · 看报告

```bash
python3 $S/scripts/check.py film <成片.mp4> --edl <edit/xx/edl.json> --storyboard <storyboard.json> --out <edit/xx>
```

`report.md` 第一节是逐条判定（✅ / ⚠️ / ❌）。**❌ 必须为 0**；⚠️ 每条给一句「已确认是有意的」或「下一轮修」。
怎么读、门槛多少、不合格怎么修、哪些是已知误报，全在 [references/qa-report.md](references/qa-report.md)。

再看 `sheet.jpg`（每镜中间帧拼图）目检六件事：字卡有没有压脸、屏幕字卡有没有落进屏幕区域、
屏幕里还有没有透出乱码、名牌 / 时间卡 / 片名有没有叠在一格、角标在不在、跨镜道具有没有漂移。

### Step 3 · 改，再跑

改一镜不要从头猜：先读 `edl.json` 里那一镜的 `flags`，它记了剪辑过程中所有的让步。
改完重跑 Step 1（转写有缓存，第二次快很多）。

## 给上游技能的素材要求

剪辑能救节奏，救不了素材。下面这些要在**分镜和出片阶段**就做到（写给短剧 / 导演 / 视频生成技能）：

1. **画面里的字一律不让视频模型画，全部后期贴。** 手机屏、监控、电视、HUD 写「屏幕纯白发光、无任何字」；
   门牌写「门牌空白」；钟表写「表盘无指针」；账本、诏书、单据写「纸面空白无字」。
   要贴什么字写进该镜的 `on_screen_text`，**制作备注写在括号里**（括号里的内容绝不上屏）
2. **屏幕类字卡给 `screen_box = [x, y, w, h]`**，相对**片段原画面**的 0–1 比例。
   给了就贴进屏幕区域；没给只能退到画面中部信息框，对不准屏幕
3. **`on_screen_text` 里的多张卡用 `／` 分开**（片名、时间地点、虚构声明各一段）。
   「AI 生成 · 纯属虚构」只做角标，不要写成正文卡；三者不要压在同一镜
4. **`duration_s` 按剪后时长给，对白镜按「字数 ÷ 3 + 0.8 秒」估**。配音约 3 字/秒，
   按 4–5 字/秒估的话对白镜会普遍说不完，成片被台词撑长一成很常见
5. **每镜写 `sfx` 和 `music`**：`sfx` 写具体声音事件（敲门三下、接单提示音、落地闷响、钥匙一响与黑场同落），
   持续环境声（雨、风、空调）交给底噪按场次铺，不用写；`music` 写情绪段落的进入、延续、骤停，
   不想每镜都写就留空，会自动沿用上一镜
6. **每镜挂场景**：`shot.scene` 或在 `refs` 里挂一个 `type: location` 的参考 id，底噪按它分段。
   都没有就沿用上一镜
7. **关键节拍写进 `strategy.beats`**，且镜头的 `beat` 字段要等于节拍名。名字或 `purpose` 里含
   「反转 / 揭 / 翻盘 / 高潮 / 爽点 / 兑现」的节拍会自动加 riser + hit
8. **`project.asl` 给镜长基准**（如 `[2.2, 3.8]`），报告用它判平均镜长
9. **提示词固定加**「单一连续镜头，从头到尾同一机位，不切换镜头、不剪辑」「表演克制自然、不夸张」
   「画面无任何文字、品牌标识、logo」；无台词镜头加「无人声」+ 本镜环境声
10. **光照突变拆成两镜**（灯亮前 / 灯亮后）。一镜内灯泡亮起并投出长影是模型最容易崩的地方，
    剪辑只能把突变点避开，救不了画面

声音素材（可选，但给了质量立刻不一样）按 [references/sound.md](references/sound.md) 第 1 节的目录和命名放。

## 执行模式

- **auto（默认）**：Step 0 → Step 1 → Step 2 一路跑完，把报告和判定交给你。本技能**不花钱**
  （不调用任何生成能力），所以没有必停点
- **interactive**：用户说「先看方案」「让我选」时，在 Step 0 之后停一次，把素材体检结果和
  「哪些镜头建议先重出」给用户看，确认了再进 Step 1

## 弹性降级（永不整体中断）

| 场景 | 降级 |
|---|---|
| 没装本地转写库 | 对白镜按分镜时长剪，`flags` 与报告明写「没定位到人声，检查是否切掉半句」；转写自检整节跳过 |
| 转写跑了但没认出台词 | 用人声频带能量兜底（`speech_by: 能量`）；再不行按分镜时长剪并标 flag |
| 缺 `sound/` 素材 | 底噪按场景合成（雨 / 室外 / 室内三种整形噪声）、音效与 BGM 用 `studio/engine/audio.py` 合成；报告的「用料」列如实写「合成兜底」 |
| 缺某一镜的 `sNN.mp4` | 警告并跳过该镜，其余照拼 |
| 找不到中文字体 | **报错停住**并给安装建议（字体错了整片字卡都是废的，不能静默降级） |
| 没有 ffmpeg | 报错停住 |
| 素材一个都没有 | 报错「一个可用片段都没有」 |
| 片尾黑场要求超过 3 秒 | 截到 3 秒并警告 |
| 报告某一项数据缺失 | 该项标 ⚠️ 并写明缺什么，不影响其他项 |

铁律：一次单步失败永远不值得杀掉整条管线。

## Gotchas

- **整段用素材**：8–10 秒的片段原样铺进对话戏 = 站桩，而且会带进模型自己切的镜头。一律按戏剪短，只取一段
- **按分镜时长硬剪对白**：配音约 3 字/秒，「这门锁换过了」会被切成「这门」。剪辑跟人声走，宁可总时长变长
- **默认从 0 秒开始剪**：生成片段开头常是参考图静帧，人物还没动。入点会自动跳过头 0.4 秒
- **只交同期声**：静场段没有底噪和音效，上楼、时间跳变这种最该吓人的段落反而最空。声音层是交付必需项
- **让模型画字**：屏幕上的乱码、停在 10:10 的钟面、自己长出来的品牌标识，后期盖不住，只能重出
- **把制作备注印上画面**：`on_screen_text` 的备注必须写在括号里，否则「竖排名牌，画右，后期合成」会当成片名打到画面正中
- **字卡叠在一起**：时间、片名、虚构声明压在同一镜同一格。用 `／` 分开，会自动排成序列依次出现；虚构声明只做角标
- **在剪辑台上救素材**：脸变了、道具漂移、门牌数字不对，这些是重出的活。报告里写清楚交回上游，别用碎切掩盖
- **碎切掩盖穿帮**：0.1–0.4 秒的碎镜不可读，会被体检报成闪帧
- **BGM 盖台词**：带人声的歌放在对白下，金句听不清就传不出去。对白段只用纯音乐长音，并自动避让
- **循环拼接音轨拉时长**：底噪按场景铺、交叉淡化，不是把一条音轨复制粘贴
- **片尾拖黑场**：卡点后黑场或空镜 ≤3 秒；底噪和 BGM 在画面结束后 0.3 秒内收掉，结尾那一声硬音效要和黑场同落
- **报告不看就交付**：⚠️ 每条都要有一句结论。一条都不解释等于没体检
- **改了阈值不重跑测试**：`scenecut.py` / `plan.py` / `sound.py` / `report.py` 的常量都有单元测试锁着，改完跑一遍 `tests/`

## 交付清单

- [ ] `check.py clips` 跑过，`internal_cuts` 非空和 `speech: null` 的对白镜都逐条处理或写进报告

- [ ] `report.md` 第一节 **❌ 项为 0**
- [ ] 每条 ⚠️ 都写了一句「已确认是有意的」或「下一轮修」
- [ ] 台词没被剪断（权威项 ✅），覆盖率低的句子已确认是同音字而不是剪断
- [ ] 响度在目标 ±1 LU 内，真峰值 ≤ −1.0 dBTP
- [ ] 片尾黑场 ≤3 秒
- [ ] 闪帧 0、剪点重复画面 0（或已确认是同机位对照）、计划外切点 0
- [ ] 平均镜长落在 `project.asl` 或片种基准区间内；超 5 秒和短于 0.5 秒的单镜都解释过
- [ ] 声音三层的「用料」列如实告诉用户哪些是真素材、哪些是合成兜底
- [ ] 字卡审计：`on_screen_text` 括号里的内容全部出现在「没有上屏的内容」里；虚构声明只在角标
- [ ] `sheet.jpg` 逐格看过（不能看图时写明「未目视检查」）
- [ ] 交付：成片 + `<成片名>.report.md` + `edl.json` + `sheet.jpg`，并告诉用户改哪个参数能改什么
- [ ] 跑过单元测试：`python3 -m unittest discover -s <本技能目录>/tests -t <仓库根>`
