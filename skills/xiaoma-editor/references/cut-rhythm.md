# 剪辑节奏：入出点、内部切镜、重复帧与闪帧

> 一句话：**节奏由分镜和台词定，不由素材定。** 素材只负责提供「哪一段能用」。

对应脚本：`scripts/scenecut.py`（检测，纯 numpy）、`scripts/plan.py`（选窗口，纯函数）、
`scripts/check.py` + `scripts/report.py`（成片复核与报告）。

---

## 1. 怎么看出片段内部自带切镜

AI 视频工具经常在一段 4–10 秒的素材里自己切了镜头（人脸 → 切到走廊），直接整段用就会：

- 剪点两侧出现**重复画面**（上一镜出点和下一镜入点几乎是同一帧，看着像卡顿）
- 留下 **0.1 秒级闪帧**（中间那段只用到两三帧）

检测办法（`scenecut.py`，全部在 64×36 灰度小图上算，32 镜约 3 秒跑完）：

1. 每帧取 `log1p(亮度)` 的 x/y 梯度幅值，展平成向量，减均值后做 L2 归一化
2. 相邻两帧向量点积 = 结构相似度（−1..1）
3. **取对数**是为了让乘性光照变化（灯亮、屏幕点亮）变成加性；**只看梯度**是为了只比结构不比亮度。
   所以「开灯」这种整幅加亮不会被当成切镜
4. 相似度低于 `CUT_SIM = 0.35`，**且左右邻帧至少比它高 `ISOLATION = 0.30`** → 硬切。
   孤立性这一条很关键：运动模糊会让连续好几帧都偏低，那不是切点
5. 黑帧判定用**第 99 百分位亮度 < `BLACK_PEAK = 24`**（0–255），不用均值——暗夜戏的均值也很低，
   用均值会把整场夜戏当黑场
6. 黑帧与非黑帧的交界也算切点

阈值速查（都在 `scenecut.py` 顶部）：

| 常量 | 值 | 含义 |
|---|---|---|
| `CUT_SIM` | 0.35 | 低于它且孤立 → 硬切 |
| `EVENT_SIM` | 0.70 | 低于它的孤立跳变（不到切镜程度）→ 画面突变（开灯、闪光） |
| `ISOLATION` | 0.30 | 邻帧至少比它高这么多才算孤立 |
| `BLACK_PEAK` | 24.0 | 第 99 百分位亮度低于它算黑帧 |
| `FLASH_S` | 0.3 | 短于它的非黑镜头段 = 闪帧 |
| `DUP_SIM` | 0.80 | 剪点两侧相似度高于它 = 重复画面 |

调阈值的经验：素材噪点大（低光、压缩块）→ `CUT_SIM` 提到 0.45；转场用了叠化 → 检不出来，
叠化本来也不该被当成硬切，别去调。

## 2. 选哪一段

`choose_segment(segs, speech)`：

- **有人声** → 取和人声重叠最多的镜头段（重叠相同再比长度）
- **没有人声** → 取最长的**非黑**段
- 全是黑段 → 退回最长的那段（总比空着强，但报告里会有闪帧/黑场提示）

## 3. 入出点规则

`plan_window(total, planned, has_line, speech, segs, events)`，返回 `{start, dur, segment, flags}`。

| 情况 | 出点怎么定 | 常量 |
|---|---|---|
| 对白镜，量到人声 | `dur = max(planned, 人声长度 + PRE + POST)`，再被镜头段长度夹住。**整句说完才出点，宁可总时长变长** | `PRE = 0.25`、`POST = 0.35` |
| 对白镜，没量到人声 | 按 `planned` 剪，并在 `flags` 写「对白镜没定位到人声，按分镜时长剪，检查是否切掉半句」 | — |
| 无台词镜 | `dur = min(planned, 段长)`，**严格按分镜时长**，素材再长也不多给 | — |

入点：

- 镜头段从 0 秒开始时跳过头 `HEAD_SKIP = 0.4` 秒（生成片段开头常是参考图静帧，人物还没动）
- 镜头段不从 0 开始（说明前面被切掉了）→ 直接用段起点，不跳
- 台词跨了片段内部切点 → **保台词**，不避切点，`flags` 写「台词跨片段内部切点，为保整句没有避开，建议重出」

最后一步 `avoid_slivers`：入点或出点距离画面突变（`detect_events` 的结果）不到 `FLASH_S = 0.3` 秒时，
把窗口挪开——优先把入点往前挪，让突变前至少留 0.3 秒；挪不动再挪到突变之后。
挪动必须同时满足「不出镜头段」和「不切掉 `keep`（人声区间）」，否则宁可留着闪帧也不切台词。

帧对齐：`frames = max(1, round(dur × 30))`，实际时长 = `frames / 30`。所有镜头都按帧数拼，
成片不会出现累积的音画错位。

### 兜底：转写没认出台词时

`plan.energy_span(stereo)` 用人声频带能量找人声区间：逐帧（60 ms 汉宁窗，30 ms 步长）做 FFT，
取 250–3500 Hz 的功率，要求

1. 比全片第 20 百分位高 `rise_db = 10` dB
2. 人声带能量占 40 Hz 以上总能量的比例 ≥ `min_voice_frac = 0.15`

第 2 条是必须的：只做第 1 条时，电机嗡鸣、雨声低频这类**强带外能量**会从滤波器边缘漏进来，
把没人说话的段落认成人声，入出点就跟着错。

## 4. 成片复核

`check.py film` 在成片上再跑一遍同样的检测，和 edl 里的计划剪点对：

| 项 | 怎么算 | 门槛 |
|---|---|---|
| `detected_shots` | 成片里的镜头段数 | 应等于镜数 + 片尾黑场段数 |
| `extra_cuts` | 检出的切点里，距任何计划剪点都超过 `MATCH_TOL = 2.5` 帧的 | 0 |
| `missing_cuts` | 计划剪点里没被检出的 | 0（相邻两镜画面太像时会漏检，人工看一眼） |
| `flashes` | 短于 0.3 秒的非黑镜头段 | 0 |
| `duplicates` | 计划剪点两侧各 0.5 秒内，任一对帧相似度 ≥ 0.80 | 0（同机位对照是有意的，人工确认后忽略） |
| `black_tail_s` | 片尾连续黑帧秒数 | ≤ 3.0 |

## 5. 节奏报告怎么读

`report.md` 第二节给三样东西：

1. **平均镜长 `asl`**，对 `storyboard.project.asl`（±0.3 秒容差）。分镜没给 `asl` 就写「人工对照片种卡」
2. **逐镜表**：镜号 / 计划 / 实际 / 偏差 / 是否对白 / 入点 / `flags`。
   `flags` 是剪辑过程中所有让步的记录，一条都不要放过：
   - 「片段内部有切点，取 X–Ys 这一段」→ 素材自己切镜了，正常，但说明提示词该加「单一连续镜头」
   - 「台词跨片段内部切点」→ 这一镜最好重出
   - 「可用镜头段只有 Xs，短于分镜 Ys」→ 素材不够长，重出或改分镜
   - 「对白镜没定位到人声」→ 装上转写库重跑，或人耳听一遍
   - 「入出点避开了画面突变，防闪帧」→ 正常
   - 「无台词镜检出人声（已压低）」→ 模型自己冒出人声，混音已压到 −30 dB，最好重出
3. **被素材撑长的镜头**（按偏差排序）。偏差为正只有一种正当理由：**台词说不完**。
   如果不是对白镜却超了计划，就是 bug 或者素材问题，要查

判读顺序：先看 `asl` 是否落在片种区间 → 再看 `over_plan` 是不是全为对白镜 →
再看 `over_5s` 和 `flashes` → 最后逐条读 `flags`。

## 6. 镜长基准

优先用分镜给的 `project.asl`（分镜技能按片种卡填）。没有时按这张表人工核（单位：秒/镜）：

| 类型 | 平均镜长 |
|---|---|
| 悬疑推理 / 程序 | 2.2–3.5 |
| 民俗氛围 | 3.6–5.5 |
| 逆袭（写实竖屏） | 2.7–3.1 |
| 逆袭（漫剧） | 2.0–2.4 |
| 穿越重生 | 1.5–2.8（快档 1.3–1.7） |
| 甜宠 | 1.5–2.4 |
| 复仇情感 | 2.5–3.5（对线 1.8–2.8，横屏 3–4.5） |
| 奇幻旁白蒙太奇 | 1.2–3.2 |
| 奇幻对白情景 | 2.7–5.5 |
| 古风言情 | 1.9–2.3（动作志怪 2.0–2.4，寓言 3.5–5） |
| 家庭短单集 | 2.1–3.5（长集 2.5–4.2） |

硬门槛（与片种无关）：

- 单镜下限 **0.5 秒**，再短不可读
- 非高潮单镜上限 **5 秒**，超了要么是分镜给长了（回分镜改 `duration_s`），要么是台词说不完（改台词或重出）
- 快段与慢段的镜长要拉开 **2 倍以上**，全片一个速度等于没有速度
- 总时长漂移超过计划的 **±25%** 要回头查：多半是对白镜时长按 4–5 字/秒估的，实际配音约 3 字/秒

对白镜时长在分镜阶段就该按「**字数 ÷ 3 + 0.8 秒**」给。剪辑只能保证不切半句，
不能把 5 秒的台词塞进 2 秒的镜头里——报告会把这笔账算给你看，但修要回到分镜。
