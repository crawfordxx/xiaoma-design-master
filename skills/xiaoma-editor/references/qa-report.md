# 体检与剪辑报告：查什么、门槛多少、不合格怎么修

> 一句话：**报告是交付物的一部分，不是日志。** 每一项都要能被一个没参与剪辑的人读懂并据此行动。

对应脚本：`scripts/check.py`（两个入口）、`scripts/report.py`（判定与渲染）。

---

## 1. 两个入口

```bash
S=<本技能目录>
# 素材体检：剪之前跑，决定哪些镜头要重出
python3 $S/scripts/check.py clips <项目目录> [--clips 片段目录] [--storyboard 路径]
# 成片体检 + 剪辑报告：剪之后跑
python3 $S/scripts/check.py film <成片.mp4> [--edl edl.json] [--storyboard storyboard.json] [--out 目录] [--no-asr]
```

`assemble.py` 结尾会自动跑一次 `film`，产物在 `<项目目录>/edit/<成片名>/review/`。
给了 `--edl` 时报告还会复制一份到成片旁边：`<成片名>.report.md`。
只给 `--edl` 不给 `--storyboard` 会直接报错（报告的一半字段要靠分镜）。

`film` 模式产物：

| 文件 | 内容 |
|---|---|
| `report.md` | 人读的剪辑报告，七节 |
| `report.json` | 同一份数据的机器可读版，给下一轮自动化用 |
| `sheet.jpg` | 每镜中间帧拼图（带镜号和时间码，最多 72 格，每行 6 格，单格宽 240 px） |

## 2. 素材体检（`clips`）字段

每镜一行 JSON：

| 字段 | 含义 | 看到什么该动 |
|---|---|---|
| `missing` | 片段文件不存在 | 补出这一镜 |
| `duration` / `size` / `fps` / `audio` | 素材规格 | `audio: false` → 这一镜没有同期声，声音层全靠铺 |
| `internal_cuts` | **片段内部自带切点**（秒） | 非空说明模型自己切镜了：提示词补「单一连续镜头，从头到尾同一机位，不切换镜头、不剪辑」后重出，或接受剪辑只取一段 |
| `events` | 画面突变（开灯、闪光，不到切镜程度） | 密集出现说明光照在飘，入出点会自动避开 |
| `black_tail` | 素材尾部黑场秒数 | 长于 0.5 秒要注意，剪辑选段会自动避开整段黑 |
| `planned` / `dialogue` | 分镜计划时长 / 是否有台词 | — |
| `speech` | 人声区间 `[起, 止]`（相对素材起点） | `null` 且 `dialogue: true` → **这一镜会被按分镜时长硬剪，很可能切半句**，先解决转写或人工听 |
| `heard` | 转写文本 | 和分镜台词对不上 → 模型念错了或漏了，重出 |

`speech` 的来源优先级：转写词级时间戳 → 转写段级时间戳 → 人声频带能量兜底。
没装转写库时 `speech` 和 `heard` 都是 `null`，素材体检仍然给时长、切点和黑场。

## 3. 成片体检项与门槛

门槛常量都在 `scripts/report.py` 顶部，改门槛只改那里。

| 项 | 门槛常量 | 值 | 不合格档位 | 说明 |
|---|---|---|---|---|
| 响度 | `LUFS_TOL` | 1.0 LU | ❌ FAIL | 实测 integrated 与 `--lufs`（默认 −16）之差 |
| 真峰值 | — | −1.0 dBTP | ⚠️ WARN | 超了平台会再压一次 |
| 片尾黑场 | `MAX_TAIL_BLACK` | 3.0 s | ❌ FAIL | 集尾卡点后黑场 / 空镜 ≤3 秒 |
| 闪帧 | `FLASH_S` | 0.3 s | ⚠️ WARN | 短于它的非黑镜头段 |
| 剪点重复画面 | `DUP_SIM` | 0.80 | ⚠️ WARN | 剪点两侧各 0.5 秒内任一对帧相似度超阈值；同机位对照是有意的，人工确认 |
| 计划外的切点 | `MATCH_TOL` | 2.5 帧 | ⚠️ WARN | 检出的切点距任何计划剪点都超过容差 |
| 没检出的计划剪点 | `MATCH_TOL` | 2.5 帧 | ⚠️ WARN | 相邻两镜画面太像或该处是黑场时会漏检 |
| 平均镜长 | `project.asl` | ±0.3 s | ⚠️ WARN | 分镜没给 `asl` 就只报数值 |
| 超出计划的镜头 | — | 偏差 >0.05 s | ⚠️ WARN | 只有「台词说不完」是正当理由 |
| 超长单镜 | `MAX_SHOT_S` | 5.0 s | ⚠️ WARN | 非高潮单镜上限 |
| 超短单镜 | `MIN_SHOT_S` | 0.5 s | ⚠️ WARN | 再短不可读 |
| 总时长漂移 | — | ±25% | ⚠️ WARN | 计划总长 vs 实际总长 |
| **台词没被剪断** | `LINE_FIT_TOL` | 0.05 s | ❌ FAIL | 剪辑窗口是否盖住素材里量到的人声区间。**不靠转写，同音字不影响，这是判「剪断」的权威项** |
| 台词转写覆盖率 | `COVER_OK` | 0.6 | ⚠️ WARN | 分镜台词里的字有多少被听到 |
| 台词跨剪点 | — | — | ❌/✅ | 没有 edl 人声区间可对时按 FAIL；`台词没被剪断` 通过时按 ✅ 并解释 |
| 转写验不了的台词 | `MIN_CHECKABLE_CHARS` | 2 字 | ⚠️ WARN | 「嗯……」这类不足两字的台词，转写验不了，人耳确认 |
| 制作备注上屏 | `NOTE_WORDS` | — | ⚠️ WARN | 后期/合成/备注/字卡/竖排/画右/画左/小窗/名牌/屏幕/片名下 |
| 无台词镜里的人声 | `STRAY_MUTE_DB` | −30 dB | ⚠️ WARN | 已自动压低，但最好重出 |
| 剪辑没用人声定位 | — | — | ⚠️ WARN | `--no-asr` 或没装转写库 |

**验收线**：❌ FAIL 必须为 0；⚠️ WARN 逐条给出「已确认是有意的」或「下一轮修」。
一条都不解释就交付，等于没体检。

## 4. 剪辑报告七节

| 节 | 内容 |
|---|---|
| 一、总判定 | 上面那张表逐条判定，✅/⚠️/❌ + 一句说明。开头一行是「N 项不合格 / M 项待人工确认」 |
| 二、节奏 | 平均镜长、计划总长 vs 实际总长、**逐镜表**（镜/计划/实际/偏差/是否对白/入点/flags）、被素材撑长的镜头排序表 |
| 三、剪点与画面 | 检出镜头段数、帧率、计划外/漏检的切点、闪帧、重复画面、片尾黑场 |
| 四、声音层 | 台词参考电平与三层相对电平、混音后未归一的 LUFS、对白避让区间数、**底噪逐段用料表**、BGM 段落表、音效清单（按类型汇总 + 逐条时间）、被压低的无台词镜人声 |
| 五、台词 | 剪辑窗口 vs 素材人声（权威项）、转写覆盖率逐句表、验不了的台词、被剪点切断的句子 |
| 六、字卡审计 | **没有上屏的内容**（制作备注和虚构声明都在这里，逐条列）、像备注却上了屏的字 |
| 七、不合格怎么修 | 每条不合格对应的修法 |

第六节是「备注没印到画面上」的证据：`on_screen_text` 括号里的内容应该**全部**出现在
「没有上屏的内容」里，条数等于分镜里写了括号的镜头数。少了就是漏了。

## 5. `edl.json` 字段

`assemble.py` 写在 `<项目目录>/edit/<成片名>/edl.json`，是剪辑单也是复核的输入：

| 字段 | 含义 |
|---|---|
| `storyboard` / `fps` / `size` / `tail_black` / `duration` / `lufs_target` / `asr` | 成片规格。`asr: false` 表示没用人声定位 |
| `shots[]` | 逐镜：`no` `clip` `planned` `start` `dur` `frames` `at` `segment` `flags` `has_line` `speech_by` `speech_clip` `clip_cuts` `clip_events` `src_w` `src_h` `has_audio` `cards` |
| `shots[].start` / `dur` | **在素材里**的入点和时长（秒） |
| `shots[].at` | **在成片里**的起点（秒） |
| `shots[].segment` | 选中的那个镜头段 `[起, 止]`（素材内） |
| `shots[].clip_cuts` / `clip_events` | 素材内部的全部切点 / 画面突变 |
| `shots[].speech_by` | `转写` / `能量` / `null` |
| `shots[].cards[]` | 上屏的字卡：`kind` `text` `screen_box`（是否贴进了屏幕区域） |
| `sound` | `levels` `beds` `sfx` `music` `speech_intervals` `stray_voice_muted` `pre_loudnorm_lufs` |
| `dropped_text[]` | 没上屏的内容：`no` + `text`（`备注：…` 或 `声明并入角标：…`） |

改一镜重剪时，先读 edl 定位是哪一步让了步（看 `flags`），不要从头猜。

## 6. 已知误报（看到别慌，但要看）

| 报告说什么 | 为什么 | 怎么处理 |
|---|---|---|
| 「制作备注上屏：#N「备注：…」」 | 屏幕内容本身可能就是订单 / 工单的「备注」字段 | 看 `sheet.jpg` 那一镜：字在屏幕区域里、内容和剧情对得上 → 确认忽略 |
| 「台词转写覆盖率 0.5–0.8」 | 按字计数，同音字一律算错（「青山路」听成「清山路」、「十七号」听成「石七号」这类，人名地名数字最容易中） | 先看「台词没被剪断」是不是 ✅。是 ✅ 就说明没剪断，把地名、人名、数字上字幕解决识别问题 |
| 「没检出的计划剪点」 | 相邻两镜画面结构太像（同机位对照），或该处正好是黑场 | 看 `sheet.jpg` 两镜是否确实是两个画面 |
| 「剪点重复画面」 | 有意的同机位对照（同一机位拍前后两个时空）相似度天然高 | 确认是设计意图就忽略；不是就挪入点 |
| 「无台词镜检出人声（已压低）」 | 模型自己生成的含混人声 | 已压到 −30 dB。听得出来就重出该镜（提示词写「无人声」） |
| 「超出计划 N 镜」且都是对白镜 | 配音语速约 3 字/秒，分镜按 4–5 字/秒估的 | 剪辑只能保整句。回分镜按「字数 ÷ 3 + 0.8 秒」重估，或砍台词 |

## 7. `sheet.jpg` 目检清单

拼图每格左上角标了 `#镜号 时间码`。逐格看六件事：

1. 字卡有没有压住脸、压住关键证据
2. 屏幕类字卡是否落在屏幕区域里（不是浮在画面中间）
3. 屏幕上还有没有透出模型画的乱码
4. 名牌、时间卡、片名有没有叠在同一格
5. 角标在不在（右上角小框）
6. 跨镜的道具、服装、场景有没有漂移（头盔颜色、门牌、袋子）——**这一条不是剪辑能修的，
   写进报告交回上游重出**

看不到图的环境（纯文本模型）：以 `report.json` 的数值为准，并在交付里写明「未目视检查拼图」。

## 8. 交付前的最后一遍

```bash
python3 $S/scripts/check.py film <成片.mp4> --edl <edit/xx/edl.json> --storyboard <storyboard.json> --out <edit/xx>
```

对着 `report.md` 第一节念一遍：

- [ ] ❌ 项为 0
- [ ] 每条 ⚠️ 都写了一句「已确认」或「下一轮修」
- [ ] 底噪 / BGM / 音效三张表的 `用料` 列里，哪些是「素材」哪些是「合成兜底」已经如实告诉用户
- [ ] `sheet.jpg` 看过（或写明未看过）
- [ ] `<成片名>.report.md` 和成片放在一起，用户能直接打开
