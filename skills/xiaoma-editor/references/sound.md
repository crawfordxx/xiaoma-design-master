# 声音三层：底噪、音效、BGM

> 一句话：**只有素材同期声的成片不算做完。** 静场段（上楼、时间跳变、等人开口）最需要有声音设计，
> 而那正是素材最空的地方。

对应脚本：`scripts/sound.py`（三层合成与混音）、`scripts/assemble.py` 的 `build_sound`（编排）、
合成音色来自 `studio/engine/audio.py`。

采样率固定 `SR = 48000`，帧率 `FPS = 30`，每帧 `SR / FPS = 1600` 个样本。
**所有层先在 numpy 里对齐到成片总样本数 `n = 总帧数 × 1600`，再一次性混音**，不在 ffmpeg 里做多轨拼接——
拼接的舍入误差会累积成音画错位。

---

## 1. 素材目录约定

```
<项目目录>/sound/
├── beds/    <场景 id>.wav      环境底噪，一个场景一条，可循环
├── sfx/     <类型>.wav         音效，一个类型一条（hit / thud / chime / pop / tick / riser / whoosh / glitch / swell）
├── music/   <情绪>.wav         BGM 长音，一个情绪一条（drone / rise / pad）
└── vo/      sNN.wav            逐镜旁白 / 播报（镜号两位，如 s07.wav），替代素材同期声
```

规则：

- 文件名就是查找键，**没有就自动走合成兜底，不报错、不中断**
- 同一类型全片只用一条素材（`render_sfx` 里做了缓存），这是「声音母题」的基础：
  同一个人的钥匙串、同一扇门、同一个手机铃声，第 3 镜和第 30 镜必须是同一条
- 支持 `.wav .flac .mp3 .m4a .aac .mp4 .mov`（`AUDIO_EXT`）。**给 wav 或 flac**，
  有损格式反复解码会有可闻损失
- 素材短了会交叉淡化循环铺满（`load_loop`，淡化 0.5 秒），所以底噪给 3–10 秒就够
- 旁白 `vo/sNN.wav` 会在混音时**加到**同期声轨上，不是替换；同时整镜算进对白避让区间

### 没有素材怎么办

优先级从高到低：

1. **自己录**：手机开录音，安静房间里录 30 秒空调声/楼道声/雨声就够用，循环点选在波形平缓处
2. **免版税素材库**：找 CC0 的 room tone、rain、traffic、crowd walla，剪 5–10 秒存成
   `sound/beds/<场景 id>.wav`。注意场景 id 要和 `storyboard.json` 的 `refs` 里 `type: location` 的 `id` 一致
3. **合成**：本技能自带，见下节。合成底噪是**整形噪声**，听感是「有空间」而不是「有内容」，
   作为兜底完全够，但雨声、人声嘈杂这类有辨识度的场景还是该用真素材
4. 什么都没有 → 交付时明确写「声音层为合成兜底，未使用真实素材」，别当成已完成

### 合成兜底的三种底噪

`synth_bed(preset, n, seed)`，按场景描述里的关键词选（`bed_preset`）：

| preset | 触发词 | 做法 |
|---|---|---|
| `rain` | 描述里有「雨」 | 300–9000 Hz 整形噪声（tilt −0.6）+ 稀疏雨滴脉冲（每样本 0.05% 概率，指数衰减 240 样本） |
| `outdoor` | 街 / 路口 / 外立面 / 广场 / 野外 / 山 / 海 / 室外 / 楼外 | 30–1500 Hz 整形噪声（tilt −1.6，接近褐噪），像远处的车流 |
| `room` | 其他 | 25–600 Hz 整形噪声（tilt −2.0）+ 50 Hz 与 100 Hz 市电哼声（0.02 / 0.01 幅度） |

`_shaped_noise` 是频域整形：白噪声做 FFT，带外置零，再乘 `(f/1000)^(tilt/2)`。
`tilt = −1` 是粉红噪声，`−2` 是褐噪声。

音效和 BGM 的合成走 `studio/engine/audio.py`：`sfx(kind, seed)` 有 whoosh / hit / thud / pop /
tick / riser / swell / glitch / chime 九种；`pad(freqs, dur)` 是锯齿波叠轻微失谐 + 900 Hz 低通 + ADSR。

## 2. 第一层：环境底噪

`render_beds(timeline, refs, beds_dir, n)`：

1. **场景怎么定**（`assign_scenes`）：`shot.scene` → 该镜 `refs` 里第一个 `type: location` 的 id →
   沿用上一镜。开头几镜都没写场景时，回填第一个已知场景（宁可有个底噪，不要开头是数字静音）
2. 连续同场景的镜头合并成一段（span）
3. 最后一段一律铺到成片结尾 `n / SR`（含片尾黑场），再由 `build_sound` 在画面结束后收掉
4. 每段：找到素材就 `load_loop`，找不到就 `synth_bed`；然后 **RMS 归一化到 1.0**，
   段间交叉淡化 `xfade = 0.3` 秒
5. 返回 `(单声道数组, 用料清单)`，清单里每段写清 `source` 是「素材 xxx.wav」还是「合成兜底（preset）」
   ——**这份清单会进剪辑报告，交付时必须能看出哪些是真素材**

归一化到 1.0 是有意的：底噪的绝对电平由混音阶段的相对台词电平决定，素材本身录多响都不影响结果。

## 3. 第二层：音效

### 从 `sfx` 字段解析

`parse_sfx(text, dur, events)`：按 `；;。，,` 分句，每句在 `SFX_RULES` 里找第一个命中的规则。

| 文字里出现 | 出什么 | 备注 |
|---|---|---|
| 敲门 / 叩门 | `thud` × N | N 从「一/两/二/三/四/几 下」读，缺省 3 下，间隔 0.32 秒 |
| 落地 / 闷响 / 砸 / 摔 / 撞 / 跌 | `thud` | |
| 钥匙 / 叮铃 / 铜铃 / 铃铛 | `chime` | |
| 提示音 / 接单 / 叮咚 / 通知音 | `pop` | |
| 震 | `tick` × 2 | 间隔 0.12 秒 |
| 咔哒 / 开关 / 门锁 / 锁 / 门链 / 插销 / 按键 | `tick` | |
| 电流 / 通电 / 短路 / 滋啦 | `glitch` | |
| 数字滚动 / 跳秒 / 滴答 / 秒针 | `tick` × 6 | 间隔 0.12 秒 |
| 呼啸 / 掠过 / 甩过 | `whoosh` | |
| 冲击 / 重击 / 轰 / 爆炸 | `hit` | |

时间点怎么定（优先级从高到低）：

1. 句子里有「黑场 / 同落 / 同时落 / 结尾 / 收尾」→ 落在**镜头末尾**（`dur − 0.05 −` 该组最后一个偏移）
2. 是第一个分句且这一镜检出了画面突变 → **踩在第一个突变点上**（声画同步）
3. 其余 → 按分句序号在镜头内均分，`dur × i / 分句数 + 0.15`

不放音效的情况：命中词之后 2 个字内出现「停 / 止 / 消失 / 不响 / 没了」（`STOP_AFTER`）。
「电流声消失」不该有电流声。

雨声、风声、空调声这类**持续环境声不在这个表里**——那是底噪的活，写进 `sfx` 字段也不会出音效，
这是有意的：持续声按场次铺比按镜放更连贯。

### 关键节拍

`beat_cues(beats, timeline)`：`strategy.beats` 里名字或 `purpose` 前 6 字含
「反转 / 揭 / 翻盘 / 高潮 / 爽点 / 兑现」的节拍，在该节拍的镜头上放

- `riser`，提前 2.0 秒进，增益 0.5
- `hit`，落在该镜头第一个画面突变点上（没有突变就落在镜头起点），增益 0.8

前提是镜头的 `beat` 字段等于节拍名。riser 起点会夹到 ≥ 0，不会跑到片头之前。

## 4. 第三层：BGM

`plan_music(timeline)` 把每镜的 `music` 字段连成情绪段落：

| 字段写法 | 结果 |
|---|---|
| `无` / `无，…` / `抽掉` / `全静` / `骤停` / `静音` / `切断` / `无音乐` / `不要音乐` | 当前段落在此镜起点结束 |
| 其中「抽掉 / 骤停 / 切断」 | 淡出 **0.03 秒**（硬切，声音抽空的效果） |
| 其余的「无」 | 淡出 **0.4 秒** |
| 含「弦乐 / 上行 / 升 / 温暖 / 抒情 / 希望 / 明亮」 | 情绪 `rise`（整段上行一个半音的渐强弦乐） |
| 含「低频 / 低音 / 长音 / 压抑 / 悬疑 / 紧张 / 不安」 | 情绪 `drone`（55 / 82.4 / 110.3 Hz 长音 + 0.11 Hz LFO + 低频噪声） |
| 其他非空文字 | 情绪 `pad`（三音锯波 pad） |
| 空字段 | **沿用上一镜的情绪**（分镜不用每镜都写） |
| 结尾「…停」/「淡出」/「收住」 | 段落收在当前镜末尾，淡出 0.4 秒 |

情绪变了就切段，前一段淡出 0.4 秒、新段淡入 `fade_in = 0.8` 秒。片尾还开着的段落默认淡出 0.6 秒。
`render_music` 按段找 `sound/music/<情绪>.wav`，没有就 `synth_music`，同样 RMS 归一化到 1.0。

## 5. 电平关系与对白避让

`mix(dialog, bed, music, fx, speech, n)`：

1. **参考电平 `ref`** = 台词区间内同期声的 RMS 换算成 dB。没有台词区间就用整轨 RMS；
   整轨都静音则用 `FALLBACK_REF_DB = −26.0`
2. 三层按相对 `ref` 定电平：

| 层 | 相对台词 | 常量 |
|---|---|---|
| 环境底噪 | −20 dB | `BED_REL_DB` |
| BGM | −14 dB | `BGM_REL_DB` |
| BGM 在对白段再降 | −12 dB | `DUCK_DB` |
| 音效峰值 | +6 dB | `SFX_PEAK_REL_DB` |

合起来就是**对白段 BGM 比台词低 14 + 12 = 26 dB**，落在「比人声低 10–15 dB 避让」要求的严格一侧；
无台词段 BGM 比台词低 14 dB，听得见情绪但不会盖住音效。音效峰值比台词 RMS 高 6 dB
（约等于峰值比台词峰值低 0 dB 上下），够突出但不炸。

3. **避让区间从哪来**（`assemble.speech_intervals`）：
   - 有台词的镜头 → 量到的人声区间，前扩 0.1 秒、后扩 0.2 秒（后扩更多，句尾余音）
   - 没量到人声 → 整镜
   - 有 `vo` 且有 `sound/vo/sNN.wav` → 整镜
4. `duck_envelope` 在区间内取 `DUCK_DB`，前后各 `ramp = 0.15` 秒线性过渡。多个区间重叠时取最小增益
5. 三层求和成单声道，再和同期声（立体声）相加。**底噪和音效不避让**：底噪一避让就会「抽真空」，
   听感是房间忽大忽小；音效是要被听见的

### 无台词镜里冒出的人声

模型有时会在没台词的镜头里生成含混人声。`build_sound` 对「无台词但检出人声」的镜头，
把同期声在那段人声区间压到 `STRAY_MUTE_DB = −30 dB`（`ramp = 0.05`），并在 `flags` 和报告里记一笔。
`--keep-stray-voice` 可以关掉这个行为（比如那确实是你要的群杂声）。**最好的修法还是重出该镜。**

### 片尾

画面结束后 0.3 秒，底噪和 BGM 用 0.3 秒 ramp 收到 −80 dB（`build_sound` 里的 `fade`），
不拖到黑场里去。**音效层不收**：结尾那一声钥匙响要和黑场同落。

## 6. 响度

`loudnorm(src, dst, target=−16.0, tp=−1.5)` 走**两遍**：

1. 第一遍 `loudnorm=I=−16:TP=−1.5:LRA=11:print_format=json -f null -` 只测不改，拿到
   `input_i / input_tp / input_lra / input_thresh / target_offset`
2. 第二遍带上测量值 + `linear=true` 真改，输出 48 kHz / 24 bit wav

单遍 loudnorm 是动态模式，会泵（pumping）并且对白忽大忽小；两遍 + `linear=true` 才是纯增益。
第一遍测到的值写进报告（`pre_loudnorm_lufs`），用来看混音本身平不平衡：
如果混音后是 −30 LUFS 而目标 −16，说明要加 14 dB 增益，真峰值可能顶穿，得先回头降音效。

**目标 −16 LUFS**（短视频平台的常见交付值）。要别的值用 `assemble.py --lufs`，
`check.py` 的门槛是实测与目标差 ≤ `LUFS_TOL = 1.0` LU，真峰值高于 −1.0 dBTP 会 WARN
（会被平台再压一次，等于白做一遍响度）。

## 7. 常见翻车

| 症状 | 原因 | 修 |
|---|---|---|
| 静场段死寂，像视频坏了 | 没有底噪层，或素材本身无声轨 | 底噪是必需层，没素材就用合成兜底，别留数字静音 |
| 底噪一段一段换音色 | 每镜单独铺底噪 | 按**场景**铺，连续同场景合并成一段（`render_beds` 已经这么做） |
| 金句听不清 | BGM 带人声，或没避让 | 对白段只用纯音乐长音；确认避让区间来自人声定位而不是整镜 |
| 音效稀稀拉拉踩不上点 | 只按分句均分，没用画面突变 | 第一个分句会自动踩突变点；关键节拍要写进 `strategy.beats` 且镜头 `beat` 字段要对上 |
| 同一串钥匙前后两种音色 | 每处各合成一次 | `render_sfx` 按类型缓存，或放一条 `sound/sfx/chime.wav` 全片共用 |
| 结尾声音拖到黑场里 | 底噪/BGM 没收 | 已内置：画面结束 0.3 秒后收到 −80 dB。要更早收就把 `music` 字段在最后一镜写「骤停」 |
| 响度达标但真峰值超标 | 音效峰值太高，loudnorm 只能整体降 | 降 `SFX_PEAK_REL_DB` 或减音效增益，别指望 limiter |
| 音画越到后面越错位 | 各层长度不等于成片长度 | 每层必须正好 `n` 个样本（`fit` / `render_*` 已保证，测试里锁死了这条） |
| 场景切换处「咔」一声 | 底噪段之间硬接 | `render_beds` 段间 0.3 秒交叉淡化；自己拼轨时也要淡 |
