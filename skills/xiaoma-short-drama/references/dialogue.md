# 短剧台词

> v0.4。例子都是自拟的。第 9–10 节部分方法改写自 Short-Drama Factory（老李，MIT，见仓库根目录 THIRD_PARTY_NOTICES.md）。

## 1. 口语硬规则
- 单句 ≤15 字为主；超过 20 字的句子拆成两镜两句。
- 每句只干一件事：推进冲突、给信息、出笑点，三选一。
- 第一句同时交代「谁 + 哪里不对」（「姐，我就问一句，你那房子到底给不给我」「周敏，你给我站住」+ 一个离谱的低价）。
- **不写解说型台词**：「三年没人进过那屋」「她再也没回来过」这种替观众总结的话，改成动作或物件（门把手上一层厚灰、老人背过身把钥匙扔过来）。台词只说角色此刻要对另一个人做的事。
- 不互报身份。新角色身份用名牌字卡（【身份】人名条、竖排书法名牌）；姓名、年龄、职业必须交代时，用一句旁白身份卡（「我叫苏禾，二十六，替人看风水」）。
- 特殊设定不让主角自报，让电话那头的配角、系统的声音、广播一句话带出来。
- 方言和口音只在人设需要时用，并写成卖点（一口川普的土地公、东北话的看事人）；方言片的笑点必须配准确字幕，转写错一个字包袱就没了。口音和人设不符会被骂。
- 生成和配音前把角色名、性别列表核对，防止同音名混用、男孩被叫成「她」。不用一眼就能看出是 AI 起的高频名字。
- 历史题材的称谓和自称做最小考据；做不到就让角色主动把漏洞变成梗（「穿过去才发现，一句古文都听不懂」）。
- 简介和标题里写的梗，正片必须有一镜 + 一句台词兑现。
- **设定词要可视化防同音误读**：容易被听成另一个词的设定术语（「厌世症」听成「厌食症」），必须配画面解释，不能只靠台词。
- **人物命名避开同姓近音**：「陆雨深 / 陆景深」「江星星 / 江雨薇」这种名字听辨成本过高；名字要有记忆点；同一角色全片不能被叫两个名字（称呼、字幕要统一）。
- **口头禅重复至少三次**，第三次放在赌约或卡点上。
- 糙汉、年代角色的誓言用他自己的粗话说，不用书面语；但粗口誓言别被写成玩梗反讽。
- **方言配音的 AI 剧必须请母语者把台词口语化过稿**：书面语词和错音是置顶负评的第一来源。
- 语速按片种卡：多数 3.5–4.5 字/秒，家庭剧约 3.4，吵架戏可以冲到 6 以上；单镜不超过 5 字/秒（director 校验会拦）。**AI 配音实际约 3 字/秒**，写分镜时对白镜时长按「字数 ÷ 3 + 0.8 秒」估，或者把台词再砍短（见 ai-production.md）。

## 2. 潜台词：嘴上一套，画面一套
| 手法 | 写法 |
|---|---|
| 心声反差 | 表面台词 + 括号字幕或 Q 版心声，一句一反差，正反配对 |
| 双声道 | 外部恭顺台词 + 内心吐槽独白；每个主角动作后紧接配角反应镜和一句心声 |
| 强颜欢笑 | 电话里报喜，画面给哭脸特写 |
| 物件代说 | 「我关心你」换成碗里多出的一块肉、挤好的牙膏；被退回的蛋糕外显顺从的代价 |
| 习惯揭身份 | 「我不吃葱，以前都是他替我挑」——不直说亡夫 |
| 嘴硬打脸 | 「这种小事别找我」→ 下一镜起身「散会」，声音桥接硬切 |
| 半截咽回 | 告白说一半咽回去 |
| 双关寒暄 | 表层寒暄、里层暗示（「这么晚还加班，辛苦了」），心理活动用画外心声补 |
| 一句两义 | 一句台词先指向假前提，回看时指向真相（「爸又忘了关火」——忘事的其实是说话的人） |
| 误读正反打 | 同一句话先拍说话人近景，再拍听者误读后的反应近景 |
| 受害者替加害者开脱 | 「你别怪他，他也不容易」，用她的维护反向暴露真凶 |
| 温柔恐怖 | 用关怀的话说最恐怖的事（「你太累了，以后我替你活」） |
| 标签字幕 | 小号「*察觉不对劲」「【醋意上头】」替代 AI 做不出的微表情 |
| 双声部（外狠内怯） | 外放台词威严 + 内心 OS 口语 / 方言；OS 段画面用表情特写或背影避开口型 |
| 心声被听见 | 吐槽心声只被特定的人听见——每条心声自动产生一组听者反应镜 + 一组不知情者反应镜 |
| 赐予式台词 | 上位者用「我许你」「我没有不准」表现权力，少用叫嚣式威胁 |
| 嘴硬三级阶梯 | 态度转变走威胁 → 试探 → 妥协三级台词，每级配特写推近，禁止用独白宣布转变 |
| 长句对两字 | 被抛弃的一方说长而重的话，离开的一方只回两个字，下一镜再揭离开方的崩溃 |
| 双关自曝 | 面具反派一句双关台词（「维持现状」）作自曝点，不靠狞笑特写 |

心声里的称呼避开伦理违和词（「妈妈」「主人」这类），用常规爱称。双声部（外狠内怯）是穿书和甜宠反差萌的核心引擎；两个角色都给心声时，观众比角色知道得多，悬念变成戏剧反讽。

## 3. 金句句式
1. **镜像回击**：照搬对方句式或偷换主语，≤15 字、不带脏字（「你说我配不上，是你够不着」）；前 30 秒写一句立场台词，反转点让对手用镜像句式反打回来。
2. **复读原话**：主角逐字复述反派原话；或者反派作案前许下的承诺（「我一定原样交给他」），在他抵赖时被回打。
3. **三连反问排比**：每问带一个具体年龄或细节，句尾重复同一句反问（「我十二岁替你做饭的时候，你怎么不说一家人？」）。
4. **顺口溜收尾**：6–8 句、每句 3–5 字的排比；字幕人工校对，确保可截图。
5. **格言翻转**：片尾黑底白字「门一直开着，不代表人一直在等」。
6. **问答式主题句**：一问一答压缩主题，同时作标题和最后一句台词（「狐狸修成人要多久？等到有人不怕它的时候」）。
7. **≤10 字动作承诺**：结尾不出现「爱」字，用动作承诺代替抒情（「明天我还来接你」）。
8. **领袖三字排比**：一组三字指令作领袖时刻（「拿干粮，背老人，往山上走」），再配一句价值对仗金句供评论区复述。
9. **对称决定句**：「你们有你们的选择，我有我的选择」。
10. **双关收束**：爽点后用一句双关收全集。
11. **主题宣言 ≤8 字**：受害者喊出世界观真相（「这镇上没有活人」）。
12. **赐予式 / 对仗收束**：大女主用赐予式台词（「我许你」）表上位；结尾用一组对称句式金句收束，给它整段最长的镜头（3–4 秒）。
13. **俗语对仗金句 ≤12 字**：每 10–20 秒落一句对仗式俗语金句，方便观众截取转发；金句要能一秒对应观众的现实痛点（房贷、加班），用物理负担说心理负担，句子 ≤10 字。
14. **立誓 ≤5 字**：卡点时主角点出宿敌全名，立一句五字以内的誓言。
15. **网络梗比喻**：穿书开场让主角像观众一样吐槽「原著」，用一句网络梗比喻做金句。
16. **更正句式收尾**：爽点后用更正式的金句打脸（「更正一下，现在她是我的妻子」）；金句前抽 0.8 秒静场，说完 2 秒内切黑。主题句（片名级台词）留给反派在高潮入口说，开场只字不提。

禁区：诅咒式回击、物化台词、密集粗口、成年人口吻的孩子台词；血腥题材别连用三句以上的食物比喻，一句就够，多了引起恶心。

## 4. 信息怎么藏进冲突
- **对质代替说明**：设定由反派或追捕者在逼问里说出来。
- **清单体**：条件一条比一条亲密，最后一条是告白；困境清单人、钱、物各一项，结尾主角一句话全接下。
- **精确数字作母题**：选一个荒诞的小数字做全集记忆点，至少回收三次，最后一次由主角反用（「八块钱」）；同一个价格让不同立场的人反复说出，标记态度变化；情感矛盾量化成金额，重复 ≥3 次且每次换说话人；模糊时长换成精确数字，高潮前说得更精确（「三个多月」→「一百零三天」）。
- **第一句报利益**：第一句报具体利益（哪套房、多少钱），冲突 3 秒内可量化；真实原因藏到约 40 秒才揭，让观众先站错队。
- **账本式独白翻转同情**：弱势方先占理，强势方后发账本式独白（彩礼、首付、回家次数）——两边都要有理，别写成一边倒的预设答案。
- **生活细节连发**：认亲、穿越自证用 3–5 条只有当事人知道的细节，一句一条一镜。
- **一句堵洞**：设定有明显捷径时，让角色主动一句话堵住；警方的强制动作配一句程序性台词（「在场的都跟我们回去做笔录」）。
- **可核对的事实反驳**：产权、出资、次数、金额，再亮手机证据。**借口 — 物证一一对应**：对手每给一个借口，下一镜用一个物件或记录拆掉。
- **推理三段式**：现象 → 机关 → 结论，每句约 2 秒，配一个证物插入。
- **对仗拆穿**：「你一直在解释 X，我问的是 Y」。
- **证人逐条描述**：证人每说一项特征，切一镜主角身上的对应物件，最后主角心声一句「说的是我」完成反转。
- **吐槽可视化**：角色吐槽某人外貌时，同步插入被吐槽对象的对应特写。
- **外部权威说主题句**：医生、律师、老板替观众说出主题句，主角只负责做决定；保姆、助理当嘴替；每个情绪节点配一个旁观者替观众说的话。
- **反派先用画外音登场**：一句使唤人的台词交代权力关系，再给正脸。
- **身份标签当扳机**：每 20–30 秒让反派说一次「外头抱来的」类标签，持续蓄怒。
- **质问阶梯**：说教写成质问阶梯，每段以问句收尾逼对方自曝双标，不用宣言式输出。
- **具体数字算账**：家庭伦理戏的证据用具体数字算账（药价、退休金、存款前后余额），由最清醒的角色当众算出来。
- **推理台词配证据插入**：推理台词说到的每个体征都配一个 0.5 秒的证据插入特写，不要只让人物说；审讯戏一问一答控制在 1 秒一轮，台词换人就换镜。
- **贯口 / 自黑卖点**：每个抢人的配角配一个自黑卖点（秃头、小黑屋、本命祖宗），三人口播贯口不超过 25 秒。
- **双视角误读**：让两位主角各持一份「剧本」（原著、前世记忆），同一动作分别配两人的旁白解读，制造双向误会。
- 反例：靠旁观者口头解说反转、画面没有证据；主题全靠对白喊出来；一个长镜里塞五条案件信息；因果只靠一句解说跳过。

## 5. 喜剧节拍
- 三拍循环 + 第四拍打破：亮相 → 判词特写 → 主角反应，每拍 ≤1 秒，第四次打破；请求 → 拒绝 → 收买 → 失败，15 秒一个小循环。
- 同一称呼梗至少用两次，第二次加反转（「叫学姐」→「叫姐姐」）。
- 一本正经的荒诞并置：严肃人物郑重说出现代词，正经说明字幕写惨事。
- 「传闻 → 否定 → 验证」三段包袱；外形与声音反差（仙风道骨的白鹤开口一嘴大嗓门方言）。
- 话痨僚机替观众问出质疑，主角正面回答。
- 反英雄出手前报一个具体价码，结尾用同一价码自嘲。
- 紧张段插入方言小人物泄压，泄压后用一句双关把怀疑拉回。
- 碎切的喜剧动作后留 1–1.5s 静止落地镜，再接反应镜。
- 冷回答：大女主不吵架，用 ≤3 字的冷回答 + 直接行动制造爽感（「哦。」然后转身签字）。
- 暖句垫冷刀：每条温情台词后 1.5 秒内接一个冷面捧哏的静止反应特写，暖句和冷刀成对出现。
- 威胁翻译成家务事：把最大的威胁写成家谱里的成员（妈、爸、孩子），高潮对峙的台词全部翻译成家务事（要不要孩子、一顿饭）。
- 直人逻辑钉死：地位反转喜剧里，在跪爬的强者中间插主角的无表情近景，把喜剧的「直人」逻辑钉在画面上。
- 配角嘴贱伏笔：结尾前让配角一句嘴贱的伏笔把私人悬念留到下一集；尾钮用三连重复句收喜剧拍。
- 重复律最多两轮：同一笑点重复三轮以上喜剧递减，第三轮重复必须升级信息量。

## 6. 权力与关系的台词节拍
- **称呼节拍器**：称呼每变一次 = 关系或权力转手一次（「哥 → 先生 → 全名 → 老公」「陛下 → 爱妃 → 皇夫」）。在分集大纲里给每集标出称呼变化点。
- **台词更短的一方赢**：权力反转戏里逐句缩短，最狠的一句给大特写；对手每打一张底牌，用 ≤8 字反问作废。
- **反派炫耀**超过 15 秒，拆成 3 个快切近景，以主角不动的反应镜收尾。
- 霸总台词控制在 6 字以内；结尾用 2–3 组「她问 / 他轻描淡写答」的对仗揭晓真相。
- 上位者用赐予式台词（「我许你」）；嘴硬型男主的态度转变必须走威胁 → 试探 → 妥协三级台词阶梯，每级配特写推近或触觉插入镜。

## 7. 旁白与解说体
- 第一人称一句话设定，≤20 字；在切镜点停半句，答案放下一镜第一帧。
- 每句旁白配一个新画面；解说体每句旁白切一镜，每句至少带一个具体数字（金额、温度、倍数、天数）。
- 世界观设定压成一镜画卷平移 + 说书旁白，≤30 秒，中途插回角色吐槽。
- 解说体里角色只保留惊呼、请求、决定三类短台词，把 2–3 句最狠的原声留给角色本人；旁白占满全片、主角只有两句原声，观众记不住人。
- 第二人称独白（「你」）适合权力反转和情感回望；「有人说……也有人说……」并列两种观点，把评论区变辩论场，但两方要真的势均力敌。
- 单段背景旁白 ≤20 秒，超出就和现在时的危险镜头平行剪。**静音测试**：关掉声音还看得懂主线吗？看不懂就是太依赖旁白。
- **硬规则：旁白只允许用在画面无法自证的设定交代上，其余信息全部走吵架台词**；能用物理阻力就不用旁白（塞钱 → 拉链拉不上 → 抬眼）；闪回段只留一句画外音。
- 说书 / 传说开场写法：三句排比旁白定世界观的「答案表」，每句配 1.5–3 秒奇观插画，结尾每句对应一个现实角色；或旁白宣布传说规则 + 异兽特写 + 闪前镜，前 15 秒立住世界规则；开场 5 秒内旁白说「一个小举动改了命」，同时画面演完该举动。
- **旁白预支爽点**：30 秒左右用旁白预告报应，留住要划走的人；旁白提前揭穿反派真面目制造观众先知的焦虑，同时掩护主角真正的秘密。
- 反例：全片绝大部分靠旁白讲、人物几乎不演，成「有声连环画」；第三人称旁白过密，对白沦为旁白配图，全片只剩一句对白记忆点；近一分钟旁白念前情，信息过载；13–16 秒单镜长独白无插镜；旁白把反派动机和主题说尽，闪回沦为配图；最强的一句台词放在 5 分钟之后，超出完播区间；线性说书节奏均匀，2 分钟内要给一个「说书人不可靠」的小钩。

## 8. 对观众说话的台词（慎用）
- 台词直接指向屏幕外（「看见的人帮我作个证」），能抬互动，但评论区会变成表情和「我作证」，没有剧情讨论；明示诱导点赞有限流风险。
- 真要用，就写成剧情内的赌约（反派亲口提出），或由有裁决权的角色说出并附带惩罚；不要插在紧张段，会打断叙事。
- 仪式式诱导（「献三朵花」）不推荐。
- 祈福接龙式号召（爽点峰值处插一句「留下一句 XX」）会把评论区做成同质化的祈福现场：零有机剧情讨论，打破第四面墙还透支故事可信感；互动量不能当内容质量的证据。
- 求赞口播放在情绪最低谷会打断情绪，评论区被表情刷屏劫持。

## 9. 神态短语：括号里写「怎么说」

剧本里 `角色（……）：台词` 的括号是给配音和出片的表演指示。台词本身只带「谁说、说什么」，「怎么说」全靠括号；括号空着或只写「愤怒」，配音和表情都会变扁、变夸张。

- **一句话判据**：麦克风录得到的是**语气词**，摄像机拍得到的是**画面词**
- **写法**：画面词在前，语气词在后，中间用全角 `｜` 隔开；同类词之间用 `·` 连。纯画面写 `（攥紧缴费单·不抬头）`，纯语气写 `（压低声音·发颤）`，两者都有写 `（把钥匙拍在桌上｜冷笑·一字一顿）`
- **不写结果词**：开心、难过、愤怒、激动、邪魅这类模型执行不了的词不写，换成能执行的写法（`压着火·低声`，不写 `愤怒`）
- **语气词从四个维度挑**：

| 维度 | 可用词 |
|---|---|
| 嗓音质地 | 沙哑、气音、发颤、哭腔、哽咽、有气无力 |
| 力度 | 低声、轻声、柔声、厉声、低吼、压低声音、拖长音 |
| 方式 | 冷笑着说、嗤笑、讥讽、阴阳怪气、咬着牙说 |
| 节奏 | 急促、一字一顿、慢条斯理 |

- **画面词守动作行的规矩**：只写看得见的动作和表情变化（指节发白、喉结一滚、眼神躲开），不写心理
- **关键台词必配语气**：钩子台词、交锋台词、卡点前最后一句，至少这三处括号里要有语气词
- 旁白、内心独白照旧标 `vo` / `os`，可以和语气词并用：`（os｜气音）`

## 10. 让观众一秒听懂

竖屏观众不会倒回去想，「听不懂」和「站着干聊」是两类最直接的划走理由。

### 10.1 对质场：物证和结论同一轮说透

第 2 节的「物件代说」管的是情感场（关心、愧疚、思念），越含蓄越好。**对质、揭穿、算账的场正相反**：亮出物证的同一轮（1–2 句内）必须用大白话把结论说出来，不让观众自己推。

- ❌ `△ 她翻过他的手机。` `她：你上周三不在公司。`（观众要想：所以呢？）
- ✅ `△ 她把手机怼到他眼前，屏幕上是一张酒店账单。` `她（举着手机｜一字一顿）：上周三你说加班，人在酒店开房。` `她：跟谁，你自己说。`

一句话分工：**情感场用物件，对质场说透。**

### 10.2 术语和设定词：当句翻译成后果

行业术语、古语、自创的玄学或系统名词出现时，当句或下一句就翻成大白话后果：多少钱、判几年、谁死谁活、归谁管。

- ❌ 「对方触发了对赌条款，我们的估值被重置了。」
- ✅ 「对赌输了。今晚十二点前补不上两千万，公司就归他们了。」

这条和第 1 节「设定词要可视化防同音误读」配合用：能拍出来就拍，拍不出来就当句翻译。

### 10.3 快慢变速

一场戏的台词如果每句都是十几个字的完整主谓宾，听起来像念稿。交锋时用**短句劈开局面**（2–6 字：「站住。」「你敢？」「签。」），紧跟**一句算账句**亮出筹码和后果（≤15 字，超过 20 字拆开，见第 1 节）。

- ❌ 甲：「你今天要是不签这份合同，我就让你在这个城市待不下去。」
- ✅ 甲（把合同推过去｜冷声）：「签。」 甲：「不签，明天你连房子都租不到。」

### 10.4 动作行：每条都要有画面分量

对白之间穿插的 `△` 动作行，每条至少命中下面一类，否则删掉或换掉：

| 类型 | 例子 |
|---|---|
| 看得见的物理结果 | 茶杯被扫到地上摔碎；门被一脚踹开 |
| 身份反差或手上正在干的活 | 被骂「废物」的主角手上还在熟练地给病人缝针 |
| 亮物证、肢体对抗 | 把检测报告拍在桌上；一把攥住对方手腕 |

**无效微动作黑名单**：单独一行写「他眼神微动」「她微微一怔」「把杯子往前推了推」——镜头拍出来什么都不是，AI 也演不准。要么升级成上面三类，要么并进台词括号里当画面词。（有意设计的静场不算，静场写法见 editing-rhythm.md 和 sound.md。）

连续纯对白不超过 6 行，中间至少插一条有分量的动作行。
