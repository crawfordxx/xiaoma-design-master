# 穿越重生

> v0.3。例子和 logline 都是自拟的。这个片种的基准数据还偏少，区间只作起步参考。

## 定义与情绪承诺

- **观众来看什么**：一个外来者带着土著没有的东西进入陌生规则，用它碾压、捣乱、撩人或救人。观众享受的是**信息差和价值错位**。外来者手里的可能是现代物件、现代手艺、剧情先知（穿书）、前世记忆（重生）、系统能力，或者未来的国家知识。
- **信息差可以叠两层**：最强的穿书写法让两位主角各持一份剧本（她知原著、他知前世），或者让主角的心声被特定角色独家听见——观众同时持有两份以上信息，爽感从「主角碾压土著」升级为「看所有人在错位里打转」。
- **调性**：多数偏喜剧（含黑色喜剧、吐槽喜剧），但**苦情催泪**（重生赎罪、年代养家）和**正剧向年代爽**（重生退婚、手艺逆袭）同样成立且收藏率极高。穿越重生不是只能搞笑：赎罪型走「悔恨 → 偿还」，年代重生走「止损 → 打脸」。
- **五种情绪按权重排**：
  1. **降维爽**：土著越震惊越爽。嫌贵的衙役咬一口炸鸡就闭眼投降；实习生心声点名摄像头位置，董事长当场起获。
  2. **反差笑**：现代梗、网络语原样说给古人或剧中人听；外放台词威严 + 内心 OS 沙雕。
  3. **规则好奇**：门怎么开、什么时候穿、体验卡何时到期、心声谁能听见。规则只给现象、不给解释时，评论区会自己推理（推理型评论能拿几千赞）。
  4. **错位珍惜**：现代人随手丢掉的东西，在过去是救命的宝贝（烂白菜、摔破的鸡蛋）。打心疼，适合中老年女性受众。
  5. **止损 / 偿还爽**：前世吃过的亏，这一世当场退回去——接亲当天被加彩礼的男主重生后当众退婚；前世害死她的混混重生后把粮全给她。爽点是「我知道结局，所以我这次选另一条路」，男频女频通吃，收藏率是全片种最高档（40–80%+）。
- **和相邻片种怎么区分**：
  - **爽文逆袭**：靠「受辱 → 亮牌」翻身，爽点在隐藏身份。本片种的爽点在错位：主角没换身份，换了世界或换了人生。注意：**年代重生退婚类是两片种的交界**——金手指是前世记忆而非外来物，打脸结构完全借用爽文逆袭（当众受辱 → 当众翻盘 → 旁观者反应镜），区别只在触发方式（重生瞬间）和信息来源（前世因果链）。
  - **奇幻、古风志怪**：观众来看世界观本身。本片种的镜头始终跟着一个带外来视角的人。
  - **甜宠**：穿书、双向时空门常落在甜宠上，但甜从信息差来（我知道结局、我知道你会想我），不靠偶遇。
  - **警惕伪穿越**：挂「重生短剧」标签但前 300 秒无重生设定，实为年代手艺逆袭，评论区没人提重生——**标签蹭流量会流失冲着设定来的观众**。
- **数据基准**：收藏 / 点赞比高的样本（19%–95%）全部有硬卡点或连载钩。累计结论：**想要追更，集尾必须抛出具体目标或新威胁，收益不结清**。分享 / 点赞范围 3%–57%，高分享靠「能 @ 人」的内容：荒诞升级、美食「馋」、历史脑洞、可复读的加码金句。常见嘲点不是 AI 画质，而是**设定洞**（实习生凭什么出席机密会议）、**货不对板**（剧名卖点首集零出场、标签无重生）、**同质化**（撞已知爆款被指抄袭）、**AI 直出文字崩坏**（挂画书法被嘲）。

## 子类型

| 子类型 | 卖点公式 | logline（自拟） |
|---|---|---|
| **穿书 / 穿剧**（最大宗） | 知道原著走向 × 拒绝炮灰命运 × 每次预知都当场兑现。变体：①配角视角跟对反派老板；②**心声流**（吐槽被特定角色独家听见，人形预警器）；③**厌世反差**（不怕死的女主把虐文套路全部反杀）；④真假千金抱大腿 | 心声流：穿书实习生的每句心里吐槽都被总裁父子听见，她以为自己漏了底，其实成了拆穿假千金的人形雷达。厌世反差：一心想死的少女穿成虐文女主，霸总逼她捐肾，她嫌「两颗一起摘」，把施虐者吓到报警。 |
| **重生逆袭（止损 / 赎罪 / 退婚）** | 前世悲剧因果链 × 重生回犯错节点 × 当场做出相反选择 × 复仇 / 追回只兑现一半留一半 | 止损型：接亲当天被临时加码二百块彩礼，他带着「这笔钱毁了三个姐姐、娶回一个让他戴一辈子绿帽的女人」的全部记忆重生，当众退婚。赎罪型：前世占了她便宜又食言、害她投河的混混，重生回到她来换粮那天，这次把粮全给她，发誓不碰她一根手指头。 |
| **降维金手指**（含美食经营、手艺逆袭） | 现代物件或手艺 × 落后世界 × 土著「嫌弃 → 真香」× 收益或地位逐级放大 | 现代烘焙师穿成边关驿站的厨娘，守将嫌她的奶油面包「花里胡哨」，三天后整个边军排队拿军饷换面包。 |
| **双向时空门** | 可往返的门 × 一边缺、一边有 × 每次往返带回一件东西或一段关系；规则只给现象 | 七十年代的知青在井里捞起一只现代保温杯，发现井底连着如今的城郊回收站，她开始用捡来的临期奶粉救全村的早产娃。 |
| **古今通话 / 改写历史** | 单一通道（电话、电台）× 古代帝王 vs 现代国家机器 × 两次方向相反的证明 × 改写观众熟知的历史结局 | 考古实习生的手机在汉墓里突然接通，对面自称「朕」，要他证明自己真来自两千年后，否则就把他的「魂」封进陵里。 |
| **元叙事系统流** | 主角吐槽短剧套路 × 当场应验 × 系统用手机应用话术发金手指 × 开卡即埋到期。（「观众同位吐槽」开场——主角像观众一样骂原书——是它的轻量变体，可单独用于穿书开场） | 她刚吐槽完「重生剧全是一个套路」，阳台的吊兰就砸了下来。系统让她从一百张短剧女主卡里抽一张，她抽到了自己，外加一张七天体验券。 |
| **废柴系统流**（穿成弱者） | 穿成最弱的存在 × 金手指带荒唐限制 × 两个废柴合体 | 他穿成一只观赏仓鼠，唯一的技能是「名字说什么就变成什么」，可全城只有一个驯兽师愿意给它取名。 |
| **未来来客**（反向穿越） | 未来亲人回到现在 × 用私密细节自证 × 撮合或阻止 | 十九岁的大学生在食堂被一个比她高的男生抱住喊妈，对方说出她袜子破洞处涂了黑笔，又指着校草说「那是我爸」。 |

> 边界样本：年代手艺逆袭（挂「重生」标签、内容无重生）归入爽文逆袭片种处理，本卡只引用它的可迁移技法（金额递增、落难钩、反应镜）。重生复仇的正剧做法见 revenge-angst 和 underdog-payoff 的「重生先知」子类型。

## 单集结构模板

**时长基准**：单集 62–256 秒。竖屏单集中位约 90–125 秒，横屏中位约 175 秒。**竖屏以 60–125 秒为主模板，横屏以 2.5–4 分钟为主模板**；多集合辑是发布策略，不是单集时长。

**首爽位置分子类型**：
- **降维金手指 / 穿书喜剧类**：首个小爽点 6%–37%，中位约 17%。
- **重生逆袭 / 赎罪类**：首爽（做出相反选择）推迟到 **50%–86%**，前 35–60% 用于「设定 + 前世清算」情绪蓄能。代价必须补偿：蓄能段每 10–15 秒一个信息点或情绪冲击（闪回一张、罪状一条），且前 15 秒必须有强钩（金钱逼迫 / 道德悬念）。
- 峰值仍在 75%–95%；硬卡点占最后 2%–15%。

### 60s（竖屏实测模板）

| 节拍 | 占比 | 做什么 |
|---|---|---|
| 钩子 | 0–10%（≤6s） | 冲突直给（带具体金额的逼迫）或人设宣言（第一句台词即 logline）。3 秒内出第一个冲击画面 |
| 设定触发 | 10–35% | 重生型：旁人抛问 → 主角愣住 → 切 OS → 物理动作三连快切确认（掐臂 0.7s×3）。喜剧型：同一笑点模板连跑两遍，教会观众游戏规则 |
| 升级链 | 35–85% | 每 6–15 秒一次反转 / 笑点 / 信息点，舞台逐级升级（人贩子 → 养母 → 男主 → 白月光；施压 → 清算 → 立誓）。峰值落 75–95% |
| 卡点 | 最后 5–15%（4–10s） | 停在动作发生前最后一帧（光脚踩上窗台），或 ≤8 字命令句后 2s 内切黑，或新威胁带具体数字闯入、台词停在追问句 |

### 90–125s（竖屏 / 横屏实测模板）

| 节拍 | 占比 | 做什么 |
|---|---|---|
| 高概念钩 | 0–12%（≤15s） | 世界观 bug 当场变成卖点：心声被听见 + 「谁在说话」；或擦边暧昧场面 + 重生自述（擦边有限流风险，见禁忌） |
| 设定独白 | 12–25% | 穿书 / 重生的设定交代做成吐槽或第一人称旁白，不用第三人称干讲。人名条同步锁身份 |
| 规则确立 | 25–35% | 金手指的边界（谁能听见 / 这次要选另一条路），同盟结成 |
| 第一次验证 | 35–65% | 预言 → 物证起获（炸弹理论：先点名线索位置，实物延迟 ≥10s，延迟期用接近类插入镜填悬念）；或「同一节点相反选择」的赎罪动作（给粮、扣扣子） |
| 反杀 / 情绪高点 | 65–90% | 证据指向反派 → 反派挣扎（苦肉计）→ 权威裁决。赎罪型这里放最长的一镜哭戏（17–22s） |
| 卡点 | 最后 8–12% | 枪口转向主角（一句 ≤8 字的「你，留下」）或新反派带债务数字闯入，切黑 |

### 3–4min（横屏主模板）

| 节拍 | 占比 | 做什么 |
|---|---|---|
| 1 前提钩 | 0–8%（≤15s） | 穿书类：先演 10–15s「原主最恶的一幕」或主角吐槽原书，再接「我叫 X，我穿书了」完成身份翻转。重生类：直接放在前世犯错节点上 |
| 2 错位落地 + 首个小爽 | 8–37% | 金手指第一次使用（预知救小狐狸 / 阴阳捧杀抽身），**必须**接对手反应特写。立 flag 台词放这里 |
| 3 重复单元 ② | 37–55% | 同一套「嫌弃 → 嘴硬 → 偷看 → 尝试 → 真香」或「施压 → 加码 → 崩溃」再走一遍，换一个地位更高或人数更多的对手，收益放大一档 |
| 4 中段挫折 / 规则限制 / 双向信息差揭示 | 55–75% | 小压抑：反派 OS 明牌、规则失控、新威胁点名。双主角各持剧本的，在这里让第二份剧本（重生者视角）揭开 |
| 5 最大爽点 | 75–92% | 全集峰值：群体背书、预言全验证、或反差角色回归（救下的小狐狸化身病娇屠兵）。快切段镜长 ≤1s |
| 6 卡点 | 最后 3–8%（5–12s） | 停在下一个具体目标被说出口、新角色登场不展开关系、或威胁名词「没来」的原因刚揭一半 |

**位置规则汇总**：
- 前 15 秒必须有钩（冲突 / 宣言 / 笑点 / 悬念四选一），这与首爽位置无关。
- 降维 / 穿书喜剧首爽不晚于 37%，最好 ≤20%；重生蓄能型首爽可到 50–86%，但蓄能段每 10–15 秒一个冲击。
- 3 分钟一集至少 3 个爽点，或同一单元重复 3 次。
- 中段挫折 / 第二信息源放在 55–75%。
- 卡点切在最后 4–12 秒，收益不结清。
- 转折频率：喜剧类每 6–15 秒一个；正剧类每 20–30 秒一个。

**两条子类型专属节拍链**：
- **重生五连**：犯错节点 → 触发（旁人抛问 / 意外）→ 确认（物理动作三连快切）→ 前世清算（降饱和闪回，串成「一件小事导致一连串惨剧」的因果链）→ 立誓 → 相反选择（爽点）→ 新威胁卡点。
- **穿书五连**：原主最恶一幕 / 吐槽原书 → 「我叫 X，我穿书了」→ 预知第一次使用（救小角色 / 拆第一招）→ 反制循环（每 40–60s 一次预知反杀或阴阳捧杀）→ 新目标 / 新角色卡点（真大腿只闻其名不见其人）。

## 钩子库

**通用数据**：
- 穿越 / 重生前提几乎都在 15 秒内交代（降维类多在 8 秒内，重生类允许到 15–20 秒，用人名条和 OS 压缩）。
- 前 3 秒 1–4 镜，均值约 2.2 镜；前 15 秒 3–15 镜，中位约 8 镜。
- 首镜景别不强求，但**必须有正在发生的事**：一句冲突台词、一个落难形象、一次失败尝试。

| # | 打法 | 拍得到的画面写法 |
|---|---|---|
| 1 | **自报家门式**：「我叫 X，一脚踩空 / 一觉醒来，穿成了 Y」 | 中景，雨夜街头女主抱头 0.8s → 0.1s 闪帧：正俯拍古代祭坛 → 中景，女主从鼎中水面冒出捂脸；旁白与标题同句 |
| 2 | **古今同框求救式** | 中景，白卫衣青年举着手机，身旁黑金龙袍的帝王按剑；台词「救命，皇帝要杀我」→ 硬切现代接警大厅 |
| 3 | **土著嫌弃式** | 中景，黑衣衙役拍摊 → 手指戳油纸特写 → 衙役怒吼正脸「八块肉五十文，你咋不去抢」 |
| 4 | **反常识宣言式**：「没人告诉我当 X 这么 Y 啊」 | 0.5s 逆光庭院，丫鬟转身，画外冷声「自己滚」；切丫鬟捂脸近景，内心独白「没人告诉我当恶毒女配的丫鬟这么爽」 |
| 5 | **一语成谶 / 元叙事式** | 中景单镜不切：女孩长椅上刷手机外放爆款短剧，笑「重生可太有意思了」；画面左后方已站着穿反光背心的工人 → 电锯锯树特写 0.8s |
| 6 | **触发器特写 + 命运旁白式** | 中近景，女孩踮脚抱稻草 → 手指渗血大特写 → 血滴落在门神画上，画像泛起金色涡旋 |
| 7 | **身份错位称呼式**（妈、爸、陛下） | 中景，食堂长桌，男生冲进画面抱住比他矮的女生，她嘴里的鸡腿掉进餐盘 |
| 8 | **剧情先知式**：旁白快剪原著结局，最后一句拒绝命运 | 红盖头下新娘流泪 → 雪地抱尸 → 男主另娶 → 棺材板被从内一锤砸裂；旁白「复活？我自己来」 |
| 9 | **惊叫式 / 被追捕式** | 女店员的抹布掉落，身后玻璃门外是灯笼和青石板路 |
| 10 | **落难形象钩**：处境 + 唯一家当，一张图交代出身 | 俯拍，她蜷在运煤车斗里，满脸煤灰抱着蓝布包袱，台词只有「下车」→ 切她跪在晨光街头捡包袱。台词 ≤3 字，观众自动问「她要去哪、包袱里是什么」 |
| 11 | **数字逼迫钩**：第一句台词就是带具体金额的冲突 | 逆光仰拍，女方母亲叉腰「你们家必须再加二百块彩礼」，竖排人名条同时弹出。不做铺垫，金额可计算、可共情 |
| 12 | **心声泄露钩**：高概念设定 15 秒内当场炸场 | 手部按桌特写 + 总裁下令「会议内容保密」→ 女声吐槽插入「最大的漏勺不就在你身边吗」→ 总裁炸毛「谁在说话」→ 全员面面相觑「没人说话呀」 |
| 13 | **人设宣言 + 失败反差钩**：第一句台词即 logline，前 3 秒三镜一个完整笑点 | 她站上椅子、头顶垂着绳圈「我有严重的厌世症」→ 绳子一股股断开特写 → 她摔进破棉被堆「每天都在研究怎么死」。随后 15 秒同模板连跑两遍（被拐 →「绑结实点」→ 人贩子自首） |
| 14 | **观众同位吐槽钩**：主角替正在刷视频的观众骂原书 | 单镜 3s 不切：深夜屏幕光下女主崩溃近景「两个男的又不是充电线，非得抢着插吗」→ 眼睛大特写 → 水杯打翻键盘电光迸射 |
| 15 | **冷开场高能片段 + 身份翻转**：先演原主最恶 / 最暧昧的一幕 | 顶光圣洁白衣女子俯视地上半裸伤男，男人「我要剐碎你」→ 赤足踩下巴特写 → 15s 处切近景「我叫 X，我穿书了」。⚠️ 擦边变体（炕边换粮）带限流和低俗风险，慎用 |

**组合规则**：
- 最强开场在 15 秒内跑完一个小循环：「被看不起或身处危机 → 立 flag → 第一次展示 → 对手动摇」。
- 喜剧型在前 15 秒把笑点模板跑两遍，等于教观众「这部剧的游戏规则」，之后每次重复观众都在等升级（这类样本收藏率能到 90%+）。
- 世界观大场面用 0.1s 闪帧塞进前 3 秒。
- 重生类可以在 17–20 秒处放「第二钩」：旁人把选择权抛给主角（「你是啥想法？」）→ 愣住 → 重生 OS。

## 反转、爽点与卡点

**爽点基础三拍**：「外来物 / 先知 → 对手反应 → 可核对的收益」，缺一不可。
- 外来物或证据给特写（炸鸡、手机屏、摄像头模组、一摞草编）。
- 对手反应给特写，1:1 紧跟，时长 1–1.5s。「每句关键台词后必接反应镜」是高收藏样本的共性。
- **打脸点单给旁观者反应特写，且这个旁观者此前必须说过看不起主角的话**：伙计说「乡下丫头不知死活」，签约后就要拍他端着搪瓷缸瞪眼；退婚台词后接当事人愣住 + 长辈背书两个反应镜。
- 收益写成数字或画面。**数字母题**：主角价值写成一串**递增的具体金额**（8 块 → 0 → 5 块 → 50 块 → 一个 8 块 ×20），每次换手都让旁人报价、贵人重新报价，观众跟着算账就是爽感。

**新增爽点机制**：
- **心声流双反应组**：每条心声爆点自动产生两个反应镜——「听者脸」（总裁凝眉 / 炸毛）+「无知者脸」（说者抱臂冷笑）。笑点踩在对方情绪峰值上（反派哭诉最惨处切女主看戏脸）。
- **加码式爽点**：固定模板「施压 → 主角加码（对方给 X 我要 2X）→ 施压者崩溃」，每 6–12 秒一次，舞台逐级升级（人贩子 → 养母 → 霸总 → 白月光）。加码台词 ≤8 字。
- **三连镜验证**（心声流）：预言 → 插入特写验证物证 → 反派变脸特写，6 秒内完成；插入特写每镜只承载一个信息点、≤2.5s。
- **赎罪镜像动作**：今生的动作要和前世的罪行镜像对应（前世解衣占便宜 → 今生只给扣扣子的手部特写），一个动作替代十句忏悔。

**反转机制**：
- **双份剧本**：穿书者知原著、重生者知前世，两人都不知对方变了。同一动作分别配两人的旁白解读（她 OS「死前摸一把美男」，他旁白「今日便是你的死期」），双向误会既是笑点也是感情线起点。
- **威胁名词计时器**：一个反复点名的威胁（「金甲卫」）当全集倒计时，至少出现 4 次，最后让它「没来」，结尾揭示原因（被救下的小狐狸把追兵杀光了）——定时器本身成为反转的引信。
- **前段救下的小角色结尾反差回归**：随手救的白狐化身红衣病娇少年立于尸堆中，用一句萌语（「阿白乖不乖」）配暴力结果画面卡集。
- **金手指限制 / 时限即反转**：体验卡到期、只能改名不能改命。
- **小反转**（被当成拍戏、被当成妖人又被认作神女）：每次 ≤15 秒，用完就推进。

**证明与规则**：
- 两次方向相反的证明建立跨时空信任（物证 + 机密）。未来来客用 3–5 个私密细节连发自证，一句一镜。
- 规则可以不解释成因，但**触发条件必须前后一致**（用血开门，回程也要见血）。
- 留一个可推理的线索镜，评论区会自己长出推理。
- **规则确立要配「同盟镜」**：心声流里父子对视确认「只有我们两个能听到」（1.5s 双人全景），金手指的边界一句话说死。

**卡点类型**（高收藏样本全部有硬卡点）：
1. 第一个任务点名（最好点观众熟知的历史反派，评论会接梗）。
2. 「我好像找到办法了」，不说是什么办法。
3. 主客倒置（他落进她的公寓，「欢迎来到现代」）。
4. 金手指激活词刚出口、门刚开时切断。
5. 体验卡到期、被顶号（顶号者必须给正脸或标志性台词）。
6. **≤8 字命令句收尾**：「你，留下」——台词落地 2s 内切黑，枪口转向主角。
7. **动作进行时停在最后一帧**：光脚踩上窗台、奔向窗户，不给结果。危险动作只拍工具和局部（断绳、掉地的剪刀、踩窗台的脚）。
8. **新角色反差登场不展开关系**：尸堆中的红衣少年，留「修罗场」期待。
9. **新威胁带具体数字闯入**：村霸带打手出现，「你爹欠了老子五斤猪肉、十斤白面」，台词停在追问句。
10. **反派预告台词**：「明儿有好戏看喽」，替观众立下集期待；合辑剪辑时用它替代「未完待续」字卡。
- **标题承诺只兑现一半**：剧名「退婚后追回彩礼」，本集只退婚，追彩礼留下集（这类样本收藏 / 赞能到 80%+）。
- 卡点前不要把本集收益结清。闭环式结尾收藏率显著低于硬卡点（约 11% vs 19% 以上）。

## 人设与台词

**人设组合**（都是「外来者 + 对照组」）：
- 外来者 + 惊叹的土著：土著越老、越有身份、越守规矩越好。
- 冷静外来者 + 嘴硬心软的土著喜剧担当。要给主角留一场 3–4 秒的完整表演长镜，否则评论里没人记得主角。
- 配角穿越者 + 反派老板。
- 话痨现代女 + 冷面古代男。
- 萌娃 + 苦难家庭。
- **穿书者 + 重生者**：双主角各持一份剧本，互为对方的「变量」。男主的怀疑（「为何这一世与前世完全不同」）就是感情线起点。
- **心声泄露者 + 独家听众同盟**：主角是叙述器 + 人形预警器 + 观众替身三合一；听众（父子 / 总裁）是行动担当。双重戏剧反讽：她不知道被听见，他们不知道她是穿书者。
- **赎罪者 + 不敢信任者**：张力来自「他已经变了，她还不知道」。受害方台词全是试探和讨价还价（「能不能让我先把粮带回去」「我绝不反悔」），说明信任要用一集以上慢慢挣。
- **厌世者 + 被吓坏的施虐者**：主角的反常欲望（求死）让所有威胁失效，是整部剧的引擎；施虐者人设被反向消解（霸总每次都被吓到失态）。
- **人设一致性红线**：开场吐槽「女配围着男人转」的人，穿书后第一步不能是「找老公」。主角的每个新目标必须与开场宣言的价值观一致，否则收获几百赞的负评。
- **低阶角色在场必须给理由**：实习生出席最高保密会议无解释，会成为全片最大嘲点。要么给一句理由，要么让角色主动自嘲化解。
- 未出场的角色可以只活在台词里（「十里八乡一枝花」的姑娘全集不露面），先抑后揭、省资源——但**剧名里承诺的角色不能这样处理**。

**台词技巧**：
- **自报家门三连**：「我叫 X / 一脚踩空 / 摔进了 Y」，每句 ≤12 字。穿书标准开门锁是「我叫 X，我穿书了」。
- **双声道 / 双声部**：外放台词用威严腔 / 文言腔（「本座今日乏了」），内心 OS 用口语甚至方言。⚠️ 方言 OS 要在第一句前给画面提示（表情崩坏特写或花字），否则观众分不清是内心戏还是配音事故。
- **心声流专属**：口述轨短、冷、权力化；心声轨长、贫、信息量大。过半台词走心声 = 过半台词免口型。
- **加码句式**：对方给 X，我要 2X——「绑结实点」「两颗一起摘」「下次加点砒霜」，≤8 字，紧接施压者反应特写。
- **语域错位**：把威胁当服务评价——「毒性太淡」「我口味重」，像在点评菜品，荒诞感来自说话场合与用词的错位。
- **比喻降维吐槽**：「两个男的又不是充电线，非得抢着插吗」「最大的漏勺不就在你身边吗」「这跟登上了要沉的巨轮有什么区别」——一句网络梗比喻把复杂局面降维成日常吐槽。
- **数字台词**：具体金额越具体越真实（「二百块彩礼」一集出现 4 次）；因果链清算用数字串（「就因为这二百块，三个姐姐被毁了」）。
- **口头禅重复**：主角的口头禅（「俺能做」）在被否定后重复出现，至少 3 次，第 3 次放在赌约或卡点上。
- **誓言用人物自己的语言**：糙汉的誓言用糙话说，不用书面语。⚠️ 粗话要防被观众反讽玩梗。
- **金句放在最低点**：「哭了就编不好了」——不喊口号，把情绪转成手艺 / 生存上的理由。
- **主题句点题**：「你的剧本也该改改了」，一句话说清穿书文核心爽点。
- **对仗式口语**：「他瞪他的，我摸我的」「以前是以前，现在是现在」，短、可模仿、能成梗。
- **抓字眼**：把对方狠话当许可——「真想死就跳窗」→「这可是你说的」。
- **现代梗进古代**：让古人照字面接。
- **称呼说服 / 系统话术 / 台词截断当卡点 / 傲娇句式 / 方言换魂**：维持常规用法。
- **敏感词用拼音或谐音替代**：字幕写「si」不写「死」，适配短视频平台审核——但涉及自杀题材本身就有限流风险，规避词只是减损。

**金句写法**：
- 主语用「我」，≤12 字，带一个反常识数字、一个类型名词（系统、主角光环），或一条时代道理（「哪个朝代的人，都扛不住一口好吃的」）。
- 放在爽点承受者反应之后 0.5 秒的静场里，或放在最低点（立誓处），或放在集尾回扣开头宣言。

## 视听风格

**画幅（按题材空间定，不再默认横屏）**：
- 仙侠 / 古代奇观、多场景、大调度 → 16:9。
- 都市 / 年代 / 职场、单场景、人脸近景驱动、旁白或心声驱动 → 9:16。
- 竖屏连续剧集（60–125s）更适合日更批量生产：单场景、20–66 镜、一人一色，一致性成本最低。

**景别分布**：
- 近景及更近 45%–75%，均值约 58%；中景 20%–35%；全景 5%–20%；插入特写（道具 / 手部 / 物证）7%–10%。
- 证据链题材（心声流）插入大特写占约 10%：手按桌、攥拳、皮鞋、白手套摸画框、摄像头模组——把商战拍成物件程序戏。
- 场内走法：「环境 → 脸 → 物」三拍维持。**情绪升级走法**：近景 → 中景 → 过肩 → 特写连环，景别逐级收紧（对峙段）。
- **人名条规则**：主要角色首次出场挂竖排人名 + 小字身份条（「某氏集团总裁 · 顾某」式），开场 10 秒内锁完全部身份，**禁止用口述台词介绍人物**。穿越后认人用闪推变焦逐个点亮，每人 ≤1.5s。

**光色**：
- **前世 / 现实冷，今生 / 书中暖**是重生与穿书的标准配色：前世闪回降饱和做旧（暖褐做旧或冷灰蓝），今生暖金；现实世界蓝黑冷调，书中世界暖金日光。
- 按情绪定冷暖：压抑苦难冷蓝，甜爽温饱暖金，权力机构冷灰蓝。
- 三段光区分三种处境（年代样本）：街头金色逆光（困境带怀旧暖）→ 桥洞冷蓝 + 火堆橙（最低点）→ 杂货铺侧窗暖光（有落脚处）。
- 反派可以用「假温柔色」：绿茶 / 假千金穿米白浅色，在满屋深色里跳色，浅色 = 假面母题，定罪后仍穿浅色。

**转场**：
- 白闪表示穿越（1 帧到 0.3s）。
- **感官门转场**：闭眼 → 前世、水下伸出的手 → 再睁眼回到现在、瞳孔隧道 + 电光爆闪 → 穿书。用身体感官画面做时空门，不用字卡。
- **色调突变当转场**：童年暖褐脏旧 → 穿书段医院冷白蓝，画风 / 色调一切就是换世界；画风断层（粗粝写实 vs 精修网红脸）可以直接包装成「书外 / 书中」两个世界的设定。
- 时间跳跃用竖排字卡（「半小时后」）或字幕直报年龄（「五岁被拐」「十岁」「十八岁」）。

**美术**：
- **服装即阵营、即阶层**：一人一色锁死（男主藏蓝、反派紫红碎花、女主黑 vs 对手白），全集不换装。阶层升级就换主色。
- **一人一个视觉符号**：叉腰手势（恶亲家）、手帕（绿茶）、金冠珠链（仙尊）、额头红纹（狐狸）——跨镜一致的锚点，也是观众认人的钩子。
- **道具母题 = 命运标记**：手（前世没拉住的手 → 今生扣扣子的手）、红色（欲望 → 赴死 → 结尾红衣少年）、绳子、包袱。母题的变化就是人物的变化；同一种颜色可以从一个意义翻转到另一个意义。
- 年代符号密度要高：搪瓷缸、中山装、玉米串、红砖墙、土坯房、高粱面——背景上方塞满，前景人物占 2/3。
- 现代物件用亮色塑料感压在土色背景上。

**运镜**：
- 固定机位 + 微推仍是最稳区间。
- 权力人物低机位仰拍；逆光仰拍反派（太阳在头后）压迫感最强。
- 情绪高点用缓推近——物理距离缩短 = 关系逼近。
- 识货 / 观察类镜头先拍看的人再拍被看的东西（贵人特写盯着草编、手指摸编纹 → 反打物件细节），台词才有画面支撑。
- 大位移用背影（她奔向窗户用背影中全景），不拍正面全身运动。

**横屏怎么做**：
- 外来者在画左、土著在画右；对称纵深显威压；三分法留虚化光斑；三镜内不越轴。
- 长镜承载旁白与哭戏：横屏赎罪 / 仙侠样本敢用 11–22s 的单镜缓推，配合大段第一人称旁白，节奏服务「悔恨 / 仪式感」（但见禁忌：旁白过载）。
- 父子 / 裁决类对话用会议桌水平权力轴，权威者置画面两端对坐，主角靠窗边 = 局外人。

**竖屏怎么做**：
- 人脸放中上部，下 1/3 留给旁白大字幕；中轴对称；前景遮挡做层次；纵深排布不横排。
- **情绪花字标签**：主角表情平静 / 不动声色时，在脸旁贴小号粉黄情绪花字（*生无可恋、*期待、*无语），给面瘫表演做注释——这也是化解 AI 表情单一的最低成本修法。
- 竖排人名条贴人物身侧，是首选身份交代方式。

## 剪辑节奏基准

**平均镜长**：范围 1.3–6.1s，均值约 2.5s，中位约 2.1s。分三档：

| 档 | ASL | 适用 |
|---|---|---|
| 快档 | 1.3–1.9s | 黑色喜剧连击、心声流商战、美食经营、3D 漫剧、真人梗喜剧 |
| 中档 | 2.1–3.3s | 穿书偶像剧、年代手艺、仙侠穿书、年代重生退婚、古今通话、甜宠双向穿 |
| 慢档 | 3.5–6.1s | 旁白驱动赎罪长镜（6.1s 是极端值）、古偶颜值 + 内心独白、奇观战斗 |

- **慢档的成立条件**：旁白驱动长镜靠「第一人称旁白 + 长镜哭戏」成立，但其中 55 秒连续旁白念前情就是流失风险——**慢档必须配强钩子，且旁白段之外要有对白段换气**。
- 前 3 秒 1–4 镜；前 15 秒 3–15 镜（中位 8）。慢档样本前 15 秒可低到 3 镜，但第一句台词必须是宣言级或冲突级。

**快段**：
- 穿越瞬间：0.07–0.33s 碎镜（水洒键盘、电光、瞳孔隧道、闪推认人），**总长 ≤6 秒**，末尾减速落定。
- 重生确认三连：0.7–1.0s×3（全身 → 掐臂特写 → 「疼」的表情大特写），是全片唯一快切处，标示生理冲击。
- 加码喜剧段：一句台词一镜甚至半句一镜（0.6–1.9s），笑点靠剪辑点卡准。
- 结尾冲刺：卡点前把镜长压回 0.3–1.0s（奔向窗户段），或阶梯加速后急刹。

**慢段**：
- 设定独白镜 3–8s（穿书自述、重生 OS 用约 12s 持续近景缓推「进入他的脑子」）。
- 哭戏 / 誓言长镜 14–22s（22s 单镜承载「她含泪讨价 + 他内心立誓」，用多段同机位生成拼接或静帧缓推做）。
- 结尾信息长镜约 15s：新角色 + 台词 + 余味压在一个画面里。
- 炸弹拖延段：威胁逼近时反而放慢（包围段连续 4.8–9.9s 长镜），用拖时间同步「他们怎么还不来」的台词。
- 喜剧包袱要给长镜落地：punchline 那镜 3.75–4.0s，留一拍让笑点着陆。

**节奏走向**：
- 「慢—爆—慢」呼吸维持；爆点落在穿越 / 重生 / 验证的瞬间。
- 后 1/3 不能慢于前 1/3（反例被评「拖拖拉拉」）。
- **先稳后碎**：判决 / 裁决段先给 3.3s 站立对峙全景压场，再接一串 1–1.5s 哭诉快切，权威的稳定与反派的慌乱用镜长对比拍出来。
- 静场：卡点前 0.5s 音乐骤停 / 环境声抽空（「等等……你，留下」）；失去感段落用无台词直视特写（2–4s）让情绪沉底。

**旁白与节奏**：
- 第一人称旁白可以铺满前 40–55%（赎罪样本前 62s 全靠旁白），但**旁白段 ASL ≤2s 或配长镜空镜**，且旁白退场后要有对白段接手（回到现在后旁白退场、对白接手，是正确示范）。
- 连续 55s 旁白念前情 = 信息过载红线，要拆成「旁白一句 + 闪回画面一张」交替（三个姐姐的命运各给一张 1.5s 做旧闪回，替换重复的惊讶脸）。
- 内心独白（双声道 / 心声流）不算旁白，可占台词量一半以上。
- 台词语速 3.0–4.0 字/秒；加码喜剧的台词压到 5–8 字/句，1 秒镜头内说完。

快档改 `"asl": [1.3, 1.9]`；慢档改 `"asl": [3.5, 6.1]`，且慢档样本的钩子镜要标 `tempo: 停留` 并写 `pace_note`（「旁白推进」「哭戏长镜」）；剧情先知式开场的旁白快剪段较长、或 3 分钟横屏前提钩用满 15 秒时，`hook` 放到 8。

## AI 制作要点

1. **画面文字一律后期贴**：字幕、人名条、花字、到账金额全后期。**场景内带字道具（字画、文件、屏幕）生成时留白、后期贴真字**——AI 直出书法字是最大嘲点（「马到驴成」式的错字会被嘲好几条）。
2. **口型压力三大泄洪口**：
   - 心声 / OS 设定：过半台词免口型（心声流是把这个规避做成了卖点本身）。
   - 第一人称旁白：长段台词走 OS，画面用表情特写或背影。
   - 对白镜头控制在 1–5s、短句正面微推；长句给说话者的背影 / 过肩，把对口型压力集中到一个角色身上。
3. **多人互动拆成单人镜**：对峙用正反打单人镜拼（各一机位）；肢体接触只拍局部（脚踩下巴、手托下巴、扣扣子、抓臂特写）；群像只做背景站桩或虚化，单镜 ≤2s；打斗屠杀全放画外，只拍之前的包围和之后的尸体 / 结果。
4. **长动作只拍结果**：偷窃不拍、只拍地上包袱压出的圆印；手术不拍、只拍剪刀掉地；跳楼不拍、只拍光脚踩上窗台；手工制作不拍过程、直接给「一夜编出的一摞」。**用缺席讲事件是本片种最省钱也最有电影感的取舍**。
5. **全身突发运动是雷区**：猛然起身、奔跑、推搡要么放画外靠音效完成，要么拆成「攥拳特写 + 桌面水杯波纹」两镜；人物大位移只用背影。
6. **手部规避**：攥拳、戴手套、两指捏物是最安全手型；手部镜全部 ≤2.5s、每镜只承载一个信息点；精细手部动作（扣扣子）可以做但必须近景静态起落——这是罕见的成功案例，默认仍应避免。
7. **一致性四件套**：一人一色服装 + 固定发型 + 一个标志符号（叉腰 / 手帕 / 红纹）+ 竖排人名条二次锚定。全集单场景单光向（农村院门口、会议室）是低成本高产量公式。⚠️ 反面：煤灰妆时有时无、被偷的包袱又出现——**状态类妆造（脏、伤、湿）要建 continuity 清单逐镜核对**。
8. **表情镜不许复读**：同一角色「张嘴惊讶近景」连用 4 次就是信息浪费。同情绪反应镜最多连用 2 次，第三次必须换角度或换成旁观者。
9. **超长镜分段生成**：20s+ 的哭戏长镜用多段同机位生成无缝拼接或静帧缓推；接缝用枪口火光、尘土、白闪遮住。
10. **0.1s 级接缝闪切必须清理**：AI 镜头拼接产生的 0.07–0.1s 残镜是剪辑瑕疵，成片前过一遍闪切检测。
11. **穿越过程不拍**：只拍之前和之后，过程用水洒键盘这类 1–2s 局部物理事件 + 瞳孔隧道 + 白闪带过。
12. **明星脸是红线**：AI 角色脸疑似融合真人演员，有肖像与口碑双重风险，主角脸要做去明星化检查。
13. **考据最小化 + 漏洞变梗 / 避开 AI 高频套路名 / 风格统一 / 食物道具是安全区 / 植入做成道具或梗**：维持常规做法。
14. **设定洞优先于画质洞**：观众嘲的不是 AI 感，是「实习生凭什么在机密会议」。高概念设定（心声被听见、穿书）确立后，**角色的反应优先级要与设定权重一致**（不怀疑心声却怀疑实习生与会 = 观众替角色算账）。

## 禁忌

- 前 15 秒没交代穿越 / 重生前提，或前 15 秒没有任何事发生（钩子 / 笑点 / 悬念四选一必须有）。
- **货不对板**：标签挂「重生」但内容无重生；剧名卖点（「绝美女知青」）首集零出场。片名和标签承诺的元素首集必须露面。
- **人设动机自相矛盾**：开场宣言的价值观与穿书后的第一个行动打架。
- **设定洞**：低阶角色出现在高保密 / 高规格场景不给理由；角色反应优先级与设定权重错位。
- **关键设定词同音歧义**：「厌世症」被看成「厌食症」——设定词要配画面解释，字幕防同音误读。
- 首爽拖过全集 1/3（降维 / 穿书喜剧类）；重生蓄能型前 35% 没有每 10–15s 一个的信息冲击。
- 连续 55s 旁白念前情；慢档无强钩子。
- 金手指只说不演；爽点后没有承受者 / 旁观者特写；同一表情镜连用 ≥3 次。
- 群像大全景拖过 2 秒；生成多人精确接触；全身舞蹈 / 比武直出（「转圈圈」）。
- 猛然起身、奔跑等全身突发运动放进 >1s 镜头。
- 让 AI 直出场景内书法、招牌、屏幕文字。
- 价格、金额、称谓、规则触发条件前后不通；状态妆造（脏 / 伤 / 湿）时有时无；已丢失的道具再次出现。
- 伏笔回收没有前置预埋（关键道具必须先入画）。
- **赎罪型重生不给早期悔恨画面**：只靠旁白忏悔会引来「只有坏人才能重生？」的道德质疑。
- 粗口誓言不防反讽玩梗。
- 擦边开场：能拿流量也拿嘲讽与限流风险，口碑偏低俗。
- 撞已知爆款设定不做差异化；用 AI 高频名；AI 角色脸融明星脸。
- 自杀等敏感题材只靠拼音规避（有限流风险，题材本身要慎选）。
- **切片不报剧名**：高光切片没头没尾、标题画面都不给剧名，流量导不到正片，只能靠观众评论区补名字。
- **单集爆款无后续储备**：「怎么就一集」会变怨气；发布前储备 3–5 集。
- 合辑中段插「未完待续」字卡打断连看；合辑内每集重复自报设定（对连看观众是冗余——用反派预告台词替代字卡）。
- 卡点用黑屏或「未完待续」；卡点前把本集收益结清。
- 中段 30 秒以上没有阻力也没有包袱；写实片混玄幻特效；拉踩原著女主。
