# 复仇虐恋

> v0.3。例子和 logline 都是自拟的。

## 定义与情绪承诺

- **观众来看什么**：先看一个人被欺负到底，再看欠的账被**一笔一笔算清**。复仇向的情绪顺序是「憋屈 → 真相 → 清算」。虐恋向在清算之后多给一拍「迟到的愧疚」（负心人跪下、认错、求一个弥补的机会）；或者在复仇完成后，给受害者一段「本来该有的普通日子」——观众最被打动的往往是这一段。
- **三条情绪路线**（立项先选一条）：
  1. **清算型**：本集或本系列内把账算完，爽点当场兑现。
  2. **无反派虐恋**：没有反派，两个相爱的人站到利益对立面或直接走散（分手后为一家店谈判、签了协议登机远走）。情绪顺序是「甜的回忆 → 立场对立 / 离开 → 各自付代价」，靠台词互换和「长句对两个字」来虐。
  3. **储蓄型**：本集**不兑现任何爽点**，把冤屈和屈辱压到极致，让观众憋出「他以后一定会后悔」「她一定会反杀」的延迟复仇期待，靠收藏追更验证（收藏/点赞 ≥29% 是「观众存起来追」的信号）。前提：集内必须给**可见的翻案伏笔**和**反击苗头**（见承诺第 5 条），且发布前有多集储备。
- **五个必须兑现的承诺**
  1. **仇要具体**：钱数、伤情、年份、证物都要说出来（「两万工资全上交，想吃碗十二块的面还要报备」「二十八年前的那个案子」）。不写「他害了我」这种空话。
  2. **羞辱当众；清算当众或战果陈列**：清算发生在宴会、婚礼、发布会、全家在场的客厅、审讯室这类有旁观者或权威在场的地方。私下清算有三种合法走法：①当面报出账目或身份（「我就是当年被你卖掉的那个人」）；②**把战果陈列给观众**——空库房全景、吊灯下满地伤员的俯视全景、寄出去的举报材料；③储蓄型把清算整体延后到下集。反面：清算全程没有一个承受者或旁人反应镜，爽点没人看见，情绪落不下来。
  3. **代价看得见**：被捕、下跪、挨打、婚约取消、资产归还、净身出户、天罚、证据寄出。不能只停在一句「你会后悔的」。
  4. **动机链不能跳步**：「为什么偏偏找他报仇」「为什么非走不可」必须有一个镜头或一句台词交代。跳了这一步，高赞评论就全是挑逻辑和立场争议。
  5. **储蓄要配翻案伏笔和反击苗头**：纯虐集里，受害者必须在集内说出一句**可被翻案的具体细节**（「那段视频是合成的」），并在集尾给一点反击苗头（攥紧某个证据、立誓、点名宿敌）。纯受虐零反击会直接流失观众。

- **三种成片形态**：**单集闭环**（真相、惩处、和解都在一集里，金句或旁白收尾）、**连载卡点**（集尾停在反派知情、惩罚兑现前一帧、话说一半、天罚将至、立誓点名）、**解说切条**（观点断言开场 + 旁白声音桥串场 + 原声金句插入，结尾是价值观卡点而非剧情卡点，驱动观众去搜剧名）。立项先定形态，结构模板分开走。
- 高收藏跟着**连载追更入口**走，不分横竖屏；高分享跟着**社会议题或可截图的虐点金句**走。

## 单集结构模板

通用骨架：**指控 / 誓言 / 冷开场 → 仇因落地 → 证据链或压迫阶梯 → 对手反咬 → 中点反转 → 情绪谷 → 当众惩处 → 收尾（闭环或卡点）**。储蓄型是它的变体：砍掉「惩处」，把整集变成压迫阶梯，收尾换成立誓。

数据锚点：第一句台词在 1.0 秒内开口（无台词开场必须在 3 秒内让动作或画质自己可读）。成片的高潮或最大反转多落在全长 36–83%；储蓄型没有高潮，卡点在 94–96%。3 分钟级单集有 4–5 次局面翻转，约 45–60 秒一次，中间每 10–25 秒一条新信息；长篇连载放宽到每 60–90 秒一个结构性反转。实拍对线戏最密，每 15–20 秒升一级。

### 60s

**A. 爽点闭环版**

| 节拍 | 占比 | 做什么 |
|---|---|---|
| 钩子 | 0–5%（0–3s） | 第一句就是罪或仇，平静语气说狠话（「我就是把他欠的，连本带利收回来了」）。1–2 镜；捉现行可以 4 镜，每镜 ≤0.9s |
| 仇因 | 5–25% | 一句给出具体数额或伤害。质询者第一次压回来：「就为这点钱？」。对线向在这一段就动手（一记耳光，只拍捂脸） |
| 讲理压迫 | 25–50% | 对方拿「正规途径」或底牌压主角：走法律、让着她、「我怀的可是你家的孩子」。主角逐条算底层账 |
| 情绪爆点 | 50–85% | 一句一镜，镜长降到 1–2.5s，景别推到大特写，怒吼或落泪；或先空 1s，再用一句 ≤8 字的短话作废对方的底牌。**爽点放这里** |
| 金句卡点 | 85–100% | 最狠的一句收尾，最好呼应开场那句，字落下就切。连载版换成惩罚兑现的第一帧，或一个抛给观众的问句 |

反转只做一次：「立场反转」或「底牌作废」二选一。最后 3 秒用安静的近景，不配音乐尾巴。

**B. 储蓄卡点版**

| 节拍 | 占比 | 做什么 |
|---|---|---|
| 一字令冷开场 | 0–4%（0–3s） | 三镜：施暴者背影 / 剪影 + 一字命令（「打」）→ 受刑画面 → 前景施暴者的鞋 + 受害者在地面爬行。台词不超过 2 字 |
| 虐点递进 | 4–30% | 身体之痛（抓裤脚哀求、渗血特写）→ 全景交代权力空间（他坐、她跪、打手站纵深） |
| 指控全貌 + 翻案伏笔 | 30–55% | 施暴者用指控式长句把罪名一次说全（替观众交代前情）；受害者辩白里埋一句**可翻案的具体细节**（「视频是合成的」） |
| 情绪最低谷 | 55–72% | 升级句（「打到肯招为止」）+ 被抛弃（他离场，她在地上追爬） |
| 无辜证明闪回 | 72–85% | 叠化闪回**只给观众看**，对手不知道。全集唯一的快段，密集切点做记忆闪烁感 |
| 无反应卡点 | 85–100% | 受害者昏倒；管家报信；**不给加害者正面反应镜**，背影或前景虚焦侧脸静止 3–4s，把「他在想什么」留给下集 |

### 90s

**A. 标准版**

| 节拍 | 占比 | 做什么 |
|---|---|---|
| 钩子 | 0–4% | 闯场指控、捉现行，或仇因闪回 + 誓言 |
| 仇因落地 | 4–15% | 谁害谁：一句台词 + 一个证物或伤痕特写 |
| 压迫 | 15–35% | 对手和帮腔的人轮番压（保安来拖、「别仗着身份」）。**埋下翻盘证物，或让反派自己说出时间地点**（「三天后发布会一结束就宣布」），观众先知道 |
| 第一揭示（小爽） | 35–45% | 证物亮出，或主角一句「好，三天后」接住时间锁。对手第一次失语 |
| 对手反咬 / 搬靠山 | 45–60% | 「哪来的骗子」或长辈到场，局面再压一次 |
| 大爽点 | 60–85% | 罪名清单一口气念完，对手付出代价：跪、被拖走、被扇、净身出户、合作告吹 |
| 余波 | 85–92% | 承受者反应镜 + 一个旁观者反应镜，不要更多 |
| 卡点 | 92–100% | 连载：警察推门、更大的反派得知消息、主角话说一半。闭环：弱者开条件，一句轻松台词收 |

| 时间锁建立 | 6–17% | 载具（飞机 / 火车 / 船）15s 内入画：手续办完 → 长廊拖箱背影 → 停机坪全景。倒计时成立：他来不来得及？ |
| 平行追赶 | 17–32% | 追赶方狂奔，只拍腿部低机位或背影（单镜可到 7s 拉长焦虑），与载具 / 登机镜头交叉剪辑 |
| 第一次交锋 | 32–44% | 长句对两个字：被抛弃方说长而重的话（「或者你开个价」），离开方只回两字（「不会」）。关键台词只拍唇部 |
| 核心虐点 | 44–51% | 最狠的台词（「我会恨你一辈子」）对最轻的回答（「随你」），挂断 |
| 延迟揭底 | 51–61% | 唯一的信息反转放在 55% 处：下一镜才揭开短句方其实已崩溃（机舱内 9s 长镜痛哭，又哭又笑） |
| 时间锁兑现 | 61–70% | 情绪顶点（手按舷窗玻璃，全片唯一高饱和红）+ 不可逆结果：载具起飞大全景，一刀把距离拉到最远 |
| 余韵卡点 | 70–100% | 时间跳切（硬切换空间不换服装）：对称构图独坐、信物特写回收、超长眼部大特写配副歌收口。开放式孤独，不用「待续」字卡 |

### 3min（三种走法，先选一种）

**A. 证据链型**（萌宝、豪门、宅斗）

| 节拍 | 占比 | 做什么 |
|---|---|---|
| 钩子 | 0–2% | 指控、誓言、认罪或捉现行，0 秒开口 |
| 核心谎言曝光 | 3–10% | 「你拜了八年的人还活着」「她是被害的」，整集要拆的谎言在这里亮出来 |
| 证据链 | 10–35% | 2–3 件证物轮流上（胎记、录音、玉佩、密码、出生证明），每 15–25s 一件，每件都配对手反应镜 |
| 对手反咬 + 中点反转 | 35–50% | 反派公开认账（「是又怎么样」），或主角来意二次反转（「我们不是来认你的，是来递诉状的」） |
| 情绪谷（虐点） | 50–65% | 误会解开、旧伤回忆、愧疚方崩溃。全集最慢的一段，ASL 4.5–7s |
| 当众惩处 | 65–85% | 反派失势：被捕、下跪、挨打、资产归还；镜长比上一段短 30–40% |
| 收尾 | 85–100% | 闭环：赎罪条件 + 一句轻喜剧（「先试用一个月」）。连载：反派下令、系统植入、天罚闪电，停在动作完成前 |

**B. 倒叙账本型**（情感账本、底层血性）

| 节拍 | 占比 | 做什么 |
|---|---|---|
| 结局冷开场 | 0–5% | 直接放最后一场冲突的最高点台词，第 2 镜给物证的手部特写（攥着那包烟）。前 14 秒约 6 镜 |
| 主题黑卡 | 5–8% | 黑底白字 2–3 行主题句，停 5–7s，全集唯一的强制停顿 |
| 压迫阶梯 | 8–65% | 4 段闪回逐级加压：私下双标 → 当众贬低 → 亲耳听到人格否定 → 公开羞辱。每段一个场景约 25–30s，段间 1 镜黑场分章 |
| 爆发 | 65–75% | 一句「分手吧」或「离婚吧」，3 镜每镜 1.0–1.5s，全集最快。主动权第一次转移 |
| 清算连环 | 75–95% | 接回开场那场戏，大反转（「这房子是我租的，要走的是你」）放在约 82%，后跟 2–3 个连环小爽：限期还钱、走法律、「搬家费我出」 |
| 金句收尾 | 95–100% | 旁白金句，最后一镜落在贯穿全集的物证上，停 4–5s |

**C. 隐忍储蓄 · 立誓型**（恶女成长、虐妻储蓄）

| 节拍 | 占比 | 做什么 |
|---|---|---|
| 屈辱开局 | 0–7% | 欺凌三镜递进：被俯视 → 被嘲（「真可怜」）→ 身体压制（按头）。质感钩可以慢，但 15s 内必须有一个屈辱动作完成冲突建立 |
| 定罪名 | 7–19% | 对手用台词把主角的「罪」定死（「丫鬟就是丫鬟」）。全景一镜交代空间和身份 |
| 第一次反咬（暗爽） | 19–24% | 全集唯一的爽点，一句反话认领藏刀：「是得谢谢她，若没有她我还进不了这座府。」表面顺从，后半句埋刀 |
| 前史闪回 + 伏笔 | 24–32% | 亡母遗命、灭门旧伤，带出一件未打开的信物（匣子、玉佩）。闪回加「回忆」字标 |
| 外部目标引入 | 32–37% | 街头闲话或一纸告示引入更大的赛场：选秀、继承、发布会。欲望从「容身」升级为「入场」 |
| 欲望觉醒 | 37–45% | 内心转折独白 + 全集唯一一次抬眼直视镜头的眼睛大特写（「难道只求一个容身之处吗」） |
| 对手群像 | 45–72% | 逐个介绍对手：竖排名牌，一次一人。分层：蠢的争艳、藏锋的示弱。让观众先于剧中人看穿镜像对手（反复切她低头） |
| 被排除在规则外 | 72–88% | 第二虐点：文字道具（待选名册）上没有她的名字。同一道具第二次出现时配情绪台词，意义升级。可用约 30s 无台词的物件叙事段 |
| 立誓卡点 | 88–100% | 独白提速到 2–3s 一镜，点名宿敌全名 + 五字以内誓言（「沈玉茹……那我便自己争」）。**立誓段不少于 20s**，短于 10 秒会被评收尾仓促 |

**长篇连载（10 分钟级）**：每 60–80s 一个结构性反转，反转信息由反派或叛徒亲口一句话说出；换层（前世 / 今生）用白闪过曝帧做统一语法，先教一次再用，换层同时换色温和服装；结尾用「时间字卡 + 武器特写」把本集恩怨回拨成下集行动。

- **反转**：3 分钟放 4–5 个（约 6%、20%、40%、65%、80%）。证据链型最大的一个放中点（35–50%）；倒叙账本型最大的一个放 80% 左右；储蓄型没有剧情反转，靠「观众先知（闪回证明无辜）+ 对手不知」的信息差撑全集。
- **爽点**：证据链型一个小爽放前 35%，大爽放 65–85%。「先压过半再大爽」的前提是压迫每 15–30s 升一级，而且开场已经把结局亮给观众。物理清算型的武戏爆点可以提前到 36%，前提是动手前亲情牌蓄压 30–60s 并中途揭穿真实目的。
- **切条窗口**：一集被切成 5 分钟以上的长条时，300 秒窗口里一定要兑现一次「对手付出代价」——**储蓄型首集是唯一例外**，它的「兑现」是翻案伏笔和立誓本身，靠收藏而不是点赞验证。

## 钩子库

第一句在 1.0s 内开口；前 3 秒 1–2 镜（捉现行 4 镜、对峙钩 3 镜、一字令 3 镜）。前 15 秒 AI 约 3–10 镜（慢钩子靠台词密度约 4 字/秒撑），实拍竖屏对线 8–16 镜。本片种的钩子是**一句话加一张脸**，不靠快切。

1. **平静认罪**：审讯室全景，犯人背对镜头坐在画面中央，对面两名警察，顶光打成一道光柱。警察：「你犯的事不小。」第 2 镜切犯人正面近景，他微微笑着：「我只是去收账。」平静地说狠话，反差就是钩子。
2. **闯场指控**：婚礼交换戒指的手部特写，戒指刚碰到指尖。切宴会厅门口，两个背书包的孩子逆着人流跑上红毯，男孩喊新郎的全名：「你今天要是娶她，我和妹妹这辈子都不认你！」先叫名字，再说指控。
3. **祭奠被打断**：雨后墓园，总裁单膝蹲下把白菊放进积水的墓台。后景五个同款白卫衣的孩子排成一排走近，第一个孩子开口：「你演了八年深情，累不累？」
4. **仇因闪回 + 誓言**：雨夜石阶，小女孩抱着母亲哭，第 2 镜泪珠特写，第 3 镜切成年女主的红瞳特写：「今天起，我要你们一笔一笔还回来。」闪回最多 10 秒，第 4 镜之后回到现在。
5. **当众毁物**：宴席上，对手两指拎起主角送的礼物：「一件旧披风，也配当寿礼？」三镜连拍：扬手、披风在空中展开、落在青石地上压住花瓣；第 4 镜切主角放下茶盏。
6. **欺压实录 + 字幕**：日光下的院墙，邻居正把墙往你家门口砌，左下角时间地点字幕（「某年九月 · 某村」）。主角：「这墙咋砌到我家地上了？」对方叼着烟：「村里批的。」字幕负责真实感，台词负责憋屈感。
7. **规则口诀开场**：①欲望快剪版：3–4 个不同的人各一个 1–2 秒正面近景对着镜头说愿望（「我要他后悔」），第 5 镜天平或柜台特写，画外念规则（「当了的东西，赎不回来」）。②片名卡版：老者眼部大特写占满画面，右侧一行红色竖排书法片名，第一句就是规矩（「你这种恶鬼，三天内必须送走」）；第 2 镜他伸出的食指特写，指尖正对镜头。
8. **结局冷开场 + 物证**：雨夜停车场，两人隔一辆车对站，女方先开口：「就为了九块钱，你要赶我走？」第 2 镜切男主的手，指节发白，攥着一包红色烟盒。荒诞的小数额 + 一件物证，问题就立住了；14 秒后接黑底白字主题卡。
9. **结局剧透 +「原来 X 年前」**（解说向）：夜景水边 3s 长镜，女主靠在男主肩上，旁白：「她告诉他自己怀孕了，然后转身走进了海里。」7 秒内塞进三个最炸的词，第 5 镜「原来三年前……」，硬切学校门口。注意：中段还要揭「她在演」，开场就别把「为了复仇」说出来。
10. **捉现行四镜**：①门把手特写，被一只戴戒指的手压下（0.9s）；②床上被子里两个人（0.9s）；③主角站在门口，冷脸：「你们在干什么。」（0.8s）；④床上两人惊慌回头（1.6s）。3 秒交代谁、看见了什么、什么态度。第 6 镜接俯拍客厅全景，主角端坐沙发正中，两人从画面下沿走进来。
11. **侦查装置**：出差回家的丈夫被妻子缠着要孩子，第 3 镜他的笑僵在脸上；第 5 镜他踮脚把一个纽扣大小的摄像头塞进书架缝，第 6 镜红灯亮起，第 7 镜拎起行李箱出门。给的不是结果，是一个行动，让观众想知道「会拍到什么」。
12. **设问自答画外音**（虐恋向）：小馆子全景，女主坐在桌边，画外音是她自己：「怎么最快走出失恋？」停半拍，第 2 镜前男友推门进来，西装革履：「答案是，和前男友变成对手。」第 3 镜一份转让合同被推到桌子中间。
13. **断联动作钩**（离别虐）：第 1 镜女主近景，泪眼，手持卡针取出手机卡（无台词）；第 2 镜跪地把卡扔进垃圾桶；第 3 镜俯拍卡片落入圆形桶口——圆孔构图像镜头光圈，叠一行字幕「断了最后的念想」。动作无需前情就能读懂，第 7 镜内让载具入画升级成倒计时钩。
14. **姿态差对峙钩**（物理清算）：第 1 镜低机位拐杖 + 皮鞋特写；第 2 镜白发长辈怒吼「你怎么敢在这里放肆」；第 3 镜主角跷腿稳坐高背皮椅，不动。用姿态差而不是台词立权力反转，第 3–5 镜叠内心旁白交代血仇 + 当面改姓宣言（「从今起我随母姓——你们的姓不配」）。
15. **一字令 + 受刑三镜**（储蓄型）：第 1 镜男主背影立于夜景落地窗前，只一个字「打」；第 2 镜女主被鞭打仰头惨叫、身后蒙面保镖持鞭；第 3 镜低机位，前景男主皮鞋占画面左侧，女主在红地毯上爬行。三镜把关系讲完：谁下令、谁执行、谁在尘埃里。
16. **危机预警 + 认知差**（重生预知）：赤脚、衣衫凌乱的女童夜里冲进房门：「娘亲快醒醒，将军府明天要被抄家了。」第 2 镜母亲温柔安抚：「是做噩梦了对不对？」孩子说出最不该她知道的大事 + 亲人不信，认知差就是钩子。15s 只用 3 镜，靠每秒 4 字的台词密度撑。
17. **命令式权力宣言 + 眼部特写**（强男强女）：男主红眼大特写坐于椅中，下令「关门，一个不留」，接大衣摆甩动的低角度运动镜。3 秒立住护短霸主，不做任何铺垫；15s 内给「谁强、谁被囚、两人有何旧怨」三个悬念各一个镜头证据（清场俯拍 → 轮椅亮相 → 锁链手腕特写）。
18. **观点断言钩**（解说切条专用）：3s 内连切 3–4 个主角最好看的近景 / 大特写，旁白抛结论（「这才是真正的大女主叙事」）。15s 内摆出观众熟悉的套路场景（捉奸），立刻反套路（「这次矛盾对准的不是女人」）。**警告：这招靠观众认识这张脸生效，AI 新面孔用会失效**。
19. **质感钩**（高风险）：约 6s 单镜，逆光暖黄、浅景深、电影级画质，无台词冲突，靠「这不像 AI」留人。仅适用于画质极高的作品，且 15s 内必须补一个屈辱动作（按头、踩手、泼水）完成冲突建立；画质一般用这个是致命慢开场。

- 钩子台词八种：**指名指控**（喊全名 + 罪名）、**平静认罪**、**誓言 / 规矩**、**结局剧透旁白**、**设问自答**、**一字令 / 命令句**（「打」「关门，一个不留」）、**灾难预警**（「明天要被抄家了」）、**观点断言**（解说专用）。无台词钩两种：断联动作、质感画面。不用「她的人生从今天改变」这种旁白。

## 反转、爽点与卡点

- **证物上场三步**：①证物特写停 1.5–2s；②对手先否认（「胡说八道」「哪来的骗子」）；③第二件证物或第三方证人（长辈、录音里的声音、进门的警察）把否认拍碎。每件证物都走这三步，不能一亮就赢。
- **罪名清单句是爽点核心**：惩处前，主角或证人用排比把罪名或账目一口气念完（「骗她出海、弄坏船舵、伪造遗书、扣下离婚协议，哪一件是假的？」）。一个罪名一镜，交替切念的人和听的人，最后一个落在反派脸上。
- **底牌作废**：对手打出最大的筹码（「我怀的是你家的孙子」），主角先空 1s，再用一句 ≤8 字的顺势话把它作废：「行，你随意。」近景，表情不动。
- **反转信息由反派或叛徒亲口说出**：结构性反转不要靠旁白宣布，让当事人一句话引爆（亲信一句「其实我一直是他那边的人」；亲情牌打到一半反派自己露底「那批货在哪」），观众瞬间明白前面全是戏。长片每 60–80s 一个这样的反转。
- **原样奉还**（物理清算核心）：清算动作用反派当年的加害方式原样奉还——同一道具、同一姿势，配一句点明当年的台词（「当年这么对我妈的时候，可想过今天？」）。这是全集情绪最高点。
- **反应镜是爽感放大器**：每个打击镜后接一个旁观者惊恐反应镜，反应镜数量可以比动作镜还多；打脸后紧接 2 个旁观者反应。反例：清算全程零反应镜，爽点没人看见，情绪落不下来。
- **代价要升级**：先罚轻的，对手不服，再加码（掌嘴三十 →「我没错」→ 再打五十板；收回财产 → 威胁被作废 → 报警 → 警察进门），3 分钟里 3 轮。
- **反派当众认账**：「是又怎么样，一个乡下女人也配进这个门？」让反派亲口承认，比被证据逼出来更爽，也给愧疚方一个当场崩溃的理由。
- **反派话多，自曝时间表**：让反派当面炫耀「三天后发布会一结束就宣布订婚」，主角只回一句「好，三天后」，变成时间锁。决战现场至少切回 2 次那块「炸弹屏幕」（后台代码、合同、大屏），屏幕字后期叠。
- **载具时间锁**（离别虐）：用交通工具出发做不可逆倒计时——前 15s 内让载具入画，后段必须让它**真的离开画面**（起飞大全景，近乎固定机位，让飞机自己走出画面 = 无力感）。
- **倒计时要可视化**：时限不能只活在台词里。重生预知用天色 / 烛火变化计时（月亮西沉 → 天色发白），天道类用红色大字「余七日」压在三分线上，重生换层用「6 小时前」时间字卡。
- **屏幕倒计时**：契约 / 鬼魂类在每个新场景的第一镜，用红色大字叠上「余七日」「余六日」。时间锁是追更最稳的钟。
- **高概念装备两段式**：给弱势设定（轮椅 / 残 / 病）配一件可视觉化的高概念装备，先给装置伏笔特写（开关、伺服、全息），后爆发齐射奇观，「弱即强」的反差拍成两段。**必须有一句世界观内的解释或角色吐槽收进世界观**，否则沦为评论区群嘲点。
- **换层语法先教后用**：白闪过曝帧做记忆 / 重生 / 换层的统一转场，全片至少先用一次教观众（开场醒来），第二次才敢承担结构反转；换层同时换色温与服装（黑战衣 → 白裙，紫蓝霓虹 → 暖白柔光），观众不用台词也能分辨层。
- **观众先知的两段投放**：闪回证明主角无辜时，先以 0.5s 闪切给碎片（白裙背影站崖边）插在辩白台词之后，后段再给全貌。悬念从「她冤不冤」升级为「**他什么时候知道**」——这是储蓄型的核心发动机。
- **延迟揭底**：短句方说完「随你」，当镜不给脸只给手的特写，把真实反应**延迟到下一镜**才揭开（机舱内长镜痛哭）。「不是不爱，是不敢爱」的反差靠延迟完成。
- **伏笔回收三次**：贯穿全集的物件至少 3 次手部特写，每次手势不同（攥着 → 捏着 → 递出去）。配角开玩笑说的预言，结尾要在画面里真的发生。文字道具（名册、婚书）复用两次，第二次配情绪台词完成意义升级。
- **反向复用台词**：对方开场说的那句，结尾由主角翻过来说（「你要赶我走？」→「这房子是我租的，要走的是你」；「你只谈生意」→「我以为你在跟我谈感情」）。虐恋向尤其好用，评论区会自己把两句拼起来。
- **「擦泪 → 微笑」揭底**：女主第一次露出真实意图时，用同一镜里的表情切换：低头擦泪，抬头时嘴角已经上扬。全集只揭底一次。
- **惩处要有权威收口**：警察进门、董事会决议、父亲断绝关系的电话、皇命律条、「走法律程序」、把证据寄给主管部门。只靠私人报复收尾的，要么用自首或审讯兜底，要么交给超自然规则。私刑虐妻类必须给一句「为何不报警」的理由（家丑不外扬、证据不足），否则逻辑悬浮被吐槽。
- **虐恋的「刀」放在真相解开那一刻**：最痛的瞬间是「原来我恨错了人五年」。愧疚方拿着证物的手部特写，接他抬头的近景，眼眶泛红但不说话，停 2–3s。
- **复仇之后的那一拍**：惩处之后不要停在反派的惨叫上。暗黑向最后一镜切复仇者空掉的脸，面无表情，眨一次眼，环境声抽空。温情向给受害者一段「本来该有的普通日子」：坐上旋转木马、手里一支冰淇淋，暖色过曝，笑。离别虐的对应物是**时间跳切后的静止**：对称构图独坐、捂脸、「被钉在过去」的宣判句独白。克制版比浓烈版高级：删掉「按玻璃 + 昏倒 + 喊医院」三连，载具离开后直切空镜与沉默，眼泪留给观众自己补。

**卡点十式**（连载用）
1. **反派知情**：电话那头的大反派听完汇报，捏紧手机：「去把那个丫头给我带回来。」话音落下就切。
2. **系统植入**：复仇者服刑后，瞳孔亮起蓝光，画外音问：「如果能重来一次，你会怎么选？」
3. **天罚将至**：恶人落水挣扎，镜头抬起，乌云里劈下一道闪电，切在闪电落地之前。
4. **新靠山登场**：「住手！」一声，切来人的鞋子和衣摆，不给脸。
5. **惩罚兑现第一帧**：门被推开，两名警察站在门口：「谁报的警？」主角近景，只说一个字：「我。」字落下 1 秒内切。
6. **话说一半**：主角终于亮底牌，「公司每一个核心模块都在我脑子里，没有我……」话断在这里。
7. **冲突进行时**：正主一把按住女主要拎走的行李箱：「我倒要看看。」切行李箱特写，不给结果。
8. **点名宿敌 + 立誓**：主角点出宿敌全名，立一句五字以内的誓言（「沈玉茹……那我便自己争」）。誓言压在全长 95% 之后，前面提速到 2–3s 一镜。
9. **施暴者无反应背影**：报信之后不给加害者正面反应镜，背影对白天城市窗景静止 3–4s，无台词——「他在想什么」留给下集。进阶版：窗玻璃反射出他半张脸，一镜给「冷」与「裂」两层。
10. **时间字卡 + 武器特写**：「6 小时前」字卡 + 武器特写（「这把老古董刚刚好」）+ 庄园大远景，把本集恩怨回拨成下集行动。

- **评论靠「站队」**：把问题放进片子里（片中直接抛给观众的问句、一句争议台词），或者选一个观众能拿自己经历对号入座的话题（工资怎么分、彩礼多少）。只在文案里写「你会怎么做」、片中没有问句，评论很少。
- **分享靠社会议题和可截图金句**：拐卖、契约换良心、工资上交这类能转给别人看的议题，加上把金句写成可截图的宣判句。
- **储蓄型靠收藏验证**：收藏/点赞 ≥29% 说明观众在存起来追更。发布前必须储备多集，只有一集会浪费流量、把催更变怨气。

## 人设与台词

| 位置 | 人设 | 一眼识别法 |
|---|---|---|
| 复仇者 | 平静、话少、记账型，说狠话不提高音量 | 统一的主色块（红衬衫黑外套 / 蓝金正装 / 浅蓝衬衫）；一个招牌生理特征（红瞳），观众会盯着看 |
| 掌权长辈（护短型） | 几乎不动，语速平，眼神斜着看人，以静制动 | 全场最贵也最稳的造型：千鸟格套装、红宝石胸针、低盘发。机位也最稳，反派那边可以略带手持晃动 |
| 加害者 | 当众嚣张、私下心虚，出事先把锅甩给弱者（「他们就是来讹钱的」）；话多，会自曝计划 | 和复仇者对立的颜色：香槟金、酒红丝绸、紫色印花 |
| 糊涂帮凶 | 男主、世子、父亲、公公。嘴上永远是「让着她」「道个歉就算了」 | 站在加害者半步之前，护的姿态 |
| 暴力执行代理 | 蒙面保镖、下属。施暴者通过他们动手、自己不亲手沾血 | 始终站在纵深不动，只作背景；受刑镜头给「前景施暴者的鞋 + 后景执行者」 |
| 镜像对手 | 藏锋型：表面素净示弱「穿什么都一样」，内里算计，是主角真正的对手 | 让观众先于剧中人看穿她：对头争艳时反复切她低头的反应镜 |
| 揭真相的弱者 | 孩子、老人、底层工人。说最狠的话，用最小的身体 | 孩子统一服装 + 一个区分点（眼镜、发型） |
| 嘴替 / 插科打诨的引路人 | 红发兄弟、贪玩的老道和徒弟。替观众说心里话，或在沉重的戏里递笑点 | 最夸张的造型：红发金链、明黄道袍。评论区的笑点都来自这个人 |
| 权威收口 | 警察、长辈、皇命、董事会、主管部门 | 进门那一下给全身，逆光 |

- **施暴者借下属之手**（储蓄型专用）：主角方的加害者不亲自动手，为后续追妻火葬场保留被原谅的余地。这是储蓄型日后能翻案的结构性设计。
- **群像反派功能化**：每人只给一句功能台词（家主立威、祖母伪慈、姑姑要货、婶婶和稀泥、堂兄挑衅第一个挨打、堂妹惊恐反应担当），便于观众记人，也便于 AI 一人一色。
- **主角的武力或身份由第三方旁证**：让保镖说「连续三年都是冠军」，不让主角自夸。
- **隐忍主角的「低头」面具**：给隐忍型主角设定低头的身体习惯，全集只允许抬眼直视镜头 1–2 次，留给欲望觉醒和立誓。「低头」本身是视觉母题：被按头 → 低头 → 低头 → 抬眼。
- **冷酷不等于无表情**：全程面瘫的冷酷主角会被观众直接嘲讽「演都不演」。至少给下颌紧绷、眼神闪避、嘴角收紧一类微表情；实在做不出，用旁白先解码再给特写（「人在极度悲伤的时候是没有任何表情的」），把表情不足变成刻意克制。
- **孩子说大人的狠话**是萌宝子类型最强的反差（「你不配」「赔罪？你也配」）。孩子台词单句 ≤10 字，语气平直。
- 愧疚方的赎罪要被**弱者开条件**（「先来面馆揉面送外卖，试用一个月」），主动权留在受害者手里。
- **隐忍的主角每次受辱都要有一个看得见的小动作**：手指把烟盒攥扁、把银行卡翻过去扣在桌上、托盘下攥紧的手、喉结动一下。主角反应镜没有变化，观众只会骂反派，不会喜欢主角。
- **反派要给一个能被理解的瞬间**：纯拜金符号的反派会把讨论推向性别对立。给她一句真实的焦虑（「彩礼是我妈逼的」）就够了。
- **同场的两个女性角色**发型、主色、配饰都要拉开（长卷发对低盘发，白丝巾对黑挂脖），否则评论区全是「两个女的长得好像」。
- **过狠台词要用喜剧化兜底**：「全家一个都别想活」这类台词会引发价值观质疑；同场配一句荒诞比喻的俏皮狠话把暴力变成笑点，是给道德边界上的保险。只惩罚一方还会被认为双标，价值观立论要给另一方一个交代。

**台词技巧**
1. **具体到数字**：一集至少 3 个具体数字或具体时限（「八千」「两万」「九块」「二十八年前」「两个时辰」「吻合率 99.99%」）。
2. **同一个数字说 4 遍，每次换人换意思**：从女方嘴里的轻蔑，到男主的恳求，到兄弟递烟的玩笑，再到旁白的定论。
3. **底层账本对比句**：「这点钱不够他吃顿饭，是我们全家的命。」句式是「X 对他 = 小，对我 = 命」。
4. **抓词反问，短句收长句**：对方说一大段，主角回一句 ≤8 字的反问（「我何时要你原谅了？」「她配吗？」）。
5. **顺着威胁说**：「行，你随意。」把威胁变成笑话。
6. **俗语定性**（中老年受众）：「知三当三」「明媒正娶」「欺负到正室头上」，一听就知道该站哪边。
7. **贬低要具体到职业，后面拿它打脸**：「只会敲几行破代码」「你就配修马桶」。高潮用的武器就是被贬低的那项本事，台词里至少点名 2 次。
8. **字面转义的俏皮狠话**：「我没推你，我只是松了手。」先认一个字面事实，再补上更狠的真相。
9. **规则口诀，首尾呼应**：开场、中段、结尾各说一次，8–12 字，带对仗或重复。
10. **延迟报身份**：对手问三遍「你是谁」，第三遍才回：「我就是你说的那个野丫头。」鬼魂版：「我就是二十八年前你卖掉的那个人。」
11. **物件来历长句**（宅斗）：把被毁的东西报出产地、工艺、工期、赐予人，念完问一句：「现在还觉得是小事？」
12. **不用套路名和套路头衔**：被用烂的霸总名字、「某圈太子爷」已经成梗。人名用两个常见字 + 一个具体职业。
13. **赐予式台词**（上位者）：用承诺代替威胁收服人——「你的心愿，我没有不准的」「宝剑赠英雄」。上位者的权力感来自「我许你」，不是叫嚣。
14. **性别对调句**：把规训原词换主语套到对方身上（「男子首当洁身自好」）。说完留 4–5s 气口让观众笑。
15. **长句对两个字**（离别虐）：被抛弃方说长而重的话（「我会恨你一辈子」），离开方只回两字（「随你」「不会」）。短句一方占上风，长句一方在崩溃；下一镜再揭开短句方的崩溃。
16. **一字令**：「打」「滚」。用最短台词定权力，配受刑画面，第 0 秒出口。
17. **调情式狠话**（相爱相杀核心修辞）：三拍对切——「你死后可与我合葬」/「可我不稀罕」/「因为你不配」。狠话用求爱的句法说。
18. **反讽式礼貌**：「这两巴掌就当我谢你不杀之恩」「抱歉啊，做我的对手你还远远不够格」。
19. **反话认领藏刀**（储蓄型）：「是得谢谢她——若没有她，我还进不了这座府。」表面顺从，后半句埋刀，是隐忍集里唯一的暗爽点。
20. **物权宣言**（搬空 / 囤货专用）：「这些东西本就不该姓柳」「砖瓦都是娘亲嫁妆银子填的」。先立正当性再爽，是「拿走」的道德底座。
21. **指控式长句替观众交代前情**：「你明知道她有心脏病，还故意气她」——一句把罪名说全，储蓄型开场不用闪回也能让观众看懂指控。
22. **旁白做情绪翻译**（AI 专用）：先给观众解码句（「人在极度悲伤的时候是没有任何表情的」），再给无表情特写让它成立。

**金句公式**
1. **「对你是 A，对我是 B」**（价值落差）
2. **「从你 X 的那一刻起，你的 Y 就一文不值」**（时间点 + 清零）
3. **「规矩 + 下场 + 停顿 + 一个字」**（「出局只有一个下场……那就是死」）
4. **「让我 X 的从来不是 A，而是 B」**（小物件翻出大真相：「让我走的从来不是那九块钱，是我在这个家早就不值钱了」）
5. **「既然你只谈 A，那你就 B 不起」**（把感情和价格对换）
6. **对称性别对调句**——「绝不因她是个男子……也绝不因她是个女子」。对称句便于截图传播，给它整段最长的镜头（3–4s）
7. **时间宣判句**——把抽象情绪落到实体动词：「这句话就宣判了这段感情的结局」「只有我一个人被钉在过去」。宣判、钉、判决这类动词配对称构图的静止画面
8. **五字以内誓言**——「那我便自己争」。短到能做标题，卡在集尾点名宿敌之后

金句单独占一镜，说话人近景或特写，前后各留 0.5s 静音；主题金句也可以放到黑底白字卡上，停 5–7s。系列的最强台词直接放进标题文案当钩，观众会复制到评论区。

## 视听风格

**景别**
- 竖屏：腰部以上单人约 55–75%（实拍对线最高，萌宝群戏约 50%；AI 古装近景 / 特写约 45%，物件插入特写约 10%）。横屏约 45–60%；漫剧动作向特写 / 大特写可到 55–60%（脸、眼、手、武器、道具），全景 / 远景 15–20% 留给空间定场和战果陈列。
- 情绪爬升按景别走：**全景建立 → 中景对话 → 近景顶撞 → 大特写爆发 → 回到安静近景**。大特写只给怒吼的那一两句。
- **群戏回位镜**：5 个人同场对线，除了 2–3 个全景，其余全是单人近景正反打；每有新人物进门，回一次全景交代站位。文戏循环「全景定位 → 逐人近景台词 → 主角特写收束」；武戏改为「中景动作 → 特写受击 → 全景交代倒地」。
- **全场一张图讲清敌我**：全家坐沙发、主角身后站一排保镖的全景，一张图交代站位和伏笔；打斗中段给一个吊灯仰拍全景或满地伤员的俯视全景当「呼吸镜」兼战果陈列。

**运镜**
- 对峙以固定 + 缓推为主，压迫靠推进，不靠晃动。运动感主要靠「主体动 + 切」：衣摆甩动、鞋跟步行、滑倒姿态，爆闪帧模拟甩镜震镜。
- 权力位用**低机位仰拍**：复仇者踩人时机位贴着地面，鞋跟在前景；反派入场先给皮鞋 / 拐杖踏上地毯的低机位特写，再上摇到脸。主角亮底牌时要拿到同等或更高规格的英雄镜头：低机位缓推近景，背后是舞台光。
- **仰俯对切 = 视线即权力**：强者高位俯拍全景、弱者仰角特写加逆光，各停留 2–4s。进阶写法：俯拍之前插一个强者眼睛大特写（0.8s），形成「眼睛 → 俯视画面 → 被看者」三连主观视点链。
- **前景鞋 + 纵深爬行 / 跪伏**：低机位一镜说完权力差——前景是施暴者的皮鞋占画面左侧，后景受害者在红地毯上爬行。
- 审判位用**高机位俯拍**：客厅全景俯拍，主角端坐沙发正中，被审的人从画面下沿走进来。全集只用一次。
- 惩处或动作段才用手持和快速横摇。奔跑追赶只拍腿部低机位或背影，与载具镜头交叉剪辑，不拍全身正面长跑。
- 推近 = 情绪确认：每推一次加一层压迫感；缓推到近景对应「进入内心独白」。

**构图**
- 竖屏多人戏用**纵深三层**：前景孩子的背影或肩膀，中景被指控的人，后景宾客或墓碑。不要横排。
- 对峙用**前虚后实**的过肩：谁占前景谁有主动权。漫剧对峙多用过肩 / 背身 / 侧贴，既保戏剧距离又回避 AI 双人正脸互动。
- 用**坐与站**表达高低：受辱的人坐着或跪着，羞辱他的人站着俯视；翻盘时让他站起来。姿态反转钩则反过来用——被怒斥的人稳坐，怒吼的人站着失态。
- 宣判、行刑、立规矩用**中轴对称**：主位居中偏高，两侧人物对称。余韵段用正中对称构图独坐 = 秩序下的空洞。
- **玻璃 / 窗 = 隔绝母题**：手贴玻璃、隔窗看载具、玻璃水痕、舷窗——「看得见够不着」全靠这一种材质；**门框套框 = 被困**（托茶盘立于门框中、月洞门框中框收尾）。
- **主角在光里，反派在暗部**：体积光柱斜射，主角总站在光柱里；恶意台词时把反派推进全暗，只留眼睛高光。

**光色**
- **阵营色块**：每个阵营一个主色，跨场不换（五人五色：婆婆灰褐、儿媳纯白、第三者紫、儿子黑、公公蓝，任何一镜都认得出谁站哪边）。群像用「发色 + 服装主色」一人一色，即使脸部漂移也认得出。
- **低饱和主角 vs 高饱和对手**：主角全程低饱和（青褐、灰、莫兰迪色），对手高饱和（橙红衣料）；把唯一的高饱和色留给「主角想要的东西」，立誓时让那个颜色入画同框。
- **全片只给一个高饱和红**：血手、红绳、口红、红盖头、红瞳——红色元素放在情绪顶点镜头上，其余画面压住。「白 → 红」可以做成单集视觉主旋律（白衬衫被血染红，中间加一个袖口滴血特写）。
- **一层一色温**：重生层暖白柔光 + 白裙，现世层紫蓝霓虹 + 黑战衣；色温即叙事层，观众不用台词也能分辨。色温也可以随情绪走：暖（家）→ 冷（行动）→ 灰（离别）。
- **压迫段明亮温暖，清算段暗冷**：欺压发生在大太阳下的村庄，复仇在夜里；关系变冷的过程就是暖黄客厅 → 冷白顶光的家 → 蓝灰雨夜。例外：家庭对线可以全场暖色不变调；离别虐是「他冷她暖」——航站楼冷蓝白高调 vs 机舱暖米柔光，但隔着玻璃与舷窗。
- **阶层靠场景色温对比**：高调香槟色婚宴 vs 暖黄蒸汽的面馆 vs 蓝紫夜景的总裁办公室。
- **换装就是换地位**：主角服装变化对应身份阶段（学生针织衫 → 复仇黑西装 → 登堂入室的白衬衫白丝巾）。换装放在场景切换处，一场戏内不换。

**美术**
- 至少一个**道具母题**贯穿全集、出现 ≥3 次：棋盘、天平、玉佩或胎记、被扔的披风、红色烟盒、一只白瓷盘、钥匙（三次手与手的交接对应信任三步）、匣子（未打开的身世秘密）。「手」本身可以做母题：求（抓裤脚）→ 压（捏下巴）→ 救（悬崖伸手）。
- 屏幕字靠后期：章节卡（每 30–40s 一条）、黑底白字主题卡、红色书法片名卡、时间地点字幕、倒计时大字、时间字卡（「6 小时前」，换层锚点）、心声字幕（黄色、以「#」开头，写主角没说出口的话）。
- **人物名牌**：群像首次出场打竖排书法名牌（姓名 + 身份），**一次只介绍一人**。密集群像不挂名牌，观众会记不住谁是谁。
- **可读文字道具**（名册、匾额、婚书、榜单）文字必须正确清晰——后期合成而非直接生成，这是 AI 剧被夸「看不出 AI 感」的硬功夫。
- 主体放在画面中间 3/5，给上下的剧名条、标识条留位置；横屏画面嵌竖屏黑边发布时，字幕压在画内下方。

## 剪辑节奏基准

| 指标 | 基准 |
|---|---|
| 平均镜长 | **竖屏对线和爽向** 实拍 1.3–2.2s、AI 1.8–2.8s；**动作漫剧（不分横竖）** 1.6–2.2s；**竖屏情感和闭环** 2.6–3.5s；**横屏叙事** 2.6–4.5s，叙事向 AI 可到 5s（要满足长镜条件）；**AI 竖屏质感古装 / 萌系叙事** 4.2–4.5s |
| 单镜中位数 | 竖屏 1.2–2.5s，横屏 2.5–3.5s |
| 短于 1s 的镜头 | AI 非动作段 8–15%，动作段 0.1–0.8s 碎切是常态；实拍对线可到 25% |
| 长于 6s 的镜头 | 竖屏对线 / 爽向 ≤10%；质感古装可到 20%，但每个长镜要有名牌、道具或连续台词在变；**单镜超过 10s 且只靠旁白撑的一律拆** |
| 前 3s / 前 15s 镜数 | 1–2（捉现行 3–4，每镜 ≤0.9s）/ AI 3–10（慢钩子靠台词密度约 4 字/秒），实拍对线 8–16 |
| 台词密度 | 3.5–4.5 字/秒，单镜 ≤5 字/秒。小说书面语直译听感吃力，配音稿要口语化 |

**快慢段落规则**
- 有情感段的单集，冲突和惩处段的 ASL 比情感段短 30–80%：底层血性压迫段慢、复仇段快约四成；鬼魂复仇公路喜剧段慢、雨夜索命快、复仇后的温情段又慢下来；萌宝认亲闯场快、真相团圆段慢一倍（但别慢成 AI 长片段直出的拖沓）。
- 物理清算：文戏段约 2.75s，武戏段 0.3–0.8s 碎切，快段比慢段短 70–80%。**长镜攒信息，微切放暴力**：一句 9–10s 的狠话长镜说完，立刻接碎切群殴。
- 强男强女重生：对白段 2–6s 长镜，动作 / 爆点段 0.1–0.5s 微切。快慢对比的位置就是情绪阀。
- 离别虐 MV：开场 15s 最密（约 1.9s/镜），交锋段 1.3–3.8s 正反打，情绪落点给 9–11s 两个超长镜配副歌——**快问慢答**。
- 储蓄型：快—慢—快—慢四段；对白放慢到 4–5s/镜，闪回是全片唯一的快段（密集切点做记忆闪烁感），结尾背影长镜收。慢剪成立的条件是质感 + 名牌 + 物件叙事，且立誓段要提速到 2–3s/镜收尾。
- 全程对线的单集可以匀速快切，但最大的爽点前要有一处「静」：先空 1s，或给一个 3s 以上的近景。
- 匀速的 AI 叙事片要有局部加速：爆点那一句连续 3 镜，每镜 1.0–1.5s。
- 情绪落点（揭底、副歌、宣判句）可以给 9–11s 超长镜，这是全片唯一合法的「静止」。

**审核参数**（写进 storyboard 的 `project.asl` / `project.hook`）

```json

```

## AI 制作要点

1. **10 秒片段直出不剪**：按台词把生成片段拆成 2–3 个镜头，中间插听者反应或证物特写；竖屏单镜无台词超过 5.5s 就剪掉；超过 10s 的对白镜（尤其反派炫耀自白）必须插听者反应镜，或拆成「半句 → 反应 → 半句」。
2. **表情单一 / 面瘫**：每镜写具体微表情（「嘴角向下压、眼眶泛红但没哭」「冷笑，只动一侧嘴角」「下颌紧绷、眼神闪避」）；惊讶脸全集最多 2 次，留给证物亮出的那一下。兜底：旁白先解码再给特写，或用**心声字幕**（黄色、以「#」开头）代替微表情。
3. **同一表情 / 同一构图连拍**：同一组人物的连续镜头，景别或角度至少变一项，否则合并。同一构图组连续 13s 就是中段塌陷；挨打后连续 5 镜两张一样的淤青脸是反面教材。
4. **生成拼接残留**：0.1–0.3s 的碎镜、几乎重复的同机位双镜是可见的 AI 瑕疵，成片前逐帧质检清掉；结尾音频 / 字幕循环要质检截尾。
5. **多个孩子或群戏跨镜不一致**：统一服装（同款白卫衣 + 书包）掩盖脸的差异，再给 1–2 个辨识点（眼镜、发髻、手里的木盒）；主讲的孩子建 `refs`，其余做背景；群戏对线「全景定位一次 + 单人近景正反打」，每镜只有一张嘴在动。**密集出场的群像必须挂竖排名牌（姓名 + 身份），一次只介绍一人**。
6. **服装颜色和发型当角色 ID**：所有角色跨镜锁定主色、发型和一件配饰，写进 `refs` 和每镜提示词；招牌特征（红瞳、红盖头、银发礼帽、明黄道袍）一镜跑掉就出戏。
7. **同一个角色出现两张脸**：预告式钩子和正片用两组角色，观众会以为换了一部剧。每个角色只用一套 `refs`，开场的闪前也从正片里剪；同一系列不混用 AI 和真人素材。
8. **打斗像挠痒痒**：碎切只能掩盖不连贯，给不了打击重量。每个打击镜 ≤0.8s（单个出手 / 受击瞬间），后接旁观者惊恐反应镜；挑 2–3 个关键打击做 0.5s 升格慢放 + 静音一拍 + 重击音效 + 受力反应。武戏整体拆成「定格 pose + 0.1–0.3s 爆闪微切 + 光效叠层」，不生成连续长武打；手部只给静态抓握特写。
9. **证物和屏幕上的字乱码**：可读文字道具（名册、匾额、婚书、榜单）后期合成贴上；监控视频、手机屏、合同这类高危道具**只在台词里提，不在画面里生成**；纸面斜 45° 或只拍抬头，或让人物念出来，纸只做道具。
10. **暴力和长动作**：不拍正面行凶，「原因特写 → 结果全景」两镜法。车祸只拍「高跟鞋踩油门 → 轮毂 → 倒地全景」，耳光只拍捂脸，鞭打只拍举鞭后的结果（惨叫、血痕），坠崖只拍「伸手」和「扑倒在崖边」两个静态姿势。搬空 / 囤货不拍搬运，用「抬手 + 粒子消失」特效镜（同一收物音效），最后给空库房全景当战果。搬家、爬楼这类长动作只在台词或旁白里讲。
11. **口型和长台词**：关键台词只拍唇部大特写，或用手机 / 手遮挡口型；长台词拆到说话人和听者两个镜头上，听者镜头配画外音；双人镜头让一人背对镜头。长段情绪交给旁白或歌曲。漫剧用「广播剧式配音 + 字幕」根本不追口型，是 AI 最省事的形态；解说体靠旁白覆盖，同理。
12. **多人肢体接触**：拥抱、扭打是 AI 短板。接触只取「捏下巴」「抓手腕」「靠 / 扶」「按蛋糕」这种双人单点姿势，多镜复用；群像同框全是静态坐 / 立，或远景剪影、爆炸遮人。
13. **配乐盖过台词**：对白比 BGM 高 6dB 以上；立誓、亮底牌、金句这几句，BGM 退到只剩低频铺底。带人声的歌曲不能压对白——MV 式混剪是唯一例外，但字幕必须承担叙事主线。长段 BGM 与人声混淆还会造成转写幻觉，混音要干净。
14. **高概念装备没有世界观解释**：奇观可以夸张，但要一句角色解释或吐槽把它收进世界观，否则笑点盖过爽点。装备先给开关 / 伺服特写 + 机械音去魔法化，再爆发奇观。
15. **时间结构没有视觉锚点**：重生 / 换层缺字卡、钟表、服装色温锚点，观众读不懂。白闪换层先教一次再用；换层同时换色温与服装；关键时间跳跃上字卡（「前世 · 死夜」「6 小时前」），与结尾字卡构成锚点。
16. **爽点没人看见**：每个打击、每次物品消失、每个打脸点，都要给一个旁观者或反派反应镜——此前说过看不起主角话的那个人最好。
17. **遮瑕破坏调性**：血迹用可爱贴纸遮，在严肃虐恋里跳戏。改用画内遮挡：阴影、切走、物体前景。
18. **剧名和导流**：剧名不在画面露出，观众找不到剧，收藏再高也导流失败——片尾或标题露剧名。发布前储备多集，断更会把催更变怨气。
19. **鬼魂和超自然造型**：红盖头、长发遮脸、背光剪影最稳，一个标志物就能跨镜锁定，不需要露脸。生物角色只给发光灵体或单次短爬行，绝不让 AI 画跨镜头的长生物运动。
20. **风格选择**：写实人脸有恐怖谷风险，3D 萌系（大眼圆脸）脸型更稳、表情更夸张可读；写实电影风古装 + 慢剪 + 名牌 + 后期文字可以赢「看不出 AI 感」的口碑，但对画质要求极高。每场固定一种主色温、按场锁定色调提示词，比追求单帧精美更能稳住一致性；单集尽量锁定一个主场景。
21. **竖屏群像畸变**：婚宴和公堂的远处群演容易糊脸、多手。浅景深虚掉后景，前景只放 2–3 个主要人物。

## 大导演工具箱

| 导演 | 手法 | 在本片种里怎么用 | 镜头写法 |

## 禁忌

- 前 10 秒只交代关系没有冲突；晚于 3 秒开口又不可读就是慢热。
- 仇因说得空泛，没有数字、伤情、时限或证物。
- **动机链跳步**（「她撞了我爸，所以我去接近她男友」，中间没有任何交代）；离别向单靠一个哭镜撑动机同样翻车。
- 证物一亮就赢，跳过否认那一步，对手当场降智。
- **爽点没人看见**：打击、搬空、打脸之后没有任何承受者或旁观者反应镜。
- 惩处只有一句「你会后悔的」，没有制度性代价或看得见的权力变化。
- 私刑复仇没有法律后果，或法外施暴不给一句「为何不报警」的理由。底层血性以审讯或自首收尾；超自然复仇交给规则兑现。
- **纯受虐主角零反击苗头**：储蓄型集尾必须有翻案伏笔或反击苗头，否则观众直接流失。
- **立誓段短于 10 秒**：储蓄型的情绪兑现就是立誓，太短会被评收尾仓促。
- 虐恋收尾让愧疚方一句「对不起」就复合。主动权必须留在受害者手里（开条件、试用期、先解决反派）。
- 施暴者亲手施暴（储蓄型）：不借下属之手，后面追妻火葬场就没有被原谅的余地。
- 开场旁白剧透了「她在演」，中段又用「擦泪 → 微笑」揭一次同样的底。
- 台词过狠没有喜剧化兜底；只惩罚一方（双标）不给另一方交代。
- 解说钩子和正片用两组演员，或同一系列混用 AI 和真人素材；解说式的「明星脸」观点断言钩直接搬到 AI 新面孔上。
- 同场的两个女性角色撞脸、撞发型、撞主色；密集群像不挂名牌。
- 用被玩成梗的套路名和头衔。
- 配乐或带人声歌曲盖过立誓、亮底牌、金句（MV 式除外，且字幕必须承担叙事主线）。
- 300 秒的切条里一次「对手付出代价」都没兑现（储蓄型首集除外，但必须有翻案伏笔 + 立誓卡点）。
- 竖屏里 AI 10 秒片段原样铺满对话戏；单镜超过 10s 只靠旁白撑；横屏里没有台词、没有运动的长镜。
- 反派炫耀自白的长镜不插反应镜。
- 打斗只有碎切没有重量（无慢放、无停顿、无受力反应）——「打架像挠痒痒」。
- 全员惊讶脸，大特写连用 3 次以上；主角全程面瘫（冷酷 ≠ 无表情）。
- 贴纸遮血等破坏调性的合规遮瑕；0.1–0.3s 生成拼接残留不清理。
- 高概念装备没有世界观内解释；重生 / 换层没有时间字卡、色温、服装锚点。
- 竖屏多人横排一字站，或证物落在下方 1/4 字幕区。
- 剧名不在画面露出（导流失败）；首集爆了没有多集储备（催更变怨气）。
- 「未完待续」黑屏直接收尾（前一镜有抛给观众的直接问句的除外）。
