# 甜宠

> v0.3。例子和 logline 都是自拟的。基准数据样本偏少，区间只作起步值。

## 定义与情绪承诺

观众要看一个**高冷的人为一个人破功**，要看到「被偏爱」这件事**发生**：钱、时间、身份、破例、当众站队，落在能看见的东西上；还要看到**偏爱被围观**——不只男主爱她，全场都在抢她，观众和女主一起被捧到中央。一集兑现三件事：

1. **破功**：他在公开场合、在众人面前、用他自己的方式认下她。破功要看得见（当众牵手、当众认妻、把名字加进族谱、把黑卡拍在桌上、把她的名字写进文件）。
2. **偏爱奇观**：两男以上同框、当众对峙或抢人；或一群人为她破例（团宠）。奇观必须发生在**公共场域**——订婚宴、家族大会、寿宴、颁奖典礼、病房走廊，有围观者才有奇观。
3. **确认**：观众替她把「他到底爱不爱我」问出来，并且当集给答案。

- **偏爱的双重语义**：男主对女主的偏爱 + 观众对女主的偏爱（团宠式万人迷）。两条都用，一条做关系线，一条做奇观线。
- **甜宠和爽剧的边界是糖**：爽剧卖打脸，糖是调味；甜宠卖糖，打脸是配菜。一部剧里打脸和糖的配比超过 6:4，就该按爽剧做（重生复仇 × 死对头 CP 的混血、打脸占主体的样本，归 underdog-payoff）。
- **虐恋和甜宠的边界是糖的位置**：虐恋前 70% 是虐、糖在结尾；甜宠前 30% 可以有压，但糖必须出现在前 60%。**前 60% 没有糖的甜宠是失败的**。
- **霸总、隐婚、闪婚不是甜宠的必需元素**，但它们是当前样本里最容易做出破功的容器。
- **数据基准**：互动率中位约 12%，全距 3%–35%（35% 是评论诱导型特例：一句「送花就能在一起」的互动钩让评论区全在刷花）。点赞 / 收藏比 15%–64%，中位约 32%；低点赞 / 收藏比（≤20%）的样本靠「值得回看」撑，高比（>50%）的靠「情绪冲击大、看完就爽」。

| **古装撩汉** | 女主主动撩 → 男主表面冷实则破功 → 破功被第三人看见 → 集尾男主主动反撩 | 女将军第一次上朝就盯着摄政王看了三息，散朝后他把她堵在宫墙上：「看够了吗？」 |

## 单集结构模板

**镜数**：ASL 1.45–3.2s，均值约 2.3s。60s 约 25–40 镜（中位 30），90s 约 35–60 镜，3min 约 70–120 镜。前 3s 通常 1–3 镜，前 15s 约 5–10 镜。**单集镜数超过 140 时，糖的密度必须跟上**，否则会被评论「太水」。

### 60s（竖屏主模板）

| 节拍 | 占比 | 做什么 |
|---|---|---|
| 钩子 | 0–12%（0–7s） | 一个动作直给关系状态：递协议、撞进怀里、被拽上车、一句宣言。**前 3s 必须有肢体或物件接触，不能是空镜或纯对白** |
| 关系 / 误会确立 | 12–35%（7–21s） | 一句话让观众懂「他们现在是什么关系、差什么」。35% 处可放一个小误会（她以为他讨厌她） |
| 第一次甜 | 35–55%（21–33s） | 破功或偏爱：他替她挡一下、当众拉她、给她钥匙、把她名字写进文件。**必须有反应镜**：先拍他做了什么，再切她的脸 |
| 反差 / 吐槽 | 55–75%（33–45s） | 喜剧调剂或糖加码：内心 OS 吐槽、第三人撞破、他嘴硬说「顺手」 |
| 确认 | 75–90%（45–54s） | 一句台词或一个动作把「他爱她」钉死，最好带一个可截图的画面 |
| 卡点 | 最后 10–15%（54–60s） | 新威胁、身份差一步揭穿、或一个未完成的动作（门要开没开、话说到一半） |

### 90s（横屏 / 竖屏通用）

| 节拍 | 占比 | 做什么 |
|---|---|---|
| 钩子 | 0–8%（0–7s） | 同上。90s 允许钩子稍缓，但第一镜必须是人在动 |
| 关系 + 阻力 | 8–25%（7–22s） | 阻力可以来自第三方（情敌、家人、公司规定）或来自女主自己（不信他） |
| 小甜 1 | 25–40%（22–36s） | 一次破功，规模小（私下替她解围） |
| 压 / 误会 | 40–60%（36–54s） | 误会升级或第三方出手。甜宠的压不超过 20% 时长，且**压的过程中男主仍要有 1 次小破功** |
| 大甜 | 60–85%（54–76s） | 公开破功：当众认妻、当众牵手、当众拒绝别人。碎镜（0.3–0.8s）+ 反应镜 + 慢动作 |
| 确认 + 余味 | 85–93%（76–84s） | 一句金句 + 一个长镜余味（2–4s，两人同框不说话） |
| 卡点 | 最后 7–15%（84–90s） | 新身份、新威胁、或「她还不知道」的信息差 |

- **90s 实测补充**：双确认卡点（先确认 A 再确认 B，集尾抛 C）；「油门 + 急刹」结构（大甜后立刻收一个冷信息）；懵逼定格 ≥2.5s 当笑点 / 糖点的落地拍；物理错位梗（他弯腰她起身，额头撞在一起）。

### 3–4min（长版模板）

| 节拍 | 占比 | 做什么 |
|---|---|---|
| 钩子 | 0–5%（0–11s） | 同 60s |
| 日常糖 | 5–20% | 2–3 个小破功，建立「他一直在破例」的累积感 |
| 关系推进 | 20–40% | 一次肢体升级（牵手 → 拥抱 → 吻）或一次身份升级（同事 → 同居 → 夫妻） |
| 压 | 40–55% | 误会或第三方出手。长版可以把压放到 15%，但**压的段落里男主每 20s 要有一次「他其实站在她这边」的线索** |
| 大甜 / 公开破功 | 55–80% | 长版的大甜要做成「仪式」：婚礼、发布会、家族大会、颁奖礼。仪式 = 围观者 = 奇观 |
| 确认 + 金句 | 80–90% | 金句 + 黑场收 |
| 卡点 | 最后 5–10% | 三层钩叠加：关系钩（他们成了）+ 身份钩（她的马甲要掉了）+ 威胁钩（有人回来了） |

- **长版爽点密度 35–40s 一个**；三层钩叠加是长版卡点的标准做法；金句落黑场收束。

**节奏规则**：
- 糖 / 破功的间隔：60s 一集 2–3 个，90s 一集 3–4 个，3min 一集 5–7 个。**两个糖之间不超过 25s 没有情绪变化**。
- 前 60% 必须有糖（见定义）。
- 压的时长：60s 版 ≤12%，90s 版 ≤20%，3min 版 ≤15%。
- 一集只主打一种糖（破功 / 偏爱 / 确认），不要三种混着上。

## 钩子库

| # | 打法 | 拍得到的画面写法 |
|---|---|---|
| 1 | **肢体接触直给** | 第一镜：她撞进他怀里，两人距离 ≤10cm，他的手动了半寸又收回去。0.8s 切她的脸，1.2s 切他的喉结 |
| 2 | **物件递出** | 第一镜：一份协议 / 一张黑卡 / 一把钥匙被推到她面前，手指在物件上停 0.5s。第二镜：她的脸。第三镜：他的脸（不看她） |
| 3 | **宣言开场** | 第一句台词：「这婚，我离定了」/「她是我太太」/「我娶你」。宣言必须带一个具体对象，不能是抽象情绪 |
| 4 | **当众破功** | 第一镜：会议桌 / 宴会厅全景，所有人看着她；第二镜：他站起来；第三镜：他走到她身边，做了一个所有人都没想到的动作 |
| 5 | **身份差暴露** | 第一镜：她以为他是普通职员，递给他一份外卖；第二镜：他接过去，身后是整面墙的他的照片 |
| 6 | **修罗场同框** | 第一镜：两个男人同时出现在一个门框里，一左一右；第二镜：她站在中间，手里的东西掉了 |
| 7 | **信物掉落** | 第一镜：一只玉镯 / 一枚戒指从她包里滚出来；第二镜：他弯腰去捡，手指在信物上停 1s；第三镜：他的表情变了 |
| 8 | **失忆者重复旧习惯** | 第一镜：他忘了她，却在咖啡店点了两杯她常喝的；第二镜：她站在门口看着 |
| 9 | **逃婚撞上陌生人** | 第一镜：她穿着婚纱跑进民政局；第二镜：她随手拉住一个男人的袖子；第三镜：男人低头看她，手里还拿着她的玉镯 |
| 10 | **撩汉被反撩** | 第一镜：她盯着他看；第二镜：他把她堵在墙上；第三镜：他的脸离她 5cm，说了一句她没想到的话 |

- 前 3s 必须有人在动或有物件在动；前 15s 必须让观众懂「他们是什么关系」。
- 钩子可以是一个误会（她以为他讨厌她），但误会必须在 35% 前解开或加码。

## 反转、爽点与卡点

**甜宠爽点五环链**：她受压 / 被误解 → 他破功 → 可看见的证据（动作、物件、公开声明）→ 压她的人当场失势 → 关系升级一格。

**爽点机制**：

1. **破功三拍**：他做了一个不符合人设的动作（0.5–1s）→ 她的反应特写（1–1.5s）→ 旁观者的反应特写（0.8–1.2s）。三拍缺一不可，旁观者反应是「奇观感」的来源。
2. **物件代理链**：糖不靠台词，靠物件传递——钥匙、黑卡、族谱上的名字、写进文件的署名、掉落的信物。每个物件特写 1.5–2s，后面必须回收一次。
3. **花钱爽 + 数字锚点**：他为她花的钱要有一个具体数字（「这条街我买下来了」「违约金我出」），数字用字幕或台词钉死。
4. **财富奇观重复仪式**：同一场仪式（订婚宴、发布会）里，他的财富 / 权力展示重复 2–3 次，每次升一级（先是一辆车，再是一栋楼，最后是一个集团）。
5. **为她改规则**：他破的不是自己的例，是「规矩」——族规、公司规定、家族传统。改规则比破例更甜，因为规则代表他背后的整个系统。
6. **公开围观 / 屏中屏**：破功发生在有屏幕的场合（直播、新闻发布会、家族大会的投影），屏幕里的画面 = 二次见证。
7. **复仇命令句**：他替她出气时只用一句命令（「让她滚」「查到底」），不解释、不辩论。命令句 ≤8 字。
8. **三级递进**：同一集里破功做三次，规模递增（私下 → 半公开 → 全公开）。
9. **反应镜分场景**：大甜之后的反应镜要给三种人——被偏爱的她、压她的人、围观者。三种反应各 0.8–1.5s。
10. **懵逼定格**：喜剧调剂用「她愣住 ≥2.5s」的定格，配内心 OS 或花字。
11. **物理错位梗**：额头相撞、手同时伸向同一个杯子、他弯腰她起身——错位本身是糖。
12. **失忆唤回**：他用一个旧习惯（点两杯豆浆、系她的鞋带）唤回记忆，唤回的瞬间给 2–3s 长镜。
13. **信物认人**：信物（玉佩、戒指、镯子）在关键时刻掉落，他捡起来的那一刻，身份差暴露。
14. **反撩**：她主动撩他，他表面冷，但身体先破功（喉结动、手指收紧、眼神移开）。反撩的爽点在「他装不住了」。

**反转**：
- **身份反转**：她以为他是普通人 / 她以为他讨厌她 / 她以为自己是替身——真相是他早就知道、早就在护她。
- **失忆反转**：集尾揭「失忆是假的」或「失忆是他自己的选择」（为了让她重新爱上他）。
- **信物反转**：信物不是她丢的，是他一直收着的；或者信物是他故意让她捡到的。
- **修罗场反转**：两个男人不是情敌，是兄弟 / 上下级 / 同一个人派来的。
- **团宠反转**：最冷的那个其实最宠（爸爸冷着脸，但门锁是最好的那把）。
- **马甲反转**：她的马甲他早就知道，但他一直装不知道，直到她快暴露。
- **阴谋反转**：压她的人不是情敌，是被收买的；或者情敌本身也是棋子。
- **救援延迟揭面**：他救了她，但揭面延迟 4–5 步（先听到声音 → 看到背影 → 看到手 → 看到脸），每一步 1–1.5s。
- **误导反转**：观众以为他选了 A，其实他选的是 B；或者观众以为她跑了，其实她是去拿证据。
- **身份揭穿句子拆分**：「我是……」停 1s，「……你老公」再停 1s，把一句话拆成两拍。

**卡点**（按常用度排）：
1. **门要开没开 / 话说到一半**：停在动作发生前最后一帧。⚠️ 单独用「门要开没开」偏弱，必须配一个新信息（门后的人是谁、话的后半句是什么）。
2. **两男对视 + 闪白**：修罗场卡点，两个男人同时看向她，闪白切黑。
3. **懵逼定格**：她愣住 ≥2.5s，配一句内心 OS 或花字，切黑。
4. **金句 + 静场 0.8s + 切黑**：一句金句落地，静 0.8s，黑场。
5. **喜剧按钮 ≤2.5s**：大甜之后加一个 2.5s 以内的喜剧尾巴（他嘴硬说「顺手」、她内心 OS 吐槽），然后切黑。
6. **多选题**：集尾抛「选谁」，把选择权交给评论区（修罗场专用）。
7. **身份差一步揭穿**：她的马甲快掉了 / 他的身份快暴露了，停在揭穿前 1s。
8. **新威胁带具体信息闯入**：一个电话、一条短信、一个突然出现的人，带一个具体数字或名字。
9. **信物掉落**：信物从包里滚出来，他弯腰去捡，切黑。
10. **失忆者说出一句不该知道的话**：他忘了她，却说出只有他们两个人知道的事。

- 卡点前不要把本集收益结清；卡点切在最后 4–12 秒。
- **闭环式结尾**（本集所有悬念都解开）收藏率显著低于硬卡点。

## 人设与台词

**人设组合**：

| 组合 | 怎么用 |
|---|---|
| 冷面男主 + 嘴硬 / 吐槽女主 | 最标准组合。男主台词短、命令句多；女主内心 OS 长、吐槽多。破功 = 男主说了一句超过 8 个字的话 |
| 冷面男主 + 怂 / 懵懂女主 | 女主越怂，男主破功越明显。女主的反应镜是糖的放大器 |
| 闷骚男主 + 主动女主 | 女主撩，男主装。破功 = 男主身体先动（喉结、手指、眼神） |
| 团宠女主 + 全员护短 | 每个家庭成员给一个固定反应（大哥拎包、二哥递水、三哥挡人），最冷的那个最后揭底 |
| 修罗场女主 + 2–3 男 | 每个男主给一个固定标签（身份、颜色、台词风格），女主全程被动，集尾抛多选题 |
| 失忆男主 + 等待女主 | 男主用旧习惯唤回记忆，女主用信物确认。张力来自「他记得习惯，不记得人」 |
| 隐身份女主 + 知情男主 | 男主什么都知道但装不知道，直到她快暴露。张力来自「观众知道他知道，她不知道」 |
| 契约夫妻 + 假戏真做 | 契约是阻力，真做是糖。破功 = 他做了一件契约外的事 |

- **发色 / 服装锚点**：每个角色锁一个固定发色或服装色，跨镜不换。
- **道具对手戏**：信物、钥匙、黑卡、族谱——道具是第三个角色，每次出现都要给特写。
- 主要角色第一次出场配人名条（竖排或横排，名字 + 身份）。

**台词技巧**：
- **命令句 ≤8 字**：「过来」「别动」「我娶你」「让她滚」。命令句是男主的标准语言，越长越不像他。
- **嘴硬句式**：「顺手」「刚好路过」「别多想」。嘴硬 = 破功的遮羞布，观众都懂。
- **内心 OS 吐槽**：女主的 OS 是喜剧调剂，也是观众替身。OS 要短、要毒、要和画面反差（他深情看她，OS 是「这眼神是哪部剧学的」）。
- **身份揭穿句子拆分**：把一句话拆成两拍，中间停 1s。
- **对仗式告白**：「你护我三年，我护你余生」。对仗 ≤12 字。
- **重复句式**：同一句话在不同场景说两次，第二次意义翻转（第一次是命令，第二次是告白）。
- **第三人称转述**：让旁观者替男主说出他不好意思说的话（「他为了你，把整个集团都押上了」）。
- **数字钉死**：花钱、时间、次数都要有具体数字（「三年」「这条街」「违约金我出」）。
- **花字命名化**：用官方花字给 CP 命名（「这对锁了」「天生一对」），喂给评论区二创。花字 ≤6 字，放在两人同框画面上。
- **敏感词规避**：亲密戏的台词用暗示不用直给（「回房间」「关灯」），画面停在动作发生前。

**金句公式**：
- 「不是 X，是 Y」：「不是顺手，是我一直在等你。」
- 「你 X，我 Y」：「你护我三年，我护你余生。」
- 「我 X，你 Y」：「我娶你，你愿不愿意。」
- 「X 不如 Y」：「全世界不如你。」
- 金句 ≤12 字，放在大甜之后或卡点之前，配黑场或静场。

## 视听风格

**景别分布**：
- 近景 / 特写 50–70%：脸、手、物件、喉结、眼神。
- 中景 20–35%：双人同框、对话、仪式。
- 全景 10–20%：仪式场合、修罗场同框、围观者反应。
- 插入特写 8–12%：信物、钥匙、黑卡、文件、屏幕。

**构图与权力**：
- **框中框**：门框、窗框、车窗框住两人，暗示「他们在一个世界里」。
- **屏中屏**：直播画面、投影画面、手机画面里的两人 = 二次见证。
- **上下分屏**：竖屏里上方是他的脸、下方是她的脸，或上方是仪式全景、下方是两人的手。
- **对角贴脸**：亲密戏用对角线构图，两脸占对角，距离 ≤10cm。
- **三人三色**：修罗场里三个角色各锁一个主色（男主深蓝、情敌酒红、女主米白），同框时颜色就是阵营。
- **服装即阶级**：女主从朴素到华丽的换装 = 地位升级；男主永远一套（西装 / 长衫），不变 = 稳定。
- **围观者半圆**：仪式场合用半圆围合构图，两人在圆心，围观者在弧线上。

**光色**：
- **冷色 = 算计层**：情敌、恶亲、阴谋用冷蓝 / 冷灰；男主对女主时用暖金。
- **暖金 = 糖**：大甜段落用暖金逆光或侧光，光晕打在两人之间。
- **三段光**：压的段落冷、糖的段落暖、卡点回到中性。
- 室内甜宠用高调平光 + 暖色点缀；仪式用逆光 + 光晕；修罗场用冷光 + 硬阴影。

**美术**：
- **道具进度条**：信物、钥匙、黑卡、族谱——每个道具出现一次，关系就升一级。道具特写 1.5–2s，后面回收。
- **仪式 = 奇观**：订婚宴、婚礼、发布会、家族大会——仪式的排场（花、灯、屏幕、围观者）就是偏爱的规模。
- 现代甜宠：写字楼、豪宅、民政局、咖啡店、车内。
- 古装甜宠：宫殿、府邸、庙会、书房、马车。

**运镜**：
- 固定机位 + 缓推为主。
- **一集只留一个强运镜**：环绕（仪式）、升格（大甜）、急推（破功瞬间）。
- **长镜给时间跳跃道具**：信物掉落、钥匙递出、文件翻开——这些动作用 3–5s 长镜，让观众看清。
- 亲密戏用缓推 + 浅景深，背景虚化，只留两人的脸。

**横屏怎么做**：
- 仪式用宽画幅交代排场；对话用过肩正反打；修罗场用三分法，两男一女各占三分之一。
- 横屏投竖屏平台时，上下黑边放剧名和集数字卡。

**竖屏怎么做**：
- 单人居中，人脸占画面一半以上；双人用对角贴脸或前后错位。
- 字幕放画面中部偏下；关键道具放画面中部，不被字幕盖住。
- 顶部常驻剧名条，底部常驻「内容由 AI 生成，纯属虚构」。

## 剪辑节奏基准

| 指标 | 基准 |
|---|---|
| 平均镜长 | 1.45–3.2s，均值约 2.3s，中位约 2.1s |
| 前 3s / 前 15s 镜数 | 1–3 / 5–10 |
| 台词密度 | 2.5–4.0 字/s；内心 OS 段可到 4.5 字/s |
| 长镜（>6s）承载物 | 仪式全景、失忆唤回、信物掉落、大甜余味、懵逼定格（≥2.5s） |
| 碎镜段 | 大甜 / 破功瞬间 3–6 镜、每镜 0.3–0.8s |

**规则**：
- **镜长下限 1.45s**：低于 1.45s 的碎镜只给大甜瞬间，其他段落保持 1.5–3s。
- **长镜张力判据**：>10s 的长镜必须有张力（仪式、唤回、余味），否则拆。
- **油门 + 急刹**：大甜后立刻收一个冷信息（卡点），不要给余味拖太久。
- **反应镜分场景**：大甜之后给三种反应（她、压她的人、围观者），各 0.8–1.5s。
- **BGM 段规则**：纯 BGM 无台词段 ≤30s；超过 30s 必须配旁白或 OS。
- **三段速度**：日常糖 2–2.5s/镜、压 2.5–3s/镜、大甜 1.5–2s/镜 + 碎镜爆点。
- 静场：金句落地后静 0.8s 再切黑；大甜余味 2–4s 长镜（两人同框不说话）。

## 审核参数

```json
"project": { "genre": "short-drama", "asl": [1.5, 2.4], "hook": 5 }
```

碎镜爆点段允许下探到 1.45；仪式 / 唤回长镜标 `tempo: 停留` 并写 `pace_note`（「仪式全景」「失忆唤回」）。

## AI 制作要点

| 翻车点 | 规避法 |
|---|---|
| 文字叠加崩坏 | 字幕、花字、人名条、屏幕文字全部后期贴；AI 生成时屏幕 / 文件留白 |
| 服装漂移 | 每个角色锁一套服装 + 一个发色 / 发型，写进 `refs`；全集不换装，换装必须有剧情理由 |
| 口型对不上 | 亲密戏台词用暗示不用直给，画面停在动作发生前；长台词给背影 / 过肩 / 侧脸；内心 OS 免口型 |
| 手部特写畸变 | 手部只给静态抓握（握钥匙、递信物、扣扣子）；精细动作（系鞋带、翻文件）用近景 + 慢速，≤2.5s |
| 多人场景穿模 | 仪式 / 修罗场用半圆围合构图，人物间距 ≥30cm；不拍肢体接触过程，只拍结果（牵手后的手、拥抱后的背影） |
| 脸部漂移 / 撞脸 | 主角脸做去明星化检查；每个角色一个固定特征（痣、疤、发色）；参考脸贯穿全片 |
| 亲密戏过审 | 画面停在动作发生前（吻戏停在距离 1cm）；台词用暗示；用物件代理（手、喉结、眼神）代替直接画面 |

## 大导演工具箱

| 导演 | 手法 | 在本片种里怎么用 | 镜头写法 |
|---|---|---|---|
| 希区柯克 | 观众先知：让观众比角色先知道，悬念从「会不会」变成「什么时候」 | 马甲文 / 隐身份的标准引擎：观众知道他的身份，她不知道；观众知道信物是他的，她以为是巧合。每次她差点发现，观众就爽一次 | ①信物掉落：他弯腰去捡，手指在信物上停 1s，观众看到他的表情变了，她没看到。②身份差一步揭穿：她翻开文件，镜头给文件特写但只露一半，观众看到全名，她只看到姓 |
| 冯小刚 | 市井贫嘴 + 反差萌：笑点全在词不在脸；冷面人设用一句贫嘴破功 | 男主嘴硬时用一句市井话破功（「顺手买的，正好路过你公司楼下那家店，排队排了半小时」）；女主内心 OS 用贫嘴吐槽 | ①男主命令句后接一句解释过度的贫嘴，暴露他其实很在意。②女主 OS 吐槽男主的深情台词「这台词是哪部剧学的」，配男主一脸认真的正脸 |
| 斯皮尔伯格 | 先看反应再看奇观：奇观的威力来自围观者的脸 | 仪式 / 公开破功的标准做法：先拍围观者的反应（震惊、羡慕、嫉妒），再拍奇观本身（他牵起她的手）。修罗场同理：先拍两个男人的脸，再拍她 | ①大甜之前给 2–3 个围观者反应镜（各 0.8–1.2s），再切破功动作。②信物掉落时先拍他的手指，再拍信物，再拍她的脸 |
| 王家卫 | 物件承载情绪 + 时间感：一个物件反复出现，每次意义不同；用长镜和静场制造「时间停了」的感觉 | 信物 / 道具进度条的做法：同一把钥匙出现三次，第一次是命令，第二次是习惯，第三次是告白。失忆唤回用长镜 + 旧习惯，时间感 = 糖的浓度 | ①信物第一次出现给 2s 特写，第二次给 1.5s，第三次给 3s + 静场。②失忆唤回：他用旧习惯（点两杯豆浆）的长镜 4–5s，她的反应镜 2–3s，中间不切 |

## 禁忌

- 前 60% 没有糖。
- 压的段落里男主没有任何「他站在她这边」的线索。
- 破功没有反应镜（先拍他做了什么，再切她的脸，再切旁观者）。
- 糖靠台词不靠动作 / 物件。
- 一集里三种糖混着上（破功 + 偏爱 + 确认），没有主打。
- 修罗场里两个男人没有固定标签（身份、颜色、台词风格），观众分不清。
- 团宠里最冷的那个没有揭底。
- 失忆唤回没有旧习惯做锚点。
- 信物掉落没有前置预埋（第一次出现就要给特写）。
- 卡点用「门要开没开」单独撑，没有新信息。
- 亲密戏画面过审失败（吻戏拍实、台词直给）。
- 金句超过 12 字，或放在大甜之前。
- 花字命名 CP 超过 6 字，或放在单人画面上。
- 道具特写后面没有回收。
- 仪式没有围观者（奇观感 = 围观者的脸）。
