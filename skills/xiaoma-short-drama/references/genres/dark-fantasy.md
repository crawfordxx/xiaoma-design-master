# 奇幻西幻

> v0.3。例子和 logline 都是自拟的。

## 定义与情绪承诺

**定义**：主角或对手是非人（血族、妖、精怪、神明、龙角亚人、巨兽、兽人），或者主角进入一个有完整体系的异世界（魔法、种族、魔导器、末日规则）。故事靠一条世界规则推动（吸血、契约、许愿、功德、魔导、科技代差、灾难生态），美术用欧式哥特、宫廷、异世界城镇、东方神话奇观或末日废土。

这个片种实际覆盖三块题材：**西幻**（血族、魔法、宫廷）、**东方志怪寓言**（神兽、成神）、**末日怪兽**（灾难奇观）。归卡判定看「非人 + 世界规则」，不看题材产地。

**七种情绪承诺**，开场 5 秒内必须让观众知道这一集给的是哪一种：

| 承诺 | 观众要的感觉 | 一句话检验 |
|---|---|---|
| 危险的偏爱 | 被一个能杀死你的存在独宠，禁忌、性感、卑微 | 结尾有没有一个「我把命交给你」的动作 |
| 东方降维 | 西方权威全线溃败后，东方术士一出手就赢，带民族自豪和反差喜感 | 东方角色出手前，西方是不是已经先输光了 |
| 非人的善意 | 一个被嫌弃的非人笨拙地对人好，最后被人接纳，泪点加金句 | 结尾能不能把主题说成一句问答 |
| 代入异世界 | 我也想去那里生活一天：逛街、买东西、做饭，轻松、羡慕 | 观众会不会在评论里说「我也想去」 |
| 反差萌喜剧 | 非人干人类的活（当护工、当公务员、被喂草莓戒断），越认真越好笑 | 非人身份和职业能不能用一句「我是 X，却在做 Y」说完 |
| 院线奇观代入 | 「省下电影票」：末日、巨兽、大场面，看完想转给别人 | 评论有没有「可以上映」「特效太逼真」；转发/点赞能不能到 0.3 以上 |
| 愤怒与解读欲 | 先给「妖怪害人」的志怪期待，翻成「人比妖可怕」的心痛，看完想解读想转发 | 结尾会不会逼观众站队；评论区有没有长文解读 |

| 相邻片种 | 它卖什么 | 奇幻西幻卖什么 | 判别动作 |
|---|---|---|---|
| 古风志怪 | 本土民俗的怪物，「禁忌 + 报应」推动 | 有身份体系的非人（血族贵族、妖界衙门、修行的狐妖、神兽阵营），重点是非人的身份和关系 | 去掉禁忌故事还成立，归本卡；不成立，归志怪卡。东方神怪当主角的社会寓言、神兽阵营大战都归本卡；纯因果报应解说剧归志怪卡 |
| 悬疑惊悚 | 恐惧和未知 | 非人第一镜就露脸、就是主角，卖欲望、奇观和善意 | 恐惧只是调料 |
| 甜宠霸总 | 权力的独宠 | 「权力」换成「獠牙 / 法力 / 寿命」，示爱的代价可以是命 | 甜里要带一点疼 |
| 穿越重生 | 主角的复仇或改命线 | 那个世界本身（城镇、魔导器、种族） | 异世界 POV 和科技流归本卡 |
| 科幻 | 技术推演 | 末日怪兽带科幻外壳，但观众来看的是巨兽奇观和生存规则 | 归本卡 |

## 子类型

### 1. 血族禁恋 / 哥特修罗场（主力）
- **卖点公式**：天敌身份（猎人 × 血族、吸血鬼 × 神父）或种族差异 + 已有婚约 / 契约 + 第三者的咬痕 → 结尾一方献出脖子。
- **logline**：嫁给猎魔骑士三年的血族公主，每晚瞒着他去地窖喝老侍从的血。骑士在侍从锁骨上认出她的齿痕那天，解开了自己的领口。
- **玩法**：同一个故事拍丈夫视角、妻子视角两集，分开发布，观众会自己拼图。
- **变体 A：双心声误判喜剧**：双方都误判对方身份，外台词狠 + 内心独白怂双轨并行。logline：牙口不好、只能咬哥哥脖子磨牙的混血吸血鬼少女被喂草莓「戒断」，盯上转学来的眼罩特困生——壁咚咬下去才发现咬不动，而他的心声是「这个笨蛋人类，好甜的味道」。
- **变体 B：双生修罗场**：双生哥哥 × 第三种族仆从，女主反手收服狼人拿回掌控感。logline：生在吸血鬼家族却长不出尖牙的「废柴」妹妹，在森林里用一滴血和狼人结下主仆契约，回家时被两个已经失控的双生哥哥堵在落日窗前。

### 2. 东方术士西行 / 东西对冲
- **卖点公式**：西方权威先全军覆没，把怪物垫高 → 东方术士以反差人设登场（躺平、市井、方言）→ 只给一次出手，就截断。
- **logline**：在城中村修了五年电动车的道门末代掌门接到一通越洋电话：海外驱魔会的七位长老昨夜被同一个恶魔吃掉了，对方只问他一句，「你会说意大利语吗？」
- **变体：欢喜冤家**——道士少女 × 血族少主，先斗法，后牵手逃跑。

### 3. 西幻宫廷甜宠
- **卖点公式**：非人贵公子 + 人类女孩 + 助攻兄弟。「替别人准备的礼物」误导 → 揭开其实是给她的 → 满屏用她名字拼成的花或烟花。
- **logline**：狼人家族的长子说要给妹妹挑生日礼服，请人类女孩替妹妹试穿了一整晚。她走出试衣间，看到花园里十万朵玫瑰拼出的是她自己的名字。

### 4. 非人成神寓言
- **卖点公式**：他人错认身份（把妖当神）→ 主角有一处身体缺陷（少一条尾巴）→ 用天生本事而不是法术帮人，请求一次比一次小 → 灾难来临，违抗天命护人，暴露原形 → 人选择接纳，缺陷以升级形态长回来 → 一句问答式金句当片名。
- **logline**：深山破庙里偷吃供品的穿山甲精被放牛娃喊成了「土地爷」。它不会法术，只会打洞，替村里找水、找丢失的耕牛、找埋了三十年的界碑；山洪那夜它用爪子挖开泄洪道，露出了一身鳞甲。
- 成败差在开场：前 3 秒就有错认台词的爆，30 秒空镜开场的没人看。

### 5. 志怪社会寓言
- **卖点公式**：说书人三句排比立「妖害人」的世界观答案表（每句配一个 1.5–3s 奇观插画，结尾每句对应一个现实角色）→ 无辜者被偏见围猎 → 公堂 / 舆论逐级加码（怀疑 → 狂欢）→ 谎言用风格化戏中戏呈现（皮影 / 剪影）→ 结尾翻成「人比妖可怕」，由一个孩子或弱小者说出唯一真话 → 单集闭环不卡点，卖愤怒和解读。
- **logline**：茶楼说书人说「越美的女子越要防，她们多是妖」。卖艺的哑女被四个「解围」的书生请上楼后暴毙，公堂上满城人都信了她是妖——只有一个孩子说，那分明是个姐姐。
- 关键差异：不卡点、不走爽点，走「虐 + 愤怒」；受害者无台词，辩护交给弱小者。

### 6. 末日怪兽灾难
- **卖点公式**：前 15s 两名配角的机密对话把「危机已存在」告诉观众 → 立即切毫不知情的普通人日常（桌下炸弹）→ 灾难奇观每 60–90s 升级一波，每波后接人物反应镜 → 怪兽四级显形（局部 → 剪影 → 掠影 → 全身）→ 集末全身亮相做卡点。
- **logline**：官方秘密收容的怪兽一直没被公开，直到一枚核爆和随之而来的沙暴吞没城市——送外卖的女骑手和一个白领躲进地下车库，墙缝里有一只眼睛正在看着他们。
- 主角选外卖员、白领这类观众日常接触的职业，职业制服做一致性锚点，职业技能被观众自己脑补成求生技能。

### 7. 拟人夺宝 / 兽人酒馆
- **卖点公式**：质感长镜立非人世界（第一帧就证明「这不是一般的 AI 片」）→ 第一人称旁白三句交代夺宝前提（我是谁 / 这是哪 / 要拿走什么）→ 同伙一句台词预告混乱 = 掩护（观众优势）→ 反派踹门、文戏交锋藏刀 → 大乱斗做掩护 → 主角第三方偷走目标 → 追杀线成立当卡点。
- **logline**：误入兽人国度的人类少女披着白狼皮混进黑市酒馆，算准夜爪会二当家来砸场的混乱时刻，从蛇老板眼皮底下偷走了神秘的「相骨」。
- 物种区分角色（蛇、猫、猩猩），武侠称谓套在兽人身上做混搭辨识度。

### 8. 元素魔法动作 / 越狱
- **卖点公式**：高潮战 15–25s 截段做闪前冷开场 → 一个大全景说清「为什么逃不掉」（跳下去 = 被深渊巨喉吃掉）→ 目标道具给全片唯一暖色 → 计划执行 → 正片原样回收闪前 + 能力升级反转（不止控水还能冻）→ 卡点。
- **logline**：被关在云端浮空监狱的水系女贼和她的前狱卒室友，为了跳下高塔不被海底巨兽吞掉，要从女典狱长手里骗到一瓶「龙息」。
- 风险：能力「最优解」没在中段演一次，会被评论区群嘲（控水为何不罩头、不抽干血液）。

### 9. 非人打工反差喜剧
- **卖点公式**：「我是 + 非人身份 + 荒诞职业」一句自白 → 非人能力在职场里错位使用（吸血吸通了血栓、妖怪考科举）→ 金钱或编制的数字梗 → 集尾来一个打破日常的人。
- **logline**：为了每晚能合法喝血，交不起房租的血族少女去血站应聘夜班采血员。入职第三天，她发现来献血的一位老人，血的味道和两百年前咬过她的那个猎人一模一样。
- **变体：妖怪群像职场**——一群落榜、被贬的妖怪当衙役，靠物种区分角色（牛、马、龟、鹤），方言做笑点。

### 10. 异世界 POV 生活流
- **卖点公式**：第一人称 POV，主角不露脸、不说话 → 一个嘴硬的非人同伴对着镜头说话 → 逛街、交易、做饭，每次交易让路人惊叹 → 开头的抱怨在吃饭时和解 → 最后一拍是第一个客人上门。
- **logline**：带着一台能充电的老式收音机穿到魔法王国的你，被兔耳学徒拖去王都赶集。你在魔导器店里打开收音机，老板娘听到里面有人在唱歌，当场跪下问你是哪位大贤者。

### 11. 穿越科技流（评价两极）
- **卖点公式**：本集先展示上集造的东西 → 主角自己指出缺陷 → 本土材料或配角种族给出解法 → 画下一件东西的图纸，集尾卡在还没试。
- **logline**：穿到精灵森林的化学老师用树脂做出了第一块肥皂。精灵长老说他们洗澡从来不用东西，第二天整个森林的精灵排着队来买。
- 风险：硬核观众会挑「为什么魔法替代不了」，同质化也容易被点名。

## 单集结构模板

位置基准：
- **第一转折分两档**：恋爱 / 喜剧向 **≤30s** 最稳；**院线奇观向可放宽到 40s 甚至更晚**，前提是前 15s 已放好信息差钩（机密对话说出「怪兽」、计划预告、闪前即钩、闪切刺点）。
- **中点**新人物、新威胁或新解法落在 **41–58%**。
- **兑现**（咬、吻、出手、牺牲、闪前回收）落在 **74–94%**；奇观向的兑现是「每 60–90s 一波」的连续小兑现 + 集末大兑现。
- **结尾**：系列集停在未解局面上；单集完结寓言 / 社会寓言收在金句或真话落点，不卡点。
- **主角能力的第一次兑现不晚于全片 60%**；主角晚于 40% 才登场一定被嫌慢。
- **片名卡可以晚**，但片名前必须有钩子；片名晚 + 开头无钩 = 流失。

### 60s（恋爱喜剧向）

| 节拍 | 占比 | 做什么 |
|---|---|---|
| 反常设定自白钩 | 0–5%（0–3s） | 第一句心声 / 旁白 =「强大种族 + 可笑缺陷」（「我发育不良，每天要咬……磨牙」），3s 内配缺陷画面 |
| 关系突变 | 5–14% | 亲密 → 被推开 / 第三者出现，3–4 镜完成，可加一镜门缝偷看 |
| 压迫与贬低 | 14–30% | 高傲方一句贬低台词（「劣质基因」），委屈攒满 |
| 降格喜剧点 | 30–42% | 日常道具降格超自然需求（吸血鬼被喂草莓戒断），全片笑点位 |
| 新人物 + 主动出击 | 42–60% | 男主 / 女主入场，主角壁咚式出击，兑现镜（咬下去——咬不动） |
| **反转 1** | 60–68% | 对方心声暴露误判或非人身份；1–2 镜，单镜 ≥3s（全片最慢处） |
| 冲突升级 | 68–77% | 第三者撞见，三角成形 |
| **反转 2** | 77–89% | 真身份揭晓：唯一大全景（教堂 / 王座）+ 后期小字点身份 |
| **卡点** | 89–100% | 拥抱贴颈 / 獠牙抵颈定格黑场，最后一镜带剧名集数卡 |

### 90s

| 节拍 | 占比 | 做什么 |
|---|---|---|
| 前提钩子 | 0–5%（0–5s） | 第一人称身份旁白或对镜一句话，加异象或世界全景。前 3 秒 1–3 镜就够 |
| 世界与证据 | 5–15% | 规则用道具和环境说：满月、哥特尖窗、空酒杯里残留的血；修罗场向用三句旁白（身份 + 缺陷 + 危险关系）各配一张不同景别画面 |
| **第一转折** | 15–20%（约 15–20s） | 第三者、欲望压力，或一次交易；恋爱向第一个小苏点也可放这里 |
| 欲望铺陈 | 20–50% | 主角瞒着谁、想要什么；每 10–15 秒一次局面变化；恋爱向每 25–35s 给一个小兑现（含指、喂血） |
| 中点 | 50–60% | 第三者以名牌字卡登场，身份暴露，或现代物品在异世界被当成神器 |
| 张力升级 | 60–80% | 调情、对峙，平均镜长降到 1.3–1.5s |
| **爽点 / 兑现** | 80–92% | 咬、吻或开吃。单镜拉长到 3s 以上；反转心声段是全片仅有的慢镜 |
| **揭示 + 卡点** | 92–100% | 偷看的人露出眼睛、契约反转、第一个客人开口。卡点至少留 3s，太短会没落地；修罗场向卡在三角未解 + 契约字幕 |

### 3min（150–300s）分三条轨

**轨 A：系列集**

| 节拍 | 占比 | 做什么 |
|---|---|---|
| 钩子 | 0–5% | 反差人设的日常（最强驱魔师吃泡面），或两个旁观者带数字的赌约（「第十九个了」「我猜撑不过一个月」） |
| 世界观压缩 | 5–15% | 一镜画卷平移加说书旁白，**不超过 30s**，中间插 1–2 镜角色吐槽 |
| 人设与任务 | 15–20% | 一句自报加一张派单（越洋订单、新县令上任） |
| 威胁垫高 / 误导 / 传闻 | 20–50% | 东西对冲：西方权威出手并付出可见代价。宫廷甜宠：「这是给妹妹的」误导。打工喜剧：配角八卦主角的传闻 |
| 中点 | 45–55% | 委员会宣布无解，或主角按「脚 → 道具 → 旁人反应 → 全貌」延迟亮相 |
| 到场 / 揭穿 / 验证 | 55–80% | 主角入场先给手部、符箓、背影，最后给脸；或传闻被验证 |
| **爽点** | 80–90% | 大招劈下、满园玫瑰，或温情落点 |
| **卡点** | 90–100% | 大招刚劈下胜负未分；或新角色雨夜门口单人近景配身份字幕。之后可接 10–25s「片场花絮」彩蛋 |

**轨 B：单集完结寓言**（光明版 / 黑暗版同一骨架）

| 节拍 | 占比 | 做什么 |
|---|---|---|
| 错认 / 排比钩子 | 0–5% | 他人一句称呼（「山神娘娘」）反打真相；或说书人三句排比配三个奇观插画（「蛇惑人 / 魅食人 / 狐媚人」） |
| 缺陷与处境 | 5–12% | 自白三短句：身份、缺陷、处境 |
| 反衬 | 12–19% | 同类世界 / 偏见环境的冷酷，给主角「留下来」或被围猎的动机 |
| **第一次善举 / 陷阱启动** | 19–26% | 光明版：用天生本事解决一件事。黑暗版：假救赎出场（「英雄救美」实为陷阱） |
| 日常积累 / 压迫递进 | 26–46% | 光明版：请求蒙太奇逐级变小（救命 → 找羊 → 找一只鞋）。黑暗版：权力 → 偏见 → 舆论逐级加码，群众台词四句完成「怀疑 → 狂欢」 |
| 转折 | 46–50% | 一句「可是——」，灾难 / 惨案来临 |
| 对抗 / 公堂 | 50–61% | 巨物占画面上 2/3 主角缩下方；或审判者竟是施害者（黑暗版反转①） |
| **高潮** | 61–76% | 光明版：法术粒子快切，代价可见。黑暗版：谎言用风格化戏中戏呈现（金色皮影伪证），观众一眼识别真假 |
| **黑场 / 隐喻悬置** | 76–85% | 3–5s 黑场加身份字幕；或一个可视化隐喻镜头说主题（众人被藤蔓蒙眼，只有弟弟睁眼），不让角色念主题 |
| 反转兑现 | 85–92% | 人群的选择（列队、跪拜），缺陷以升级形态回收；或黑暗版「在众人眼里她『真的』成了妖」的定性一刻 |
| 首尾呼应 + 落点 | 92–100% | 问答金句即片名；或弱小者说出唯一真话（「那分明是个姐姐」）。**落点台词不得晚于 4:30**，再晚部分观众到不了 |

**轨 C：院线长集（5–14 分钟）**

| 节拍 | 占比 | 做什么 |
|---|---|---|
| 冷开场 | 0–8% | 三选一：闪前高潮截段 15–25s（正片 86% 处原样回收）；机密对话信息差（前 13s 说出「怪兽」再切日常）；质感奇观长镜（20s 内必须给闪切刺点或笑点） |
| 世界观与困境规则 | 8–25% | 一个大全景说清「为什么逃不掉 / 不能跳」（深渊巨喉吞人一镜讲完规则）；色调分段立空间 |
| 目标与计划 | 25–40% | 目标道具给全片唯一暖色并进前景虚焦特写（橙色药瓶）；计划预告给观众优势（「到时候这里肯定乱作一团」） |
| 升级波 | 40–75% | 奇观每 60–90s 一波，每波后接人物反应镜；对话块 ≤30s；中点放设问字幕卡点（「还有谁能压制它」） |
| 高潮最长镜 | 60–75% | 20–38s 奇观长镜（神兽大战），镜内必须有连续画面事件 |
| 兑现 + 反转 | 80–90% | 闪前原样回收 + 能力升级（冰封头）；或真相定性（草席下的白狐尸体） |
| **卡点** | 90–100% | 怪兽全身亮相 / 追杀线成立 / 设问台词，最后一镜带剧名集数卡 |

- **转折间隔**：旁白蒙太奇型中位约 13s；对白情景型 30–45s，靠美术奇观撑，镜头里要一直有人在说话或走动；只有画面没有事件的，低表现。院线双峰型按「60–90s 一个呼吸循环」排（长镜奇观段 + 快切簇）。

## 钩子库

前 3 秒 1–3 镜；院线向常见 1 镜长镜开场，恋爱向仍 1–3 镜。**前 3 秒有一句人声（台词 / 旁白 / 心声）的明显更好**；纯质感开场是例外（见 H13）。

| # | 打法 | 拍得到的写法 |
|---|---|---|
| H1 | 身份对立 / 反差职业 / 强大种族 + 可笑缺陷自白 | 0–1.5s 她唇间一滴血的特写，旁白「我的妻子是吸血鬼」；1.5–3s 他拇指弹开银色打火机，「但我是猎人」。反差缺陷版：哥特少女立在露台，心声「我发育不良，每天都要咬……磨牙」，同秒配獠牙 / 咬颈画面 |
| H2 | 他人错认 + 反打真相 | 0–2.4s 小女孩正面中景瞪大眼「山神娘娘」；2.4–4s 反打：破庙台阶上白发少女捧着馒头在啃 |
| H3 | 旁观者数字赌约 | 衙门口一对石狮子固定机位，「第十九个了」「上一个待了多久」「三个月」「这个我猜一个月」 |
| H4 | POV 第二人称召唤 | 第一人称镜头，长角女仆回头对镜头「我们到了老板」，远山上是城堡；镜头不切 |
| H5 | 结果先行 + 反应镜 | 第一帧 0.5s 就是枪口白烟，下一镜 1s 叼烟斗的矮人瞪眼 |
| H6 | 危险进行时 | 雨夜小巷，獠牙已经扎进路人颈侧（0.3s 一镜），下一镜红色玛丽珍鞋踩进水洼 |
| H7 | 亲密开场 + 被撞见 | 第一镜就是壁炉前的吻；第 20 秒她捂嘴回头，门口站着一个人 |
| H8 | 反差人设喜剧 | 「地表最强驱魔师」穿睡裤吃泡面，被徒弟吓得打翻碗 |
| H9 | 威胁台词先行 | 派对天台，金发女孩笑着说「像你这样的，会死得很快」 |
| H10 | 血月剪影（第二钩子位） | 第 10–16 秒，巨大血月中张开斗篷的剪影，停 5s |
| H11 | 机密对话信息差 | 0–13s 俯瞰军事基地，两名配角低声说「上头为什么不把这些家伙公开」「舆情不安比怪兽还大」——观众拿到炸弹，立刻切毫不知情的外卖骑手穿城日常 |
| H12 | 闪前高潮截段 | 把正片 80% 处的高潮战剪 15–25s 放开头：水流翻卷的金发女贼一句「没用的」，水柱冲开重甲骑士；正片里原样回收，留存线拉到片尾 |
| H13 | 质感奇观长镜（高风险） | 第一帧就是写实毛发兽人酒馆 + 体积光，一镜 10–12s 不切，靠「这画面是 AI 做的？」留人。**仅在质感达到院线级时用**，且 20s 内必须给节奏刺点（闪切、冷笑话） |
| H14 | 说书排比答案表 | 说书人高台大全景 + 旁白「山海有妖」，三句排比各配一个 1.5–3s 奇观插画，15s 内出片名；每句在结尾对应到一个现实角色 |

- **慎用**：只靠画风氛围、没有人声也没有事件的开场。质感长镜能成立是因为质感极端 + 20s 内有刺点，不要默认复制。
- 自报身份可以用，但只限**种族 / 天敌 / 反差职业 / 可笑缺陷这种前提身份**，并且同一秒要配一个视觉证据（獠牙、圣器、供品、草莓）。

## 反转、爽点与卡点

- **观众优势是本片种第一手法**：让观众比角色先知道。五种信息差各有写法——
  1. 危机信息差：观众知道有怪兽，城里人不知道，日常每一秒都带不安
  2. 计划信息差：同伙预告「会乱作一团」，打斗戏同时承担「爽」和「等她出手」双重悬念
  3. 心声信息差：双方互给心声，两个角色都误判对方，悬念变喜剧
  4. 道具信息差：目标物放前景虚焦，观众知道在哪、角色还没拿到——**之后每个关键段落都要再给道具特写，断线就断悬念**
  5. 违约信息差：观众已知她私吞，惩罚拖了半集，中间的渴望、失踪、设陷阱全是悬念利息
- **怪物 / 反派延迟显形四级**：局部（墙缝里一只眼）→ 剪影（沙暴中轮廓）→ 掠影（掠空飞影）→ 全身，全身亮相放集末卡点。反派进屋版：逆光门框剪影 + 屋内飘尘 + 一拍静场，先轮廓后正脸。已露面的威胁复现只用阴影 / 水花。悬念镜头后不要马上释放下一级：墙缝之眼后应先切众人屏息 3s 静场再给剪影。
- **恐怖 / 反转揭示三拍**：物件异常（鸡蛋失踪）→ 目击者门内剪影全景 → 怪诞动作特写（蹲地生吃），三镜景别逐级逼近，不摇不甩只靠切。
- **风格化谎言**：伪证、回忆、谣言拍成与正片截然不同的风格（皮影、剪影、黑白），观众一眼分辨真假，顺带绕开 AI 口型和脸部一致性。
- **镜像人物复用仪式场面**：第二个角色走一遍第一个角色的仪式，只改特写表情与动机台词，场景成本减半、道德对照翻倍。
- **反转靠视角，不靠巧合**：同一事件两集互为谜底；同一个存在在两套台词里身份不同（村民喊「河神老爷」，灵宠说「不入流的小妖」）；审判者就是施害者。
- **把怪物垫高，再给东方降维**：先用 2 分钟让西方权威失败，东方主角的一招才有分量。
- **误导—揭穿型甜反转**：「这是给我妹妹的生日礼物」→ 让她试穿 → 花园里拼出她的名字。
- **包袱三段式**：传闻 → 否定 → 验证，间隔 30–60s。规则台词同理：中段说给不信的人听，高潮由对手原句复述。
- **缺陷升级回收**：前 15 秒给主角一个看得见的缺陷（少一条尾巴 / 长不出尖牙），结尾以升级形态回收（功德金尾 / 一滴血立契约）。评论会替你说出来。
- **能力最优解中段必演**：观众能想到的最狠用法（控水罩头、抽干血液），至少在中段演一次，不要等评论区替你想——拖到高潮才给，前半程的评论全在嘲能力逻辑。
- **母题三现功能升级**：选一个实物（血、水、鸡蛋、木匣）在开头、中段、结尾各出现一次，每次功能不同（血：诱惑 → 交易 → 契约；水：指尖水滴 → 水鞭 → 冰块 → 水晶球）。
- **爽点五环在本片种的写法**：欲望被压（饿 / 拒饮）→ 主动献出（解开衣领）→ 可见证据（颈侧两个血点）→ 第三者的代价（门口的人攥紧拳头）→ 关系重排。
- **奇观爽点波次**：院线向每 60–90s 一波奇观升级（蘑菇云 → 冲击波俯拍 → 沙暴墙 → 巨兽剪影 → 巨兽全身），**每波后必接人物反应镜，不允许奇观连续出现而无人观看**。
- **路人抬咖**：扮猪吃虎让第三方用异世界术语夸（「我竟然感觉不到里面有魔导」）。**金钱爽点连砸三次**：具体递增的数字，每次给听者反应特写。
- **兑现那一下拉长**：咬、吻的单镜停 3s 以上（调情段 1.3s/镜，咬的那段 3.3s/镜）。快切铺垫，慢镜兑现；反转心声段可以是全片仅有的两处慢镜。
- **法术出手三角度**：两指夹符 0.3s → 符纸破空侧面 0.3s → 贴上额头正面 0.5s → 对方僵住中景 1.5s。打斗不拍过程，只拍运动模糊镜加结果镜。
- **高潮后先停再翻**：高潮奇观后接 3–5s 黑场或静音字卡，悬置关键人物态度再给反转。上限 5s。
- **碎切动作后留落地镜**：0.1–0.2s 碎切后给 1–1.5s 静止全景（尘土落下、轮椅轮子还在转），再接反应镜。
- **卡点七种**：
  1. 偷看者的眼睛：窗外一双发白光的眼睛，2 镜推近
  2. 献祭请求说到一半：「求你，让我成为被你咬的那个——」切
  3. 大招落下前一帧，接毛笔「未完待续」
  4. 求婚 / 拥抱的手伸到一半（拥抱贴颈定格黑场）
  5. 新角色在门口：雨夜石阶背剑孩子仰脸近景配身份字幕
  6. **追杀线成立**：两方都输给第三方，「没有人可以从我手中跑掉的」
  7. **设问台词卡点**：把下集悬念写成一句设问字幕放中点或结尾前 10s（「还有谁能压制它」），比纯画面钩子更可被评论转发
- **卡点必须是危险或抉择，不能是笑点**：喜剧收尾会让下一集失去期待。
- **卡点集最后一镜带剧名 / 集数卡或续集入口**：没有入口，「只有一集我就不关注了」直接掉粉；精品化周期和追更节奏冲突，要提前攒集。
- **CTA 祈福接龙（双刃剑）**：在爽点峰值插一句对观众的指令口播（「留下一句时来运转」），能换来大量评论，但评论区会全是复制接龙、零有机讨论，且打破第四面墙透支故事可信度。**只用于民俗祈福题材，系列剧情向禁用**。
- **单集完结寓言不卡点**：收在问答金句或弱小者的真话上，金句即片名。
- 「未完待续」字卡可以用，前提是放在大招出手之后、胜负揭晓之前。
- **留一个规则疑问不解释**：只能留一个，且要是观众想追问的（「她为什么不喝丈夫的血」；「她到底是不是妖」由片名反问承载）。其余规则必须自洽，规则 / 常识漏洞是评论区最常见的挑错点。

## 人设与台词

**人设组合**（每个组合都要配**发色和主色块双重区分**；双胞胎 / 同外形角色首次出场打名字卡）
- 猎人丈夫（银发、白衬衫）× 血族妻子（黑发、酒红礼服配红帽）× 血仆第三者（深棕短发加墨绿马甲）
- 躺平大师（长发、黑色道袍）× 话痨女徒弟（短发、西装）：一个冷一个吵
- **双心声误判组**：外狠内怂的吸血鬼少女（黑双马尾哥特裙）× 眼罩「特困生」神父——眼罩是极强识别锚点；两人各给心声，观众全知
- **双生修罗场组**：黑发双生哥哥（一个邪笑一个阴郁，银刺绣军礼服）× 红棕卷发妹妹（珍珠头饰 / 白纱两套 = 被管束 / 自由）× 狼耳少年（黑背心）。双生外形太像，名字卡必须前置
- **夺宝搭档组**：冷傲寡言女主（金发麻花辫，两句口头禅立人设）× 嘴碎前狱卒男主（黑长发敞领白衬衫，承担喜剧和信息输出），一句「当过你六年狱卒、三年室友」完成前史 + 权力反转
- **物种群像**：蛇老板（单片眼镜、油滑）× 猫二当家（长毛金眼、台词全部 8 字内冷硬）× 猩猩打手，物种即辨识度；神兽阵营跨集复用模型，画面内要给身份线索
- **平民求生组**：外卖女骑手（黄色制服 + 头盔）× 白领男主（灰衬衫），观众日常接触的职业，职业技能被观众自己脑补成求生技能（「因为他是外卖员，所以知道哪条路更近」）
- **说书群像**：无台词的哑受害者 × 替她发声的弱小者（弟弟）× 偏见广播者（说书人）× 伪善者（证词最长最流利的书生）× 施害者兼审判者
- 非人主角 × 不说话的另一半（植物人总裁、POV 主角）：另一半不开口，主角对着他自说自话，观众把自己的反应填进去
- 嘴硬心软的非人 × 儿童见证者：孩子第一个看见它，多年后变成老人最后一个记得它，一个人物串起全片时间线
- 外在可笑、内在可靠：白天被孩子嘲笑「骗子」，夜里出手。早点用一句旁白身份卡交底（姓名、年龄、职业）

**台词技巧**
- **第一人称旁白串蒙太奇**：一句 3–8 字，画面只负责证据和情绪。自白短句化，每句一个信息。
- **双轨对白**：外台词狠 + 内心独白怂（「不如给我当磨牙棒」vs 心声「救命！要咬」），两个角色都给心声；画内星号小字吐槽当第二叙述者（「*戴假牙过敏」），一个负责设定科普一个负责玩梗。
- **设问三拍**：A 给结论、B 留例外、C 追问——「那东西什么都吃」→「嗯，几乎什么都吃」→「几乎？」，规则说完即变悬念。
- **排比答案表**：三句排比定世界观（「蛇惑人 / 魅食人 / 狐媚人」），每句在结尾对应一个现实角色。
- **反讽式客套**：把对方踹门说成「我这门可没来得及自己拆啊」，笑里藏刀；施害者说「我定会为你主持公道」。
- **道具代台词**：「罗盘不会说谎」，让道具替角色下结论，省掉大段推理对白。
- **危机播报 + 具体编号**：「8 号安全区现在非常危险」——具体编号让末日有坐标感，比「基地危险」可信。
- **设定反问句**：「世界树不是被视为中立阵营吗」，一句反问完成反转，比陈述句省一半铺垫。
- **命令式短句推行动**：「快」「隐蔽」「不要停留」「控制一下你自己」，6 字以内立权威。
- **降格幽默**：神该管生死，请求却降到「丢了只老母鸡」；吸血鬼的血腥降到「磨牙棒」。
- **日常道具降格复用**：选一个日常道具（草莓、手帕）做奇幻需求的替代品，第一次当笑点、结尾当情感道具复用。
- **唯一口白留给谎言**：旁白体全片只让角色出声一次，把这次「出声」留给最大的假誓（「我一定照做」），反讽最大化。
- **群众台词递进**：四句话完成舆论从怀疑到狂欢（「头发都变白了」→「一定是妖怪」→「我家丢的鸡」→「真是活该」）。
- **语言选择**：西幻恋爱向用外语对白加双语字幕，异域感是卖点；**用了外语配音必须同时上双语字幕**，否则被吐槽听不清。剧情或技术信息密的用中文配音。
- **方言做喜剧**：方言给喜剧角色和群像，配准确字幕。
- **数字梗**：「第十九个了」「录取率三千分之一」，数字要具体。
- **猎奇描写只说一句**：连说三句会引发生理不适。
- **称谓统一**：旁白体里角色称谓必须从头到尾统一，一会儿「妹妹」一会儿「妻子」，首看者会把两个人认成一个人。
- **设定名词做弹幕诱饵**：每集投放 3–5 个可考据的专有名词（世界树 / 8 号安全区 / 净化之力），高赞评论自发变成设定讨论区。

**金句公式**
1. 把伤害说成恩赐：「求你，让我成为被你咬的那个。」
2. 用感官认出身份：「你身上有我最熟悉、也最憎恨的气味。」
3. 亲昵称呼反差：獠牙抵在颈侧时叫她「馋猫」。
4. 大战前一句家常话：恶魔扑来，术士说「猜你肯定没吃过中餐」。
5. 陌生化求婚：准备了一整晚的人，开口却是「美丽的小姐，迷路了吗？」
6. 猎人和猎物对调：「你再不吃饱，我就要忍不住吃你了。」
7. 轻蔑顶回宏大：天神说「此地生灵当有此火劫，乃是天命定数」，她回「废话真多」。
8. 问答式定义：「怎么就成了神仙？」「做了神仙该做的事。」同时当片名。
9. 道具下结论：「罗盘不会说谎。」
10. 重新定义关系：「或许我们该重新定义我们的关系。」
11. 反问完成反转：「世界树不是被视为中立阵营吗？」

## 视听风格

**画幅**：这个片种的主流是横屏「电影感」（16:9 叙事、2.39:1 遮幅给史诗段、4:3 给哥特私密戏和寓言），投竖屏平台时横屏加黑边反而显得「这是电影」。竖屏做法已有实测验证（见下）。

**景别（分两档）**
- **恋爱 / 喜剧向：特写 + 近景 65–80%**。几乎没有中景过渡，全靠特写质感撑场；全景每场只给一个，留给「真相」（全片唯一大全景 = 揭身份）或立空间。
- **院线奇观向：大远景 + 全景 50–60%**。航拍大远景给灾难尺度；文戏用道具特写（木匣、罗盘、镣铐、药瓶）。
- 寓言 / 社会向：大全景约 25% + 近景特写约 45%，道具大特写约 10%（琴弦、递杯、草席）承担叙事转折。
- 非人 / 神永远全景或中全景保持距离感，人给中近取表情——「人—神」垂直权力构图（全（神）→ 中（人反应）→ 全（人神关系）交替）。
- 眼睛大特写用在情绪转折（含泪的眼、血红瞳、植物人睁眼、裂缝里的兽眼）。
- **延迟亮相**：先脚、手、道具、侧脸、剪影，再给脸，可以拖到 20 秒。

**运镜**
- 兑现戏用缓推或固定机位停住；亲密戏浅景深 + 轻微横移 / 环绕（贴近呼吸距离）。
- 文戏固定机位和慢推为主，让质感显出来；说书段缓推 =「进入」故事。
- 打斗段手持晃动 + 快速横移，跟着力量方向走；灾难段航拍俯冲 + 纪录片式晃动。
- 长镜奇观段用慢推 / 慢移 / 环绕，掩盖生成瑕疵同时给体量感。
- 垂直机位标叙事位置：房梁俯拍 = 主角在空间高位也是叙事上位；公堂缓慢横移扫群像 =「众口」压迫。
- 揭示段用切不用摇，靠景别递进制造逼近感。
- POV 生活流：手持轻晃，用一个被风吹走的小道具带镜头进城，转场和世界展示合成一个镜头。

**光色**
- **冷暖二分**：冷蓝尖窗逆光 + 暖烛光 + 酒红服装；冷色是危险或异界，暖色是欲望、人间或东方力量。
- **按幕 / 按场换色**：一幕一个主色，观众凭颜色知道走到哪。神域青蓝丁达尔 vs 人域土黄 vs 宝藏金红；三色真相（茶楼青灰 / 惨案暗红 / 皮影谎言金黄——「谎言是暖色的」）；三段灾难色（日常冷灰蓝 → 核爆白热 → 沙暴土黄，颜色变化即灾难阶段）；硬切换场靠色温突变承担转场。
- **单色海洋里只留一个暖色 / 高亮**：全片冷灰蓝、唯一暖色是目标道具（橙色药瓶，每个关键段落给它一次特写）；青蓝底、唯一暖橙是火光（情绪峰值镜，出现即重音）；琥珀暗调里唯一高亮是主角的头套（任何一帧一眼认出）。
- 全片锁定单一 LUT 保一致性，不一致藏进压死的暗部（单一暖色体积光 + 暗背景）。
- 哥特内景三层光：窗外冷月、手边烛火、人脸一道暖侧光；高调柔光奶油暖金给甜宠，低调布光给夺宝。

**构图**
- 神像 / 秩序居中对称 + 凡人前景剪影；对称的「明镜高悬」匾做反讽——对称秩序衬「公道」不存。
- 逆光门框剪影 = 英雄 / 反派进门：门外白光、屋内飘尘、只有轮廓。
- 前景虚化遮挡营造偷窥私密感（前景头发 / 花 / 门框；门缝偷看母题）。
- 巨兽在街道纵深、人群在前景朝镜头逃 = 用人物做比例尺。
- 三分法偏置 + 大面积留暗给单人（2.39:1 遮幅）。
- 美术混搭出辨识度：东方木结构酒馆 × 西部酒吧吧台、现代都市 × 军用装甲车 × 巨兽、末日废土 × 山海经神兽、凡尔赛宫廷 × 哥特洛丽塔 × 徽章校服。

**横屏怎么做（默认）**
- 2.39:1 遮幅给史诗段，16:9 给叙事，4:3 给哥特私密戏和寓言。
- 双人戏用过肩加纵深，前景放烛台或帷幔虚化。
- 官场、殿堂用中心对称，用秩序感衬非人的乱。
- 人物尽量放画面中央、字幕居下，给竖屏裁切留余地。

**竖屏怎么做（已实测验证）**
- 双人对手戏：**前景人物虚化半边 + 主体在另半边**，一格画面塞进两个人，窄画幅也能拍对手戏。
- 三人修罗场：**主角居中、两男从画框两侧入画**的近景构图，肢体接触只用搭肩、握手、含指小动作；对称张臂把「双生」直接画出来。
- 每场开头一个全景立空间（长桌、森林、落日窗），之后一直待在近景特写里，情绪最高点切大特写（唇指、耳坠），出场回中景。
- 服装即人设：一套服装对应一种处境（深蓝裙 = 被管束，白纱 = 自由危险），换装本身承担叙事。
- 仍适用的推导项：尖拱窗竖向画框、血月放上 1/3、咬颈上下构图、巨物占上 2/3、字幕留下 1/4。

## 剪辑节奏基准

**四种节奏模式**
- **旁白蒙太奇型**（血族禁恋、打工喜剧、寓言、恋爱快剪）：平均镜长 **1.1–2.3s**。极快剪（约 1.5s/镜）本身就是对 AI 的规避——每镜只要 1–2s 稳定。无台词单镜不超过 5.5s。
- **对白情景型**（宫廷甜宠、驱魔正剧、妖怪群像、酒馆夺宝）：平均镜长 **2.7–6s**，文戏 2–7s，单镜可停到 9s。
- **POV 长镜型**：真实镜长 7–9s、单镜可到 18s，前提是镜头里一直有人对镜说话或走动，一停下就切。
- **院线双峰型**：名义 ASL **3.2–4.7s**，内部分是「长镜奇观段（10–38s）↔ 快切簇（0.2–2s/镜）」交替，每 60–90s 一个呼吸循环；**快簇永远紧贴慢段之前当引信**（21 镜快簇 → 对话块 → 7 镜 5s 快簇 → 38s 最长镜）。

**长镜头的硬线**
- **奇观长镜 20–38s 可以是卖点**：前提是镜内有连续画面事件（神兽对战、巨兽行走、废墟推进）。低表现的是**无事件**静态镜。
- **对话块 ≤30s**：静态对话块超过 30s 且只推进 1–2 条信息，是「水」评重灾区。超过 30s 必须插入画面事件（威胁逼近 / 道具特写 / 闪回）。
- 无台词、无事件的静态镜头仍 ≤20s。
- 单个对话镜头不超过 8s，长对话和道具特写交叉剪。
- 10s 以上的镜头里必须有一个小事件（风吹落红布条、手指碰到衣角、眼神变化），否则拆成 3 个短镜。
- 例外：说书长卷（48s）一直有旁白在讲，而且前面的冷开场已经把人留住了。不要默认复制。

**快慢分布**
- **甜宠和喜剧越剪越快**，随后一镜降速让金句落地。
- **恐怖和温情越剪越慢**：慢本身就是恐怖手段；夜戏单镜可放到 10s；寓言结尾放到 4–5s；惨案前后 11–15s 长镜制造窒息感（但两个长镜叠加有流失风险）。
- 动作开场例外：打斗快切后越剪越慢，把空间让给浪漫。
- 兑现前的调情、对峙段剪得最快（1.27–1.5s/镜），兑现那一镜拉长（≥3s）。
- 高潮段最快可到 0.1–1s/镜，之后立刻 3–5s 黑场骤停。
- **反转心声段是全片仅有的慢镜**：全片 1.5s/镜的快剪片，只有反转两处放慢到 5s 上下。
- **打完就让怪兽「站着」被看**：炮塔快切之后，6s → 7.6s → 19s 逐级放慢。

**审核参数**（写进 storyboard 的 `project.asl` / `project.hook`）

```json
"project": { "genre": "short-drama", "asl": [1.2, 3.2], "hook": 5 }
```

对白情景型改 `"asl": [2.7, 5.5]`；POV 长镜型改 `"asl": [5, 9]`；院线双峰型改 `"asl": [3.2, 4.7]`，并在 `notes` 标明每个 >10s 长镜的镜内事件，奇观长镜豁免停留上限，对话块超限必须在 `pace_note` 写插入的画面事件。兑现镜标 `tempo: 停留`，`pace_note` 写「兑现：让观众盯着看」；高潮后的黑场标停留，≤5s。

## AI 制作要点

| 翻车点 | 规避法 |
|---|---|
| **题材选择是第一规避** | 立项时优先选非人主角、大场面、流体 / 毛发材质题材（神兽当主角、环境奇观为主、生物只给灵体或单次短爬行）——人手、口型、群戏三大难题一次清零；把镜头预算花在 AI 擅长的环境奇观上（爆炸、沙暴、废墟、云海） |
| **材质跟着 AI 强项走** | 魔法元素选水 / 火 / 烟 / 光（流体是模型强项，动作最流畅）；拟人题材选动物脸不选真人脸（物种差异比真人脸好保持） |
| **长镜藏不一致 vs 碎镜降稳定要求** | 两条路二选一：奇观长镜 20–38s（镜内必须有事件，少切少暴露跨镜不一致）或极短碎剪约 1.5s/镜（每镜只要 1–2s 稳定）；暗部压死藏漂移。不要用 8–15s 的中等长镜暴露漂移 |
| **男性角色同脸、撞脸、双胞胎** | 每个男角色建 `refs`，发色 / 发长 / 主色块 / 配饰至少换两项；同外形角色首次出场打名字卡；跨集复用模型给画面内身份线索（字幕标注 / 特征强化）；参考图避开热门游戏和动画角色 |
| **口型** | 按题材选一种主规避法：非人脸或不说话角色扛对白、旁白体、皮影剪影证词、心声独白、背身 / 面罩 / 远景、兽人嘴型无标准观众不挑、外语配音观众不指望中文口型、大远景背侧 + 字幕承载信息。人脸角色说话用背影、侧脸、道具特写和画外音 |
| **服装锁人** | 每个主角一套主色服装 + 一件固定配饰（眼罩、戒指、头套），全片不换；换装即叙事（两套 = 两种处境） |
| **动作与打斗** | 不生成连续长动作；打斗切成 0.7–2s 单动作镜、每镜一个力的方向；扑击拆成 6 个 0.2–0.6s 单姿态碎镜 + 动态模糊；接触动作拆「靠近—局部大特写—反应」三镜每镜 ≤1.5s；逃生 = 1–2s 单向奔跑、扑倒用尘土掩盖；群体镜头用全景 + 动态模糊；暴力只拍前一刻道具和后一刻结果，中间用天气 / 空镜跳过 |
| **世界规则 / 常识 bug** | 开拍前写 3 条规则（吃什么、怕什么、能力边界），每场对照；物种特性符合常识或台词解释一句；能力最优解中段演一次；服装先符合场景逻辑再求好看（森林里的头纱和高跟鞋会被顶赞吐槽放大成全片第一印象），或让角色自己吐槽化解 |
| **闪帧凑数** | 连续 0.07–0.5s 微镜混入生成瑕疵帧，拉低「特效逼真」口碑。成片前扫一遍 0.2s 以下碎镜；连续闪帧合并成一次 0.8s 冲击帧 |
| **BGM 带人声盖对白** | 高潮段压低歌声或留空；外语配音必上双语字幕 |
| **静态长镜 / 对话块凑时长** | 素材不够不要拉长镜头，改成 3–4 个 1s 暗示短镜（水面鼓起、火把熄灭、暗影划过）；对话块 ≤30s，超限插画面事件；黑场 ≤5s |
| **獠牙时有时无** | 獠牙只出现在大特写插入镜里；对白和吻戏镜头写「獠牙收起」，每镜在 `notes` 标獠牙状态 |
| **近景背景一律虚化像 AI** | 特写也保留可辨认前景物（烛台、窗棂），景深中等 |
| **画风选择** | 优先选造型简化、材质统一的风格（木偶、黏土、动物拟人、写实厚涂），比写实人脸稳，观众夸质感、不挑脸；谎言 / 回忆段整体换风格（皮影 / 剪影）既表意又避险 |
| **画内文字** | 名字花海、符纸字、匾额、会议屏标题一律后期贴，生成时留空白；不需要读的文字做成手写稿 / 大字风格化 |
| **素材复用、连贯性** | 复用的素材换景别或翻转；闪前回收段重新生成关键帧核对服装；成片前扫 0.2s 以下碎镜 |
| **手部** | 手只做一个动作，单手入画；需要多指细节的用巨手、兽爪或剪影；暧昧戏的手部特写多抽卡只留干净的 |
| **群戏** | 群戏拆成「群像静态 + 单人近景」；群体动作只给同方向奔跑或全景动态模糊 |
| **恐怖段的脸部变形** | 只有恐怖段可以放开（不稳反而成了效果），其他段落照常锁脸 |
| **尺度** | 上身最多到裸背和锁骨；咬颈只给两个血点，不拍喷溅；暧昧给局部特写不给全脸 |

## 大导演工具箱

| 导演 | 手法 | 在本片种里怎么用 | 镜头写法 |
|---|---|---|---|
| 希区柯克 | 桌下的炸弹：让观众比角色先知道危险；POV 揭示链；道具信息差 | 五种信息差（见「反转、爽点与卡点」）全是他。规则明确告诉观众，再让角色去破它；30s 以上的甜蜜段插威胁方 1s 短镜 | 危机信息差：「基地机密对话远景 2 镜 13s → 毫不知情的骑手穿城跟拍 11s」。违约利息：「她藏私房钱（观众已知）→ 26s 的渴望 / 失踪 / 设陷阱 → 门内剪影全景 → 蹲地中景 → 怪诞动作特写」，三拍逐级逼近只靠切。道具悬念不断线：「目标瓶前景虚焦 + 后景人物 → 之后每个关键段落再给瓶子一次特写」。递杯前加 0.8s 下药手部特写，让预感变煎熬 |
| 斯皮尔伯格 | 奇观先给反应；怪物少露、延迟显形；平民视角；巨物压场用人做比例尺 | 所有奇观镜头的前后排法；末日怪兽子类型整个建立在他的语法上 | 先反应后奇观：「角色仰惊 2s → 光柱显圣全景」；「蘑菇云 → 人群扑倒」——每个奇观必须有「谁在看」。四级显形：「墙缝一只眼特写 → 沙暴中剪影远景 → 掠空飞影 → 街尾全身 + 人群朝镜头逃」，全身放集末卡点。体量先行：开场两个 10s 长镜不切、先给奇观再给事件。巨物压下：「天神巨掌占画面上 2/3，主角在下方 1/6 大远景 1.5s → 主角仰头眼睛大特写 0.8s」 |

## 禁忌

- 两个男主同发色、同肤色、同服装色；男角色长得像热门游戏或动画角色；双胞胎 / 同外形角色不打名字卡。
- 开场 3 秒没有人声、也没有事件，只有空镜或氛围（质感长镜开场是院线级质感 + 20s 内有刺点才成立的例外）。
- 无台词、无事件的静态镜头 ≥20s；静态对话块 >30s；单个对话镜头超过 8s 不剪；黑场超过 5s。
- 主角能力的第一次兑现晚于全片 60%；主角晚于 40% 才登场。
- **能力最优解整集不演，等评论区替你想**。
- 规则自相矛盾又不解释：吸血鬼吃早餐、白天出门不怕阳光、控水不罩头、物种特性违背常识，片中没有一句交代。
- **服装违背场景常识**：森林里穿高跟鞋、短裙、头纱。
- **卡点集没有剧名 / 集数卡、没有续集入口**；**卡点落在笑点而不是危险或抉择**。
- 最强台词 / 落点放在 5 分钟之后，部分观众到不了。
- 高潮段带人声 BGM 盖住关键台词；外语配音不上双语字幕。
- 闪帧、残帧凑数。
- CTA 祈福口播用在系列剧情向（换来评论量，牺牲讨论质量与沉浸感）。
- 东方降维时贬低真实宗教人物或教义：反派用虚构的恶魔名号、虚构的组织，画面加「纯属虚构」角标。
- 尺度越线：腰以下裸露、咬颈喷血特写。
- 猎奇、血腥的感官描写连说三句以上。
- 口音和角色身份错位（贵族少主满口方言，除非这就是笑点）。
- 系列集兑现完再拖 10s 以上抒情；最后一拍必须是未解局面（单集寓言收在金句上）。
- 改编网络随笔、小说不署原作者；桥段和热门作品撞型；用热门作品的 BGM。
- 系列名里的核心道具整集不出镜；目标道具给过一次特写后断线。
