# 古风志怪

> v0.3。例子和 logline 都是自拟的。本卡分三支：**志怪寓言**、**仙侠爽剧 / 喜剧**（多为横屏）和**古风言情**（竖屏、横屏都有）。竖屏志怪还没有验证过，不要直接套横屏的节奏数字。

## 定义与情绪承诺

**三个情绪引擎**（立项先选一个当主承诺）

- **引擎一（寓言 / 报应）：一条「非人规则」照出人心，最后兑现善恶有报但带代价。** 妖鬼本身不是卖点，卖点是规则让人现形。观众会主动总结「写的从来不是鬼，是人心」「鬼有什么好怕的，来看看世间人心」。承诺三样：看完能复述一句规则；看到一次「表象和本质翻面」；结局是带代价的善报（成了河神，也从此困在一方水里——观众会为这个代价写长评）。
- **引擎二（仙侠爽剧）：规则型金手指的爽感。** 被踩到泥里的人靠一件破道具、一句话契约翻盘（「叫名答应即收人」），或者无敌本身成为喜剧前提（「天道跪求我飞升」）。爽点是「规则可复述 + 前 30 秒内验证 + 原样回敬」。这类作品收藏高，被当追更资产存起来。
- **引擎三（喜剧 / 共情）：设定降格与妖怪日常。** 把世界观里最严肃的概念翻译成家务事（雷劫 → 认娘的毛球、天雷之眼 → 上门要孩子的妈），或让妖怪过人的日子（「背着房子过日子压力大」= 房贷，是能转给朋友看的社交货币）。喜剧引擎的天花板不低于寓言。

- **志怪 / 仙侠里赢的是人性题和喜剧题，不是打斗。** 纯降妖打斗表现最差；打斗可以有，但不能是一集的主承诺。例外是「这真是 AI 做的」级别的中式奇观（民俗仪式、神像崩坏、伪仙现形、巨物仙兽），能靠制作力爆一次，但评论只聊画质。
- **古风言情**：身份差加撩拨拉扯（甜），或者誓言落空的意难平（虐）。甜的那一类在最后 20% 兑现一次亲密或一句撩到顶的台词；虐的那一类要把誓言回收成一句新台词。虐可以做，前提是 5 秒内出事——长旁白慢铺才是死因。

| 相邻片种 | 它卖什么 | 古风志怪卖什么 | 判别动作 |
|---|---|---|---|
| 奇幻西幻 | 体系和设定 | 超自然扎在中式民俗物件或古籍上（纸人、泥胎、壁画、锁链、桃木、符、破盆、照影缸、古籍原文），规则一句白话就能说清 | 去掉禁忌故事不成立，归本卡；成立，归西幻卡 |
| 穿越重生 | 改命复仇 | 仙侠穿书的爽点是「共享剧透的上帝视角 + 反套路」，落点在宗门世界观内部自洽 | 看世界观是否志怪 / 仙侠原生 |
| 甜宠霸总 | 钱和权 | 权力差来自称谓和礼法（太傅 / 女帝、公主 / 敌国太子），翻盘靠礼法证据和称谓，不靠钱 | |

**传播特征**
- 分享倾向最高的三类：**治愈共情金句 > 女性互助泪点 > 能转述的道理**（寓言、意难平次之）。**爽剧收藏不分享**（收藏/点赞可到 0.3，但十几次点赞才有一次分享），寓言和共情分享不收藏——两类指标分开看，立项时定主指标。
- 评论率最高的是人性寓言和解读门槛高的片子；门槛高时评论区会自己补完剧情翻译，这是风险不是优点。治愈系留「观众自己补」的空（角色设计自带的二创空间比台词值钱）。
- 言情和连载的评论区在催更或找正片（「看了上集没下集」「在哪看 / 叫什么名」）——卡点要比志怪更硬，剧名必须露出。

## 单集结构模板

**通用位置规则**
- 第一句台词或旁白在 1 秒内进来（纯 BGM 混剪靠字幕）。
- **前提验证在前 30 秒**（志怪 / 仙侠专属）：金手指、世界规则或荒诞前提必须在前 30 秒内完成一次可视化兑现（叫名收人在 28s 闪白验证、无敌宣言在 8s、世界规则在 15s + 第一案报应在 28s、穿书前提在 10s）。观众要的不是「后来会爽」，是「已经爽了一次」。
- 第一次反转或身份揭示落在 **26–40%**。拖到 48% 才出第一个信号，观众已经在别处看过剧情了；大反转压在 68% 的，前 2 分钟必须给「叙事不可靠」的小钩兜底。
- 情绪高点落在 **72–98%**。
- 动作志怪的爆发段落在 **60–70%**，前后都夹长镜，像一次呼吸。
- 转折间隔：喜剧 30–40 秒一次反转或笑点；竖屏言情 10–13 秒；横屏志怪 20–40 秒升级一次。

### 60s

**A. 失忆错认（竖屏言情）**

| 节拍 | 占比 | 做什么 |
|---|---|---|
| 前史速讲 | 0–40%（0–25s） | 旁白一句配一个正在发生的画面，中间夹 2–3 句角色原声（「这是你表妹」）。不准纯旁白配空镜 |
| 转折黑卡 | 40%（约 1s） | 全黑底上一行白字，写转折句（「后来，我失忆了」）。这是本集**第一反转** |
| 错认 / 误会 | 40–60% | 女主做出错误判断并当场行动（起身去找「夫君」） |
| 对质 | 60–80% | 一问一答，每句 1–2 秒，问句收尾：「你是我夫君吗」 |
| 亲密卡点 | 80–100% | 吻或逼近 + 一句反问台词（「我是不是，你现在清楚了吗」）。台词说完就切，不加余韵 |

**B. 誓言落空（横屏 3D 国风，平均镜长约 3.5s）**

| 节拍 | 占比 | 做什么 |
|---|---|---|
| 誓言 | 0–8% | 两人各说一句承诺（「我等你回来娶我」/「此战若胜，我便回来娶你」），近景对切 |
| 死讯 | 8–32% | 0.4s 雪地伸手的闪帧 → 红甲背影跪倒 → 城门口盖红布的担架 → 女主在军阵里愣住。不拍死亡过程，只拍结果 |
| 认尸反转 | 33–40% | 染血信物的特写，台词「原来真的是他」。这是**第一反转** |
| 二选一逼迫 | 40–58% | 敌方开条件，「你若是嫁」「你若是不嫁」各一句，一句一镜 |
| 誓言回收（高点） | 58–81% | 白色送葬队伍和红嫁衣交替切；女主对遗体说「你见过我红盖头下的容颜，也算是娶了我」 |
| 新局卡点 | 81–100% | 新男主一句「娶了本公主，可就不能再娶别的女子了」开出新三角，停在大远景 |

**C. 高光混剪（横屏，平均镜长约 0.7s）**

| 节拍 | 占比 | 做什么 |
|---|---|---|
| 结局前置（慢） | 0–30% | 婚礼或团圆画面，单镜 1.5–2.5s，夹 1–2 个 0.07s 闪白 |
| 回忆卡点（快） | 30–85% | 按 BGM 一拍一切（约 0.47s，约 128 BPM）。每镜只留一个情绪峰值（吻、哭、怒、笑），每镜配一句 ≤10 字字幕。中段插 3–5 个「刀」镜，马上用糖盖住 |
| 闭环（慢） | 85–100% | 回到开场的画面（分屏也行），1.3–2.5s/镜，停在半句情话上。**画面上必须打剧名**，否则评论区一片「求剧名」 |

**D. 设定降格喜剧 skit（横屏，平均镜长约 1.3s）**

| 节拍 | 占比 | 做什么 |
|---|---|---|
| 违反常识报丧 | 0–4%（0–2s） | 一句台词立荒诞前提（「小师妹把雷劫抓回来了」），画面只给奔跑远景 + 听者抬眼，不揭底 |
| 本体局部揭示 | 4–14% | 第 4–7 秒才插入「双手捧怪物」的特写，先手后物；听者捂嘴反应镜替观众吃惊 |
| 解释三连 + 冷吐槽 | 14–28% | 面瘫主角用 3 句短句解释离谱行为（「她一直劈我 / 我嫌烦就揍了一下」），捧哏一句冷吐槽（「你管这叫老实」）收笑点 1 |
| 物理 gag 闪切 | 28–31% | 0.25s 级闪切 ×4 把设定外化成身体喜剧（被电炸毛），踩 BGM 鼓点 |
| 温情垫冷刀 | 31–43% | 温情台词后 1.5s 内接冷刀（「今晚想吃什么」→「断头饭」），冷刀前留半拍静场 |
| 威胁入场 | 43–60% | 巨物只给局部（天花板对称巨眼睁开），空间跳切制造「被盯着」的惊悚喜剧 |
| 对峙 = 家务事 | 60–85% | 高潮对峙台词全部翻译成家务事（「你孩子不要了 / 你还家暴」），最大笑点放这里 |
| 三连怼收尾 | 85–100% | 三连排比怼句（「大的打不过 / 小的不要脸」）+ 萌宠斜眼反应镜 + 与片头呼应的对称镜书挡收束 |

### 90–120s

**A. 竖屏反套路甜撩**

| 节拍 | 占比 | 做什么 |
|---|---|---|
| 钩子 | 0–5% | 身份反差台词 + 两个主角同时出现（分屏或一句话点名）：「恳请女帝大婚」「你要给本世子纳妾」 |
| 女主的计划 | 5–30% | 女主定一个想逃或想挑的计划，用快切蒙太奇演出来（「这个不行」×3，前 15 秒 13 镜，平均 1.15s） |
| 第一反转 | 30–40% | 计划被男主截胡，称谓或身份亮出来（「怎么是你」） |
| 撩拨拉扯 | 40–80% | 3–4 轮称谓梗或试探（「爱妃」→「皇夫」），每轮 8–12 秒 |
| 亲密高点 | 80–90% | 吻、逼近、贴耳。镜长放慢到全片平均的 1.2–1.5 倍 |

| 节拍 | 占比 | 做什么 |
|---|---|---|
| 主题宣言 | 0–3% | 受害者冲镜头喊出世界观真相，≤8 字（「成仙是骗人的」）。系列中段集靠这一句补前情 |
| 处境 | 3–14% | 全景里人群在动，主角下短指令（「放这儿」「扶我一把」，3–5 字一句）。不要留 10 秒长镜 |

| 反转一（世界观） | 18–28% | 镜头自上而下摇，脸 → 手中物 → 胸口 → 脚，脚已经是龟裂的泥胎 |

| 分工 + 护盾 | 42–55% | 主角用职业道具护人（戏班红幕旋转罩住众人） |

| 节拍 | 占比 | 做什么 |
|---|---|---|
| 罪人祈愿钩 | 0–8% | 有罪之人跪拜祈愿，祈愿词 = 认罪书，第一案直接开始，无旁白解释 |
| 规则宣告 | 8–18% | 神自报一条规则（「有求必应」），≤2 句，配信使（乌鸦展翅）特写——全片伏笔总闸 |
| 案 2：祈愿 → 报应 | 18–37% | 四拍剪辑：祈愿中景 → 自白特写 → 报应物件插入（药罐）→ 人脸反应，反应镜比动作镜长 0.3–0.7s |
| 案 3：祈愿 → 报应 + 温情 | 37–63% | 恶愿升级（称人为「货」）→ 报应（变驴驮孩归家）→ 人声主题曲进，情绪转上扬并一路铺到片尾 |
| 反派入场 | 63–73% | 枯花 / 黑庙空镜过渡，黑袍者逼近，节奏压暗 |
| 主题句 + 终极反转 | 73–93% | 反派在高潮入口喊出片名级台词（「装什么慈悲」）；神反问「你有何心愿？尽管说来」——规则对神也生效 |
| 母题合拢尾声 | 93–100% | 最后一帧母题合拢（石手开花、乌鸦立掌），延长到 3s、去字幕 |

**A. 聊斋人性镜（志怪寓言）**

| 节拍 | 占比 | 做什么 |

| 冷开场 | 0–8% | 一句带刺的反问或冲突宣言（「我看郎君倒像个歹人」）。画面要有人在动，不要用署名压空镜 |
| 片名 | 约 5–15% | 竖排书法片名**压在剧情画面上**，停 2–3 秒，改编古籍的再加一行「改编自 ××」给出处。不要做 11 秒的独立片名镜 |

| 翻面对峙 | 85–100% | 弱者说破规则，异类用规则回答（「她心甘情愿养我，自然要拿东西换」），卡在半句或受害者愣住的脸上 |

|---|---|---|

**4–5 分钟长集两式**
- **妖怪市井群像**：单元串烧（每单元约 15s：一个角色、一个特征梗、一次冷判词收）→ 一个共同需求（「饿了」）把单元收拢成一条线 → 魔法道具转场进第二空间 → 小人物高光（静场 15s 造悬念）→ 两线汇流回开场空间闭环 → 系列卡点（须提前埋 1s 视觉伏笔）。生产上「15s 一条视频 = 一个节拍」，条内给全景—双人中景—单人反应三镜；中间插一条 5–8s 短条打破机械感。
- **伪志怪长集**：传说规则冷开场 + 闪前 → 困境建立（完美女儿被当货物）→ 旁白揭穿一个反派制造观众先知（掩护主角的真秘密）→ 怪事段（每件怪事都要有拍得出的人为解释，作视觉伏笔：窗格狐影 = 皮影）→ 前世情感段（萌宠 + 雪景让观众相信超自然）→ 表层高潮（白轿抬走）→ 框架叙事露出（说书人现身画内）→ 大反转（不要晚于 60%；前 2 分钟要给「叙事不可靠」小钩）→ 倒叙逐一揭底 → 主题句翻义升华 + 系列化。

> 5–10 分钟的长集：第一反转不要晚于 40%；长集要在结尾给「下集 / 合集」导航，否则评论区全在问剧名和「在哪看」。

## 钩子库

每条都是开场前 3 秒的打法。

1. **谶语开场**：先黑 0.7 秒，切蒙眼人仰头的近景，画外念七言打油诗「瞎子睁眼不见天，纸糊皮囊半神仙」。画面写法：`雨夜古镇石阶，蒙黑布的说书人仰面，手里摇一只铜铃，雨水顺着布条往下流，近景，冷灰调`。
2. **禁地警告**：路人喊住主角，「你疯了，××都敢去」，主角一句反问回去（「河里有鱼，为何不敢」）。竖排书法片名同时压在画面上。画面写法：`夜色黑河，远景一叶小舟，船头挂一盏暖橙渔灯，船上斗笠老人撑篙，画面左侧竖排白色毛笔字片名，水面冷青色`。
3. **受害者喊真相**：第一镜就是一张变异的脸冲镜头伸手，喊出世界观的反转。画面写法：`金碧壁画大殿前，满脸泥裂的男人向镜头扑来伸手，嘴张到最大，背景跪倒的香客虚化，暖金烛光从下往上打`。台词不超过 8 个字。
4. **异象三特写**：点火 → 异色瞳 → 灯闪，三镜各约 1 秒。画面写法：`漆黑走廊里一簇打火机火苗是唯一光源，大特写；切：火光里一只瞳孔亮成金色；切：天花板日光灯管连闪三下`。
5. **夜路反问**：男人搭讪，女子用一句反问把「谁是猎物」翻过来。画面写法：`月夜窄巷，胖员外举灯笼凑近，白衣女子回头只露半张脸，鬓边一朵白花，暖灯照男、冷月照女`。
6. **誓言即死讯**：0 秒互许誓言，第 2 秒切一个 0.4s 的闪帧，把结局先甩出来。画面写法：`近景，女子含泪捧着一枚玉佩说话；切 0.4 秒：雪地里一只戴铁护腕的手伸向画外；切：红甲将军单膝跪在雪中，背影，远处城楼`。
7. **结局前置**：先亮婚礼、红榜、团圆的结果，再倒叙。画面写法：`红帘被一只手掀开，新郎乌纱红袍笑着探身，下一镜凤冠新娘回眸，花瓣从画面上方落下`。长集可以把后段最强的一幕剪 3 秒放到最前面。
8. **身份反差第一句**：第一句台词就把反常身份说出来，「恳请女帝大婚」，第二镜切说话的老臣。画面写法：`女帝托腮趴在御案上发呆，金凤步摇，前景虚化的奏折堆；切白须老臣拱手特写`。
9. **分屏同台词**：上下分屏，两个男主各说一遍几乎一样的话，一秒交代两对 CP。画面写法：`竖屏上下两格，上格黑衣世子金冠正面近景，下格红抹额少年侧脸近景，两人同时皱眉开口`。
10. **前史快讲**：第一句旁白就交代身世之痛（「我是个孤女，爹娘获罪被斩杀」），2 秒内切到人物在场景里的画面。前史旁白不能超过全集 40%。
11. **单镜身份压迫**：第一帧仰拍施暴者站立、受害者俯伏在画面下角同框，第一句台词直接侮辱身份（「你一个血奴不配享用」）。画面写法：`低角度，红衣金冠师姐居高临下俯视，画面左下灰布少年伏地、脸颊带血痕，两人之间一株发光灵草，冷青灰柴房，窗光单暖源`。
12. **系统结算宣告**：画外系统音报「奖励到账」，10 秒内主角亲口宣告无敌，20 秒内抛出情感锚。画面写法：`黑袍青年负手立于旧屋中，胸前金色光粒缓缓汇聚又散开，他睁眼，冷灰蓝晨光，画外第一句是机械男声「万年签到期限已满」`。
13. **违反常识报丧**：第一句让配角喊出打破世界观的报丧（「不好了！小师妹把雷劫抓回来了」），画面只给奔跑与反应，第 4–7 秒才插「双手捧怪物本体」的特写。画面写法：`红柱大殿前弟子奔跑的全景，切绛红袍女修缓缓抬眼；再插入：一双手捧着一团发光紫色毛球，特写，毛球只有两只大眼`。
14. **异形部位特写 + 进行时台词**：第一帧是一个非人身体部位的特写，画外音正在数数，6 秒内揭示「在数什么」。画面写法：`一排毛茸茸的虫足大特写占满画面，暖褐油灯侧光，画外苍老嗓音数「三十五、三十六」，再切刺猬郎中扶眼镜与千足虫的双人中景`。
15. **巨物尺度钩**：四镜立尺度——部位大特写 → 全貌大全景 → 低角度巨物与人群同框 → 主角与巨物肢体接触，第一句台词故意误读（「活的！」）。画面写法：`丹顶鹤头部金瞳大特写；切云柱间鹤的全貌大全景；切低角度鹤腿穿行人群，人只到脚踝高；切少女张开双臂抱住鹤腿`。
16. **传说规则冷开场 + 闪前**：旁白念一条传说规则（「凡被选中者，白轿接走，再无归期」），同时插一个 5 分钟后才回收的闪前镜头。画面写法：`雨后湿亮的夜街，一盏灯笼落地，一双腿奔跑掠过；切月下男人回头狂奔、面目惊恐——此镜第 5 分钟才回收；旁白带戏曲腔抑扬`。
17. **罪人祈愿悖论**：第一帧是加害者在神像前跪拜，祈愿词即认罪书，不写旁白评判。画面写法：`黑庙内体积光束斜落，粗布衣人影跪拜叩首背影，供台上白瓷神像半张脸隐在阴影里，第一句字幕「我不过是杀了一个乞儿」`。

- ❌ 反例：**先甜后摧的长旁白**（前 44 秒全是「世人羡慕……」的唯美旁白才出事）；**署名压空镜 + 11 秒片名**（前 15 秒只有 2 个镜头，钩子全靠一句画外音）。

## 反转、爽点与卡点

**反转**
- **表象与本质翻面**是志怪的主反转：异类是好人，神仙是坏的，被当成坏人的是救人者，老实人遇到利益变了心，传说是假的、人是真的（「轿子里从头到尾只有我自己」）。写法：开场让观众站在错误的一边，在 26–40% 处用一个**身体或物件特写**把真相亮出来（泥脚、飞走的襁褓、红轿），不要靠台词解释。
- **两级反转**：先给全场最高承诺（天品灵根、全场沸腾），再用一句定义式笑话收回（空灵根 =「漏勺：什么都能装但什么都留不住」），同场人群散场全景完成落差。
- **态度反转**：权力者由「求你走」秒变「欢送你走」（「早说呀」「我给您开天门」），触发点是主角一句真实欲望（「我本来就要上去接老婆」）。
- **规则对规则制定者也生效**：报应规则最后作用于神或砸庙者（「你有何心愿？尽管说来」），终局做一次规则升级，不加新规则。
- **称谓反转**是古风言情最便宜也最好用的反转：同一个人换一个称呼，权力就倒过来（「太傅」→「爱妃」→「皇夫」，「哥哥」→「夫君」）。每换一次称谓给说话者一个近景，给被叫的人一个 1 秒反应镜。
- **计划被反用**：先让观众看到计划（Q 版插画或画像墙），再让男主在第一反转点亲口说出来。
- **智斗反转要先埋后收**：准备动作要真拍出来，隔 20 秒以上再回收。
- **结案式逻辑反杀**：主角把羞辱性结论说成主动选择（测灵石没反应 →「破案了：友好宗门」），反杀台词 ≤15 字。
- **不可靠叙事机关**：让说书人 / 旁白在后段现身为画内人物且是局中人；旁白提前揭穿一个反派制造观众先知，借这份信任掩护主角的真秘密。

**爽点**
- **志怪的爽点是报应**：恶人死在规则手里，不靠主角动手。善人的回报要带代价，观众会为这个代价写长评。
- **原样回敬**：反转后原样回敬反派开场的羞辱台词（「今日灵田浇了吗」），切受害者怒脸反应镜放大结算感；可做成三叠递进，每叠插一次反应特写。
- **报应密度**：84 秒四案「愿成 = 罚成」，每案爽点是规则的字面执行；密度换来了理解门槛，案与案之间要给足物件插入特写保因果可读。
- **共情爽**：金句一秒对应现实痛点（房贷 / 加班 / 情绪管理），用物理负担说心理负担。每个苦点后立刻跟一个笑点卸力，否则观众喊压抑。
- **不入画的神迹见证**：顶级战力不拍过程，爽点来自证人台词 + 结果（破门、裂口、沉山）+ 群体跪伏大全景。
- **降妖的爽点是先挫后扬**：被击倒 → 一句轻蔑的话 → 光效法阵闪切。打不出「命中」时，补后果特写：伤口、碎片、倒地。
- **礼法三连问**（「我拜堂了吗 / 我进你家的门了吗 / 我上你家族谱了吗」）、**物证排场**（嫁妆、红榜拍成一眼数不过来的纵深）、**时空反差**（古人到了现代）照旧。

**卡点**
- **卡点必须有伏笔，硬切卡点是禁忌**：正法——闪前预付（开场那个逃跑的男人 5 分钟后回收）、配角嘴贱一句把私人悬念留到下集、提前 2 分钟埋 1s 视觉伏笔（水面倒影里闪过带血羽毛）。反例——结尾突然切到一个零铺垫的意象，与前 4 分半的日常喜剧调性断裂。
- **倒计时 + 双向选择**：结尾叠「逃跑 vs 回取道具」的两难 + 倒计时（师尊十日归），以双人侧面大特写逼近定格收钩。
- **集体拟声口吃 + 被触发物件插入**：「你你你」前加 0.5s 被碰倒之物（丹炉盖 / 钟槌）的特写，让恐惧有对象；灾难本体留到下一章第一镜。
- **三连重复尾钮**：「走了 / 真走了 / 这祖宗终于走了」收喜剧拍。
- **灯灭卡**：一盏灯或一团火的熄灭当作角色生死的计时器。
- **异物特写卡**：最后一镜是一件不该在那里的东西（带血的羽毛），后面不接解释。
- **愣住的脸卡**、**半句卡**（「可是我若走了——」）、**黑屏撩语卡**、**双关包袱卡**、**首尾闭环**（婚礼—婚礼、点烟—点烟、对称之眼书挡）：结尾重复开场的动作或画面，再多给一样东西（血羽、剧名）。黑屏本身不是坑，空黑屏才是坑。
- 卡点前的镜长：竖屏言情最后 20% 放慢（慢 14–47%）；横屏志怪最后 20% 反而比中段快（结尾 0.8–2s 递紧），因为卡点前正好在打或在出事。

## 人设与台词

**人设组合**
- **面瘫捧哏 + 喜剧引擎**：主角情绪零波动（面瘫 / 淡定，全程站姿缓步），笑点全靠配角的崩溃和反应镜落地；引擎是失态的权力者（天道跪爬抱腿）或冷面吐槽役（师父「你管这叫老实」）。注意别让主角长时间当背景板，否则「双簧缺一只脚」。
- **尺度差二人组**：把一方缩进道具成小人，权力关系变成物理关系（俯视 / 揣兜）；逆转后用规则复述建立「可复制期待」。爽感要带裂缝——新反派的存在让逆转不彻底，才有追更欲。
- **祈愿即认罪群像**：反派不需要旁白定性，祈愿词同时完成人设、罪状与信息缺口（「这货自打到我手上便不吃不喝」——称人为「货」即罪）。
- **一物一梗功能角色**：每个妖怪的身体特征 = 它的麻烦 = 它的台词，一个特征只用一次、一个单元讲完；轴心角色（刺猬郎中）只说短句判词，冷面毒舌靠谱。角色设计自带的二创空间比台词值钱（观众会自己补「刺猬遇到医闹可以缩起来」）。
- **草台班子**：说书人 / 口技者 / 翻墙者 / 共情父亲各有一门手艺，倒叙揭底段给每人一个 2s 技能展示镜。
- **女性互助群像**：受害者即主谋；被压迫者用排比扩成群像（「被继母虐待的庶女 / 被卖给老翁的闺女 / 被卖进青楼的妹妹」），个案变共性。
- **异类 + 被照的几种人 + 第一个说破的人**：异类是镜子，苦妻是规则的第一个受害者，也是第一个说破规则的人。
- **怀疑论长辈 + 天真晚辈 + 被试的人**：观众知道局，主角不知道。设局手段要过一遍伦理，否则讨论会跑偏。
- **孤独凡人 + 善鬼**：一来一往的小恩情要拍两次以上，最后的牺牲才有分量。
- **民间手艺人主角**（戏班老班主、盲眼说书人）：干瘦、嘴碎、怕死但讲义气，本事全来自职业道具（红幕、空衣、铜铃、灯）。造型锚点三件套：八字胡 + 黑帽 + 背戏箱。
- **冷面降妖师 + 指控他的普通人**：主角几乎不说话，台词全给配角；误会段至少给主角一句回应。
- **想逃的女主 + 早看穿她的男主**；**白衣兄长 vs 黑红死对头**、**红甲将军 vs 蓝衣敌国太子**：两个男角色靠服色对立。古风言情男主服色以黑或黑红为主（师长身份可以白衣，身份变了再换红）。

**台词技巧**
- **规则句**（志怪专用）：每集至少一句由异类或设局者亲口说出的规则，主谓宾完整，≤15 字（「她心甘情愿养我，自然要拿东西换」「自尽之魂，不得轮回」「期限百日」「成仙是骗人的」）。金手指规则必须口语化到可复述（「我叫你一声，你敢答应吗」），验证后立即复述一遍。最好能单独截出来当评论区金句。
- **术语降格**：把世界观里最严肃的名词翻译成家务事——雷劫 → 孩子、仙魔对峙 → 家暴、处刑饭 → 断头饭。设定降格喜剧的笑点发动机。
- **定义式笑话**：用一个日常器物解释设定（「空灵根 = 漏勺：什么都能装，但什么都留不住」）。
- **三段排比 gag**：「X 攻击你 → X 自败」×3（雷劫散 / 法则断 / 封无可封），间隔 ≤6 秒，一次性立住无敌设定。
- **贯口**：多人各带一个自黑卖点轮报（三人 ≤25 秒）；一串物品名快报（每 0.6–0.7s 一个）再用反高潮细节收住（「阳春面不要葱」——评论会追着问放没放葱，留话头）。
- **暖句垫冷刀**：温情台词后 1.5s 内接冷刀（「师父你真好」→「断头饭」），冷刀前留半拍静场。
- **主题句复读翻义**：同一句话前后出现两次，第一次由受压迫者绝望地说，第二次由主角反讽地说（「人怎么斗得过仙」）。片名级台词留给高潮入口、由反派喊出，开场只字不提。
- **神性靠沉默**：神 / 巨物全片只说 ≤2 句规则语，不解释、不动情；巨物只给局部 + 带混响的声音（「吵死了」）。
- **原样回敬**：结算时原样复读取缔者开场的羞辱句。
- **配角嘴贱伏笔**：结尾前让配角一句玩笑把系列悬念说出口（「您老婆要是不认您」），再捂嘴找补（「祝您夫妻团聚」）。
- **祷告即认罪书**：让恶人自己数罪（「半辈子只给我下了个病秧子」——一句话立住重男轻女），无需旁白评判。
- **具体数字**：寓言用数字计量考验（「两文钱」「三条街」「50 两」「30 日」「饭钱八文，跑腿三文」）。数字让寓言具体。
- **短问短答**：撩拨段每句 1–2 秒、2–5 个字，一句一个镜头。
- **短指令串**：危机现场用 3–5 字指令（「放这儿」「靠住柱子」），配方言腔泄压（「我的天爷呀」）。
- **反派温柔腔**：越温柔越瘆人，「没良心的」像情人嗔怪。
- **誓言回收**、**称谓梗 / 句式回声**（「刚才还是 / 现在不是了」）、**内心吐槽 OS**（穿书者 OS 当旁白与对白交替，避免信息堆砌）、**谶语 / 打油诗**、**因果倒置贫嘴**（「她闹我才烫到的」——把责任推给不在场的人）。

**金句写法**
- **物理负担说心理负担**：「家得背，气也得喘」（= 房贷）、「刀快是本事，收不住就是毛病」（= 职场情绪管理），≤10 字，一秒对应现实痛点。
- 对仗收束：「鬼也好，人也罢，在这淄水相遇，便是缘分」。前半句两个对立词，后半句落到地名或物件上。
- 否定排比加转折：「跪天跪地跪父母，就是不会跪你」。
- 主宾互换：「不是你顾家不要我，是我沈若华不要你顾承安了」。
- 比喻规则：「纸沾了什么颜色便变成什么颜色」。物件 + 变化 + 人。
- **定义式收回**：先把承诺拉到最高，再用一句器物比喻一次性收回。
- 片名一字多义：选一个能同时指动作和道理的字（「渡」：渡河、渡人、渡己），观众会自己解读。
- 二创文案用意难平式提问（「能不能让他复活」），评论区会自发讲完整个故事。治愈系留「观众自己补」的空。

## 视听风格

**景别分布**
- 竖屏言情：特写和近景 70–80%，中景约 10%，全景和远景 15–25%（建立关系、摆排场）。
- 横屏写实志怪：近景和特写 35–55%，中景 20–40%，全景 15–25%。法术段走「人物近景 → 道具特写 → 效果全景」。
- 横屏志怪喜剧 / skit：特写 / 大特写 50–55%，中景 25–30%，全景约 15%。对话场三拍循环：「说话人中特写 → 听者反应特写 → 插入特写（手 / 物）」。
- 横屏仙侠漫剧：特写 40–60%，中景 25–30%，全景 / 大全 15–30%（奇观段全景占到 30%）。喜剧三拍：全景奇观 → 中景互动 → 特写反应。
- 横屏妖怪群像：**中景 / 双人镜约 55%**——两人对坐说话是主体，全景 20%，特写 15%。
- 横屏写实伪志怪：特写 35%、中景 40%、全景 25%；叙述段用「插入特写（物件 / 表情）→ 中景人物 → 全景交代关系」的旁白蒙太奇，不是对话正反打。
- 横屏 CG 奇观：远景和大全景约 35%，面具或眼睛大特写约 35%。
- 横屏 3D 言情二创：特写和近景约 55%，双人中景约 35%，全景约 10%。

**场内景别走法**
- 盘问 / 对峙场：全景定位 → 中景双人交换 → 特写施压 → 逆光剪影全景 → 大特写收，「宽定位—中交换—特收压」三段收敛。
- 反派入场：物件先于人的插镜阶梯（鞋跟 → 腿 → 被窝 → 脸 → 眼 → 反打）。
- 诊室 / 对话单元：固定站位秩序（「左轴心右来访者」全程保持），全景交代进门 → 中景双人对话 → 单人中近景收包袱。
- 威胁升级场：对称大全特效 → 人群全景 → 个体脸特写逐级收。

**运镜**
- AI 生成以固定机位 + 缓慢推近为共同底座；推近动机 = 揭示或「笑点落地」。
- 真运动只给四类：飞行 / 位移跟移、1–2s 运动模糊动作切（掩盖 AI 长动作弱点）、俯拍下推入水面 / 镜面（「进入另一个空间」）、背影向光源缓步（唯一带叙事方向的运动）。
- 三级推近（punch-in 三连推，三级逼近巨眼）：用剪辑制造运动感，不用真运镜。
- 揭秘用「缓推 + 下摇」，从脸往下看到脚；悬疑段用低位跟背影；撩拨段用缓推贴脸。
- 大动作放远景、主体小，形变看不出；人物位移多用剪影 / 逆光静止位代替走动长动作。
- 运动预算花在切点上而非镜头内：无手持晃动、无快速摇甩，「猛」的冲击交给闪白和切分。

**构图**
- **对称仪式感做书挡，怼脸特写做正文**：一点透视对称（天花板巨眼、金色天门、庙堂光束、云台白柱列队）标记世界观的「严肃」，怼脸偏置特写标记人物的「离谱」——构图反差本身就是喜剧。
- **尺度差构图**：俯视盆中小人（上帝视角）、低角度巨腿穿人群、天花板巨眼俯瞰——把权力关系直接画成物理尺寸关系。
- **框中框**：窗棂、门框、月洞门做框中框把人框住（深宅戏）；盆口圆框把男主的脸映进去；照影缸永远居中圆形构图。
- 上下位构图写权力：站 / 跪对角、祈愿者居画面下三分之一而神像 / 光束居上、天道跪地仰拍主角衣摆而主角始终占上位。
- 都市志怪：一点透视长走廊，规则标志反复入画。伪神揭秘：大殿对称纵深，画中人和真人同框，手伸出画框的那一下就是主题。
- 竖屏：大量前景遮挡（竹叶、纱帘、屏风、圆窗），人物放画面中上部，下方留字幕区。竖屏双人亲密镜两张脸上下错位不并排；横屏双人放对角线。
- 物证排场：嫁妆、聘礼、红榜排成一条透视线。

**光色**
- **全片只留一种高饱和色，并且挂在一个意义上**：翡翠绿 = 法术和怪眼；金色 = 男主；红幕 =「护」；渔灯暖橙是冷青夜河上唯一的暖点；红 = 死亡和婚嫁；血红 → 灵芽红构成「代价—翻身」同色母题；秩序金（天门）vs 崩坏紫（天裂）；红（被交易的深宅）vs 白（出逃与神异）双色板对立；紫色电光是唯一高饱和（毛球的萌与巨眼的凶是同一色系两面）。
- **色温硬切 = 世界 / 情绪切换**：暖宅 → 冷雪标记进入前世；日常暖褐 → 冷灰白 + 暗红血迹标记卡点危机；章节随色温换配器。
- 写实志怪的底色：冷白荧光加青灰（医院）；敦煌金、朱红、石青（壁画大殿）；墨绿青灰去饱和（夜河）；低饱和青灰 + 体积光束分「人间温度 vs 神域冷峻」；诊所暗木 + 青灰、酒楼橙红灯笼 + 白蒸汽、水巷高调天光蓝绿。
- 仙侠漫剧底色：冷青灰夜景内景 + 单暖源窗光烛光、冷灰蓝雾底 + 金门爆光、白云金光仙界高调。
- 港式聊斋：90 年代港片的暖黄绿胶片调色 + 柔焦 + 颗粒；法术用冷蓝光标「非人」。
- 竖屏言情：逆光和侧逆光，金色轮廓光，浅景深。白天暖金，夜戏冷蓝月光配烛火暖点。大婚整场铺满红金。

**美术**
- 志怪的核心道具要「中式且会变」：纸扎、头花、泥胎、锁链、红幕、灯、符、破盆、照影缸。变化本身就是叙事（头花变色、灯灭、泥脚开裂、神像裂纹 = 神承恶业）。
- **重复母题物件建 prop refs 并在最后一帧合拢**：照影缸一集两用（通讯 + 情报）、乌鸦 / 裂纹 / 花（枯 → 开）、破盆跨 6 镜同锈色、紫毛球与紫巨眼首尾对称。
- **拟人动物比真人脸更容易跨镜一致**：每只的识别点是物种轮廓（刺、壳、触手、复眼），嘴不需要精准对口型，观众容忍度高。
- **双画风系统**：写实主风格 + Q 版第二画风（同色系二头身），Q 版只用于演绎 / OS / 回忆，独立成段不与写实同镜混用；切换语法要先建立（首次切换前给 4 帧白闪），否则首看被误读为画风崩坏。
- **怪物用局部不用全身**：巨物只给一只眼睛、妖怪出现优先用投在窗纸 / 墙上的影子 + 声音 + 他人反应（事后看还是「人在演」的视觉伏笔）、只在暗光 / 雨夜 / 水下给全身。同一异类准备「可亲脸」和「可怖脸」各一张。
- 非人造型：人脸骨架 + 1–2 个动物或材质特征就够了（鳍耳、金瞳、泥胎脚）。
- 言情的核心道具要贯穿全场（一只青瓷药瓶出现在约 15 镜；染血玉佩是认尸证据）。
- 古籍和出处：古文原文竖排字幕、「改编自」角标；改编公域文本要标出处，否则被质疑原创性。
- 场景资产复用 + 统一 LUT：石院 / 云海 / 金门连用、诊所布景连用 100s 以上、暖褐 + 青灰统一调色颗粒。

**竖屏 vs 横屏**
- **横屏（16:9）**：志怪 / 仙侠全部验证于横屏。双人中景、大殿纵深、群像列队、巨物尺度都需要横向画幅；横屏漫剧走「番剧感」，适合投屏（观众会留言「要可以投到电视上看就好」）。在竖屏平台上可以直接发横屏，上下留黑。
- **竖屏（9:16）**：目前只验证过言情，走「信息流感」。近景对切加前景遮挡，字幕放中下部，每句台词一个镜头。**竖屏志怪至今没有验证过，不要直接套横屏的节奏数字。**

## 剪辑节奏基准

| 类别 | 平均镜长 | 要点 |
|---|---|---|
| 竖屏古风言情 | **1.9–2.3s**，每分钟 26–32 镜 | 超过 5 秒的镜头 ≤6%；前 15 秒最快（约 1.15–2.5s），最后 20% 放慢到 2.15–2.93s |
| 横屏动作志怪 | **2.0–2.2s**，中位 1.4–1.8s | 爆发段每镜 0.25–0.4s，最多 10 秒；每分钟约 30 镜 |
| 横屏 CG 奇观 | 约 2.9s | 慢 4.3 → 爆 1.6 → 中 3.1 |
| 横屏聊斋寓言 | **4–5s** 能成立 | 单镜超过 10 秒的对话拆出至少 2 个反应镜；超过 5 秒的镜头 ≤42% |
| 横屏志怪喜剧 / skit | **1.3–1.5s**，每分钟 42–45 镜 | 快切服务于笑点密度（30–40s 一次反转或笑点），对话镜仍要给 1.5–4.2s 让包袱落地 |
| 横屏仙侠漫剧连载 | **2.8–3.5s** | 「动作快、独白慢」二元节奏：验证 / 爆点段 0.2–1.2s，对话段 3–8s |
| 横屏旁白 / 群像慢档 | **5–5.5s** 能成立 | 前提是台词密度撑节奏（270s 约 80 句）或旁白一句一镜推进 |
| 卡点混剪 | 快段约 0.45–0.5s，慢段 1.5–2.5s | 「慢—快—慢」，快段就是回忆，86% 的镜头短于 1s |
| 横屏言情叙事二创 | 约 3.5s | |

**硬规则**
- **氛围段不能用喜剧的快切**：志怪氛围镜（神像、空镜、仪式）至少停 2.4–3s；用 1.3s 的 ASL 把神域空镜切碎，「氛围刚起即走」。
- **闪切下限 0.25s**：低于 0.2s 在部分设备被读成卡顿 / 坏帧；过切牺牲因果可读性。闪切只允许用于物理喜剧 gag、动作爆点和三级推近。
- **对话喜剧长镜 ≤8s，每 3–4s 内切一个反应特写**（超长对话镜会被评「全是口水仗」）；**独白长镜 ≤10s 且拆三镜**——道具 / 铭文特写 → 人脸 → 听者反应（19s 独白长镜是全片最大弃剧风险点）。
- **节奏笑话上限 6 切**：同构连切（十四连 1s「哎」喘气切）超过 6 次喜剧递减；砍到 6 个并做音高递进。
- **反应镜规则**：报应 / 打击后反应镜比动作镜长 0.3–0.7s 让情绪落地；笑点后给 1–2s 冷面静止反应当句号（每个离谱台词后 1s 内必给听者静止脸）；群体反应用大全景做笑点收束。
- **奇观揭示镜至少停 3s 再切反应**。
- **呼吸式快慢分布**：全片只放一个爆发段，前后都夹长镜；喜剧全片曲线「碎切蒙太奇（最快）→ 对话长镜（慢）→ 反应链（中）→ 收尾三连（慢）」。追击段要加速不要减速。
- **「施压—反应」对打剪辑**：对白场每次施压后必切对方脸特写（羞辱 → 怒脸，盘问 → 隐忍血脸），让对白场有动作场的节奏。
- 台词：竖屏言情每秒约 3.5 字，单句 1–2 秒、2–8 字；群像慢档靠台词密度撑节奏（每句 ≤8 字、一来一回两句一个包袱）；喜剧 skit 平均句长 <10 字。

**审核参数**（写进 storyboard 的 `project.asl` / `project.hook`）

```json
"project": { "genre": "short-drama", "asl": [1.9, 2.3], "hook": 3 }
```

横屏动作志怪改 `"asl": [2.0, 2.4]`；横屏志怪寓言改 `"asl": [3.5, 5.0]`、`"hook": 5`；喜剧 skit 改 `"asl": [1.3, 1.5]`；仙侠漫剧连载改 `"asl": [2.8, 3.5]`；旁白群像慢档改 `"asl": [5.0, 5.5]`，每个长镜在 `pace_note` 写明镜内推进的台词或事件；卡点混剪改 `"asl": [0.5, 1.0]`。双人对话长镜写 `pace_note`。

## AI 制作要点

1. **口型的第一解法是画外音**：说书人旁白 + 蒙太奇（80% 信息由旁白承载）、穿书者 OS 与对白交替、内心独白承担规则解释与两难陈述、祈愿者第一人称独白、配音剧惯例 + 侧脸 / 捂嘴 / 低头特写、短句 + 嘴部小幅特写。需要开口的只给短句近景；长段情绪交给独白、背影或歌曲。
2. **顶级战力与长动作一律画外**：只拍结果与物件——「收人」只给 0.2s 闪白 + 光丝入盆、「一掌碎法则」只拍破门裂口与震惊脸、变驴只拍驴蹄 / 驴头、闹狐用窗格影子、大动作放远景主体极小、1–2s 运动模糊切代替完整动作。这是「断续剪辑代替完整打斗」的 AI 版。
3. **尺度差 trick 规避多人互动**：把一方缩进道具成小人，全片无同框肢体接触；巨物只生成局部（一只眼），成本与穿帮双降；群戏只给对称列队全景或各干各事的平行动作，近景永远 ≤2 人。
4. **手部问题改写成设定**：多肢 / 异形肢（蜈蚣脚、章鱼触手、蛤蟆蹼）崩了也像设定，「蛤蟆握不成拳」甚至直接拿手做不好当笑点；人手只拍持物短插入（握玉、缚绳、捧球），不拍持续精细操作；石手代替人手收尾。
5. **角色一致性**：每个角色锁 3 个不撞的锚点——发冠 / 发型 + 服装主色 + 面部记号（抹额、泪痣、疤、金瞳、额头朱砂点）；同外形角色用竖排名字卡补识人；**拟人动物比真人脸好保**；重复道具建 prop refs（破盆同锈色跨 6 镜）。
6. **角色撞脸和明星脸**：「几个男角色怎么长得都差不多」是最常见吐槽；生成结果被认出像某位明星，讨论被带偏还有肖像风险。提示词里不写明星名，出图后拿 refs 和常见明星脸比一遍。
7. **配音三坑**：现成音色会被听出「像某明星」削弱角色辨识度；克隆知名配音演员声线有版权 / 口碑风险；音色辨识度本身可以是卖点（特色声线会被大量评论点赞）——好配音值得在简介署名。每个角色用不同音色，语速按性格分（天道语速快、主角语速慢 = 性格声纹）。
8. **混音：人声明确高于 BGM**：BGM / 音效压过人声会让语音转写整段失效，影响字幕生成与平台理解。
9. **文本工序质检**：字幕错别字密集、结尾句循环重复十余次，损耗世界观可信度；同音梗密度高的片子字幕要同步校正。
10. **画风切换语法先教后用**：写实 ↔ Q 版切换只用于演绎 / OS / 回忆，切换点落在台词气口，首次切换前给白闪提示；语法未建立时两度往返会被误读为画风崩坏。
11. **生产单元**：15s 一条生成、每条只承载一个节拍（一个病人 / 一个包袱），条内给「全景—双人中景—单人反应」三镜；但要在中间插短条打破机械感。
12. **规则不可见就给指示物**：规则配一个每集都出现、生成稳定的指示物（头花颜色、锁链、灯火、破盆、照影缸、紫毛球），建成 prop refs，每次变化单独出一镜特写。
13. **身体状态和物理不连续**：「摔伤了腿，跑起来健步如飞」。角色有伤、有孕、看不见时，之后每一个走动镜头的提示词都写明这个状态；打斗角色穿贴身衣服，不披外套。
14. **打不出「命中」**：用法器效果（水柱、布、光刃、符阵）代替肢体接触，真实接触最多 2 次；每次出招后接一个后果特写，否则评论会问「法术命中率这么低」。
15. **画面里的汉字**：卷轴、匾额、招牌、片名、字卡都生成空白底，字在后期贴；场景内避免剧情文字道具（符纸做成无字金卷）。
16. **统一质感**：一层统一调色 + 颗粒压平镜头间生成差异；叠化少用，用多了像在藏瑕疵。
17. **设定逻辑漏洞会被评论抓住**：「失忆了都找夫君」「女主莫名其妙就恨上」——反派仇恨要给一个 POV 或回忆镜落地；失忆、错认、试炼类设定要给画面上的理由或规则补丁。
18. **系列导航与入口**：剧名 / 合集名角标必须常驻或片尾露出，否则评论区全在问剧名；中段集开头 5 秒补一句前情；上线前囤够集数。
19. **AI 标识**：放画面最下沿小字或固定角标（「AI 生成 · 仅供娱乐」），不要压到字幕区。
20. **软色情服化会劫持记忆点**：擦边服化的最高赞评论会稀释叙事钩子的讨论，还引发监管类吐槽。服化卖点可以有，但别让它盖过规则钩子。
21. **付费 / 变现链路损耗口碑**：付费墙怨气会进热评（「要钱不看了」）；投放前先想好免费段与卡点集的关系。

## 大导演工具箱

|---|---|---|---|

## 禁忌

- 前 25 秒以上全是旁白加空镜，没有角色原声，也没有事发生。
- 用署名压空镜开场，或者片名单独停超过 5 秒。
- 竖屏言情里超过 5 秒的镜头占三成以上；任何片种里超过 10 秒的对话镜头不拆反应镜；超过 8 秒的对话喜剧长镜；超过 10 秒的独白长镜不拆。
- **低于 0.25s 的闪切直接入片**（设备读成卡顿 / 坏帧）；同构节奏笑话连切超过 6 次。
- **氛围段用喜剧的快切**。
- 追击和对决段反而放长镜。
- **卡点零铺垫硬切**（与全片调性断裂）；**大反转晚于 60% 且前段无「叙事不可靠」小钩**。
- **反派仇恨没有动机镜头**；压迫全靠台词堆叠、反派无实质威胁动作（「说出来的坏」）。
- 角色共用一张脸、一套服色；直接用明星脸；现成音色不区分角色、克隆知名声线不署名。
- 志怪把妖异写成纯恶，没有规则，也不翻面。观众会主动替异类翻案。
- 规则只在台词里存在，画面上没有指示物。
- 主角从头沉默到尾；面瘫捧哏主角长时间当背景板、喜剧全压配角一人。
- 试炼或设局手段在伦理上荒诞，而且没有规则补丁。
- 打斗想靠 AI 拍肢体接触，或者有伤的角色在下一镜健步如飞。
- 让 AI 直接生成匾额、卷轴、红榜、招牌上的汉字；字幕错别字与循环重复句不做质检。
- **软色情服化当主卖点**。
- **改编公域文本不标出处**。
- 集尾黑屏但上面没有新信息或撩语（空黑屏才是坑）；亲密戏卡点之后再加抒情余韵。
- **片内不露剧名 / 集数、长合集无章节卡**；系列中段集没有前情入口；单集爆款无后续储备。
- **人声被 BGM 压住**（转写失效、字幕和平台理解都出问题）。
- 简介文案写得比成片好、最好的反转台词被剪掉。
- 现实映射过重而不卸力（每个苦点后必须跟一个笑点）。
