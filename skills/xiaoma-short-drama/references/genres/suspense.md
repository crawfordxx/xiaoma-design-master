# 悬疑刑侦

> v0.3。例子和 logline 都是自拟的。

## 定义与情绪承诺

观众要的是「我比角色多知道一点，我能跟着推，答案在下一集」（连载），或「看完必须回看、必须进评论区对答案」（完结短片）。一集兑现三件事：

1. **不适感**：开头 3 秒看到一个不该出现的东西（尸体局部、蒙眼石像、成群直立的动物、门缝下的白鞋、把头发撒进鸡饲料的手），或听到一句不该这么说的话（把手术台上的孩子叫「这批货」、母亲对女儿吼「怎么死的不是你」）。不适可以是生理的，也可以是道德的。
2. **秩序感**：按固定间隔递一条新线索或新疑点（≤3 分钟的单集每 10–25 秒一次，5 分钟长首集每 25–40 秒一次）。氛围类用「异常信号」替代线索，间隔同样约 20 秒。
3. **秩序被打破**：集尾用一个越出常理的证物、一个新对手或一句挑衅，把刚建立的推理掀翻（死者来电、外面的雨是黑的、身后楼梯上的白鞋、洞找到了人没出现、耳边一声低语、黑底白字的问句）。

**数据基准**：连续剧形态收藏率 15–43%，单本完结短片 8–14%；分享率和恐惧强度正相关（民俗遇鬼向分享/点赞可到 50% 以上，细思极恐向 20–30%）。观众四大高频差评，写分镜前逐条预防：①关键规则交代太晚（「为啥不开枪」刷屏）；②主角降智或没有主动性；③逻辑/空间漏洞（「隔壁杀人他没听到？」）；④只上一集或单集太短。

| 相邻片种 | 它卖什么 | 悬疑刑侦卖什么 | 判别动作 |
|---|---|---|---|
| 竖屏爽剧 | 情绪兑现：受辱 → 打脸 | 信息兑现：线索 → 推翻 | 每次转折是「一条新信息」，不是「一次出气」；打脸也必须带一条推理 |
| 纯恐怖 | 惊吓本身，不求解 | 惊吓只是线索的包装 | 每个吓人镜头后面都跟一个「这说明什么」的台词或证物 |
| 心理惊悚 | 主观崩溃 | 主观崩溃也要留可以核对的客观证据 | 不可靠叙事至少埋两组互相矛盾的画面证据 |
| 玄幻异能 | 能力展示 | 规则和代价 | 异能、系统、特殊体质只能帮主角「看见」，结论仍要靠证物推出来；给金手指一个可推理的物理线索（「他的声音很空旷」），最好再加代价（听完手抖、流鼻血） |
| 温情志怪 | 思念、和解 | 真相 | 悬疑外壳 + 温情内核能拿高分享，但不要指望它追更；做系列必须回到「谜面」 |
| 情感虐恋挂悬疑标签 | 爽—虐—更虐的情绪过山车，谜底只有一个 | 谜面是结构主线，线索可推理 | 挂了推理标签、评论区却没人讨论推理，就是承诺没有兑现；标签蹭流量会被识别 |

## 子类型

| 子类型 | 卖点公式 | logline（自拟） |
|---|---|---|
| 写实程序流 | 地方性的尸体发现 + 一张排查清单 + 集尾一个越界信息 | 城郊排污渠里漂出一只裹着蓝雨衣的行李箱，警方刚锁定送煤气的嫌疑人，失踪者的手机却给办案民警发来一句「别找了」。 |
| 神探本格推理 | 主探被看轻 → 10 秒内亮能力 → 每 60–90 秒一次推理反转 → 证物指向最热心的人 | 深冬，县中冰湖下冻着一个穿校服的人，被派来的「专家」是个刚毕业的女孩，她只看了一眼冰面的气泡，就说人是死后才放进去的。 |
| 真实案件倒叙 | 第一秒给凶手 → 看他在亲人、警察、镜头前演戏 → 刑警用他自己的原话拆穿 | 丈夫报警说妻子半夜离家出走，可小区三个出口的监控都没拍到她，只有当晚他家的电表在凌晨跳了四个小时。 |
| 社会派冷案重启 | 前史直击罪行 + 一句物化受害者的台词 →「X 年后」字卡 → 同一个人名在新时代被喊出 → 砸开一道物理的门，罪证一次显形 | 二十年前福利院大火「烧死」的七个孩子，名字全出现在一家私立医院的捐献者档案里；当年唯一活下来的保育员，如今在给院长开车。 |
| 连环仪式杀人 | 死法 = 死者的罪 + 每集固定的尸体特写开场 + 主角身边的日常物件长出「眼睛」 | 第三个死者是收费的「情感导师」，被锁在自己的直播间里，嘴被缝上，桌上摆着他所有付费课的讲义；当晚女主收到一个快递，里面是同款针线。 |
| 封闭空间误认 | 广播先报 2–3 条凶手特征 → 一个完全符合的人走进电梯 / 车厢 → 喜剧泄压 → 他不是凶手，真凶在他身后 | 台风夜，广播说越狱犯左手缠着纱布；末班公交上，一个左手缠纱布的男人坐到女司机身后，他其实是来押解的便衣，真正的逃犯坐在最后一排，正给他递纸巾。 |
| 不可靠叙事 | 质疑证词开场 → 前 1/3 整段翻成妄想 → 情感真相 → 假结局 → 二次反转 | 消防员在火场救出一个自称邻居的男人，男人说屋里没人了；醒来时他躺在病房，队友说那场火是一个月前的事，屋里烧死的是他妻子，可探视登记簿上，那个「邻居」昨天刚来过。 |
| 金手指刑侦 | 主角被冤成嫌疑人 → 审讯室里获得系统 / 体质 / 读取能力 → 用它推理自证清白 → 当场补上专业人员没看到的一环 → 和冷脸队长组 CP | 殡仪馆化妆师给女尸补妆时说了句「她不是淹死的」，当场被当成嫌疑人带走；关进审讯室那一刻，她发现自己能听见死者最后 30 秒的声音。 |
| 海龟汤式完结短片 | 一条民间规则立在前 10 秒 → 每 10–15 秒推翻一次「谁是活人」→ 对称空镜揭底不给台词 → 黑底白字问句收，答案交给评论区 | 家宴上女儿指着妈妈说「她昨天已经走了」，爸爸笑着说女儿发烧说胡话；电视里正播讣告，照片上三个人，餐桌上只摆了两副碗筷——第三副是谁的？ |
| 异能探案 / 物品通灵 | 一句台词 5 秒直给金手指 → 三段式当场验证（笑点 → 泪点 → 正案）→ 权威怀疑 → 用可推理的物理线索回收 → 结尾「找到入口没找到人」 | 当铺老板娘摸到什么就能听见物品原主的最后一句话；警察请她听一把凶器，她听见的却是自己的声音在说「别报警」。 |
| 邻门凶手 / 居家悬疑 | 独白把威胁放进主角空间 → 主角装作没看见 → 片名后揭示他早已察觉（信息重排爽点）→ 违令调查 → 撞见凶手正在隔壁动手 | 夜班保安每晚都听见楼上拖着箱子走的声音；他把摄像头对准楼道，画面里拖着箱子的，是这栋楼的物业经理。 |
| 怪物灾变 + 国家应对 | 刑侦开局（警察上门）→ 16–20% 处附身反转、到场力量全灭 → 黑场换挡 → 指挥 / 封锁 / 特战逐级升级，每段一个固定色温 → 悬念挂在窗口外 | 警方处置一起家暴报警，四人进屋再无声音；十二小时后全城警报拉响，特战队拿到的第一条命令是「不许看她的眼睛」。 |
| 民俗规则怪谈 / 借命 | 怪异行为特写 + 异常三连开场 → 可数的替身一只只死（倒计时可视化）→ 规则立下 30 秒内被触发 → 揭秘「这条命是借的」→ 债主上门，亲人决定替死 | 守夜的儿子发现父亲二十年来每月喂流浪狗一撮自己的指甲；狗死的那天晚上，门外传来和父亲一模一样的声音叫他开门。 |
| 天才画像师单元探案 | 谜面自带社会黑幕 → 双认罪或口供拉扯 → 天才签名镜推理 → 群体场景一次揭底 → 竖排预告条钩下一集 | 拐卖案嫌疑人自称失忆，画像师注意到他掌心的茧是握手术刀磨出来的，不是握锄头。 |
| 山野遇鬼 / 民俗恐怖 | 禁忌意象 2 镜冷开 → 立刻切回日常代入 → 异常人群「站着不动整齐看镜头」→ 消失 → 以伤者形态重现 | 独自徒步的女生在垭口遇到一队穿同款雨衣的登山客，拍照时镜头里只有她一个人；下山时，其中一个躺在观景台的木板上，还活着。 |
| 民俗禁忌悬疑 | 一个被封住的东西 + 一个手欠的人 + 异兆逐级升级（物 → 天 → 人） | 修水库的工人从坝基里挖出一口贴满黄符的石棺，包工头让人撕了一角看看，第二天全村的井水都变成了红色。 |
| 怪物灾变 + 异能（群像向） | 观众先看见怪物 → 群像在压抑里探索 → 最后 1/4 异能者用火光一次放完 | 考场突然断电起雾，考生们发现监考老师的影子在墙上多长了两只手，一个背着桃木剑的转学生推门进来。 |
| 时空错位 / 宿命 | 一部能打到另一个时间的电话 + 一个必须避开的日期 | 女孩用旧手机号打出去，接电话的是三年前的陌生男生，她查到他三天后会死在一场火灾里。 |
| 温情志怪（边界） | 民俗禁物活了 + 孤老的未竟心愿 | 奶奶给去世的老伴扎了个纸人准备烧掉，纸人却站起来，拉着她去照一张从没照过的结婚照。 |

- **按发布形态选子类型**：单集 ≤2 分钟的试水作品选「海龟汤式完结短片」（45 秒也能成立）或「封闭空间误认」；要做连载选「社会派冷案」「连环仪式」「金手指刑侦」「民俗规则怪谈」「怪物灾变」「单元探案」，它们的前提本身能撑多集。但连载首发必须备 2–3 集（见禁忌）。
- **前提即传播**：社会派题材把一句都市传说直接写成标题（「孤儿院失踪的孩子全成了器官供体」），评论区会自己讨论现实；一个词概括黑幕（「被掏空的巢」）同理。

## 单集结构模板

**镜数**：推理 / 程序 / 审讯类按平均镜长 1.7–3.4s 算，60s 约 18–35 镜，90s 约 26–53 镜，3min 约 53–105 镜。氛围 / 恐惧类按 3.7–5.4s 算，2min 约 22–32 镜，3min 约 33–49 镜。对话复盘主导的居家悬疑可到 5–8s 一镜，但要靠信息重排撑住。

**主反转位置分两型**：
- **揭示型**（谁是凶手 / 真相是什么）：主反转在 65–90%。
- **威胁确认型**（怪物 / 附身 / 危险近身）：主反转可提前到 15–25%，之后靠规模升级续压，每 60–90 秒升一级（一户 → 指挥中心 → 城市封锁 → 特战进场）。

### 3min（120–220s，主模板）

| 节拍 | 占比 | 做什么 |
|---|---|---|
| 钩子 | 0–4%（0–7s） | 2 镜：异常物、凶案局部、一句指控或独白把威胁放进主角空间。氛围类允许禁忌意象冷开 2 镜，但要在 0:03 处插 1 秒最强恐怖画面预告防划走 |
| 定调 + 入局 | 4–15% | 年代地点字卡或新闻旁白定性案件规模；15 秒内完成「凶手—受害者—行凶」三件事，或堆完「异常三连」 |
| 谜面 / 威胁成立 | 15–30% | 谁来查、谜面是什么（双人认罪、门后有人）；威胁确认型在这里完成「她变了」 |
| （威胁型）升级链 | 30–60% | 每 60–90 秒升一级规模，黑场分段、每段一个固定色温（家暖 → 指挥冷蓝 → 街道阴灰） |
| 线索递进 / 拉扯 | 30–65% | 揭示型每 10–25 秒一条新线索；审讯戏 1 秒一轮逐条拆口供；中段放一个假答案或红鲱鱼 |
| 复盘 / 半揭示 | 55–75% | 主反转前的小爽点：逐条回收前段三个细节并重插原镜头，或一次签名镜推理 |
| 主反转 | 65–90% | 用嫌疑人自己前面说过的话拆穿他，或用物证推翻身份；揭秘后紧跟二次反转（「变的不是鸡，是你」式的调包） |
| 升级 / 假结局 | 85–94% | 一个具体证物把矛头指向意外的人；或先给「他接受了现实」的假收束，再让那个人出现在走廊尽头 |
| 卡点 | 最后 8–11s | 越界信息、身后有人、「找到入口没找到人」、行凶开始的第一秒切黑、单字问答配黑屏；连载可加竖排「下集预告」画面条（给画面，不给「未完待续」四个字） |

- **氛围慢热变体**（2min、24 镜、平均镜长约 5s）：禁忌意象冷开 → 16s 日常跟拍代入 → 每约 20 秒一个异常信号（死鸟 → 断信号 → 凝视人群 → 消失 → 倒地者）→ 前 90% 全是长镜，最后 7 秒 4–6 个闪切 + 黑场。慢可以成立且分享率极高，代价是「只有一集」的怨气也最重，且开场意象最好当集回收。
- **5min 长首集**：0–50s 前史或冷开场直击罪行；50s–1:10 时间跳切 + 主角团入场；1:10–3:40 每 25–40 秒一个调查节拍，中间放一次惊吓点；揭示型主揭示在 3:45–4:15，威胁确认型可在 0:52 就翻；民俗怪谈用双计时器撑长段（「还有三只」+「还有三天」，两条倒计时尽早并行）；4:40–5:00 新嫌疑人、新对手或进场悬念作下一集的钩。

### 90s（85–98s，两个实测变体）

**变体 A：封闭空间误认**

| 节拍 | 占比 | 做什么 |
|---|---|---|
| 钩子 | 0–3% | 受害者画面 + 新闻或广播播报，3 秒内定性「有凶手在逃」 |
| 设定 + 匹配 | 3–15% | 片名卡；播报给出 2–3 条拍得出来的凶手特征；一个完全符合的人走进封闭空间 |
| 怀疑加压 | 15–40% | 用计时器（电梯楼层、站点、倒数）压迫；配一个市井小人物做喜剧泄压 |
| 第一次摇摆 | 40–60% | 嫌疑人说出不像凶手的话，紧跟一句双关把怀疑拉回 |
| 新疑点 | 60–75% | 离开封闭空间，切一个 10s 以上长镜，带出环境线索（声控灯亮着 = 楼梯上有人） |
| 主反转 | 75–90% | 嫌疑人身份翻转（他是刑警），同时插一个 3 秒真凶细节镜（白鞋站在台阶上） |
| 卡点 | 90–100% | 主角回头，停在看见真凶前一拍 |

**变体 B：异能验证型**

| 节拍 | 占比 | 做什么 |
|---|---|---|
| 设定直给 | 0–8% | 一句台词 5 秒内交代金手指（「你摸到物品，就能复述主人最后说的话」），一个 7s 长镜不急着切 |
| 验证一（笑点） | 8–19% | 生活化小物件当场验证（皮夹 →「私房钱藏冰箱最底下」），对手一句反应收证明（「我爸确实这么说过」） |
| 验证二（泪点） | 19–29% | 同一套镜头模式换重物（钻戒 →「下辈子我还嫁你」），顺手给验证者一层背景伤口（丧妻） |
| 进正案 | 29–46% | 案件物件登场，能力输出求救句（「我要死在后山山洞里」） |
| 冲突怀疑 | 46–58% | 权威否定（「后山根本没有山洞」）；主角用可推理的物理细节顶回去（「他的声音很空旷」） |
| 行动 + 阻力 | 58–95% | 夜搜，怀疑再压一次；线索快切段加速（0.3–1.1s），悬念收紧 |
| 卡点 | 95–100% | 「真的有洞」——找到入口，不找到人；揭示留给下一集；接「纯属虚构」免责黑卡 |

- 90s 单集必须交付「一个完整的小反转 + 一个新钩子」。只有一集在线时，催更会变成怨气：首发至少 2–3 集，或把单集做到 3 分钟以上。

### 60s（45–60s，完结解谜型）

| 节拍 | 占比 | 做什么 |
|---|---|---|
| 指控钩子 | 0–9%（0–4s） | 第一句台词就是指控（「你不是我妈」）+ 一个反常细节特写（「我妈从来不吃鱼」） |
| 立规则 | 9–23% | 一句民间口头禅立下超自然规则（「鱼死不瞑目，能看见不干净的东西」），后面所有反转都必须能用它解释 |
| 第一层站队 | 23–45% | 观众被引导怀疑 A；A 辩解（重复「我真是你妈」，重复本身让观众起疑） |
| 反转 1 | 45–64% | B 入场一句话推翻（「她儿子一年前已经溺水身亡了」），配 A 的困惑反应镜同步错愕 |
| 反转 2 | 70–86% | 客观信息插入镜（新闻「三人落水，两死一生」）当转场，把剧情变成观众要自己算的数学题 |
| 反转 3 + 揭底 | 86–95% | 对称空镜一次揭底（母亲独坐、两边空椅子、桌心那条鱼），不用台词解释 |
| 卡点 | 95–100% | 黑底白字问句点题眼（「那条鱼是做给谁吃的？」），把答案交给评论区 |

- 反转密度：45–60s 完结短片每 10–15 秒推翻一次，这是全片种最高密度，只适用于完结解谜型；连载型不要照抄。
- **爽点分三种**：智商爽（推理打脸、信息重排）、火力爽（异能放大招、砸锁）、认知爽（每 10 余秒推翻一次「谁是活人」）。一集只主打一种；火力爽放在 75% 左右，紧接着给它砸出来的罪证。
- **标题承诺放到后段兑现**（「死者来电」「借命」都在 2 分半以后才点题），前面靠线索密度续命；但开场就要露出承诺物的一角。

## 反转、爽点与卡点

**反转**

- **伏笔三处叠加**：真凶被点破前至少露 3 次破绽（身上有怪味 → 恰好路过 → 主动说出死者名字），集尾再用一个证物收口。
- **规则型悬念**：前 10 秒用一句民间口头禅立一条超自然规则（「鱼死不瞑目，能看见不干净的东西」），后面每次反转都必须能用这条规则解释；观众回看时发现规则本身就是答案。规则怪谈同理：规则立下后 30 秒内让它被触发或违反，并在规则台词里埋一个反常例外（「听见谁叫你都别答应」「包括我」）。
- **配角先说特征，主角做相反动作**：让配角在辩护台词里说出「我从小打她，她都不敢抬眼的」，下一拍她抬眼、微笑、说一句两个字的话。反讽台词同时是伏笔。
- **信息重排 / 装傻揭示**：主角先「装作没看见」（门口摸猫、自言自语），片名卡之后一句独白揭示他早已察觉；复盘段把前段埋的每个视觉细节逐条点名回收（血腥味 / 猫 / 白鞋），回收处重插原镜头并补一个没给过的新角度。回放要带来新信息，不只是解释。
- **双计时器**：一组可数的替身（「还有三只」，每死一只报数）+ 一个日期倒计时（「还有三天」→「提前了」），两条计时从开场就并行，把悬念做成画面里看得见的东西。
- **对称空镜揭底**：最后一次反转不用台词，用一个对称全景完成（母亲独坐、两边空椅子、桌心的鱼）。从极紧的景别突然「拉开」到极松。
- **客观数字变数学题**：插入新闻播报或档案镜头给出可计算的客观事实（「三人落水，两人当场溺亡，一人存活」），让观众自己算谁活着。注意时间逻辑：一年前的事故别写成今日新闻，改「一周年」字样或「看回放」。
- **对立识别细节**：给主角和真凶各设计一个能并排比较的细节（主角黑鞋 / 真凶白鞋），真凶的那一个用 3 秒低机位插入镜揭示，观众会自己完成推理并把它顶成高赞评论。
- **同一事实讲两遍，主语换人**：先让可疑的人说「我把黑色轿车里的女人拖了出来」，后面让同事说「是你把她救出来的」。
- **死法 = 罪**：死法和死者的罪一一对应（写恶评的人被自己的恶评塞嘴）；开场露出对应物的一角，中后段完整展开。
- **主动解释的人可疑**：嫌疑人每次开口都在解释「她为什么会走」，从不回答「她怎么走的」；顶罪者反复强调动机。写台词时给嫌疑人 3 次以上「主动补充」。
- **越平静越可疑**：可疑者全程不动、语气平铺直叙，反衬主角越来越急。
- **用证物推翻身份**：反转要落在一个能特写的物件上（镜像纹身、指纹与骨盆体征、十五年前的旧头发），不靠台词宣布。
- **开头的证物在结尾回扣**：电子钟回扣两处用水时间；母题物件三次出现；猫和白鞋在复盘段回收。
- **跨时代同名**：冷案重启剧让同一个人名在两个时代各被说出一次。
- **给搭档埋一个不解释的异常表情**：只放一次、约 1–2 秒的冷脸特写，评论区会自己生成第二条悬念线。
- **物理细节留给「细节党」**：在亡者 / 真凶身上放一个可回看发现的物理细节（湿头发、门口的水渍），再加一个 0.5s 的下意识信号（发梢滴到桌上的一滴水）给第一遍看的人。
- **红鲱鱼要有名字和动机**：被开除的醉汉、送货说不出地址的人、看见特征就喊抓人的大妈。
- **开放结局先给情感落点**：事实层可以不给答案，但线索要指向唯一答案、情感层要定。唯一答案 + 开放情感是最优解。

**爽点（悬疑版五环链）**：现象 → 主探看见别人没看见的细节 → 一句「现象—机关—结论」三段式台词（每句约 2 秒）→ 证物插入特写 → 质疑者的脸僵住。

- **推理台词说到的每个体征，配一个 0.5s 的证据插入特写**，不要只给说话脸（「信息只走耳朵」是最常见的批评）。写法：肾衰腹水 = 浮肿眼皮 + 关节色素沉着 + 下坠腹部，三个插入镜各 0.5s。
- **用配角惊叹抬主角**：「这你都看得出来」——神不自己说，让旁边的人说。
- **能力验证做三次，按「笑点 → 泪点 → 正案」递进**：每次复用同一套镜头模式（推物 → 指尖触物 → 复述 → 反应），同一输出格式先逗笑再催泪再进案。
- **打脸对象选偏见者，不选专业者**：要让主角超过专业人员时，让专业人员先给出正确的一半（「是刀伤」），主角补上他没看到的一半（「刀是新买的」）。
- **火力爽要先抬代价**：先立「军工级磁吸锁」再砸开；抬了门槛就要给合理破法，否则观众笑场。
- **每个爆点按「揭示镜 → 1–2 个主角反应镜 → 物证细节特写」三拍剪**；氛围类拉成四步：回头 → 主观全景揭示 → 反应近景 → 空镜确认。反应镜 2–6s，比物证镜长，情绪落在人脸上。

**卡点（12 种）**

| 卡点 | 写法 |
|---|---|
| 新对手 / 新目标入场 | 「听说这边又出了新案子」，停在他摘墨镜前 |
| 越界信息 | 听筒里：「我是你们昨天捞上来的那个人。」 |
| 身后有人 | 主角回头，切楼梯台阶上一双白鞋，停在看清之前 |
| 异兆报告 | 「老大，外面的雨——是黑的。」切窗外黑雨远景 |
| 证物指人 | 「这种防腐剂，学校里谁用得着？」切门口那人的背影 |
| 隔线对峙 | 凶手：「那只能说明你们还没找到。」切抽污管空镜 |
| 二次反转 + 空间揭示 | 镜头穿过铁窗升高，俯瞰满院病号服 |
| 定格亮相（异能向） | 两人背靠背站定，符箓螺旋升起，停住 |
| 找到入口没找到人 | 「真的有洞」，两张被手电打亮的惊愕脸，洞内不揭示 |
| 单字问答 + 黑屏 | 黑场闪切里贴耳低语「谁？」「我。」——把威胁放到主角身后 |
| 黑底白字问句（完结短片专用） | 对称空镜揭底后，黑底白字点题眼：「那条鱼是做给谁吃的？」答案交给评论区 |
| 行凶开始的第一秒切黑 | 撞见凶手正在隔壁拖人，动作发生的第一秒切黑，不给过程 |

- 卡点只留一句台词，答案一律放到下一集（连载）或评论区（完结）。
- 连载卡点后可加**竖排「下集预告」画面条**：4–5 个强画面（被堵嘴哭泣的女人、解剖素描本）不给解释。这和被骂的「黑屏未完待续」不是一回事——预告要给新画面。
- **黑屏收尾的裁决**：黑屏本身不是禁忌，条件是①最后一个声音和画面一起落（耳语、问句、重音）；②线索指向唯一答案或情感已落地；③连载有下一集可追。仍是禁忌的：「逻辑开放、指向不了唯一答案」和「黑屏 + 未完待续四个字没有任何画面」。
- 付费卡点前必须先兑现一次阶段性满足（先给解剖室全景，再卡）。

## 人设与台词

**人设组合**

| 组合 | 怎么用 |
|---|---|
| 沉稳主探 + 冲动副手 + 法医（信息出口） | 主探只说指令和判断；副手问话看监控；法医把尸检口语化 |
| 被看轻的天才 + 以貌取人的陪衬 | 陪衬当面说出观众的偏见，主角 10 秒到 2 分钟内亮能力 |
| 暴躁队长 + 怂技术宅 | 队长的暴躁要配一次温度镜；推人吼人一集最多一次 |
| 贫嘴主角 + 市井小人物 | 方言大爷、看热闹大妈做喜剧泄压；每次泄压后一句双关拉回怀疑 |
| 被窥视的女主 + 老刑警 | 凶手只通过屏幕和物件说话 |
| 不可靠主角 + 平静可疑者 | 主角从命令句变成哀求句，可疑者几乎不动 |
| 天才 + 高冷护短队长（CP 向） | 队长嘴上冷、判断上护 |
| 过分热心的配角 | 主动出现、主动给方向，往往是真凶候选 |
| 理性派 + 先开玩笑的人 | 理性派用常识给异常背书；先装鬼吓人的先落单 |
| 手欠者 + 贪财老大 + 劝阻者 | 劝阻者喊「都先别动」，手欠者偷偷掀布 |
| 寻亲少年 + 知情老人 | 老人只说半句，然后失踪 |
| 沉默守护者 + 提问型孩子 | 守护者台词全是短句命令（「少问」「进屋」「别动」），孩子负责提问。**孩子的提问不能超过揭秘段台词的三分之一**，其余信息用物件、动作或沉默交代，否则被骂「人机」「十万个为什么」 |
| 异能者 + 怀疑派队长 | 异能者安静、低头、语速平；队长是观众的怀疑代理，但怀疑要有度——验证两次已信还持续怀疑会被骂逻辑不一；队长的暴躁要有道具动机（质疑前先摸口袋里亡妻的戒指） |
| 带伤独狼 + 画外上司 | 主角带伤、违规、天赋高；上司只通过电话存在，嘴硬心软，功能是阻力 + 替主角口头交代背景（「中枪第二天就出院」） |
| 天才 + 视觉签名镜 | 给天才侦探设计一个固定签名镜（琥珀色瞳孔大特写），每次关键观察插一次，代替 AI 难做的复杂表演，签名镜本身就是反应镜 |
| 不露面的「它」 | 超自然反派不露面，只通过声音模仿、动物异常、镜像延迟三类间接证据出场；模仿声做轻微失真 |
| 无台词异常群体 | 四个人并排站立、齐刷刷看镜头微笑，不说话反而是最大的威胁；「整齐」本身就是不对劲 |
| 理性解释者配角 | 自来熟的话痨给异象一个理性解释（「可能从旁边的小路走了吧」），先给观众降温、再被更大的事吓；给 TA 一件高饱和单色服装当视觉锚点，也是潜在嫌疑人 / 下一个受害者 |
| 复杂施暴者亲人 | 施暴者也是唯一追问下落的人（「你把她弄到哪里了」）；道德复杂的人物是讨论引擎；喊完最狠的话后给 TA 2 秒沉默特写和一次伸手想碰 |

- 主要角色第一次出场配**名牌字卡**（姓名 + 身份），群像剧靠它降低认人成本。
- 每个角色锁一个**固定服装色或造型符号**；给配角一件高饱和单色（橙冲锋衣）在冷调里当一致性锚点和视觉焦点。
- **主角脸要有一个独特特征**（疤、痣、断眉、发型）；用固定参考脸要防「撞脸明星」被认出。
- **系列集前 20 秒给一句前情锚点**（开场独白一句带出上集的白鞋悬念）。

**台词技巧**

- **审讯问答 1 秒一轮**，连打 6 轮以上，台词换人就换镜，严格对齐（「人是你杀的吗」「怎么杀的」「几下」「我记不清了」）。用细节问题戳破口供（「水果刀上为什么没有你的指纹」）。
- **对仗拆谎**：「你一直在解释她为什么要走。我问的是她怎么走出去的。」**原话回击**：「刚才你说是水管漏了。」
- **术语去人性化 / 日常名词双关**：施害者用医学或商业术语说最残忍的事（「这批货的成色」）；前 15 秒用一个普通名词做双关伏笔（「把货备好」），集末用推理揭开真实含义。
- **规则式短台词 + 反常例外**：「今晚听见谁叫你都别答应」「包括我」——越短越可怕，例外埋钩。
- **极简非人感**：附身者的第一句台词只有两个字（「我饿」），比任何狠话都可怕。
- **感官化审判**：把道德判断写成感官描述（「你的心是臭的」）；施暴关系里的情绪出口放在这句，是当集最强爽点台词。
- **反问代替回答**：「谁告诉你，他们没死过？」——第一个答案本身就是更大的问题。
- **一问一答阶梯揭秘**：「本来活不过三天」→「什么意思」→「这条命不是你的」→「向谁借的」→「不该借的人」，每问推进一格；但提问方台词要克制，过密就像审讯稿。
- **双关台词**：「不要困在一年前」——字面是劝别人，实际说的是自己；揭秘后观众重听才懂。
- **一句话两重受众**：对猫说的「往常我一下班你就在门口了」其实是演给门后的人听的，复盘之后观众重新理解这句。
- **客观数字播报**：新闻腔报「两人当场溺亡，一人存活」，冷静的客观信息和家庭争吵的情绪声形成反差，同时把剧情变成数学题。
- **重复本身是信号**：「我真是你妈」重复两次，重复让观众起疑。
- **单字问答收尾**：「谁？」「我。」——用最短的台词完成卡点。
- **名词串汇报，一镜 ≤3 条**；**借第三方说设定**：广播、新闻、电话那头的同事、系统的声音、审讯者复述能力规则，主角从不自报设定；**屏幕字代台词**；**同一称呼做声音桥**；**内心 OS 吐槽一场最多 2 句**，用口语自嘲冲淡恐怖并立住主角语气；**平静说荒诞**；**省略号交给画面**；**半句悬置**；**禁令先行**，民俗向开场就立禁令等观众破禁。

**金句写法**：一个日常词 + 一个反常词，句子不超过 12 字，放在开场、卡点或拆穿处。如「外面的雨是黑的」「这批货的成色」「变的不是鸡，是你」「镜子认的也不是脸」。推理金句 = 把物证关系写成对仗判断句；揭秘金句 = 把主题写成一个可反转的短句（「那条鱼是做给谁吃的」）。

## 视听风格

**景别分布**

| 景别 | 占比 | 用在哪 |
|---|---|---|
| 特写 / 大特写 | 25–60% | 证物、尸体局部、手部操作、惊恐反应、屏幕字、签名镜（瞳孔）、指尖触物、门缝下的鞋 |
| 中景 / 中近景 | 25–45% | 审讯正反打、群像、双人揭秘、法医交流 |
| 全景 / 远景 | 15–30% | 现场建立、对称揭底空镜、恐怖人群、空间转场 |

- 远景比竖屏爽剧多：悬疑要交代「在哪儿、离多远、谁在看」。
- **取证三步**：远景建立现场 → 中景俯身看尸 → 戴手套的手部特写取证 → 回中景交流。「推物 → 指尖触物 → 复述 → 反应」循环是它的室内变体。
- **验证循环复用镜头模式**：三段式验证每次用同一套机位与流程，观众一眼就能读懂；证物展示可统一同顶光、同机位俯拍，形成仪式感。
- **证物照相法**：同一机位、同一俯角连续切 3–4 次，只换工具，每镜 2–3s。
- **审讯收紧**：全景三人围桌定位 → 单人近景 → 过肩紧两人 → 回中景 → 嫌疑人近景沉默；**推理越深景别越紧**，走廊推理戏从双人中景逐级推到嘴部特写。
- **景别收紧标记「变了」**：面部特写三连（闭眼 → 抬头 → 微笑）用同一张脸的三种状态完成附身反转。
- **对视剪辑（物件长眼睛）**：屏幕跳字 → 键盘上的手 → 女主侧脸与玩偶同框 → 玩偶玻璃眼大特写 → 女主正面惊恐。
- **恐怖探索「空 — 人 — 脸 — 怪」**：先给反应、再给原因。
- **异象四步走**：主角近景回头 → 主观全景揭示 → 主角反应近景 → 空镜确认消失，空镜至少停 5 秒。
- **孤立证人构图**：前景肩膀虚焦，后景目击者小小地立在路中央实焦；下一次同机位只剩空路，就交代了「他跑了」。
- **推理靠物件链**：数据屏 → 文件 → 地图 → 红笔圈出，每镜不超过 4 秒。
- **暴力不拍全程**：拆成「工具 → 局部伤口 → 一滴血 → 带编号的物证」四个特写；或闪黑 + 结果物。
- **水下仰拍 = 「它」的主观**：水面上站着一个模糊人影，从潭底往上看，代表不露面债主的视角。
- **对称构图 = 缺席**：正中人物 + 两边对称空椅子 + 桌心核心道具；餐桌纵深构图让核心道具始终在画面中心，三次出现。
- **光束做构图元素**：夜戏几乎全黑，只有手电光柱，光束本身就是画面结构。
- **低机位压迫**：门缝下的白鞋压在画面下三分之一，上方是门缝的黑；同一构图重复三次、中间插别的镜头，成为全集视觉锚点。
- **网格 / 夹缝构图**：巷子窄长灰砖纵深线把人夹在两墙之间；父子站在鸡笼铁丝网前，网格把人「关」起来。

**运镜**：固定机位加缓推为主，营造写实纪录感。值得动的地方：行凶追逐用手持晃或主观运动模糊 + 闪黑；惊吓前缓推人脸；走廊 walk-and-talk 给推理对白移动感；跟拍背影建立「走了很久」的时间感；主观手持把观众放到「活人」的位置；水下镜固定或缓慢上浮；拖行段全片唯一大幅运动 = 失控信号。**静止用来立规则，运动只留给失控**。一集只留一个连续运动大镜给最关键的空间揭示（穿窗俯瞰）。鱼眼加暗角模拟「被什么在看」，一集用一次。

**光色**

- 底色是低饱和冷调：阴天灰绿、雪地冷蓝、冷青走廊、冷青绿手术室、雾林墨绿、老村灰砖、楼道冷青灰加湿地反光。
- **全片只留一个高饱和色当母题，并绑定一个意思**：红毛毯、售货机红到火焰红、朱砂符布、红色楼层数字 = 危险、红叉纸墙 = 网暴、橙冲锋衣 = 冷绿世界里唯一的活人锚点、鸡冠红与血月红 = 命数。进阶：让母题色随剧情变暗——每死一只替身，鸡冠红暗一档，结尾全灰只剩一根红绳；颜色从画面里消失 = 活人没了。
- **用光色区分场景 / 现实层 / 段落**：三段三种固定色温（家暖钨丝、指挥中心冷蓝屏光、街道阴天灰绿），黑场分段时一起换，每段单独生成也能统一；暖黄家常被新闻冷蓝打断 = 现实闯进幻想；闪回冷白低饱和 + 白色晕边对现实暖金。
- **用反讽色**：儿童医院卡通熊招牌、大红锦旗对着解剖室；黑产窝点用暖粉美容中心包装。
- 民俗恐怖靠「真」立住：写实去奇幻化；石窟暖黄烛光对冷窗光表示「另一个空间」；夜戏暖台灯加大面积黑。
- 证物室质感：百叶窗光束、丁达尔光柱穿过灰尘。

**美术**：年代道具是卷宗感的来源——翻盖手机、显像管显示器、旧皮日记本、搪瓷缸、老式台式机；地域场景带来代入和分享（县城菜市场、林场木屋、爬山党代入的垭口、南方老村落）；红头文件、警衔、制服这类制度道具做对了会被专门夸，做错了会被逐项挑（警衔和制服衬衣颜色不匹配）。母题物件贯穿一集：头发 = 命的凭证、鸡 = 替身、镜子 = 身份、水潭 = 债主；鱼；石阶、凝视、倒地之物同构；门、雨、白鞋。

**横屏 vs 竖屏**

| | 横屏 / 横构图入竖屏（默认） | 原生 9:16 |
|---|---|---|
| 适合 | 全部悬疑子类型：纵深构图、对称揭底、多人站位、餐桌 / 审讯桌横贯画面、前景威胁 + 背景人物 | 单人推理、真人表演 + AI 置景；原生竖屏悬疑尚无验证过的成功打法 |
| 构图 | 前景怪物 + 背景人、前景交警 + 后景目击者、门缝下三分之一的鞋；餐桌纵深让核心道具始终在画面中心；三人同框横排可以成立 | 单人近景居中、过肩人物占一侧边缘；双人全景用道路 / 门框做中轴、两人分立两侧表现距离；情绪峰值切大特写 |
| 镜头 | 远景和纵深是悬疑的主要信息载体 | 少远景，对话全部单人正反打，不同框 |
| 字 | 新闻字幕、人名条、「下集预告」竖排条、免责黑卡全部后期叠加 | 画面就是一块信息版面 |

- 默认横屏 16:9 或横构图入竖屏；想要电影感用 2.35:1 遮幅，背景细节崩坏也更难被看出。竖屏投放的悬疑剧可以先借情感剧的竖屏语法：每 20–30 秒插一次双人全景重新交代空间、情绪峰值切大特写、反应镜占比拉高。中英双语字幕面向大赛和海外分发。

## 剪辑节奏基准

- **平均镜长**：全距 1.7–7.7s，中位约 3.3s。分档：推理 / 程序 / 审讯 / 解谜类 1.7–3.4s；氛围 / 恐惧 / 民俗类 3.7–5.4s；对话复盘主导的居家悬疑可到 5–8s（但 30 秒以上的纯电话复盘容易被指掉人）。不要把民俗戏剪成 2s 一刀，也不要把审讯戏拖成 5s 一轮。
- 镜长和点赞没有正相关：最快的（1.7s）和 44 秒完结的（2.6s）都能是爆款；最慢档的氛围片点赞低但分享率全场最高。氛围到位和反转密度比快切重要。
- **节拍间隔**：≤3 分钟单集每 10–25 秒一条线索或异常信号；45–60s 完结短片每 10–15 秒一次反转；5 分钟长首集每 25–40 秒一个调查节拍或规模升级。
- **「长镜等待 → 碎切爆发」**：先给 8–21s 的等待长镜（凝视人群、空石阶、嘴唇特写、倒地），后接每镜 0.1–1.3s 的碎切。氛围类公式：**前 90% 用长镜压慢，最后 5 秒连续 4–6 个 0.2–0.5s 闪切再接黑场**。
- **异常与死亡用快切，规则与揭秘用长镜**：异常三连 0.3–1.4s 像心跳，揭秘段 16–19s 长镜承载台词。
- **审讯段镜长 = 台词轮长**：1 秒一轮问答，换人就换镜，严格对齐。
- **快段之后的长镜 = 危险换了位置**。
- **快慢分界可以压在片名卡上**：前 28 秒约 2.4s/镜的紧张段，片名叠在走廊空镜上做章节停顿，之后进入长镜复盘。
- **碎切段**：<1s 镜头控制在 0–20%，用在开场闪切、监控快翻、闪黑行凶、对峙正反打、情绪顶点嘶吼三连、线索收紧（0.3–1.1s 直接接卡点）。行凶闪黑后必须接一个 5s 以上的结果长镜。
- **推理段放慢**：「现象—机关—结论」每句约 2s，证物特写停 1.5–4s；**真相复述段**用 10–19s 长镜，中间插一个 2–3s 插入镜。
- **静场**：隐情前空 4 秒、凶案后黑门口 4–5 秒、杀戮后 13s 静止结果镜、异象时抽掉环境声 0.5s，每集 1–2 处。
- **反应镜要限量**：同一惊恐表情（瞪眼大特写）重复 6 次以上会同质化；情绪台阶要管理——每镜都哭，到反转时就没有台阶可上。把眼泪 / 惊恐大特写全片控制在 2–3 次、分别对齐反转点。
- **转场**：硬切为主；黑场分隔段落 / 现实层；电视新闻插入当转场；时间字卡做跳跃；母题物件做声画桥（蝉蜕落地 → 医院外景）；闪黑当动作省略；竖排预告条做正片 → 预告的硬切标识；同一称呼做现实层切换。

## 审核参数

```json
"project": { "genre": "short-drama", "asl": [1.8, 3.5], "hook": 3 }
```

氛围 / 恐惧 / 民俗向改 `"asl": [3.6, 5.5]`，并允许一个 20s+ 的凝视 / 空镜；审讯密集段允许下探到 1.2–1.7。超过 8s 的镜头标 `tempo: 停留`，`pace_note` 写「停留：等它出事」或「长镜：画外音推进」；超过 16s 的镜头画面里必须有变化（推近、人物入画、光变），台词信息 ≤3 条。

## AI 制作要点

| 翻车点 | 后果 | 规避法 |
|---|---|---|
| 尸体 / 核心证物不连续 | 悬疑观众把画面当线索看，穿帮即证据链崩塌（手臂换人、杯子瞬移、一镜之间换装） | 尸体、包裹物、桌面道具都建 `refs`（type: prop）；分镜表写清每件道具的位置，正反打逐镜比对 |
| 口型对不上 | 一说话就露 AI | 台词放背影、过肩、侧脸、低头半暗、手机挡嘴、眼部 / 嘴部特写签名镜；每句台词 1–2s 短句让口型误差不明显；歌曲段 / 画外音 / 新闻播报完全免口型 |
| 行凶 / 打斗 / 长动作 | 完整动作必崩 | **一律省略过程**：6–10 个 0.1s 闪黑 + 主观运动模糊带过，接 5s+ 结果长镜；或「前一刻的危险 + 后一刻的结果物」两组镜头（俯拍一堆脱下的衣服、落地的枪、血迹）；拖行只给一个姿势定格式画面；逃跑拍「在 → 不在」；翻阳台等动作用台词交代 |
| 多人互动 | 手臂穿模、站位乱 | 单人近景正反打；同框不接触、静态站位；把弱点变卖点——异常人群「站着不动整齐看镜头」、满屋孕妇一人一镜、献祭式半圆围站；身体接触只给「手递手」特写或捂嘴、搭肩、拉手的简单接触 |
| 手部畸变 | 手指数错、握姿怪 | 手部特写只做单指按、推、放（指尖压钻戒），戴手套静态握物，暗处虚焦小动作（摸猫、抓玉米）；避开握持和多指交错；握刀用远景或虚化 |
| 脸部漂移 / 撞脸 | 认不出谁是谁；固定参考脸被认出「融了某演员的脸」引争议 | 口罩、兜帽、警帽遮半脸；服装色块锁角色；参考脸要做差异化修改并加独特特征（疤、痣、断眉） |
| 情绪突变生硬 | 「AI 角色突然生气暴躁，转变太生硬」被高赞点名 | 情绪升级要有动作或道具做过渡（质疑前先摸口袋里的戒指）；正脸情绪爆发戏少写——美型脸在怒吼戏塑料感明显 |
| 跨场景时间 / 天气不统一 | 电话戏两边一边晴天一边雨夜，会被评论逐条抓 | 正反打的两个场景在提示词里统一写明「夜、雨」；分场生成前建全局时间 / 天气变量，逐镜核对 |
| 制服、警衔、公文细节错 | 刑侦 / 军事观众逐项较真（警衔和衬衣颜色不匹配） | 生成后逐项核对现实制度细节；红头文件、新闻字幕、人名条、预告条、证件文字全部后期贴图，不让 AI 生成 |
| 关键规则无视觉线索 | 「为啥不开枪」「为啥脱衣服」成为最集中负面 | 超自然规则必须在异象发生的当下给视觉线索（瞳孔放大、握枪的手松开、空气扭曲的微弱视效），事后台词只做确认不做补丁 |
| AI 物理瑕疵 | 观众会把瑕疵当线索讨论——这次是运气，下次是穿帮 | 关键道具生成后检查有无无意义运动；瑕疵要么修掉，要么有意变成线索 |
| 怪物 / 动物运动扭曲 | 生物动作一动就假；特效不够可怕会笑场 | 用姿态代替动作（趴着、倒挂、直立不动、整齐凝视）；用 AI 擅长的写实动物当核心视觉道具替代超自然怪物；怪物前 1/3 只给倒影、一条腿、门缝里的一只眼 |
| 台词被 BGM 压住 / 转写失效 | 台词可懂度低；语音转写在配乐上产生大段幻听重复 | 对白比 BGM 高 6dB 以上；台词烧录字幕；成片自查台词时间轴有无整段重复——重复 / 拼接痕迹会被观众当「剪辑粗糙」 |
| 画面内文字乱码 | 证件、屏幕、纸条出乱码；官方标识有风险 | AI 只出无字背景或单个短词；证件上的徽记和文字一律打码或背对镜头；屏幕字后期叠加；电脑屏只给图形不给文字 |
| 切点预算不够 | 生成片段多、成本高 | 10–15s 信息长镜配画外音推进（汇报、简报、新闻旁白）；但单镜不超过 3 条信息 |
| 声音克隆 / IP 配音 | 侵权风险，流量越大风险越大 | 原创角色不用他人 IP 名字与声线；借鉴气质可以，复制名字和声音不行 |
| 道具被「刻意忽视」 | 观众骂「为了推进剧情」 | 关键道具转手后，至少给一个角色看它一眼或问一句 |
| 恐惧消费向画质 | 高清本身就是卖点（「这么高清」能拿最高赞评论） | 做超分 / 高码率导出 |
| 场景数量失控 | 场景越多漂移越多 | 全片场景压到 4 个左右、每场光色统一（雨夜街 / 审讯室 / 走廊 / 窝点；院子 / 巷子 / 屋内 / 潭边；前半一个审讯室演完） |

## 大导演工具箱

| 导演 | 手法 | 在本片种里怎么用 | 镜头写法 |
|---|---|---|---|
| 希区柯克 | 桌下炸弹（观众先知）、麦高芬、日常物件恐怖 | 把答案先放进画面深处再让角色走过去；让观众比警察先懂；给日常物件装上「眼睛」。本片种第一工具箱 | ①静态线索微微挪动点着引信：门缝白鞋第二次出现时让鞋尖动 2cm。②观众专供插入镜：搜山时插一个只有观众看到的 0.5s 镜头（洞内黑暗里的一只手），结尾「真的有洞」的释放更强。③麦高芬前置：进窝点时镜头先扫过一排虚焦婴儿床，观众先懂、警察后懂。④威胁凝视镜头 20s+，主角还在打招呼 |
| 大卫·芬奇 | 程序化细节、证据可视化、逐步收紧 | 线索统一成「卷宗翻页」的视觉语法；推理台词逐条配证据插入镜；对话张力靠景别收紧推进 | ①每条物证同一角度俯拍、同一冷白顶光、编号牌入画，每镜 1.5s；多次证物展示复用同一构图形成仪式感。②推理说到的每个体征配 0.5s 证据特写三连（浮肿眼皮 → 关节色素沉着 → 下坠腹部），不要只给说话脸。③电话戏逐步收紧：上司骂人给中景，说到关键句切眼睛大特写。④「全部都是胸口致命伤」配 2–3 个 0.5s 法医照片插入 |
| 诺兰 | 信息重排、双计时器、规则与数学、闭环线索 | 同一画面先给一种意思，后面改写它的意义；复盘回放必须带来新信息；倒计时可视化 | ①复盘段闪回重插原镜头 + 补一个没给过的新角度（主角眼角余光的主观镜），让回放是信息不是解释。②「还有三只」与「还有三天」两条倒计时从开场并行：报数台词后紧接 1s 血月日历插入镜。③客观数字做成数学题：「两死一生」再加半截信息被换台打断，让观众在答案边上停住。④开场不明身份的叩拜者与后续受害者用同一道具（红绳、香灰）勾连成闭环 |

## 禁忌

- **挂羊头卖狗肉**：标签写「悬疑」「烧脑推理」、内容是情感虐恋，评论区没有一条讨论推理，承诺没有兑现。发什么内容打什么标签。
- **直接挪用知名 IP 的角色名和声音**：用已有作品角色名 + 疑似克隆配音，流量越大侵权风险越大；被认出「像某部剧」「跟我最近看的小说很像」就会被贴抄袭标签。用模板时至少加一个原创变量（职业、空间、母题物）。
- **用已经被用烂的答案**：「心理医生是凶手」；借命、模仿声叫门是常见梗，需要独特设定加持。
- **把关键规则留到事后解释**：超自然规则（为什么不开枪、为什么脱衣服）必须在异象发生的当下给视觉线索，4 分钟后的台词解释只能做确认，否则「为啥 XX」刷屏。
- **犯刑侦程序 / 战术 / 制度常识错误**：双人执勤、执法记录仪、监控排查、警衔与制服匹配、「派四个人上门」要有一句台词合理化、「第一遍为什么没搜到」要有交代——刑侦军事题材观众会较真。妄想段和戏剧化段也要用一句台词把漏洞堵上。
- **让专业配角降智来衬主角**；不要让队长的暴躁没有来历。
- **让主角没有主动性**：全片只会问「为什么」「什么意思」会被骂「跟个人机一样」「十万个为什么」；主角提问不超过揭秘段台词的三分之一，其余信息用物件、动作或沉默交代。也不要让主角明知故犯——被警告「别照镜子」仍去照，在上帝视角观众看来是降智。
- **把惊吓当答案**：每个吓人镜头后面都要有一句「这说明什么」的台词或证物。
- **让角色直接讲世界观设定**：用广播、传闻、新闻、档案、电话那头的同事、系统的声音。
- **动机不明地性化画面**：附身者脱衣没有当场给出线索，会被读成擦边反噬（「打架就打架，脱衣服干嘛」）。
- **只上一集就停 / 单集太短**：「就一集」「以后这种只有一集的不要给我推了」「两分十九秒，打发要饭的呢」都是高频差评。发首集前备好 2–3 集，或在简介写明更新时间；连载单集信息量要够。
- **让中段变成纯台词长段**：30 秒以上电话复盘全靠说话脸、画面信息少，容易掉人；复盘必须重插原镜头并补新角度。
- **黑屏收尾**：黑屏本身不禁，禁的是①逻辑开放、线索指向不了唯一答案（「没看懂」）；②黑屏加「未完待续」四个字没有任何画面。卡点最后一个声音要和画面一起落。
- **用括号字幕代替最后的视觉反转**（「（可走廊尽头空无一人）」）。
- **预告了人物却不兑现**：观众记住了名字却没见到人。
- **时空 / 宿命类时间线自相矛盾**；新闻插入的时间逻辑要通——一年前的事故别写成今日新闻。
- **恐怖民俗开局招来「全家不沾」刷屏**：片名卡下方加一行小字「虚构演绎 请勿迷信」；完结短片加「本故事纯属虚构」免责黑卡。
- **在第 20 秒前把怪物完整露脸**；特效做不到位宁可全程不露（尾巴穿帮、惊吓透支都会笑场）。
- **用固定参考脸撞明星**；主角团不能只靠造型区分，每个主角首集要有一个私人欲望（找父亲、限期破案、洗清嫌疑、亲手抓住杀人犯）。
- **把 AI 物理瑕疵当彩蛋策略**：道具乱动被当线索讨论是运气，关键道具要检查无意义运动。
- **在结尾闪切里丢画面信息**：0.2–0.3s 且过暗的镜头几乎看不清发生什么，惊吓全靠声音——闪切至少保证每镜有一个可辨认的形状。
- **砍掉情绪台阶**：全片每镜都哭 / 都瞪眼，到反转时没有台阶可上。
