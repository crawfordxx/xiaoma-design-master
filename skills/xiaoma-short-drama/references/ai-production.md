# AI 短剧制作手法

> v0.3。适用于用 AI 视频工具逐镜生成的短剧；实拍项目只看第 5 节里与 AI 无关的常识核对和第 7 节的流程卡点。例子都是自拟的。

## 1. 画风选择

| 画风 | 适合 | 风险 |
|---|---|---|
| 写实 AI（真人感 / 电影感），主流 | 都市家庭、悬疑、复仇、爽剧、奇幻、民俗 | 同脸、塑料感、近景背景一律虚化成空壳、场景漂移 |
| 3D 国漫 / 游戏 CG | 穿越、网文改编、古风虐恋、异世界生活流、乙女向 | 脸型同质化；撞知名游戏或动画角色的脸 |
| 2D 平涂 / 2.5D | 志怪改编、寓言、轻甜宠 | 画风统一能掩盖一致性问题，但表情要夸张才有戏 |
| 定格木偶 / 黏土 / 剪纸 / 旧胶片 | 经典民间故事重述 | 热度容易只停在「这怎么做的」，剧情没人聊 |
| 真人实拍 + AI 合成 | 喜剧、自嘲梗、一人多角 | AI 部分被察觉后，评论会拿来调侃；同系列混用 AI 素材容易穿帮 |

选择原则：
- 题材靠「像真的」卖（民俗、年代乡土、真实感案件、社会派）→ 写实电影感。
- 造型复杂、角色多、一致性难保 → 造型简化、材质统一的风格（木偶、黏土、剪纸、港风胶片），风格本身就压住生成差异。
- 题材靠表情夸张和萌点卖 → 3D 国漫或 2.5D，可以穿插 Q 版镜头。写实人物 + 卡通系统宠物的混搭有人不买账，但能冲淡阴暗设定的压迫感；混搭时只让非人角色卡通化。
- 真人 + AI：台词、多人互动、连续动作交给实拍，AI 只做无对白的奇观或闪镜。
- **低成本高共鸣的真人形态仍然能打**：巴掌混剪、一人分饰多角的小品、二创解说、室内伦理实拍，在打脸 / 伦理 / 讽刺题材上比 AI 剧更容易出高共鸣；这类题材可以先考虑实拍 + AI 补奇观。
- **3D/CG 已是漫剧主流**：古风志怪、奇幻、穿越的漫剧多用半写实 3D + 统一的 Q 版第二画风；也可做厚涂立绘风、写实毛发拟人风。
- **非人主角策略**：让神兽、怪物、机甲当主角，人手、口型、群戏三大难题一次清零；拟人奇幻优先用写实动物脸（毛发、鳞片）不用真人脸，用物种差异区分角色，顺带避开口型和人脸漂移。
- **院线感配方**：2.39:1 遮幅 + 单一暖色体积光 + 压暗背景，把 AI 画面里不一致的地方藏进阴影。

画风写进 `style.frame_style` 和 `style.prompt_prefix`，全片锁定，见 director/references/frame-prompts.md。

## 2. 画幅
按投放平台定，详见 shot-language.md 第 1 节。投竖屏平台默认原生 9:16；横构图入竖屏时，钩子、关键反转和卡点镜按竖屏重新设计。不论横竖，片名卡要在前 40 秒内出画——40 秒前划走的观众永远看不到剧名。

## 3. 角色一致性（最大扣分项）
1. **定妆参考图**：每个角色正面 + 侧面 + 背面定妆图，每镜生成都挂同一张（`refs`）。挂了参考图，单镜内人脸和服装基本稳定；跨镜一致靠每镜都挂。
2. **服装色块 + 标志物锁定，全集不换装**：每人一个主色 + 一个随身标志（红鞋、黑金长袍、竹节簪）。单集最好限定「一天、两场景、每人一套衣服」。
3. **同性角色至少两项区分**：发色、发型、脸型、体型、服装主色。重灾区：两个男主、主角和第三者、姐妹、正反派女性、一群反派、和男主同发型的配角。
4. **新角色先全身轮廓再给脸**：门框全身剪影 1.5s → 近景。每次换装段落开头补一个正脸确认镜，防脸型漂移。
5. **用造型遮脸**：面具、盖头、口罩、兜帽、斗笠、背影，压缩裸脸镜头。
6. **非人角色承担对白**：灵宠、器灵、写实动物头、面具人说大部分台词，规避口型；群像用不同物种和轮廓区分。
7. **合集结构**：每段新角色，绕开跨集一致性。
8. **把缺陷写进剧情**：一群人脸相似，就改写成主角「看谁都像他」。
9. **不跨作品套用标识**：同一个标志（比如红瞳）每部都用会被识破为模板；玄幻特效别进写实历史。
10. **证物、尸体、金手指形象也建参考图**（`type: prop`）。
11. **人物状态写进每一条提示词**：受伤、怀孕、失明、淋湿之后，每个走动镜都写明，否则「刚摔伤腿就健步如飞」。
12. **场景也锁参考**：同一套房子前后不能一个旧墙筒子楼一个精装公寓；同一场的站 / 跪连续。
13. **统一后期滤镜压生成差异**：胶片调色 + 柔焦 + 颗粒；或一个贯穿全片的光影母题（百叶窗光栅）。
14. 角色避开当红明星的五官，用一个原创特征（泪痣、眉骨疤、发色挑染）定脸；模板脸会被拿去和明星比。
15. **跨镜道具与服装锁定**：只挂角色参考图不够，头盔、保温箱、手提袋、雨衣、反复出现的那扇门最容易漂（实测一集里头盔银 / 黑 / 灰三色、保温箱和手提袋互换、同一扇门三种颜色材质、雨衣忽长忽短）。每件在 `refs` 里写死颜色 + 材质 + 款式（「哑光黑色全盔」「方形白色硬壳保温箱」「墨绿铁皮门、黄铜猫眼、门牌空白」），出现它的每一镜 `visual` / `frame_prompt` 原样再写一遍；摘头盔、换手拿这类状态变化写成一镜动作，不让它在镜间凭空发生。
16. **职业制服 / 标志色当锚**：主角选骑手、白领这类日常职业，制服就是最好的一致性锚点；高对比服装色块 + 单场景单时段拍完一集；三件套服装锚点，变装每集只摘一件；换装只发生在闪回里；每角色锁一套标志色服装 + 固定姿势，全集一个场景一个光向。
17. **配角也要锁**：配角形象多次漂移（「律师像三个人」）会被点名；只露几帧的插入角色崩脸也会成嘲点——配角和外援也锁一套造型和道具，每次出场检查。
18. **锁脸参考要跨批次**：多批次生成不挂锁脸参考，主角会中途换脸；每一批、每一镜都挂同一张角色参考图。
19. **状态 / 道具连贯性清单**：煤灰妆时有时无、被偷走的包袱又出现、胎记位置前后不一（认亲戏里尤其致命）、服装突变、分场生成没统一时间和天气——把身体状态、妆容、天气、关键道具列成表，出片后逐镜核对。
20. **风格分区规避一致性**：把伪证、回忆、谣言拍成和正片截然不同的风格（皮影、剪影、黑白、动画），观众一眼分辨真假，同时绕开口型和脸部一致性问题。

## 4. 实测出来的生成规律

这几条是真实出片踩过的坑，写分镜和提示词时直接照做：

| 现象 | 对策 |
|---|---|
| **定妆图会自己长出真实品牌 logo**（制服、头盔、背包、车身），挂成参考图后一路带下去 | 角色和道具提示词必须写「服装无任何品牌标识、无文字、无 logo」；定妆图过审时专门查衣服、帽子、包、车 |
| **场景参考图会压过分镜写的景别**：近景挂了走廊场景图，模型直接给走廊全景，人缩成远处小人 | 场景参考图（`type: location`）只挂在远景 / 全景 / 中全景镜头；近景和特写只挂角色和道具 |
| **模型会在一段里自己剪辑**：一镜生成出「人脸 → 切到走廊」两个镜头；加了提示词仍会发生 | 提示词固定加「单一连续镜头，从头到尾同一机位，不切换镜头、不剪辑」（写进 `style.prompt_prefix`）；剪辑先检测片段内部切点，只取一个镜头段，剪点两侧不能是重复画面（否则像卡顿、留下 0.1s 闪帧），见 editing-rhythm.md 第 2 节 |
| **跨镜引用看不懂**：「与第 7 镜同机位」模型不认 | 每镜把机位、景别、构图完整写一遍，不引用别的镜号 |
| **表演容易过火**：惊恐、愤怒演成大特写夸张脸 | 提示词加「表演克制自然、不夸张」，只在情绪顶点那一镜单独放开 |
| **台词放双引号能出同步人声**，但同音字会错 | 关键词、人名、地名一律上字幕，不只靠配音 |
| **AI 配音约 3 字/秒**，比分镜默认的 4–5 字/秒慢，对白镜几乎都说不完 | 对白镜时长按「字数 ÷ 3 + 0.8 秒」给；或者把台词再砍短；要快就写「语速快、干脆」 |
| **台词不一定从片段开头说**，可能前几秒是表演 | 剪辑时用语音转写找人声入点出点，不默认从 0 秒剪 |
| **最短生成约 4 秒**，按生成秒数计费 | 分镜 2–3 秒的镜头也生成 4 秒再剪；预算按生成秒数算，不按成片秒数算 |
| **生成偶发失败或排队超时**（失败通常不扣费） | 原样重提一般能成；只重出失败镜，不整批重跑；超时不要自动连发 |
| **影子、门缝、半张脸这类悬疑构图做得出来** | 前提是不挂场景图、构图写具体（墙上人影从左侧滑入、越肩看门缝里的半张脸） |
| **一个镜头里的光照突变**（灯泡亮起、断电）最容易崩 | 拆成「之前」「之后」两个首帧；「之后」那帧用「之前」的帧做图像编辑生成（换光、去灰、加物件），亮起的那一下用后期亮度闪接 |
| **钟表指针不可控**，模型偏爱 10:10 | 表盘生成无指针，指针和跳秒后期合成；时间是关键信息时尤其要这样 |
| **时长不足看不清**：1.4 秒的钟面没数字、线索太隐蔽 | 承载线索的插入镜 ≥2 秒，配一声提示音或一个角色停顿；字卡挪到字幕区放大 |
| **屏幕会写乱码**：手机屏要么一片空白、要么满屏假字 | 提示词写「屏幕纯白发光、无任何字」；`on_screen_text` 写明屏幕区域和内容，剪辑把字贴进屏幕区域 |
| **门牌、号码会被画成别的数字** | 门牌写「门牌空白」，号码后期贴；关键数字不交给模型 |
| **无台词镜头会冒出含混人声**，集尾多出一句对不上字幕的话 | 无台词镜头在 `sfx` 写「无人声」+ 本镜环境声；成片转写和字幕比对 |

## 5. 规避 AI 弱项

| 弱项 | 规避写法 |
|---|---|
| 画面文字（手机、文书、招牌、HUD、匾额、门牌号、钟面） | AI 只生成无字画面，文字全部后期合成；做不到就虚焦、斜放或只拍抬头 |
| 真实品牌 | 提示词写「无品牌、无 logo、无文字」，出图检查车身、衣服、包、背景招牌 |
| 数字 / 年代 / 生活常识 | 生成后逐项核对：温度、价格、换算；钱币、票证、电器；物种、地理、季节 |
| 首帧复杂人体姿态 | 第 1 镜禁弯腰、下腰、扭身，用蹲、站或手部特写 |
| 手部 | 少拍手部大特写；必须拍时让手有固定支撑（握杯、按桌、戴手套单手握物） |
| 多人肢体（亲密、打斗、抢夺） | 只拍局部或结果镜 + 加害方同框；同框人物站位分散、无接触，最多一个手扶肩 |
| 连续动作（跳、推搡、打人、拖拽） | 拆成前因特写 → 碎片 → 结果镜；或「起手 + 后果」两镜中间硬切；单片 ≥0.5s |
| 舞蹈 / 比武 | 拆成 6–9 个 1.5–3s 局部镜（裙摆、鞋、手、披帛）+ 1 个全景；AI 舞蹈「只会转圈」 |
| 快速甩头 | 3–5 个 0.1–0.5s 虚焦快切模拟 |
| 抱起、拥吻 | 只给结果姿态，过程用粒子、前景虚化或切镜遮挡 |
| 穿越 / 瞬移 | 只拍之前和之后，过程用闪帧、蒸汽、虚焦、白场 |
| 打斗命中 | 法器效果（水、布、光刃）代替肢体接触；光效闪切；真实接触只留 1–2 个瞬间 |
| 灾难 / 大场面 | 声音 + 人物反应 + 远景局部，不直接生成 |
| 群众 | 高俯拍光点或一排静态站立；只拍伸入画面的手；虚焦的路人别是空壳；一张图里清楚的正脸不超过 6 张 |
| 走路 | 只拍鞋或背影；逃跑只拍「在 → 不在」（同机位有人 → 空路） |
| 口型 | 说话镜放背影、过肩、低头、侧后肩、手持电话的背影；昏迷、封印、病床等不能说话的设定承载独白；正脸只给无台词反应 |
| 站桩 | 多人同框每 4–5 秒插反应镜；每个群像镜给一个人一个小动作 |
| 表情单一 | 写具体微表情（「嘴角往下压、眼眶泛红但没哭」），惊讶脸全集最多 2 次；做不出的微表情用小号标签字幕补 |
| 物理道具 | 披着的外套打斗不掉、拧开的瓶盖被踩扁——出片后逐镜查物理 |
| 服装擅自加料 | 牛仔裤长出蕾丝；定妆图锁细节，出片后对照 |
| 道具瞬移 | 每场首镜 `notes` 标桌面道具位置，正反打逐镜比对；关键道具转手后至少给一个角色看一眼 |
| 黑补丁帧 / 闪帧 | 导出前逐帧扫 |
| 片段复用 | 同一生成片段别在一集里出现两次（有意的环形结构除外） |
| 恐怖谷 | 慎用脸部变形、会说话的写实动物 |
| 暗场 | 小屏全黑 = 零信息；看不清的段落改成几个 1s 暗示性短镜 |
| 宗教 / 民俗混搭 | 佛像配佛教元素、道观配道教元素，核对后再生成 |
| 恐惧向画质 | 恐惧、血腥质感向值得超分、高码率导出，清晰度本身就是卖点 |
| 尺度差 | 让一方缩进道具变成小人，规避同框肢体接触与长动作 |
| 手部特写 | 只允许握卡、持机、整理袖口这类简单手势；指尖互触类动作暴露手指畸变 |
| 电话戏 | 拆成单人正反打，用手机遮挡口型，避开多人同框 |
| 关键台词口型 | 只拍唇部或用手机 / 手遮挡，长段情绪交给旁白或歌曲 |
| 心声 / 独白 | 「被听见的心声」设定让叙述者免口型，还自动产生反应镜 |
| 非人主角 | 神兽、怪物、机甲当主角，人手、口型、群戏三大难题一次清零 |
| 小动物插镜 | 橡胶质感明显，快切特写只能遮一次，能不用就不用 |
| 货币 / 地域本地化 | 人民币语境出现美元钞票，出图后做本地化检查 |
| AI 接缝闪帧 | 0.1s 级接缝闪切要清理；生硬的短闪白转场像补素材 |
| 美术逻辑穿帮 | 森林里出现高跟鞋、短裙、头纱，会被顶赞评论放大成全片第一印象 |
| 服装细节穿帮 | 赤膊披棉袄的「空心棉袄」会被当笑点 |
| 关键文书 | 应后期叠加清晰文字，AI 直出的小字一眼被看穿 |

## 6. 提示词写法：让镜头可控

`frame_prompt` 和视频提示词按下面顺序写（视频提示词由 `video_render.py` 从 `style.prompt_prefix`、景别角度运镜、`refs` 设定、`visual`、台词音效自动拼出，所以分镜表写对了，提示词就对了）：

```
[景别] [机位高度 / 角度] [主体：角色名 + 服装主色 + 标志物 + 当前身体状态]
[本镜出现的跨镜道具：颜色 + 材质 + 款式，照 refs 原样写]
[唯一动作：一个动词，起止状态] [视线方向] [表演强度：克制 / 自然 / 情绪顶点]
[场景 + 时段 + 主光方向 + 色温 + 本片光影母题] [镜头运动：固定 / 缓推 / 横移，只选一种]
[禁止：画面文字、品牌 logo、额外人物、手部特写、复杂人体姿态]
```

`style.prompt_prefix` 里固定写：画风、画幅构图、「单一连续镜头，从头到尾同一机位，不切换镜头、不剪辑」「表演克制自然、不夸张」「画面无任何文字、品牌标识」。

- 一镜一个主体一个动作；多人镜写清站位（前景 / 中景 / 后景、门口 / 桌后）和「不接触」。
- 写结果不写过程：要「捂着发红的脸」，不要「被扇耳光的全过程」。
- 奇观镜加比例尺人物；揭示镜写「只露一只眼 / 只露悬空的脚 / 只露脚步」。
- 情绪靠物件：写「凉掉的三碗菜 + 挂钟」，不写「她很失望」。
- 屏幕类镜头写「屏幕纯白发光、无任何字」，`on_screen_text` 写明屏幕区域；HUD、名牌、门牌号、章节卡、倒计时一律后期。
- 无台词镜头在 `sfx` 写「无人声」（`sfx` 会拼进视频提示词）。
- 光色写进每一条，不只写在第一条；同场景色温、太阳角度一致。
- 长动作先列 6–9 个局部镜清单，再逐条写。
- 口型风险镜头：提示词里直接改成侧背机位、手部物件特写或单一表情的震惊脸。
- 怪物 / 巨兽只生成局部（一只眼、爪印、剪影），永不给全身，省一致性成本。
- 灾难奇观用人物做比例尺 + 声音设计，不直接生成完整灾难。
- 连续空间漂移运镜是 AI 的强项，留给全片最关键的一次空间揭示。
- 镜头的 `refs`：角色和道具按需挂；场景只在远景 / 全景 / 中全景挂。

## 7. 流程卡点（生成前 → 发布前）
1. **生成前**：角色表（名字查重、性别、主色、标志物、三视图定妆、身体状态变化表）；场景参考表；年代 / 常识 / 品牌清单；规则自洽表；逻辑洞清单（见 structure.md）。
2. **定妆过审**：同脸、像明星、标志物不清楚、衣服上长出品牌或文字，都要重出。
3. **生成中**：每场先出全景定位图，再出近景；每场首镜出好后作为后续镜头的参考帧；同场景复用同一张背景参考。先低档出小样，满意再换高档逐镜升级。
4. **剪辑**：生成片段一律按戏剪短；按人声定入出点；每个片段只取一个镜头段，剪点两侧不重复画面；不用 0.1s 碎切掩盖穿帮；扫黑帧、闪帧、复用片段；删看不出内容的空镜和重复外景。
5. **混音**：声音层是交付必需（环境底噪、关键音效、BGM 情绪段落），见 sound.md。
6. **发布前**：片种标签与内容一致；写实画风常驻「AI 生成 · 纯属虚构」角标（放画面最下沿，不压字幕，不和片名、时间字卡叠在一起），「像真人真事」的评论说明标识还不够显眼；改编作品在简介和片头显眼署名原作者并说明授权，同人 / IP 向点名具体角色有侵权风险；不借用知名 BGM；备至少 3 集；剧名在投放平台搜得到并打在片尾，片名卡在前 40 秒内出画；简介别把「AI」当卖点主语；方言配音经母语者过稿；货币、年代、品牌做本地化检查；真实品牌、机构、名人一律虚构化。
