# 单集结构与多集连续性

> v0.4。例子都是自拟的。1.5 的行动坚持型、第 4 节最后两种卡法、6.4 前三集节拍卡改写自 Short-Drama Factory（老李，MIT，见仓库根目录 THIRD_PARTY_NOTICES.md）。全剧层面的单元和付费点见 series-arc.md，跨集记账见 continuity-ledger.md。

## 0. 时长与形态

- 单集默认 1–5 分钟。超过 5 分钟只有「每集有强事件的奇观连载」（灾难、怪兽、异世界奇观）才撑得住长时长，且要在 300 秒内放一个集尾级卡点，或者拆成两集；静态对话的长片一律掉观众。
- 首发单集太短也吃亏：90 秒左右只够「设定 + 一次反转」，观众会骂「就这？」。首发要么一次放多集，要么单集做到 3 分钟以上，并交付「一个完整小反转 + 一个新钩子」。
- 先定成片形态：**连载卡点**（追更，集尾必须有卡点）还是**单集闭环**（转发，结尾落在金句、问句或情绪落点上）。结构模板分开走。

## 1. 单集节拍

### 1.1 通用密度
- 每 15–25 秒一次局面变化：新信息、新人物、新证据、关系升降一级。
- 爽剧：每 40–60 秒一次身份翻牌或打脸；清算段每 15 秒一个爽点。
- 推理剧：每 60–90 秒一次「智商反转」。
- 证据链：每 15–25 秒亮一件；家庭侦探类每 30–40 秒升一级证据；揭发分三层「物证 → 人在哪 → 钱去哪」，层与层之间隔 60–120 秒，并配新道具或新场景。
- 低信息段单段上限：无台词受辱 / 追逐 12s，背景旁白 20s，世界观交代 30s（压成一镜画卷平移 + 说书旁白），说明性会议 60s；超出就平行剪或删。
- 甜蜜段超过 30 秒，插一个威胁方 1 秒短镜做倒计时，否则被嫌拖。
- **对话块单块不得超过 30 秒**：超过就插入画面事件（威胁逼近、闪回、道具插入），否则是「水」评重灾区——一段接近 1 分钟的静态对话只推进两条信息，会被集中吐槽。
- 每 60–80 秒一个结构性反转或实物级爽点；奇观类每 60–80 秒升级一次奇观，升级后接反应镜。
- 每 45–90 秒一个视觉爽点（洗净、换发型、换装这类「变新」画面）。
- 穿书 / 预知类：每 40–60 秒一次预知反制或阴阳奉承式拆台。

### 1.2 主角要主动
- 入局段必须有**外部压力**逼主角动：扣钱、限期、差评、被开除、被封号、被冤枉。只靠「愧疚」「好奇」推动的主角显得被动。
- 主角至少一次**自己看出别人没看出的细节**（悬疑尤其如此），或自己做一个改变局面的决定；不能全程被事件推着走。

### 1.3 2–3 分钟单集
| 时段 | 任务 |
|---|---|
| 0–3s | 钩子（见 hooks.md） |
| 3–15s | 身份、处境、规则交代完，出现第一个转折 |
| 15–60s | 第一次压迫或第一次能力展示；立一个可兑现的约定（赌注、期限、数字）；给主角一个外部压力 |
| 60–120s | 两轮升级（阶梯式能力、逐级权威、证据递进），中间插一个观众先知的信息差镜头 |
| 120–150s | 最大爽点或反转，给 4–5 秒的全片最长镜落地 |
| 最后 5–10s | 卡点（见第 4 节），峰值前一秒切断 |

### 1.4 4–5 分钟单集
把 60–240s 拆成 2–3 轮「压迫 → 反击」或「线索 → 误导 → 推翻」。三轮同模板时，第三轮必须变形：换施压者的阶层、换反击方式，或者让第三轮输一次。同一循环重复到第四轮，观众一定疲劳。

### 1.5 题材专用节拍
| 题材 | 单集推进 |
|---|---|
| 科技流 / 种田 | 展示成果 → 主角指出缺陷 → 本地材料或配角给出解法 → 画出下一件东西的图纸，集尾卡在新东西还没试用 |
| 穿越美食 | 前 15 秒完成「被看不起 → 立 flag → 下锅出锅 → 对手破防」，食物镜不晚于第 10 秒；同一打脸单元重复三次，每次换地位更高、人数更多的反对者 |
| 异世界生活流 | 开头的抱怨或冲突，在结尾一起吃饭时用一句台词和解，单集情绪闭环 |
| 民俗志怪 | 白天喜剧立主角「外在可笑」→ 中段说出禁忌 → 夜里破禁 → 主角兑现「内在可靠」 |
| 寓言 / 试炼 | 每次考验的利益比上一次大一个量级（三文钱 → 五十两 → 功名），中点插一次旁观者评论 |
| 时间锁复仇 | 让反派亲口说出复仇窗口（时间 + 地点 + 场合），主角一句「好，十天后见」接过来；被贬低的技能就是决战武器，台词里点名 ≥2 次 |
| 生存 / 养家 | 每集两个递进的生存问题，第一个本集解决，第二个结尾抛出，卡在「我有办法了」 |
| 灾难求生 | 每个危机段结尾升级目标（逃命 → 安置 → 新威胁），最后一句埋一个具体的下集威胁 |
| 喜剧转复仇 | 前笑（暖调长镜）→ 中爽 → 后哭（冷调短切），类型切换时色调和镜长一起换 |
| 催泪寓言 | 高潮前 20–30 秒放请求逐级变小的日常蒙太奇；高潮奇观后 3–5 秒黑场或静音字卡悬置态度，再反转 |
| 灾难 / 怪兽奇观 | 前 15 秒配角机密对话把危机告诉观众再切日常；奇观每 60–80 秒升级、升级后必接反应镜；怪物四级显形（局部 → 剪影 → 掠影 → 全身放集末） |
| 无敌流 / 系统签到 | 10 秒内系统结算 + 无敌宣言双宣告、20 秒内情感锚；力量差写成地位反转行为（强者下跪、爬行、抱腿）；顶级战力全程画外，只拍结果 + 群体反应 |
| 穿书 / 心声流 | 第一句像观众一样吐槽「原著」；持剧本的主角每 40–60 秒反制一次预知；心声被听见 = 解说、喜剧、悬念共用一条信息差引擎 |
| 重生 / 赎罪 | 第一场直接放前世犯错节点，15 秒内让观众知道「这次要选另一条路」；前世冷调 / 今生暖调，感官门（闭眼、水面）转场；赎罪动作与前世罪行镜像对应 |
| 悬疑 / 规则怪谈 | 前 10 秒立一条超自然规则解释所有反转；每 10–15 秒推翻一次「谁是死人 / 谁是真的」；可数的替身或道具报数做倒计时 |
| 大女主 | 15 秒内摆熟悉套路再反转受害者 / 施害者；赐予式台词表现上位；清算时原样奉还加害方式；没有男主救场 |
| 拟人动物奇观 | 优先用写实动物脸不用真人脸，物种差异区分角色（避口型和人脸漂移）；主角锁一个全片唯一高亮色或强符号道具 |
| 家庭伦理 / 孝道 | 冲突中段切入、弱者受辱第一镜；具体数字算账（药价、退休金、存款）；老照片旧物当呈堂证供；说教写成质问阶梯；赎罪动作蒙太奇 |
| 好人被讹 / 常识智斗 | 第一镜让观众看到真相物证再让主角被冤；争议做成具体数字差；反击按「物理常识 → 监控 → 逻辑两难」三级递进；终局「先让步再翻牌」 |
| 行动坚持型（末世囤货、预知备灾、闷头搞事业） | 反常的准备动作当钩子（观众要问「他为什么这样」）→ 旁人嘲笑阻挠 → 主角不解释、准备升级 → 阻挠升一档（从嘴上到举报、偷拍、断水断电）→ 第一次验证前兆，质疑者傻眼；卡在「验证前一秒」。三条铁律：**解释就泄气**，用动作回答；每次阻挠必须升档；每个准备动作都要拍得到、改变处境。对白天然少，靠质疑者配角替观众发问，主角只在最后一拍开口 |

### 1.6 观众作证结构（慎用）
让剧中受冤者或裁决者请屏幕前的观众「作证」，能抬高评论量，但评论几乎全是表情和「我作证」，没有剧情讨论；明示诱导点赞还有限流风险。真要用：
- 先完整拍出作案过程（偷听 → 进屋 → 拿起 → 藏好），观众是唯一目击者；藏匿处在后续抵赖镜头里始终留在画内。
- 号召由有裁决权的角色说出并附带惩罚，或由反派亲口提出赌约（「有人看见，我当场跪下」）；号召段 ≤20 秒，和作案画面交叉剪；放在全片 65–75% 处。
- 卡点前至少兑现一半反转线索，不能把惩罚全押到下一集。

## 2. 爽点设计法

爽点是一条五环链：**先前状态 → 主角行动 → 可见证据 → 对手代价 → 新状态**。证据和代价都要拍得到。

1. **阶梯式升级**：能力至少分 4 级，每 15–25 秒加一级，最后一级用最荒诞的手段做反差（手枪 → 机枪 → 坦克 → 一张符纸）。第一级就要够爽。
2. **逐级权威背书**：主角不自报身份，每次由比上一次更高的第三方替他背书（前台 → 经理 → 董事长）。
3. **数字化 + 递增**：每个爽点一个精确数字并可视化；钱用具体且递增的数字连砸三次，每次接一个听者反应特写；「要了 → 全款 → 两台」三连，每句之间插一个反派反应近景。
4. **先立赌注后执行**：反派先说出具体赌注（「你买得起我当场辞职」），由第三方权威执行；中段让对手说一句可以被立刻打脸的 flag，10 秒内主角一句短话反杀。约定的数字前后一致。
5. **信息分批递交**：揭身份拆成「数额 → 期限 → 姓氏 → 全名」四次，每次之间给一句反派追问；或清单式揭底抬价（材质 → 工艺 → 来历 → 赐予者），每项配一个物件特写。
6. **以退为进的交易**：主角主动放弃大利益，换一个看似无用的东西，并安排反派当众嫌弃它（观众已知它是宝）。
7. **复读二次爽**：主角逐字复述反派原话，或让反派亲口说出他之前骂主角的那句话。
8. **同构图下跪 / 镜像回收**：每个羞辱过主角的人，在后半段以同一构图低头一次，主角站着复述原话；开场受辱镜头结尾镜像回收，位置对调。
9. **对照组**：写一个善待主角的小人物，爽点后把好处给她，上级当众惩罚势利者。
10. **底牌作废**：对手每打一张底牌，主角用 ≤8 字反问作废它，并逐级升级惩罚。
11. **惩罚两层落地**：先当众失去靠山，再被带走；惩罚要有面对面的对质镜。最大的爽点可以是反派本该护短的亲人倒戈。
12. **被贬低的技能 = 武器**；或者用时代 / 制度规则做武器，用一张盖了红手印的凭证特写收住。
13. **群众代表表态**：每个打脸后插一个旁观者反应镜 + 一句表态，替观众确认「赢了」；这个旁观者此前必须说过看不起主角的话。
14. **打脸物理化**：泼酒浇回胜过口头赢话，拆成瓶口特写 + 已溅结果两镜，配齐受害者、旁观者、权威三种反应镜。
15. **原样奉还**：清算动作原样奉还反派当年的加害方式（同一道具、同一姿势），一句台词点明「当年」；反转后把反派开场的羞辱台词原样回敬，完成情绪结算，切受害者怒脸反应。
16. **第三方旁证**：主角的武力或身份由第三方台词旁证（保镖、下属），不让主角自夸。
17. **价值写成递增金额**：主角的价值写成一串递增的具体金额，每次换手让旁人报价、再由更高的人重新报价，让观众跟着算账。
18. **蓄压 → 爆发**：打脸前让反派们轮流打亲情牌蓄压 30–60 秒，中途揭穿真实目的（要货、要钱），再动手。
19. **奇观升级阶梯**：爽点前先连立两级标尺（「已经是最高一档」「多少年没出过了」）由旁观者台词明说，主角最后打破所有标尺；奇观镜拉到 6–16 秒，「他人臣服、权威起立」的反应先行，再露主体。
20. **三段反应镜打脸**：打脸后依次给受害者、旁观者、权威的反应特写三拍。

反例：爽点全堆在前 3 分钟，反派没有反扑，后段靠植入撑；打脸对象层级太低，真反派本集没处理；挂着爽文标签却零打脸；前 5 分钟只有升级没有反转或胜利时刻，主角「说赢了但没赢」；某个时点之后只有反应补叙没有新动作，爽点密度断崖。

## 3. 反转设计法

- **伏笔 ≥2 处，至少一处是画面**：物件、背景、插入镜。关键信物至少出现三次，最后一次手部特写揭示，并在前段点明它的意义，否则观众会忽略。
- **伏笔和反转隔 ≥20 秒**：智斗反转前先给主角做准备动作的镜头（偷偷换掉外套、在桌下按下录音）。
- **动机先种**：主角要做一个伤人的选择，动机必须在反转前用 1 秒闪回先种一次，否则观众在反转点站错队。
- **观众先知**：让观众比角色多知道一层，比「突然揭晓」更撑中段；也可以开场用一句画外音抛结果 +【十分钟前】回溯，15 秒内完成。
- **主观镜头藏真相**：用主观镜头让观众默认镜头前的人有问题，在全片 55–70% 处切客观视角揭底，揭底段逐件重演开头的「又……了」事件。
- **同一事实讲两遍、换主语**：先让可疑的人说「是我把她拖出来的」，后面让同事说「是你把她救出来的」。不可靠叙事靠这一招。
- **双视角切换**：前 80% 只给一方心声，约 80% 处切到另一方心声。
- **只揭底一次**：开场已经剧透的结局，中段别再揭一遍；真实意图可以用「擦泪 → 微笑」同一镜内的表情切换来翻。
- **金手指入场时点**：推理、刑侦类的金手指放在全片 65–75% 处，HUD 上写明它给了哪一条信息。
- **专业人士不降智**：先让专业人士说对大部分，主角只补最后一环。
- **二次反转**：主角决定弥补时再翻一次，把主动权交回受害者。
- **反派要抵抗**：至少抵赖一轮、被证据堵死一次。
- **三级验证 / 三级身份阶梯**：验证做「自己见 → 家人见 → 权威见」，每级加一名证人并换一次场景，末级落在卡点上；身份阶梯至少三级（办事员 < 中层 < 隐藏天花板），每 20 秒倒转一级，最后一级藏在被侮辱最狠的角色身上。
- **两级反转**：先给全场最高的承诺（天材地宝），再用一句定义式笑话收回（原来是把漏勺），同场人群散场镜完成落差。
- **排除法揭秘**：揭秘前先用两句「我不是……我也不是……」排除观众最可能猜的答案，再给真相；揭秘后再加一层误会式二次反转。
- **罗生门双认罪**：两个人同时认罪，各配 1 秒互相矛盾的行凶闪回，让观众自己找破绽。
- **镜像人物复用同一仪式场面**：第二次只改特写表情和动机台词，场景成本减半、道德对照翻倍。
- **不可靠叙事者现身**：说书人 / 旁白在后段现身为画内人物，且他也是局中人——把「不可靠叙事」做成反转的机关。
- **黑底白字问句开放结局**：结尾不给答案，用黑底白字问句把讨论交给评论区——但线索要指向唯一答案，开放的应该是情感而不是逻辑。
- **外部来电要埋伏笔**：第三方来电揭穿谎言前，前三分之一先给一个手机反扣震动的特写；英雄出手后给一个不揭示对象的「叫人」电话做下集底牌，但底牌不能长期不兑现。
- **堵逻辑洞**：写完列出观众会问的每个「为什么不直接……」，每个用一句台词或一个画面堵住。常被骂的几类：
  - 设定能力为什么不用（会魔法为什么还要逃、有系统为什么还挨打）
  - 非人设定的常识（吸血鬼白天出门、狐妖怕不怕狗、鬼能不能碰东西）
  - 程序常识（只有一个目击者就当街押人、执法没有两个人、没有执法记录、证人不带回去做笔录）——强制动作配一句程序性台词（「所有目击者都跟我们回去做笔录」）
  - 年代常识（那个年代有没有这东西、敢不敢这么干）、材料来源（古代哪来的辣椒）
  - 规则自洽（穿越去的时候要血，回来为什么不要）
  - 身体状态（刚摔伤腿，下一场健步如飞）
  - 人物关系（撞人的是她，为什么报复她男友；护卫去哪了；为什么不找家人）
  - 关键规则交代太晚（异象发生 3 分钟后才解释成因，「为什么不直接 XX」成为最集中负评）；高概念装备不给世界观内的解释
  - 低阶角色出现在高保密场景（实习生列席机密会议）；派出的人数没有一句台词合理化
  - 信物识别逻辑（隔着车窗看清一块玉佩）；物种特性违背常识（狗的反应比猫快）
  - 人设自相矛盾（一边吐槽别人「围着男人转」，穿越后第一步是找老公）；宠爱行为没堵住最显而易见的替代方案（为什么不先戴上耳机）

## 4. 卡点（集尾钩子）

规则：
- 卡在峰值前一秒；卡点后黑场或空镜不超过 3 秒；卡点必须在片内，不能只写在简介里。
- **卡点逻辑要硬**：集尾那个「对不上的点」必须在故事的时间线和规则里真的成立。写完回头核一遍：这个矛盾在下一集开头还站得住吗？站不住就换一个更硬的。
- 付费卡点前先兑现一次阶段性满足，再卡。

| 卡法 | 写法 |
|---|---|
| 请求未回应 | 停在角色提出请求、对方还没回应的那一帧 |
| 伸手不给答案 | 告白或求婚前一句，画面只给伸出的手 |
| 偷看者揭示 | 暗处剪影 + 发光的双眼，揭示有人一直在看 |
| 秘密即将暴露 | 被拍到、被录音；把下集事件写进最后 3 秒字幕 |
| 只有心声知道的数字 | 「什么十年？」给听者缓推反应脸 + 静场，不用黑场 |
| 更高阶层递名片 | 爽点场景结尾，更高一级的人物入画 |
| 证物指向热心配角 | 一个具体证物把矛头指向此前最热心的人 |
| 环境异变 | 雨变黑、井水变红、天色骤暗 |
| 外部视角台词 | 门外一句「这家店又开门了」把下集冲突引进门 |
| 半句话 + 已知威胁 | 一句没说完的话 + 点名一个已知的外部威胁 |
| 第二人称选择题 | 「如果是你，你会怎么做」，配一张字卡 |
| 最硬一句不给结果 | 停在主角最狠的台词上 |
| 远景 / 背影悲剧 | 赶到约定地点，看见倒地的人，只给远景或背影 |
| 新角色门口亮相 | 雨夜门口新角色的单人近景 + 身份字幕，直接接系列核心设定 |
| 新东西未试用 | 图纸画完、东西造好、还没试 |
| 预告回到受辱地点 | 主角打电话说「明天我去一趟」，切开头受辱处的空镜 |
| 反派闯门 | 反派闯门喊一句贪婪的台词，停在受害者惊恐特写，两人在争一个具体物件 |
| 惩罚第一帧 | 停在惩罚即将兑现的第一个画面，只留一个字 |
| 无台词震惊特写 | 被反杀的人不给回应，只有脸 |
| 生命计时器熄灭 | 一盏灯、一团火、一根香灭了 |
| 异物特写 | 首尾同一人物动作闭环，最后一镜一个本不该在那里的东西 |
| 空 → 有 | 打开空箱失落，移动的光引出藏在角落的宝物 |
| 主客倒置 | 开场谁闯入谁的世界，结尾反过来 + 一句对仗台词 |
| 体验卡到期 | 开卡时埋时限，结尾「到期」反转 |
| 开放结局 | 先给确定的情感落点，再埋两组互相矛盾的画面证据，问句黑场 |
| 时限卡 | 时间字卡 + 武器特写，把本集恩怨回拨成下集行动 |
| 钟面倒计时卡 | 结尾前给截止时刻的钟面卡，铃响瞬间先给物体反应再给人脸 |
| 门将开未开 | 高潮给全片最长镜（8–12s）停在亲密前一刻，门外第三者只给毛玻璃模糊人影 |
| 黑底白字问句 | 结尾不给答案，黑底白字问句点题眼，把讨论交给评论区 |
| 萌宠黑化 | 前段救下的小角色结尾以反差形象回归，一句萌语配暴力结果画面 |
| 三重钩同场 | 集尾叠任务倒计时 + 偷听来的悬念 + 轻喜剧尾巴 |
| 双钩同场 | 主角金手指升级独白压轴 + 反派抢同一目标的消息 |
| 命令句 + 切黑 | ≤8 字命令句收尾，台词落地 2 秒内切黑，不留尾巴 |
| 反派闯门带债 | 开口就骂人的反派带着具体债务数字闯入，台词停在追问句 |
| 切回最穷困家 | 一段爽完，集尾切回主角最穷困的家庭画面，用欠账逼下一集 |
| 立誓 + 宿敌全名 | 卡点时主角点出宿敌全名，立一句五字以内的誓言 |
| 背影 / 虚焦定格 | 不给加害者正面反应镜，背影或虚焦侧脸静止 3–4 秒 |
| 情绪反差落地（治愈 / 情感向） | 情绪攒到临界点，用一个克制的动作切黑，不靠悬念：办完离婚手续走出门，等了她很多年的人只是把外套披到她肩上，她低头看外套、再抬头看他，切黑 |
| 宝物认主 / 系统弹窗（AI 漫剧） | 主角捡到或激活关键宝物、系统，在解锁新能力前一瞬切黑：系统面板弹出「是否解锁」，手指悬在按钮上方；或捡回的破旧器物在推门进屋那一刻微微发光。实拍剧少用 |

反例：黑场 6 秒后什么都没有；结尾 7 秒纯黑场；停在反派嘴硬「我偏不」，情绪没落地；最大的爽点只给 3 秒；片尾把同一句台词循环拼接拉时长。

## 5. 首尾回环（单集闭合）

- 开场的狠话结尾原样回放；开场报的价码，结尾主角自嘲（「这钱收少了」）。
- 开场构图结尾回收；受辱镜头镜像回收，位置对调。
- 一个贯穿首尾的儿童角色（跨几十年），首尾相同构图。
- 前史悲剧和结尾抉择做镜像：主角在同样的处境下做出相反的选择。
- 环形结构：开头倒放最大奇观，结尾用原素材回收；划火柴开场、划火柴收尾。
- 片名里的那个实物，在施害者手中、受害者手中、时代转场处各出现一次。
- 前 15 秒给主角一个身体缺失，结尾以升级的形态回收。
- 主题压成一句问答式金句，同时作标题和最后一句台词。

## 6. 多集连续性

### 6.1 卡点 → 下集开头
1. **回放 + 后果**：下集开头 3–5 秒重放上集最后一句或最后一镜，第 5–10 秒给后果；不要整段重放。
2. **不要重复冷开场**：同一段先导最多用一次，第二集起改成上集卡点的后果镜。
3. **日期卡倒计时**：把期限做成每集开头一张字卡（「距离还款还有 2 天」「第三天」），建立追更的钟。
4. **双视角互相导流**：同一故事拆两个视角各一集，每集结尾露出另一视角的人物。
5. **长线宿命道具**：预言纸条、信物每集出现一次；系列名里的核心道具每集至少出镜一次，最好放在卡点。
6. **连载中段集要能单独看**：第一镜让受害者喊出世界观真相（≤8 字）兼做前情；或情绪闪前 ≤15s 后给一句前情台词或字卡。没有前情锚点的中段集，新观众连人名关系都看不懂。同集并行线 ≤2 条。
7. **系列固定开场仪式**：每集同一种开场（例如零帧证物特写 + 集数卡），老观众认得出、新观众知道是系列。
8. **答案留到下一集第一个字**：卡点抛出的答案，下一集第一镜必须兑现。
9. **新角色身份卡**：集尾新角色单人近景 + 身份字幕，下一集从他的视角或他带来的事件开场。
10. **尾帧 - 首帧匹配剪辑**：集间衔接用上集回顾或尾帧 - 首帧匹配剪辑，缺了就生硬。
11. **卡点写成台词**：把下集悬念做成一句设问字幕，放在中点或结尾前 10 秒，比纯画面钩子更容易被评论引用转发。
12. **发布前攒集**：「首集爆了却没有后续」是最常见的差评来源；精品化的长制作周期和追更节奏冲突，提前攒 2–3 集，或在简介写明更新时间并守约。

### 6.2 发布节奏
- 上线前至少备 3 集。单集爆了却没有下一集可看，催更会变成「又拿这种钓我」的差评；集尾钩子越强、续集越供不上，负面越重。
- 简介写清更新节奏，并守约；观众默认 AI 剧应该更新得快。
- 标题写剧名、片尾打剧名，保证观众在投放的平台搜得到全集；中段集也要能被单独找到。
- 引流用的片段也要有阶段闭环。
- 番外、联动不要在正片断更期发。
- 植入广告 ≤10% 时长，且写成剧情道具（善待落魄者的对照组、一个梗的终点）。

### 6.3 片种标签
标签与内容不符会把片子推给错的观众：挂古风志怪实为虐恋混剪、挂爽文实为苦情故事，都会被骂。按内容的主情绪挂标签。

### 6.4 前三集节拍卡

立项后、写正文前，先用这张卡锁定前三集；写完逐集对照。

| 集 | 任务 | 必须做到 | 不许 |
|---|---|---|---|
| 第 1 集 | **受害事件 + 主角立场**双重锁定 | 观众知道「帮谁、恨谁」；主角有明确表态或行动（不辩解，但也不退让） | 只铺背景不立冲突；主角挨打不还手也不立 flag |
| 第 2 集 | **证据加码 / 考验递进** | 恩情账、付出账或考验加一笔，有新物证；对立方加码施压 | 重复第 1 集的话；没有新信息 |
| 第 3 集 | **冲突升级** | 矛盾从私人摩擦升到公开、金钱或关系层面，情绪吊到付费点前 | 第 3 集还在铺日常 |

共同手法：每集 1–2 个贯穿物件（账本、旧碗、转账截图），情绪落在物件上，特写好拍、AI 好生成；设一个**质疑者配角**替观众把狠话和疑问喊出来，主角保持冷静。行动坚持型（见 1.5）把第 1 集换成「预知灾变 + 开始准备」，第 3 集出现第一次验证。

**四种前三集节奏型**（按题材和成本选）：

| 节奏型 | 三集时长走势 | 特征 | 适合 |
|---|---|---|---|
| 递减型 | 第 1 集最长，之后逐集收短加压 | 单场景为主 + 回忆插叙，信息密度逐集上升 | 都市反击、恩人反杀、家庭 |
| 波动型 | 铺垫集给足，短集快推 | 多场景碎片，「画饼 → 兑现」交替 | 萌宝、治愈家庭 |
| V 型 | 第 1 集火力全开，第 2 集短促过场，第 3 集拉回 | 羞辱 + 回忆 + 立誓集中在第 1 集 | 逆袭打脸、变美、校园 |
| 微集型 | 第 1 集立规矩，之后每集只推一个情绪点 | 单场景长对话，续航长 | 乡村现实、慢情绪剧 |

前三集写完自查：第 1 集立住受害和立场了吗？第 2 集有新信息吗？第 3 集升级到公开 / 金钱 / 关系了吗？有贯穿物件和质疑者配角吗？

## 7. 把评论区变成内容

1. 结尾抛一个二选一或第二人称选择题；「有人说……也有人说……」的辩论式结尾要让两方真的势均力敌，否则会被看穿是预设答案。
2. 选观众会现身说法的议题（家务分工、婆媳、彩礼、姓氏），把矛盾量化成一个能报出来的数字（「九块钱的烟」）。
3. 埋一个可讨论的暗线或可推理的线索镜，让评论区自己猜。
4. 让话痨配角在戏里替观众问出质疑，主角正面回答，提前消掉逻辑攻击。
5. 给配角足够的性格，让观众对他有具体的剧情诉求（「下集让那个嘴碎的表弟撞一次鬼」是最健康的催更）。
6. 设计一个可复用的剧内梗（数值名、口头禅），观众会拿它写评论。
7. 结尾指向观众熟知的历史或常识，给评论区接梗的空间。
8. 避免：引战论据（性别对立、地域标签）；明示诱导点赞；在简介里把「AI」当卖点主语（评论会变成 AI 与演员站队）；改编别人的故事不署名。
9. 观众最常骂的几件事，写完逐条查：同脸换脸、欠更钓鱼、撞题挪用、逻辑和常识洞、AI 穿帮、价值观（物化、美化暴力、性别对立）、人物降智或一味忍让、拖沓、标题党、看不懂。
