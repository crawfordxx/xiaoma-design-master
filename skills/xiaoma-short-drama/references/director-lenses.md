# 大导演思维工具箱

> v0.3。用法：立项时按片种从速查表挑 2–3 位导演（一位管叙事，一位管视听）；写剧本和分镜时对照「短剧招式」逐条问「这集哪一镜可以这样拍」；招式写进分镜的 `purpose`。招式只取手法，不在画面里模仿任何具体影片的场景和角色。片种专属的导演写法在各片种卡末尾。例子都是自拟的。
>
> 希区柯克的「观众先知」是短剧最通用的一招，几乎每集都用得上。

## 三个随时能问的问题
1. **希区柯克问**：观众这一场比角色多知道什么？有没有一个 0.5–1s 的「炸弹镜」可以提前埋？
2. **斯皮尔伯格问**：这一场的奇观或揭示，能不能先拍看的人，再拍看到的东西？能不能只露一半？
3. **是枝裕和问**：这句「我关心你 / 我委屈」能不能换成一个物件或一个家务动作？

## 1. 希区柯克 —— 观众比角色多知道一层
- 手法：桌下炸弹（先给观众看炸弹，再拍角色若无其事）；物体在画面里的大小 = 它此刻的重要性；麦格芬串起情节。
- 短剧招式：
  1. 反转前 30–90 秒插一个 0.5–1s 的「炸弹镜」：反扣震动的手机、门锁屏上「权限已删除」、上游水位标尺、温度计、船底的黑影。
  2. 让观众亲眼看作案全过程（偷听 → 进屋 → 拿起 → 藏好），角色抵赖时观众是唯一知情人；藏匿处持续留在画内。
  3. 禁忌先说给观众：先给规则，再看角色破禁。
  4. 景别随情绪递进到变形大特写。
  5. 惊吓改悬念：怪物出现前先插 1s 暗示镜（树梢晃动、灯管闪一下），告诉观众「有东西在场」。
  6. 重要伏笔分两次投放：第一次虚焦藏在全景里，第二次清晰揭示。
  7. 最暧昧的一刻黑场只留声音。
  8. 倒计时画面化：月亮西沉、天色发白，让时限被画面计时而不只在台词里；可见的计时器（水位、香、替身数目）反复切回。
  9. 麦格芬三次给局部不揭全貌：盖布下的货物每次只给一角，全貌留到卡点。
  10. 规则必须在异象发生的当下用视觉线索给出，事后的台词解释只做确认。
  11. 给第一遍看的人一个 0.5 秒「好像不对」的下意识信号：发梢滴水、碗底的反光、疤痕一闪。
  12. 日常物件恐怖 + 声画错位：用最日常的东西（一只鸡、一件雨衣）做恐怖源，声音和画面故意对不上。
  13. 开场就把底牌交给观众：先给主角藏好的秘密一个特写，全集悬念变成「什么时候被发现」；旁白提前揭穿反派、掩护主角的真秘密；目标道具前景虚焦持续在场；契约揭晓前插 0.5 秒印记特写；反派入场先给偷听者的静默特写。
- 常见错失：来电揭穿没提前埋震动；做局的证据没给观众看；一个倒计时（水位、温度）没有做成可见的计时器反复切回；开场已揭底、中段又揭一次，炸弹炸了两次；本可以让观众先知道真相、看主角一步步踩雷，却选了突然揭晓。

## 2. 斯皮尔伯格 —— 先拍看的人，再拍看到的东西
- 手法：反应先于奇观；延迟揭示；孩子视角；先展示威胁再请英雄。
- 短剧招式：
  1. 奇观三镜：惊愕脸 → 眼部特写 → 奇观；奇观后 0.5s 内切旁观者反应。
  2. 局部先于全貌；怪物按「局部 → 背影 → 正脸」分三次露出。
  3. 先藏后露：只听枪声、只拍敌人倒下；看不见的威胁用声音和人物反应表现（洪水不出画）。
  4. 孩子视线高度机位；孩子作道德指南针，大人围绕他转变立场。
  5. POV 揭示世界。
  6. 群体同时抬头的慢推反应全景确认奇迹；巨物出场先给仰视反应特写。
  7. 平民视角灾难：怪物延迟露面、多级显形，水面阴影反复出现；怪物本体少露。
  8. 杀戮全程不露，靠结果物讲故事（破碎的碗、雪地上的拖痕）。
  9. 威胁靠龇牙近景 + 被救者的恐惧脸传递。
  10. 反应先于揭示：他人俯首、权威起立之后才露主体；爽点一律用汗脸 / 震惊脸特写接收。
  11. 体量先行：开场长镜先奇观后事件；惊奇脸慢推代替奇观主观镜。
  12. 给能力一个代价（用完虚脱、流鼻血），悬念更持久。
  13. 救援者五步延迟揭面：门缝光 → 烟尘剪影 → 逆光中景 → 走近 → 特写。
- 常见错失：长镜和黑场代替了暗示短镜，主角一分多钟才登场；本可以先给结果悬念（红榜 + 妻子惊愕）再给片名；结尾可以只露暗处一张脸的局部；穿越进现代城市可以用孩子视角低机位仰拍。

## 3. 诺兰 —— 时间结构与规则
- 手法：非线性叙事；规则逐条验证；跨时空物证；不可靠叙事者；平行剪辑压缩说明。
- 短剧招式：
  1. 冷开场闪前 → 时间回拨卡；环形结构：开头倒放、结尾原素材回收。
  2. 古今因果交叉剪：一端动作、一端结果 1:1 交替。
  3. 不可靠叙事：同一事实讲两遍换主语；用画面而不是括号字幕让观众自己判断真假。
  4. 说明段 >60s 或旁白 >20s 和现在时行动平行剪。
  5. 用一个画面让前面的台词改变意义（肩上的弹孔，让「他受伤了」翻成「他中枪没死」）。
  6. 首尾仪式闭环（划火柴开场、划火柴收尾）。
  7. 三幕魔术结构：铺垫（展示效果）— 转折（怎么做到的）— 致敬（高潮兑现）。
  8. 现实为锚 + 闪回倒序插入：现在时做锚点，闪回按倒序插入，结尾合拢。
  9. 结局前置 + 回绕：把情绪峰值放开场，旁白交代结局再绕回起点。
  10. 时间作结构武器：时间层字卡做锚点（过去 / 现在 / 未来三个锚）；钟面卡、时刻数字反复出现。
  11. 人物小目标填长镜空档：长镜段给每个人一个可执行的小目标，防站桩。
  12. 双峰节奏：超长镜与闪帧对撞，每 60–90 秒一循环；双计时器并行（「还剩三只」「还剩三天」）。
  13. 感官门时空转场（闭眼、水面）+ 同一手势匹配剪辑；声音桥（电话忙音延续到下一镜）；把悬念做成一道数学题，让观众停在答案边上。
- 常见错失：最后的反转用括号字幕「（走廊尽头空无一人）」代替画面——应该给一个反打，只剩一扇还在晃的门；「钱我已经交给她了」处可以闪回 0.5s 塞包的画面；主角登场晚，前 60 秒可以交叉剪主角在场；脱身诡计可以按「展示 — 隐藏 — 揭示」三步埋伏笔。

## 4. 张艺谋 —— 色彩即叙事，重复即力量
- 手法：大色块分阵营 / 分段落；单一强调色；阵列表现权力；红色仪式。
- 短剧招式：
  1. 每个角色 / 阵营一种主色，全集不换。
  2. 全片冷灰里只给主角一种色（红、明黄、粉）。
  3. 段落色彩弧 / 四幕四色；反转段落色调断崖切换。
  4. 阵列与纵深对称（满屏黑甲的大殿、火把长龙）。
  5. 生活里的红物件一步步变成恐怖符号；红色也可以反过来做保护（一面红幕护住众人）。
  6. 同色押韵连接两个事件（火光的橙红接红手印）。
  7. 院子即公堂：对称庭院、俯拍磕头，观众当判官。
  8. 食物即情感：爱、愧疚、和解全用做饭和夹菜拍。
  9. 物件 + 局部讲往事：3 个 1 秒的静态插入镜代替一整段闪回。
  10. 谎言金色、真相灰色：不同颜色讲不同版本的「真相」。
  11. 色温即叙事层：前世冷调、今生暖调；唯一暖色标记活人；单色海洋里的一滴互补色，暖色重音的出现次数随危机升级而增加。
  12. 等级和阵营用颜色编码（四种水晶色 = 四个等级）；服装颜色转换写成长线；白衬衫被血染红做本集视觉主旋律；冷来自规矩而非坏人——制度的色调整个不给暖色。
- 常见错失：「红白同路」只在台词里说，没把送葬队和花轿合成一个同街交汇的大俯拍；可以用唯一的朱红把前史的人和结尾的人连起来；幻觉里的人物在另一个现实层里仍可以带着原来的冷蓝和湿发。

## 5. 王家卫 —— 物件、时间与暧昧
- 手法：物件替代欲望；独白 + 时间数字；前景遮挡、慢门；色温切割。
- 短剧招式：
  1. 亲密戏用手、项链、蜡烛快切代替肢体交缠。
  2. 旁白放具体数字和日期；数字化台词增强记忆（「九块钱的烟」）。
  3. 倒数拆成手 / 眼 / 钟三个 1s 分镜。
  4. 回忆段每镜只留一个情绪峰值的时间切片。
  5. 「正在输入…」的欲言又止，加静场空镜放大停顿。
  6. 留白长镜内必须有一个微小事件。
  7. 把最甜的回忆放在结尾反刺（悲剧结局）。
  8. 毛玻璃前景隔断：门外人影 / 门内亲密的双层叙事。
  9. 抽帧顿挫：贴脸的亲密动作（摸额试温）用抽帧顿挫拍；甩镜运动模糊 + 滞留的脸部特写承担潜台词。
  10. 身体局部特写（唇、手指、耳坠）拍欲望；两种占有同机位镜像；窗玻璃反射半张脸，前景虚焦留白。
  11. 内心独白 + 情歌 + 时间跳切的错过美学。
  12. 同一种红从欲望变死亡；结尾首次大面积用红，与前段血迹呼应。
  13. 旧物特写替台词讲时间跨度（一只旧手表讲完五年）；电子钟时间母题，钟面首尾对照。
- 常见错失：几十秒的留白长镜里什么都没发生；男主的心声段可以改成窗边背影 + 慢门光斑；结尾两人对望手机可以改成前后景同框；一个 15 秒长镜可以升格抽帧 + 心声。

## 6. 冯小刚 —— 贫嘴、算账与市井讽刺
- 手法：市井贫嘴；嘴上一套心里一套；前倨后恭；把小事拔成态度；一句金句落版。
- 短剧招式：
  1. 嘴硬 → 打脸两镜，声音桥接硬切。
  2. 重复句式三次，第三次被抢话打断；讨价还价用三拍。
  3. 势利眼变脸：同机位同景别连拍三次脸色变化。
  4. 市井群像：旁观者一句话即舆论；保姆、助理当嘴替。
  5. 家庭群戏一人一句台词分阵营。
  6. 配角以玩笑说出预言，结尾真的兑现。
  7. 临终 / 煽情台词后留 1.5s 静场；一句金句落版。
  8. 潜规则明码标价：把办事的规矩说成「办事学」语言，感情和规矩都拿来讨价还价。
  9. 性别对调句：规矩倒过来念，男女一换即成讽刺。
  10. 相声式群口：三人抢人的贯口，群口节奏。
  11. 俗物撑阶层讽刺：土鸡、大葱、月薪，小物件比大道理狠。
  12. 笑点全在吐槽词不在脸：冷面相声（用民政局下班倒计时算爱情）；金句笑着说 + 对方 0.5 秒定格脸。
  13. 群像反应编号喜剧（震惊一号、二号、三号）；道具跑梗，打脸时回收；煽情节制，眼泪留到反转点；群像嘴仗让反派内部出裂缝；给奇观加一个家人来电动机（去看怪物，因为家人在那里）。
- 常见错失：零花钱讨价还价没做成三拍；沉默的大多数可以补几个路人躲开的特写；本可以让女主越过男主的肩膀看镜头、挑一下嘴角，代替一句旁白点破。

## 7. 昆汀 —— 章节、类型拼贴、话多的对峙
- 手法：章节卡与定格名牌；类型戏仿与梗拼贴；对白即动作；复仇清单；反高潮。
- 短剧招式：
  1. 章节卡显性化升级或倒计时（「第三天」）。
  2. 角色首次登场定格 + 大字名牌 + 专属音乐。
  3. 对峙爆发前 2 秒三角静止；对话即对决，用机位高低表现权力翻转。
  4. 复仇对象逐个「出局」卡。
  5. 喜剧到恐怖的类型突变（色调 + 剪辑速度一起换）。
  6. 重复问话里换一个陷阱问题。
- 常见错失：长独白可以逐级推近到大特写再切大全景；重复问话可以换一个陷阱问题让主角先掉坑再翻盘；孤胆客入镇可以补一个村民门缝窥视的主观镜。

## 8. 大卫·芬奇 —— 证据、控制与冷色
- 手法：程序化搜证；证据墙；对称 + 冷蓝低饱和；按罪设计死法；精确快剪。
- 短剧招式：
  1. 证物照相法：统一俯拍、硬光、编号牌入画；同一机位只换工具连切 3–4 次。
  2. 口述证据改成插入特写；推理段插物证，让推理落在画面上并交代信息来源。
  3. 死法与死者的罪一一对应，开场露对应物一角，后段完整展开。
  4. 快问快答释放信息，每个信息点切更近一级景别。
  5. 对称正反打 + 逐镜推近，让权力翻转有视觉曲线。
  6. 冷绿荧光的一点透视长走廊。
  7. 给破解加代价，不让高规格障碍几秒破解。
- 常见错失：「军工级」密室被蛮力几秒砸开，没有代价；动机链缺可视化的证据镜，逻辑被吐槽；药盒、小票、门锁记录本可以统一拍成俯拍硬光证物镜；反派炫耀段信息密度没压缩。

## 9. 宁浩 —— 小人物荒诞与连锁
- 手法：方言群像；一本正经的荒诞并置；小人物算账；多线因果连锁；黑色幽默。
- 短剧招式：
  1. 正经的说明字幕写惨事。
  2. 神力之后接一个世俗小反应。
  3. 一句算术立住荒诞世界观；金钱数字递增砸人。
  4. 方言小人物与杀机错位（举起相机配一声上膛音效）。
  5. 多线因果链回收（贷款 → 囤货 → 催债）。
  6. 小人物公路荒诞（电驴载鬼、被交警拦、没电推车）。
  7. 反派自曝是群演，拆穿片场（自嘲）。
  8. 把观众设成陪审团，但别做成明示诱导。
- 常见错失：喜剧配角线中途消失，后半情绪单一；赌鬼可以加「把镯子藏进旧烟盒」这类黑色幽默细节；反派的心声威胁可以做成暗处窥视镜；市井证人（先问有没有奖金、又怕被灭口）的喜剧化可以再放大。

## 10. 是枝裕和 —— 生活细节承载情感
- 手法：吃饭、家务、旧物代替煽情；非血缘家庭；固定机位；不说破的照顾。
- 短剧招式：
  1. 身份证明用 3–5 个生活细节，一句一镜。
  2. 被强调的生活道具必须配一个动作特写兑现。
  3. 同一道具从施舍到温暖（同一只碗），完成冷暖对照。
  4. 高潮前的琐碎日常积累作泪点地基（请求逐级变小的蒙太奇）。
  5. 用价目物件讲亲密关系里的权力（烟、冰棍、工资条）。
  6. 委屈台词后留 3–4s 无台词小动作镜（抹平被角）。
  7. 结尾无台词长特写留白。
  8. 每晚的日常仪式（倒一杯酒、留一盏灯）建立人与非人的情谊。
- 常见错失：「在哪儿都能凑合」后缺一个 3–4s 无台词抹被角镜；争吵可以换成压在碗底的十块钱；可以给公公一个独处凝视孙子照片的静默镜，复杂化他的立场；热水袋、红糖水插入镜可以代替一句台词宣言；追凶缺一个受害孩子的主观镜，没有情感驱动；丧亲缺一张照片插入镜。

## 11. 小津安二郎（补充）—— 低机位与无声离场
- 短剧招式：老人离开用低机位固定全景，门缓慢合上，不配台词和煽情 BGM。电梯门关上、地下室门推开，都可以这样拍。

## 12. 贾樟柯（补充）—— 超自然从现实里长出来
- 短剧招式：灵异题材先用 60 秒建立真实的地域劳动 / 生活场景（采石场、北方农村的红塑料盆和二八自行车），再让异物出现；方言台词不配普通话腔调。

## 13. 徐克（补充）—— 港风志怪与以柔为刃
- 手法：柔焦暖黄、红衣、烛光；飘带布料作武器；武侠奇观的节奏。
- 短剧招式：
  1. 怀旧港风：胶片调色 + 柔焦 + 颗粒，统一 AI 镜头之间的差异。
  2. 打斗用布料、水、光刃代替肢体接触；布料掠过镜头直接当擦除转场。
  3. 红衣化身作视觉锚点。
- 常见错失：几十秒无威胁的恋爱段，本可以借红衣和飘带改成带威胁的动作段。

## 14. 伊丹十三（补充）—— 食物即欲望与情感
- 短剧招式：「馋」拆成鼻子、喉结、眼睛三连特写；品尝镜后插一个记忆闪回，把口腹之欲升成情感。
- 常见错失：主角只有「笃定」一种状态，观众只记住食物不记住人。

## 15. 吴宇森（补充）—— 暴力美学的定格
- 短剧招式：打斗快切到最高点，加 0.5s 升格慢放 + 定格，做一张能截图的爽点画面。
