# 剪辑节奏

> v0.3。片种的具体镜长区间以片种卡为准，本页给通用规则。例子都是自拟的。

## 1. 平均镜长（ASL）基准

| 片种 | 常见区间 | 建议目标 |
|---|---|---|
| 甜宠霸总 | 1.6–2.6s | 1.6–2.3s；偏慢会明显吃亏 |
| 穿越重生 | 1.5–2.8s | 1.5–2.8s |
| 古风志怪 | 2.0–4.8s | 甜宠 / 宅斗向 1.9–2.9s；志怪长集 2.5–3.5s |
| 奇幻西幻 | 2.2–6.0s | 2.0–3.5s（6s 级多半是站桩） |
| 爽文逆袭 | 2.4–3.6s | 2.0–3.0s |
| 复仇虐恋 | 2.0–4.0s | 实拍 1.3–2.2s；AI 2.5–3.5s |
| 悬疑刑侦 | 2.5–3.7s | 2.5–3.7s；民俗氛围向更慢 |
| 都市家庭 | 2.2–4.2s | 1.8–3.5s（对口戏可压到 2 以下） |

- **ASL 不能单独预测好坏**，快剪和慢剪都有爆款；慢而好看的几乎都是横屏悬疑、志怪、催泪，靠信息差和氛围撑。**快慢的对比比平均值更重要**。
- 实拍短剧比 AI 剧快（实拍常见 1.3–2.2s）；AI 剧受生成时长约束，常见 2.5–3.5s。
- 量自己成片的 ASL 时人工复核：暗场和叠化会漏切、闪烁会多切、连续跟拍会被误切；ASL 低于 1.4s 先查是不是碎切。
- 大盘基准：全片种中位镜长稳定在约 2.5–2.9 秒；竖屏比横屏更快（约 2.1 秒 vs 2.8 秒），镜长主要由片种决定。
- **按段落的镜长基准**（比全片 ASL 更有用）：恐怖开场约 1.3 秒；决战 / 高潮战 1.1–1.5 秒；奇观 / 世界观展示 1.6–2.2 秒；情感高潮 / 重逢 2.4–4.3 秒；灾难开场段约 1.3 秒。
- 前 3 秒只有 1–2 镜时全片 ASL 失真，要人工逐镜看。

## 2. 快慢段落

| 段落类型 | 镜长 | 写法 |
|---|---|---|
| 打斗 / 开挂高潮 | 0.3–1s | 单动作快切，前后台词段 3–6s，用快慢差放大爽点；最高点加 0.5s 升格定格 |
| 法术 / 符阵 / 光效 | 0.1–0.2s 闪切 | 只用于光效，不用于叙事动作；肢体接触只留 1–2 个关键瞬间 |
| 卡点混剪 / 回忆蒙太奇 | 0.45–0.5s 一拍一切 | 每镜只取一个情绪峰值；现在时 1.5–2.5s，回忆一拍一切，慢 — 快 — 慢 |
| 美食 / 工序 | ≤1.5s，食物和反应 1:1 交替 | |
| 喜剧 | 快切；转折和揭晓前放慢到 ≥3s | |
| 喜剧碎切之后 | 1–1.5s 静止落地镜，再接反应 | |
| 对白戏（都市） | 一句一镜，反应镜 ≤1s，单镜 ≤7s | |
| 情绪 / 心动 | 2–3s 慢动作，或 4s 以上长镜 | 动作段和情绪段镜长拉开 2 倍以上 |
| 恐怖等待 | 3–10s，越慢越怕 | 喜剧段快、恐怖段慢，慢本身就是手段 |
| 奇观后喘息 | 8s 以上静止长镜 | |
| 主导权转移 / 真相确认 | 全片最长镜（≥10s），其余 2–4s | |
| 反转台词落地 | 4–5s，紧接对方反应大特写 | |
| 歌曲蒙太奇 | 每镜 1–2s，结束接 10s 以上长镜 | |
| 爽点揭晓 | ASL 压到 1.5s 以下，多角度反应镜 | |
| 封闭空间 → 离开 | 封闭空间里快剪，离开后切一个 10s 以上长镜，暗示危险换了位置 | |
| 类型突变 | 喜剧长镜 → 复仇 2–3s 短切，同时换色调 | |
| 灾难奇观冷开场 | 12s 长镜慢起 → 连续闪切制造刺点 → 快切动作蒙太奇 | 双峰节奏，每 60–90 秒一循环 |
| 恐怖开场 | 首 15 秒 ASL 约 1.3s | 首镜若是慢长镜，把最强的恐怖画面剪 1 秒预告插到最前 |
| 决战 / 高潮战 | 1.1–1.5s | 奇观镜可拉到 6–16s，但前后必须接反应镜 |

上下限：
- **叙事动作单镜下限 0.5s**。0.1–0.4s 的碎切只用于光效闪切、穿越闪帧、轮盘；不要用来掩盖生成不出的走位。轮盘太快、落点不明会看不懂，末尾必须减速到 0.3–0.5s 并上字幕。
- 导出前清理误剪的闪帧（0.1s 以下的残帧）。
- **非高潮单镜上限 5s**；对话单镜 >8s 就和动作或道具特写交叉剪；>10s 的对话戏拆出至少 2 个反应镜；>12s 的对话长镜拖节奏；20s 以上的说话长镜口型一定穿帮。
- **留白长镜 ≥10s 必须有一个微小事件**（风、落物、眼神变化），否则拆短。
- 切点预算不够时，可以用 15–25s 的信息长镜配画外音推进，把快切预算留给惊吓段，但单镜别塞超过 2 条新信息。
- 不要均匀 2 秒一刀：全片镜长都落在 1.5–3.5s，没有快慢落差，等于匀速。
- 好几镜恰好 8–10s，说明是按生成时长直接拼的；生成后一律按戏剪短。
- 前 15 秒别只有 2 镜。
- 三个划走元凶，逐条查：**超过 30 秒的静态对话块**（拆成多镜或插入画面事件）；**冷开场十几秒无变化的走路长镜**；**开场一个接近 9 秒的不变单镜无台词**（前 5 秒插一次反应镜或动作）。

**AI 出片的剪辑约束**（见 ai-production.md）：
- 生成片段最短约 4 秒；分镜写 2–3 秒的镜头也要生成 4 秒再剪，按生成秒数计费。
- **台词不一定从片段开头说**，有的前几秒是表演、台词在第 4 秒才出口。入点和出点用语音转写定位人声，不能默认从 0 秒剪；按分镜时长硬剪会切掉半句。
- AI 配音约 3 字/秒，比分镜默认的 4–5 字/秒慢，对白镜会普遍超长。剪辑跟着人声出点走，宁可总时长变长，也不切半句；要压时长就回剧本砍字。
- **片段内部会自带切镜**：提示词写了「单一连续镜头」，模型仍可能在一段里自己切成两三个镜头。剪之前先对每个片段做镜头检测，只取其中一个镜头段，其余丢掉；不要把内部切点当成自己的剪点。
- **剪点两侧不能重复画面**：上一镜出点和下一镜入点是同一帧（同一个鞋印、同一只眼睛、同一面钟），观众看到的是卡顿。每个剪点比对两侧首尾帧，重复就往里裁；镜头检测抓到的 0.1s 级残帧一并清掉。

## 3. 反应镜
- 每个打脸 / 取财爽点后，接受压方 1.5–2.5s 反应特写；钱的数字每砸一次，接一次听者反应。
- 每个信息爆点按「揭示镜 → 1–2 个主角近景反应 → 物证细节特写」三拍剪，反应镜比物证镜长，情绪落在人脸上。
- 每句狠话后接一张对方的脸；单场独白 >8s 就拆。
- 反应先于奇观；奇观后 0.5s 内切旁观者反应。
- 关键信息后插群体反应镜，用旁观者的震惊把荒诞设定转成可信。
- 每个情绪节点配一个旁观者反应镜 + 一句替观众说的话。
- 群像说话镜用反应镜、背影、远景代替正脸。
- 苦情段：受害者哭脸特写 2–3 镜 → 施助者红眼反应 → 施助动作。
- 四人静态同框 15 秒没有反应镜 = 站桩；合成时可以用顶部字幕写反应。
- 卡点后给缓推反应脸 + 静场，不直接黑场。
- 误会戏：同一句话，说话人近景 → 听者误读的反应近景。
- 情绪转折之间缺过渡镜，人物动机会显得突兀（从误会直接跳到娇羞）。
- **同功能的插入镜只留一个**：两个看手机屏的镜头功能重复，就合并，省下的秒数给更需要停留的镜头。
- **奇观后必接反应镜**：奇观每 60–80 秒升级一次，每次升级后给人物反应，不允许奇观连续出现而无人观看。
- **反应先行**：揭晓爽点前先拍反应镜（愕住、公文包滑落），再从背影推到正脸。
- **反派转变三拍反应镜**：不屑 → 震惊 → 臣服，比台词快。
- **权威角色反应镜作收束拍**：奇观或宣告落地后，用最有权威的人起立 / 俯首收拍。
- **用反应镜标记节奏**：爽点 → 被嘲者 1–2s 反应特写 → 下一爽点。
- **三段反应镜拍打脸**：受害者、旁观者、权威依次给反应。

## 4. 转场语法（全片统一，不混用）
| 转场 | 含义 |
|---|---|
| 闪白 / 0.1–0.4s 闪帧 + 蒸汽 / 虚焦 | 时空跳跃、穿越、开挂 |
| 色温突变硬切 | 两个时空 / 两个现实层 |
| 提示音 + 闪白 + 眼睛大特写 | 金手指换挡 |
| 黑场 | 死亡、终结、「答应」后的断电式切换 |
| 黑场字卡 / 静音字卡 3–5s | 时间跳跃、高潮后悬置态度 |
| 破碎的物理动作 + 色温跳 | 梦醒 |
| 声音桥接硬切 | 嘴硬打脸；同一句称呼跨现实层 |
| 地点 + 年份字幕硬切 | 冷案的两个时代 |
| 【十分钟前】/ 半年前字卡 | 倒叙回溯 |
| 画框形状（椭圆暗角）/ 白晕边 | 闪回，不用字幕说明 |
| 电视 / 镜面匹配转场 | 进入闪回 |
| 布料掠过镜头擦除 | 古风打斗中换场 |
| 道具带路跟拍 | 进入新场景 |
| 场景牌「另一边」 | 双 CP 平行 |
| 章节卡 / 假海报 / 游戏 UI / 章回字卡 | 阶梯升级、换世界、倒计时 |
| 色调整体切换 | 合集段落 |
| 时间回拨字卡（或 2s 倒放） | 闪前后回到起点 |
| 光照突变（灯亮 / 断电） | 拆成「之前」「之后」两个镜头，中间用后期亮度闪接，不让一个生成镜头完成光照突变 |
| 白闪过曝帧 | 换层（前世 / 今生、现实 / 异空间）的统一语法，先教一次再用 |
| 尾帧 - 首帧匹配剪辑 | 集间衔接，缺了就生硬；或用上集回顾 |
| 视线匹配 | 反派视线接主角正面特写，威胁落地 |
| 感官门（闭眼、水面） | 重生换层，配同一句誓言做声音锚 |

反例：叠影过渡用得太多，画面糊成一团像在藏瑕疵；约 7 秒的白场零信息。

## 5. 静场
- 第二幕后半删对白、靠环境推进，前提是冷开场已经告诉观众危险在哪；恐怖段先放慢，用黑场和静场等待。
- 揭示前 1–2 秒静场再爆发；「你自己听」后加 2 秒静场。
- 情绪最高点：同机位连续特写只换表情和台词，配 2–3 秒静场，不加运镜。
- 临终台词 / 金句后留 1.5s 静场；夜路对话后留 2–3s 无台词背影；金句后接一个无台词的离开空镜。
- 黑场 ≤3–5 秒；结尾 7 秒以上纯黑场是流失点。
- 开场和无台词段落纯 BGM ≤10s；后 60 秒几乎没台词全靠配乐、中段一分多钟纯音乐，都是节奏塌陷。
- 具体时长参考：金句前抽 0.8 秒静场、说完 2 秒内切黑；宣判前静场 2–3 秒；金句后静场 2 秒收尾；反派进场一拍静场；威胁句后静场一拍再切威胁源；爆炸后 1–2 秒静止再推；卡点前 0.2 秒黑场 + 音效切断。

## 6. 平行剪辑与压缩
- 说明会议 >60s 平行剪入行动；背景旁白 >20s 和现在时的危险镜交叉。
- 主角登场晚时，把主角交叉剪进前 30–60 秒。
- 古今因果交叉剪：古代刻字一笔、现代屏幕跳一下，1:1 交替。
- 作证 / 互动段和作案画面交叉剪，≤20 秒。
- 无台词受辱段和说明交叉剪。
- 双 CP：第一对完整演，第二对只演差异。
- 开场电话、寒暄段压到一镜一句：三四镜的来回通话压成一镜 + 一句关键信息（「取消要扣两百」）。
- **删无意义镜头**：每镜一句话说得出观众看到了什么。看不出内容的空镜（墙角斜拍、无主体的暗部）、和前面几乎一样的楼体外景，删掉或换成承载信息的插入镜（钥匙交接的手、门把手上的灰）；省下的秒数给线索镜。
- 结尾峰值后空镜 / 纯音乐 ≤3s；片尾把音轨循环拼接拉时长是硬伤。
- 正片后不接花絮。
- 同一生成片段在一集里出现两次会被发现，回收素材只用于有意的首尾环形结构。
- 闪前冷开场从高潮战里截 15–25 秒，正片第 4 分钟前后原样回收，省一次生成又成环。
- 前世冤案用旁白三句压缩 + 交叉闪回，第 20 秒落标题卡。
- 冷开场高能片段与正片的穿书自述交叉剪。
