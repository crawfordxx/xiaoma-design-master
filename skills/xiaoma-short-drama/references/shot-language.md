# 镜头语言：画幅、景别、构图、运镜、招牌镜头、站位、光色

> v0.3。术语和分镜字段见 director/references/shot-language.md、director/references/storyboard-schema.md。例子都是自拟的。

## 1. 画幅：按投放平台定

**画幅按投放平台定，不按片种的习惯定。** 横构图（16:9 / 2.39:1）放进竖屏平台，上下留黑后主体只剩约三分之一屏：开场的脸、同机位对照、证物细节都会缩到看不清，这是开场被划走的头号原因。

- **投竖屏平台**：默认原生 9:16。想要电影感、群像或奇观时，仍可局部用横构图，但**钩子、关键反转（尤其同机位对照）、卡点这几个镜头必须按竖屏重新设计构图**——楼梯井、走廊纵深、门缝、仰拍巨物本来就适合竖屏。
- **投横屏平台或长视频站**：悬疑、奇幻、志怪、穿越、古风奇观用 16:9 或 2.39:1 遮幅，电影感更强。
- 片种比画幅更决定热度：同样的横屏，悬疑志怪受欢迎、爽文家庭不受欢迎。别为了「横屏更火」把一部对话撕扯戏硬做成横屏。
- 一部片选定一种主画幅，不在集内混用；横构图入竖屏时字幕加大，关键信息放画面中间 60%，在 `post.edit` 注明上下留黑区放剧名和字幕。

| | 竖屏 9:16 | 横屏 16:9 / 2.39:1 遮幅 |
|---|---|---|
| 主景别 | 单人近景、胸像，人物占画面宽度 60% 以上 | 中景、全景、大远景都能用 |
| 多人 | 不横排。用纵深（前后）、上下分屏，或单人正反打 | 可同框，用左右分色区分阵营 |
| 奇观 | 竖向尺度（巨物仰拍、坠落、楼梯井俯拍） | 横向尺度（军队、雪原、火把长龙） |
| 文字版面 | 顶部剧名条 / 章节标题 + 中部大字幕 + 竖排名牌 | 字幕加大，照顾竖握观看 |
| 适合 | 对话撕扯、家庭伦理、甜宠、爽剧打脸、解说体 | 悬疑氛围、奇幻奇观、志怪、电影质感 |

**竖屏重构的写法**：横构图里「人在左、门在右」的关系，竖屏改成「人在前景下方、门在后景上方」；同机位对照（前后两次同一个画面看变化）要让变化的东西占画面中部至少三分之一；时间卡、片名、小字不要压在同一个镜头里三层合成，拆到两个镜头：片名单独一卡，时间地点另一卡，「AI 生成 · 纯属虚构」只做角标。

## 2. 景别

### 2.1 分布基准
- 对话为主：中景 50–70%，近景 / 特写 20–40%，全景 ≤10–15%。民俗志怪参考：近景 45% / 中全景 35% / 特写 20%。
- 多人对话：单人近景正反打，**每 4–8 镜回一次全景重新定位站位**；群戏只在新人物进场时回全景。
- 一句一切的中近景正反打连续超过 20 镜会单调；整集全是胸像快切，就没有一张能截图的招牌画面。
- 空镜和外景必须承载信息：看不出在拍什么的墙角斜拍、和前面几乎一样的第二个楼体外景都删掉；建立镜头一个场景一次就够。
- **对话戏三件套**：60% 以上的对话戏放密闭空间，固定双人中景锚 + 特写正反打 + 每 40 秒一个旁观者插入镜。
- **回合标记全景**：每一轮升级先切一个多人全景重建站位，再进正反打近景——全景是回合标记，站位变化就是阵营变化。
- 情感戏每 20–30 秒插一个双人全景：用道路或门框做中轴，把两人放在两侧，用距离表现关系。

### 2.2 景别走法
- **情绪递进收紧**：全景 → 中景 → 近景 → 大特写，最狠的一句用广角变形大特写，结尾退回平静近景。
- **权力反转**：对称正反打 + 逐镜推近，最狠一句给大特写；占理的一方越拍越紧、仰拍，被驳倒的一方俯拍。
- **长独白**：随台词逐级推近到大特写，再切一个大全景。
- **审讯 / 对质**：全景定位 → 单人近景 → 过肩紧两人，问答每轮 1–2 秒，连续 6 轮以上。
- **景别断崖**：大远景直接切极端特写，揭示非人身份或异常，特写停 ≥4 秒。
- **撩拨三步**：正反打大特写 → 双人近景 → 身体局部插入，镜长 1.5–2.5 秒。
- **同机位同景别连拍三次变脸**：势利眼前倨后恭，机位不动，只换表情和台词。
- **揭示三拍组**：揭示镜 → 1–2 个主角近景反应 → 物证细节特写。
- **仰俯对切表权力**：强者高位俯拍全景、弱者仰角特写加逆光，各停留 2–4 秒；开场用仰拍施暴者与俯伏受害者同框立身份压迫。
- **对话张力递进**：中景骂人 → 关键台词切眼睛大特写。

## 3. 构图
| 构图 | 用途 |
|---|---|
| 权力倒置（强者跪、弱者坐） | 甜宠权力反转，结尾同构图回收 |
| 纵深：前景危险、背景无知角色 | 观众先知的危险 |
| 纵深：前景旧时代、远景新时代 | 一镜交代穿越落点，代替台词 |
| 门框 / 铁栅 / 门槛分隔 | 外来者与家、阶层隔阂；第一镜就把被排斥的人放在门外 |
| 对称 + 顶光光柱 | 审讯、宣判的高压 |
| 中心对称的官府 / 宫殿 | 体制、仪式感（纵深大殿 + 满屏黑甲） |
| 中轴对称的大女主 | 开挂后的地位确认 |
| 人物当比例尺 / 巨掌压下 | 超尺度奇观 |
| 一点透视长走廊 | 都市志怪的冷与压迫 |
| 纵深阵列（箱子、人、灯笼排到远处） | 数量即权力 |
| 高俯拍光点长龙 | 群体撤离，同时规避多人肢体 |
| 月洞窗 / 圆镜框中框 | 古风回忆、两人分层 |
| 窗格逆光剪影 | 密谋、背叛，第三者不露正脸 |
| 前景虚化窥视 | 被注视感、网恋掉马 |
| 左右分色同框 | 敌对双方一冷一暖 |
| 并排全景交代身份反差 | 豪车和旧三轮停在同一个车位线上 |
| 孩子视线高度仰拍 | 萌宝、孩子作道德指南针 |
| 孤胆客入镇 + 门缝窥视主观镜 | 外来英雄 |
| 同构图下跪 / 镜像位置对调 | 打脸回收 |
| 首尾同构图（跨时间） | 单集闭环 |
| 信息版面式（人物居中 + 头顶提示字 + 身侧名牌） | 真人抠像或单人推理 |
| 框中框（月门、镜、格栅门）+ 前景背影压画面下 1/3 | 偷窥、捉奸场，省掉关系交代台词 |
| 毛玻璃前景隔断 | 门外人影 / 门内亲密的双层叙事，第三者只给模糊人影 |
| 对称全景审判 | 逻辑高潮一眼交代阵营和争夺物 |
| 一点透视对称（天花板、法阵、列队） | 片头片尾书挡，与怼脸特写制造构图反差喜剧 |
| 逆光门框剪影 + 屋内飘尘 + 一拍静场 | 反派登场先给轮廓再给正脸 |
| 人物做比例尺（巨兽在街道纵深、人群在前景） | 超尺度灾难奇观 |
| 三角站位俯拍全景 | 荒诞群像对峙 |
| 俯拍磕头 / 仪式 | 仪式化权力、神域俯视 |
| 对称空镜（空椅子、独坐）揭底 | 结尾不用台词，一个对称空镜揭真相 |
| 屏中屏 | 把私密宠爱变成公开围观 |
| 2.39:1 院线遮幅 | 插叙 / 回忆段用遮幅区分时空，强化电影感 |

## 4. 运镜
- **默认固定机位**。AI 生成和抠像合成时，机位运动越多越容易穿帮；运镜只在有动机时用。
- 有动机的运动：
  - **缓推近反应脸**：卡点、心声揭示、恐惧前。
  - **慢推横移扫证物墙**。
  - **主观镜头**：棺内仰视、POV 手持代入、凶手藏在物件里的视角（玩偶的眼睛）、失忆者的主观视角误导。
  - **道具带路跟拍**：一个被风吹走的小道具带镜头进新场景，转场和世界展示合一。
  - **由远至近逼近**：鬼脸从院子全景一路逼到近景。
  - **镜头不动只动光**：手电、烛光引导视线。
  - **连续空间漂移**：AI 的强项，一集只用一次，留给最关键的空间揭示（从病房推向铁窗、穿过栏杆、升高俯瞰）。
  - **群体同时抬头的慢推反应全景**：确认奇迹。
  - **低机位广角**、**航拍大景开场后断崖切特写**。
  - **惊奇脸慢推反应镜代替奇观主观镜**：揭晓前先拍看的人愧住（愕住、手里的公文包滑落），再从背影推到正脸。
  - **空库房回拉全景**：回拉展示「搬空了」的战果，让成果被一眼看见。
  - **走廊式缓推独白**：行走 + 缓推，给重生和回忆段一种回忆质感。
- 不做：无目的漂移；所有镜头同一种推拉；连续三句都是大特写加推。

## 5. 招牌镜头库（每集至少用 1 个，集中在钩子、翻盘、卡点）
1. **先拍看的人**：惊愕脸 → 眼部特写 → 奇观；奇观后 0.5 秒内切旁观者反应。
2. **延迟登场**：先物后人；局部（脚、手）→ 道具特写 → 旁人反应 → 全貌，揭示前先让配角八卦传闻；侧脸近景 → 标志物特写 → 全身 → 背影；低机位脚步特写入场；怪物局部 → 背影 → 正脸，分三次露出。
3. **局部大特写替代亲密 / 暴力**：手、项链、蜡烛快切代替肢体交缠；「馋」拆成鼻子、喉结、眼睛三个局部连切。
4. **结果镜代替过程镜**：不拍打的过程，拍碎掉的存钱罐、散一地的硬币。
5. **证物照相法**：证物统一俯拍、硬光、浅景深、编号牌入画；同一机位只换工具连切 3–4 次。
6. **暗处发光眼剪影**。
7. **墙缝 / 门缝里的眼睛**。
8. **镜面 / 反光**：镜中倒影一镜完成主观 → 客观的揭示。
9. **延迟露全貌**：灾难、怪物、宝物都先给局部。
10. **同机位对照**：四季、昼夜、前后（同一间屋，灰尘 → 干净、空 → 满）；狗窝软垫和潮湿地铺同机位俯拍对剪。变化的东西要大到竖屏上看得清。
11. **章节卡 / 假海报**。
12. **美食俯拍流水线**：整块食材 → 空锅 → 逐样下料（每镜 ≤1.5s）→ 出锅 → 大口吃 → 旁人闻香；食物特写和人物反应 1:1 交替。
13. **手机三镜组**：脸部近景 + 后期气泡字幕 + 手机屏插入；决战场景里反复切回「炸弹屏幕」。屏幕一律生成「屏幕纯白发光、无任何字」，`on_screen_text` 写明屏幕区域，内容后期贴进屏幕。
14. **头顶 HUD / 数值**（后期合成）。
15. **老虎机轮盘**：锁同一张脸同一构图，每格 2–3 帧，末尾 3–5 格减速到 0.3–0.5 秒落定，并上字幕。
16. **三张大全景排比**：宏大愿景一句一景。
17. **双人小剪影远景接黑场**：悲剧结局里最后的甜回忆。
18. **雨夜门口单人近景 + 身份字幕**：新角色卡点。
19. **冲击重复**：打脸或翻盘的关键动作从 2–3 个角度各给一次，全集只用一次。
20. **背后仰拍**：低机位从主角身后仰拍他走向对手。
21. **救援者五步延迟揭面**：门缝光 → 烟尘剪影 → 逆光中景 → 走近 → 面部特写，全程逆光与烟尘。
22. **怪物四级显形**：局部（眼睛、爪印）→ 剪影 → 掠影 → 全身，全身亮相放集末做卡点。
23. **侦探签名镜**：每次关键观察插一次瞳孔大特写，代替复杂表演。
24. **物件代理链**：助理甩名片 → 名片文字满幅特写 → 对方汗脸特写接收，主角全程不自我介绍。
25. **证据插入特写**：推理台词每个体征配 0.5 秒证据特写；便利贴名单、聊天记录作证据插入镜。
26. **萌宠 / 巨物局部**：巨物反派只生成一只眼睛或局部、永不给全身；萌宠局部揭示（先手后物、先猜后见）。
27. **手部插镜三件套**：嫉妒和情绪物化成抓袖、攒拳、搭肩，每件套 ≤1.5 秒；禁止只写「眼神一变」。
28. **对称空镜揭底**：结尾一个对称空镜（空椅子、独坐）揭真相，不用台词。

## 6. 站位与调度
- **每场先写站位**：锚点（门、桌、台阶）+ 每人位置和朝向 + 轴线 + 本场谁会移动，写进该场第一镜的 `notes`。
- 双人对话：过肩镜交替，每镜只露一张说话的脸；不越轴。
- 群戏：只让两位主角真互动；配角 ≤1 秒反应镜。多人场戏用静态站位，对白拆单人中景正反打，每句重磅台词后切不同旁观者的反应。
- 单场景群戏：每镜只让一人开口。
- 一人对群体的战斗：只拍主角动作 + 敌人倒地。
- 两位强势者冲突用单人打电话完成；古今对话用手机等单一通道拆成两端单人镜交叉剪。
- 人与非人角色互动：正反打每格只放一个角色，靠可传递的道具（酒、灯、信物）完成交接。
- 救星站在受害者身后，同色同框。
- 揭示前让第三个视点（门口的人、窗外的人）提前入画。
- 证物的藏匿处（包、口袋）在后续抵赖镜头里持续留在画内，让观众一直看着谎言。
- 群像角色用不同物种、体型、轮廓区分，说话镜尽量用背影、远景或反应镜。
- 两人戏站位要连续：跪 / 站、坐 / 站不能在镜间跳变；手里拿着什么、哪只手拿，前后镜对得上。
- 跨镜道具和服装（头盔、箱 / 袋、门、雨衣）颜色材质款式全片锁死，每镜提示词重复写（见 ai-production.md 第 3 节第 15 条）；摘头盔、换手拿要给一镜动作。
- 竖屏多人戏靠纵深，不靠横排：主导者中景居中，对手分在前景边缘和后景门口。
- 三人修罗场：女主居中、两男从画框两侧入画的近景构图；肢体接触只用搭肩、握手、含指小动作。
- 高潮放进门内门外的封闭空间：门外第三者只给毛玻璃模糊人影，门内只拍两人特写。
- 60% 以上的对话戏放密闭空间，既省场景生成又天然增压。

## 7. 光色
- **每场锁一个主色**；同场景色温、太阳角度一致。
- **冷暖切换标记世界、时间线或类型**：梦 / 现实；古代暖金 / 现代冷蓝（切时空用硬切 + 色温突变，不做特效门）；年代冷蓝土黄 / 现代高调暖阳；回忆白晕边高调 / 当下冷蓝夜景；两个现实层用两套色系，切层时衣服和色调一起换；白天暖黄 + 生活红物件 / 夜里青绿 + 单一暖光源，切开喜剧与恐怖；暖客厅 / 冷地下室硬切讲良心。
- 反转段换掉全片光色体系；喜剧进复仇时暖 → 冷；四幕四色分段。
- **全片唯一高饱和色**只给主角或主题：一件明黄外套、一件粉碎花褂、一只红丝绒首饰盒、只属于复仇女主的红。
- 生活道具的红可以一步步变成恐怖符号（红盆 → 红鞋 → 红面具 → 红眼）。
- **光影母题统一画风**：百叶窗光栅贯穿全片；或锁一个季节光。
- 前 3/4 冷色长镜压抑，最后 1/4 暖色快切释放。
- **暗场警戒**：小屏上近乎全黑的镜头信息为零；黑场或暗部单段 ≤3 秒，看不清的段落改成几个 1 秒的暗示性短镜。
- 甜宠别用红眼妆 + 红色 HUD，会被看成恐怖片。
- **色剧本 / 三段色**：全片用三段色彩标记阶段或阵营（火橙 / 夜蓝 / 琥珀金；日常冷灰 → 爆燃白热 → 沙暴土黄），让观众不靠台词就知道局势变了。
- **色温即叙事层**：重生 / 前世用冷调、今生用暖调，切层时色温和服装一起换；白闪过曝帧作换层的统一语法，先教一次再用。
- **颜色区分真相与谎言**：谎言是华丽的金色、真相是灰的；不同颜色讲不同版本的「真相」。
- **暖色重音随危机升级**：冷景里唯一暖色的出现次数随危机升级而增加，让色彩弧线更咬人。
- **能力专属色**：给超能力一个专属颜色（冷景里的金光），全片只在能力发动时出现。
