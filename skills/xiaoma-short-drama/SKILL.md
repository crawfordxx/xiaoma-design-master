# 小马短剧编导（xiaoma-short-drama）

把「我想做个短剧」变成一集能让人看完、想追下一集的片子：先定片种和卖点，再写分集钩子和单集剧本，然后出分镜表、过导演审核、定妆出图、逐镜出片、剪成片，最后按评分标准自评。

## 定位

- **AI 短剧为主**：画面由 AI 生成，剧本和分镜从第一步就躲开 AI 的弱项（同脸、口型、手、画面文字、多人肢体接触、光照突变），见 [references/ai-production.md](references/ai-production.md)
- **兼顾实拍**：实拍项目照样用前四步（立项、剧本、分镜、审核），跳过出图出片，或只用 AI 补空镜、奇观、道具特写；评分时「AI 完成度」换成「制作完成度」
- 单集默认 1–5 分钟。超过 5 分钟只留给**奇观驱动的连载**（每集有强事件、奇观持续升级，如灾难怪兽、连载漫剧）；静态对话驱动的长集普遍掉，拆成两集，或在 300 秒内放一个集尾级卡点。首发别只放一集 90 秒
- **画风在立项时就选**：写实 AI、3D 漫剧 / CG、2D/2.5D、定格风、真人实拍 + AI 合成，按 [references/ai-production.md](references/ai-production.md) 第 1 节的选择表定。古风志怪、奇幻、穿越题材 3D 漫剧已成主流形态；打脸、伦理、讽刺题材的真人喜剧小品（一人分饰多角、套路混剪）互动中位仍然最高，低预算项目优先考虑

## 目录与变量

下文 `S=<本技能目录>`（直接用安装路径，不必解 symlink）。技能目录里有三个软链接：

| 路径 | 是什么 | 本技能用它做什么 |
|---|---|---|
| `director/` | 小马导演技能 | 复用分镜 schema、片种卡 `short-drama`、校验 / 审核 / 出图 / 出片 / 质检 / 渲染脚本 |
| `shared/` | 仓库共享规则 | 运行时规则、角色卡写法、视频提示词写法、复刻方法论、产线工作流 |
| `toolkit/` | 生成能力入口 | 出图出片的底层调用（由 director 的脚本代为调用） |

工作区按 [shared/runtime-rules.md](shared/runtime-rules.md) 的约定：`workspace/projects/<slug>/` 下放 `brief.md`（立项）、`episodes/epNN.md`（剧本）、`storyboard/epNN/storyboard.json`（分镜，出图出片都写在这个目录里）。

## 片种速查

先判片种，只读匹配的那一张卡。卡里给情绪承诺、子类型、60s/90s/3min 节拍表、钩子、爽点和卡点写法、视听、镜长基准、审核参数、AI 翻车点、导演工具箱和禁忌。

| 片种卡 | 片种 | 判定信号 | 平均镜长（AI 默认档） |
|---|---|---|---|
| [suspense](references/genres/suspense.md) | 悬疑刑侦 | 命案、失踪、冷案、连环案、民俗禁忌、怪物灾变、时空电话 | 推理 / 程序 1.7–3.4s；氛围 / 民俗恐惧 3.7–5.4s |
| [underdog-payoff](references/genres/underdog-payoff.md) | 爽文逆袭 | 隐藏身份、打脸、金手指、暴富、重生预判、嘴替回怼 | 写实剧情 2.7–3.2s；漫剧 2.1–2.8s；喜剧快切 0.9–2.0s；双人吵架 5–6s（台词 ≥6 字/秒） |
| [time-travel-rebirth](references/genres/time-travel-rebirth.md) | 穿越重生 | 穿越、穿书、双向时空门、古今通话、系统、未来来客 | 快档 1.3–1.9s；中档 2.1–3.3s；慢档 3.5–6.1s（必须配强钩子） |
| [sweet-romance](references/genres/sweet-romance.md) | 甜宠霸总 | 霸总、她撤他追、网恋掉马、先婚后爱、心声 / 数值、修罗场团宠 | 1.5–2.4s；≥4s 的镜头控制在 10% 以内 |
| [revenge-angst](references/genres/revenge-angst.md) | 复仇虐恋 | 复仇、清算、情感账本、追妻、萌宝认亲、宅斗、鬼魂复仇、储蓄型纯虐 | 对线 / 爽向 1.3–2.6s；情感闭环 2.6–3.5s；横屏叙事 2.6–4.5s |
| [dark-fantasy](references/genres/dark-fantasy.md) | 奇幻西幻 | 吸血鬼、狼人、驱魔、非人打工、成神寓言、末日怪兽、异世界 POV | 旁白蒙太奇 1.1–2.3s；对白情景 2.7–6s；院线型 3.2–4.7s（长镜奇观段 ↔ 快切簇交替） |
| [guofeng-supernatural](references/genres/guofeng-supernatural.md) | 古风志怪 | 古风言情、宅院、纸人、泥胎、善鬼、伪神、仙侠穿书 | 言情 1.9–2.3s；动作志怪 2.0–2.2s；连载漫剧 2.8–3.5s；寓言 / 旁白慢档 4–5.5s；喜剧 skit 1.3–1.5s |
| [family-drama](references/genres/family-drama.md) | 都市家庭 | 婆媳、愚孝、藏起来的老人、重组家庭、家产姓氏、年代 | 短单集 2.1–3.5s；长集 2.5–4.2s；说教庭审 4.7–4.9s；喜剧斗嘴 1.1–1.5s |

- 夹在两个片种之间（例如「重生后复仇」）→ 按**观众来看的那种情绪**定主卡（爽 / 痛 / 甜 / 怕 / 认同），另一张只借子类型和钩子。在 `brief.md` 写一句理由
- 完全看不出来 → 只问一个问题：「观众看完最想说的一句话是：真爽 / 真甜 / 真解气 / 真吓人 / 我家也这样？」
- 片种标签要和内容一致，挂错标签会被推给错的观众
- 镜长以片种卡「审核参数」和「剪辑节奏基准」为准。**平均镜长不能单独预测热度**，快剪和慢剪都有爆款；快慢段落的对比比平均值更重要

## 工作流

### 1. 立项：片种判定 → 卖点与人设 → 分集钩子

产出 `brief.md`，下面六块缺一不可：

1. **片种与情绪承诺**：主卡 slug、子类型、一句话情绪承诺（照片种卡的「情绪承诺」写）；**画风**（照 ai-production.md 第 1 节选择表）；投放平台和**画幅**（见下文「画幅按投放平台定」）
2. **卖点**：一句 logline，能写进 15 字以内的标题，结构是「前提 + 反差」；列出这一集观众能截图的三个瞬间（受辱物证、兑现数字、地位倒置画面等）；一个能让观众在评论区说「我家也是 / 换我也这样」的口子
3. **人设表**：每个角色写 名字 · 性别 · 年龄 · 欲望 · 秘密或软肋 · 语言指纹（口头禅、句长、称谓习惯，遮住名字也认得出是谁在说）· 服装主色 · 一个标志物 · 发型发色 · 原创面部特征；反派加写**赌注**（要什么、肯付出什么、拿什么当筹码），防止「就是坏」。具名角色全剧不超过 12 个，多的降为群演。同龄同性的角色在发型、发色、主色、配饰里至少差两项；名字和性别在这里定死，不用 AI 高频默认名。**主角要主动**：写清逼他动起来的外部压力（扣钱、限期、被冤、被开除），和他本集自己做出的一个决定或自己看出的一个细节
4. **规则自洽表**（有设定的片种必填）：金手指能做什么、限制是什么、触发条件；换算比例（钱、时间、年龄）；非人角色吃什么、怕什么；护卫和旁人在哪；年代里什么行为犯法。再列一张**逻辑洞清单**：观众会问的每个「为什么不直接……」，各配一句堵洞台词或一个画面；角色的身体状态变化（受伤、怀孕、淋湿）列成表，之后每镜照着写
5. **分集大纲**：3 集以上的项目，先按 [references/series-arc.md](references/series-arc.md) 写情绪契约、单元和全剧回合表、付费点，并按 [references/continuity-ledger.md](references/continuity-ledger.md) 建台账；前三集照 structure.md 6.4 的前三集节拍卡排。然后每集一行「集名（4–12 字，概括冲突）· 本集爽点或反转 · 集尾卡点 · 称呼变化点」，相邻集有因果；下一集开头接上一集卡点的后果。**卡点逻辑要硬**：集尾那个「对不上的点」在故事时间线和规则里必须真的成立
6. **发布计划**：上线前备 2–3 集再发，或在简介写明更新节奏（首集爆了却无后续，催更会变怨气）；剧名写进标题、**片名卡前 40 秒内打在画面上**、片尾打剧名、剧名在目标平台搜得到；改编作品写明原作者和授权

钩子从 [references/hooks.md](references/hooks.md) 的 16 类里选 1 个主钩 + 最多 1 个辅钩；卡点从 [references/structure.md](references/structure.md) 的卡法表里选。结构、爽点、反转、题材专用节拍、多集接法也在 structure.md。选钩参考：有金手指或高概念的用「说规则 + 当场验证」直给型；慢热恐怖 / 悬疑优先反常行为悬念；横屏奇观片优先画风质感第一帧留人；冲突直入是最拥挤的赛道，要用具体数字和最狠一句把它做出区分。

### 2. 单集剧本：场次、台词

产出 `episodes/epNN.md`，每集 2–4 场，按场写：

```
第 N 场 · 日/夜 · 内/外 · 景
出场：角色（服装主色）
站位：锚点（门、桌、台阶）+ 每人位置和朝向 + 手里拿着什么
△ 动作（只写拍得到的）
角色（画面词｜语气词 / vo / os）：台词
```

- 节拍按片种卡的时长模板分配，在剧本页眉写出每个节拍的起止秒数
- 台词规则见 [references/dialogue.md](references/dialogue.md)：单句 ≤15 字为主，不互报身份，**不写替观众总结背景的解说型台词**（改成动作或物件），信息藏进冲突，金句按 16 种句式写，用心声、物件、半截咽回做潜台词；**旁白只解释画面无法自证的设定**，连续念前情不超 20 秒，其余信息全部走台词和动作（别做成「有声连环画」）
- 每场先想清楚「这场谁赢了、地位怎么变」，没有变化的场删掉；开场电话、寒暄压到一镜一句
- 台词括号写**神态短语**（画面词｜语气词），不写「愤怒」这类结果词；对质场物证和结论同一轮说透，术语当句翻译；每条 △ 动作行都要有画面分量，连续纯对白不超过 6 行（见 dialogue.md 第 9–10 节）
- AI 漫剧同一场景里换机位不算换场
- 多集项目每写完一集更新台账（continuity-ledger.md 第 3 节）
- 写完自查：主角 30 秒内在场；反转前 ≥2 处伏笔（至少一处是画面，伏笔和反转隔 ≥20 秒）；动机先种；反派至少抵赖一轮；专业配角不降智；每个动作的前因后果和持物都交代了（他打给谁、铃声为何停、手机在谁手里）；卡点在峰值前一秒

### 3. 分镜表：director 的 storyboard.json

字段照 [director/references/storyboard-schema.md](director/references/storyboard-schema.md) 写，提示词写法照 [director/references/frame-prompts.md](director/references/frame-prompts.md)，基础规矩读 [director/genres/short-drama.md](director/genres/short-drama.md)。再按本技能的片种卡补齐下面这些短剧要求：

| 位置 | 写什么 |
|---|---|
| `project.genre` | 固定写 `short-drama`（director 的片种 id）；本技能的片种卡 slug 写进 `project.assumptions` 第一条：「片种卡：suspense · 子类型：封闭空间误认」 |
| `project.aspect` | 按投放平台定（见下文）；横构图投竖屏平台时写 `16:9`，在 `post.edit` 注明上下留黑区放剧名和字幕，并列出按竖屏重构的镜号 |
| `project.asl` · `project.hook` | 抄片种卡「审核参数」节给的值，覆盖 director 卡的默认值 |
| `project.extra_columns` | `["情绪钩子"]`，每镜填「压 / 扬 / 悬 · 一句具体内容」 |
| `strategy.beats` | 第一个节拍就是钩子本身；节拍名和剧本页眉一致 |
| `style.prompt_prefix` | 画风 + 构图 + 固定加三句：「单一连续镜头，从头到尾同一机位，不切换镜头、不剪辑」「表演克制自然、不夸张」「画面无任何文字、品牌标识」 |
| `refs` | 人设表里每个跨镜角色一条（`prompt` 写死主色、标志物、发型、面部特征，并写「服装无任何品牌标识、无文字、无 logo」）；核心道具、证物、尸体、金手指形象建 `type: prop`；每场主场景建 `type: location`。**跨镜道具和服装细节**（头盔、保温箱或手提袋、雨衣长短、反复出现的门）各写死颜色、材质、款式，例如「哑光黑色全盔」「方形白色硬壳保温箱」「墨绿铁皮门、黄铜猫眼」 |
| 每镜 `refs` | 角色和道具按需挂；**场景参考图只挂在远景 / 全景 / 中全景**，近景和特写挂场景图会被拉成全景 |
| 每场第一镜 `notes` | 站位、轴线、本场谁会移动、持物、桌面道具位置 |
| `visual` · `frame_prompt` | 每镜把机位、景别、构图、人物状态完整写一遍，**不写「同第 N 镜」**；出现在本镜的跨镜道具和服装，把 refs 里那句颜色、材质、款式原样再写一遍；光照突变（灯亮、断电）拆成之前 / 之后两镜；钟表写「表盘无指针，后期合成」；门牌号、钟面数字、屏幕内容一律不让模型画（门牌写「门牌空白」，号码后期贴） |
| `duration_s` | 对白镜按「字数 ÷ 3 + 0.8 秒」估（AI 配音约 3 字/秒），放不下就砍字；承载线索的插入镜 ≥2 秒 |
| `on_screen_text` | 名牌字卡、时间地点字卡、金额、心声字幕、HUD 都写在这里；`frame_prompt` 一律不出字。**屏幕镜头**：`visual` / `frame_prompt` 写「屏幕纯白发光、无任何字」，`on_screen_text` 写明屏幕区域和要贴的内容（如「屏幕区域：画面中部手机屏 · 订单备注 + 送达时间」），剪辑把字贴进屏幕区域，不浮在画面上。**字卡不叠**：片名单独一卡，时间地点另一卡，「AI 生成 · 纯属虚构」只做角标，三者不压在同一镜 |
| `sfx` · `music` | `sfx` 会拼进视频提示词：无台词镜头写「无人声」+ 本镜环境声（雨声、楼道回声），防止模型冒出含混人声；关键音效点（提示音、跳秒、落地、敲门）写在对应镜。`music` 写情绪段落的进入、骤停和卡点 |
| `purpose` | 叙事目的 + 用到的导演招式（见下文「大导演思维」） |
| `pace_note` | 片种卡允许的长镜（悬疑等待长镜、家庭剧独白长镜、甜宠最重那句）写明理由并标 `tempo: 停留` |

镜头语言、剪辑节奏、声音分别查 [references/shot-language.md](references/shot-language.md)、[references/editing-rhythm.md](references/editing-rhythm.md)、[references/sound.md](references/sound.md)。

**画幅按投放平台定**：投竖屏平台默认原生 9:16。片种倾向可以反过来指导平台选择——奇观 / 氛围类（悬疑、奇幻、古风志怪）几乎全走横屏，对话 / 打脸类（都市家庭、甜宠、爽文）以竖屏为主。片种卡写了横屏传统（悬疑、奇幻、志怪）而仍想用横构图时，钩子、关键反转（尤其同机位对照）、卡点这几镜必须按竖屏重新设计构图，否则主体只剩三分之一屏；投横屏平台再用 16:9 或 2.39:1。详见 shot-language.md 第 1 节。

### 4. 导演审核

出图之前审，改秒数和台词不用重出图。

```bash
python3 $S/director/scripts/validate.py <dir>/storyboard.json
python3 $S/director/scripts/review.py <dir>/storyboard.json
```

1. `validate.py` 有 ❌ 改到通过；`review.py` 退出码 0 才算过（偏紧、拖沓要改秒数、删字、标 `tempo` 或写 `pace_note`）
2. **短剧专项检查**（脚本查不到，逐条过，不通过就改）：

| # | 检查 | 标准 |
|---|---|---|
| 1 | 首镜 | ≤3 秒，有运动主体或异常物，不放复杂人体姿态；第 2 镜 3 秒内上人 |
| 2 | 第一句台词 | 1 秒内出口，含「谁 + 异常」，抛具体数字或物件；最狠一句 / 最响一记放第 1 秒 |
| 3 | 第一个转折 / 主角在场 / 设定验证 | 转折按片种卡（多数 ≤15s；奇幻 ≤30s）；主角 30 秒内在场；金手指或核心设定 30 秒内完成一次画面可视化验证（说规则 + 演规则）；前 15 秒镜数照片种档（爽 / 甜宠 / 穿越 7–9 镜，悬疑 / 都市 5–7 镜，氛围慢热 3–5 镜但第一句必须宣言级）；前 15 秒只有 2 镜几乎一定被嫌单调 |
| 4 | 主角主动 | 入局段有外部压力；主角至少一次自己看出或自己决定，不是被事件推着走 |
| 5 | 局面变化密度 | 片种卡的转折间隔内必有一次；同一模板第三轮必须变形 |
| 6 | 爽点五环 | 先前状态 → 主角行动 → 可见证据 → 对手代价 → 新状态，证据和代价都拍得到 |
| 7 | 承受者反应镜 | 每个打脸、揭示、狠话后都有对方的脸（1.5–2.5s） |
| 8 | 伏笔与因果 | 反转前 ≥2 处，至少一处是画面插入；每个动作的前因、持物、去向都对得上 |
| 9 | 卡点 | 片内、峰值前一秒；矛盾在故事时间线里成立；之后黑场或空镜 ≤3s；不靠「未完待续」撑（片种卡另有说明的除外） |
| 10 | 纯 BGM 空段 | 开场和无台词段 ≤10s |
| 11 | 招牌镜头 | 每集至少 1 个，集中在钩子、翻盘、卡点 |
| 12 | 重复与解说 | 没有同功能的重复插入镜；没有替观众总结背景的解说型台词 |
| 13 | 人设一致 | 名字、性别、称呼和人设表一致；同场不换装；身体状态跨镜连续 |
| 14 | 规则与常识 | 数字、换算、年代道具、程序常识、物种地理过一遍规则自洽表和逻辑洞清单 |
| 15 | 画幅 | 竖屏平台的钩子、反转、卡点镜按竖屏构图；关键证据不落在下方 1/4 字幕区 |
| 16 | AI 可做性 | 说话镜多放过肩 / 背影；多人不接触；手部大特写和连续长动作已拆；光照突变已拆；画面不出字；对白镜时长够配音说完 |
| 17 | 合规 | 无真实品牌、机构、名人；暴力给结果不给过程；写实画风常驻「AI 生成 · 纯属虚构」角标；不写明示诱导点赞的台词 |
| 18 | 道具与服装锁定 | 每个跨镜道具和服装细节（头盔、箱 / 袋、门、雨衣）在 refs 里写死颜色、材质、款式，出现它的每一镜 `visual` / `frame_prompt` 原样重复；门牌号、钟面、屏幕内容都标了后期合成，没有交给模型画 |
| 19 | 无效镜头 | 每镜一句话说得出观众从它看到了什么；看不出内容的空镜（墙角斜拍、无主体的暗部）和重复的楼体外景删掉或换成承载信息的插入镜 |
| 20 | 对话块与长镜 | 静态对话块 ≤30s，超过就插画面事件（威胁逼近、道具特写、闪回）；>10s 的长镜镜内要有一个小事件或连续台词推进；慢 ≠ 拖沓，拖沓来自长镜内没有新信息；奇观长镜 20–38s 有连续画面事件时可以是卖点；快节奏片开场一镜 8s 以上画面不变是划走位 |
| 21 | 闪切下限 | 闪切 ≥0.25s（更短在部分设备被读成卡顿 / 坏帧）；闪切只用于光效、穿越闪帧、动作爆点和喜剧 gag，不用来掩盖生成不出的走位 |

3. **导演审片**：派一个没参与创作的子代理，按 [director/references/director-review.md](director/references/director-review.md) 逐镜审，只给它 storyboard.json、本片种卡、上表和机检报告；没有子代理时自审，`review.reviewer` 写「自审」
4. 只改被指出的镜头，重跑两个脚本，最多 3 轮；结论写进 `review` 字段，要拆镜并镜的意见标 open 交给用户

### 5. 角色定妆与出图

```bash
python3 $S/director/scripts/frames.py <dir>/storyboard.json --dry-run          # 先看张数和预估费用
python3 $S/director/scripts/frames.py <dir>/storyboard.json --only ref_hero,ref_rival   # 先出定妆图
python3 $S/director/scripts/frames.py <dir>/storyboard.json                    # 定妆确认后出全部分镜图
```

- 先出 `refs` 的定妆图给用户确认（必停点）：每个角色正面一张，主角补侧面和背面服装；角色写法照 [shared/character-design.md](shared/character-design.md)
- **定妆过审**：同脸、像真实明星、标志物不清楚、衣服 / 帽子 / 包 / 车身上自己长出了品牌标识或文字，都要重出；带进视频参考图后会一路带下去
- 超过 30 张先确认；失败或画面不对用 `--only s03,s07` 重出（先改 `frame_prompt`）
- 用户没配出图模型时，跳过出图，直接 `python3 $S/director/scripts/render.py <dir>/storyboard.json` 渲染不带图的分镜表

### 6. 逐镜出片

```bash
python3 $S/director/scripts/video_render.py <dir>/storyboard.json               # 干跑：每镜提示词写回 shot.video.prompt
python3 $S/director/scripts/video_render.py <dir>/storyboard.json --live        # 真出片，默认只出缺的镜头
python3 $S/director/scripts/video_render.py <dir>/storyboard.json --live --shots 3,7   # 指定镜头重出
python3 $S/director/scripts/video_qa.py <dir>/storyboard.json --scores '<七维分数 JSON>'
```

- 干跑提示词先给用户看，确认后再 `--live`（必停点）；先低档出小样，满意再换高档逐镜升级
- 每场首镜出好后作为后续镜头的参考帧，换镜不变脸
- 出片后逐镜对照 refs 查跨镜道具和服装（头盔颜色、箱 / 袋、门的颜色材质、门牌、脸），漂移的镜头先改提示词再 `--shots` 重出；屏幕上冒出乱码的同样重出或遮掉
- 生成片段最短约 4 秒、按生成秒数计费，预算按生成秒数算；偶发失败或排队超时时，再跑一次 `--live` 只会补出缺的镜头，不整批重跑，超时绝不自动连发
- 质检 repair（60–75 分）走局部修改，fail（<60 分）整镜重出

### 7. 剪辑成片

交给 **xiaoma-editor** 技能（它用 `scripts/assemble.py` 拼片、`scripts/check.py` 检查成片）。给它：

- 出片目录和 storyboard.json：镜序、计划时长、台词、`on_screen_text`（含屏幕区域和要贴的内容）、`sfx`、`music`、`post.sound`
- 片种卡的镜长基准和快慢段落要求，以及 [references/editing-rhythm.md](references/editing-rhythm.md)、[references/sound.md](references/sound.md) 两份规则
- 声音素材或声音设计单：环境底噪、关键音效点（镜号 + 时间）、BGM 情绪段落的起止

剪完要满足（`check.py` 会查的项标「机检」，其余剪辑时自己过）：

- **按人声剪，不按分镜时长剪**：台词不一定从片段开头说，用语音转写找人声入点和出点；宁可总时长变长，也不切掉半句；转写在无人声处会幻听出单字和套话，定位时过滤
- **每个片段只取一个镜头段**：模型会在一段里自己切镜，剪辑先检测片段内部的切点，只用其中一段（机检）；**剪点两侧不能是重复画面**，上一镜出点和下一镜入点同一帧会像卡顿（机检）；清掉 0.1s 级闪帧（机检）
- 生成的长片段一律按戏剪短，不把 8–10 秒原样铺满对话戏；看不出内容的空镜和重复外景不进成片
- 平均镜长落在片种卡区间，快段和慢段镜长拉开 2 倍以上；单镜下限 0.5s，非高潮单镜上限 5s（机检）
- **声音层是交付必需**：只有模型同期声不算完成。成片要有环境底噪（静场段尤其要有）、关键音效踩点（提示音、跳秒、落地、敲门、卡点那一下）、BGM 情绪段落；对白段 BGM 用纯音乐、比人声低 10–15 dB 避让；不能冒出画面和字幕都对不上的含混人声（机检：响度、转写与字幕比对）
- 台词清楚：关键设定句、人名、地名、数字同时上字幕；成片跑一遍语音转写自检
- 字卡：屏幕内容贴进屏幕区域；片名、时间、虚构声明不叠在一起，虚构声明只做角标
- 卡点后黑场或空镜 ≤3s；不循环拼接音轨拉时长；正片后不接花絮；片尾打剧名

没装 xiaoma-editor 时，交付片段目录 + 按镜号排好的剪辑单（镜号、人声入出点、字幕、音效、音乐提示），用户在任意剪辑软件里拼。

### 8. 自评

按 [references/scoring-rubric.md](references/scoring-rubric.md) 打分：三个评委视角（商业爽感 / 作者导演 / 技术完成度）各给 9 维分数、每维一句带镜号或时间码的证据、最该改的 3 处；先对照文末「评委最常扣分的地方」过一遍。有子代理时三个评委各派一个独立子代理盲评；没有时自评并标明。只有分镜时预评六维，其余标「待成片」。低于 70 分或某维低于该维满分 60% 的，回到对应步骤改，再评一次。

## 大导演思维

写剧本和分镜时，不是拍完再想风格，而是每一步主动调导演工具箱：15 位导演的通用招式见 [references/director-lenses.md](references/director-lenses.md)，片种专属的写法在片种卡末尾。

1. **立项时选人**：按 director-lenses.md 的「片种 → 导演」速查表挑 2–3 位，写进 `brief.md`，一位管叙事（信息差、时间结构、证据链），一位管视听（色彩、物件、构图）
2. **写剧本时逐场问三个问题**：
   - 希区柯克问：观众这一场比角色多知道什么？有没有一个 0.5–1s 的「炸弹镜」可以提前埋？作案过程有没有给观众看全？
   - 斯皮尔伯格问：这一场的奇观或揭示，能不能先拍看的人、再拍看到的东西？能不能只露一半留到下一拍？
   - 是枝裕和问：这句「我关心你 / 我委屈」能不能换成一个物件或一个家务动作？
3. **写分镜时落招式**：每个节拍至少一镜写明招式，写进 `purpose`，例如「推翻假答案 · 芬奇：证物俯拍编号」「爽点前静场 · 远景与眼部大特写交替」「势利眼变脸 · 冯小刚：同机位三连」。一集至少一个招牌镜头，出彩镜头占一到两成，集中在钩子、翻盘、卡点
4. **审核时反查**：导演审片子代理拿着选定的 2–3 位导演，逐场问「这一场哪一镜可以这样拍却没拍」，列为 P2 意见

招式只是落到镜头、剪辑或台词上的具体做法，不在画面里模仿任何具体影片的场景和角色。

## 执行模式

- **auto（默认）**：一路做到出片前。四个必停点：立项 `brief.md` 确认、定妆图确认、出图出片费用确认、干跑提示词确认（花钱的决定交给人）
- **interactive**：用户说「交互模式」「先看方案」时，在立项、分集大纲、单集剧本、分镜表四处各停一次
- 用户只要剧本 → 做到第 2 步；只要分镜 → 做到第 4 步并渲染 HTML；给了现成剧本 → 从第 3 步开始，台词逐字照用，在 `project.assumptions` 写明「台词为用户定稿」

## 弹性降级

| 场景 | 降级 |
|---|---|
| 片种判不准 | 给最接近的片种和理由，按它做，在 brief 里标「待确认」 |
| 投放平台不明 | 默认竖屏平台、原生 9:16，在 brief 里标「待确认」 |
| 没配出图模型 | 交付不带图的分镜 HTML + 每镜提示词 |
| 没配视频模型或出片失败 | 交付分镜 HTML + 提示词包；单镜失败跳过继续，最后汇总，再跑一次只补缺的 |
| 下载失败 | 保留原始 URL，绝不重新生成 |
| 没装剪辑技能 | 交付片段 + 剪辑单 |
| 没有子代理 | 导演审片和自评改为自审，标明 |

## 交付

告诉用户：片种和理由、画幅和投放平台、集数和本集时长、镜数、导演审核结论、自评总分和最该改的 3 处，以及结果链接区（brief、剧本、storyboard.json、分镜 HTML、片段目录、成片路径）和一条下一步建议。

## Gotchas

- **先写分镜后补剧本**：分集钩子和单集剧本没定就出分镜，卡点和伏笔会对不上，返工最贵
- **横构图直接投竖屏**：主体只剩三分之一屏，开场的脸和同机位对照都看不清
- **慢热开场**：幸福铺垫、旁白念背景、纯 BGM 空镜超过 10 秒，观众已经划走
- **主角被动**：只靠愧疚或好奇推着走，没有外部压力，也没有自己看出的细节
- **报头衔代替证据**：「我是董事长」不如门禁亮绿灯；身份由证据、价签或第三方替主角说
- **解说型台词**：「三年没人上来过」这种句子交给门把手上的灰
- **同脸**：同性角色只差一件衣服，评论区会变成「哪个是哪个」
- **让 AI 画字、画钟、画光照突变**：手机屏、诏书、账本、名牌、门牌号后期合成；指针后期加；灯亮拆两镜
- **跨镜道具没锁**：头盔换了三种颜色、保温箱变成手提袋、同一扇门换了颜色材质，观众会以为换了人换了地方；refs 写死、每镜重复
- **只交同期声**：静场段没有底噪和音效，上楼、时间跳变这种最该吓人的段落反而最空
- **定妆图带出品牌 logo**：衣服、头盔、包上的标识一路带进视频，定妆时就查
- **按分镜时长硬剪**：AI 配音约 3 字/秒，台词会被切成半句；剪辑跟人声走
- **生成片段原样拼接**：8–10 秒一镜铺满对话戏 = 站桩
- **对话块泡水**：两人对坐超过 30 秒没有画面新信息，是「这集很水」的头号来源；插证物特写、威胁逼近或闪回
- **旁白连环画**：全片大半靠旁白讲、人物几乎不演；旁白只用于画面无法自证的设定，连续念前情不超 20 秒
- **碎切掩盖穿帮**：0.1–0.4 秒的碎镜不可读，闪切下限 0.25 秒，宁可换机位重出
- **BGM 盖台词**：带人声的歌放在对白下，金句听不清就传不出去
- **只有一集**：单集爆了却接不上第二集、搜不到剧名，催更会变成差评
- **诱导点赞**：让角色喊观众「点亮右边」，评论区只剩表情，还有限流风险
- **挪用知名作品的开局或诡计**：老观众一眼认出，悬念失效还招来抄袭指认；改编要署名
