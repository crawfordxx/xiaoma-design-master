# 通用生图（gen-image）

从一句模糊的想要，到一张构图、风格、比例都对的图。

## Onboarding

> ✅ **生图编排已就绪！**
> 描述你想要的图（越具体越好），或贴一张参考图说"照这个感觉改"。
> 我会先出提示词方案给你看，draft 档试稿确认后再 final 档正式出，不浪费你的额度。

## Usage

- "画一张深夜程序员的书桌，电影感" —— 从描述开始
- "参考这张图的风格，画一个咖啡店场景" —— 参考图模式
- "3:4 竖版，小红书用" —— 带比例和用途

## Pipeline

下文 `S=<本技能目录>`（直接用安装路径，不必解 symlink）；`$S/toolkit/gen` 是生成能力的唯一入口。

**Step 1 意图确认**：比例（没说用途就问一句）、用途（封面/内文/社媒/头像）、风格偏好（没说默认跟随内容调性）。批量需求（>3 张）先报预估再动。

**Step 1.5 人物逻辑（画面里有人且用户未提供照片时）**：读 [`shared/character-design.md`](shared/character-design.md)。从需求提取四元组（身份/年龄/地域/气质）→ 按十要素结构生成角色卡（骨相/五官/皮肤/神态各一句，至少 2 处不完美细节）→ 角色卡给用户过目 → draft 档生成定妆照 → 确认后存档 `workspace/projects/<slug>/characters/<名字>.png`，后续画面复用（作参考图或文本锚定，见 character-design 的角色复用节）。

**Step 2 提示词构建**：按 [`shared/visual-prompts.md`](shared/visual-prompts.md) 五要素：比例 + 文字指令（要字逐字写、不要字 no-text，见其「图上文字规则」）+ ≥3 风格词 + 色彩对齐 + 具象场景。有人物时把角色卡的骨相+五官+皮肤段原样编入提示词（文本锚定），或用定妆照作 `--ref`。参考图模式写清"保什么改什么"。把构建好的提示词给用户过目。

**Step 3 draft 试稿**：
```bash
$S/toolkit/gen image --prompt "<五要素提示词>" --ratio 16:9 --tier draft
```
单方案 1 张；风格不确定时出 2–3 个方向的 draft。

**Step 4 迭代**：一次只改一个变量（光/构图/色/主体细节），别一次改三个。要字的图逐字校对，错字 → 重试一次 → 仍错走底图 + 排版叠字；不要字的图出现乱码 → 加严 no-text 重试一次。

**Step 5 final 出片**：参数锁定后：
```bash
$S/toolkit/gen image --prompt "<锁定提示词>" --ratio 16:9 --tier final --out workspace/projects/<slug>/images/<name>.png
```

**Step 6 交付**：本地路径 + meta 位置 + 下一步建议（按 [`shared/runtime-rules.md`](shared/runtime-rules.md)）。

## 执行模式

auto（默认）：Step 1 必问比例/用途，其余自动。interactive：提示词和每次 draft 都给用户看。

## 弹性规则

生成失败 → 检查提示词（抽象词换具象）重试一次 → 仍失败交付提示词包让用户换工具。批量中单张失败跳过继续，最后统一报告。

## Gotchas

- **抽象病**："体现高效工作的图"这种提示词 = 抽盲盒。每个名词都要可视化
- **文字不校对**：模型写的字没逐字核对就交付 = 错字上墙；长文字直接走排版叠字，别让模型写段落
- **三变量齐改**：改三样看不出哪样起作用，一次一样
- **风格漂移**：批量图不锁四件套（色温/风格/复杂度/光感）= 拼贴画
- **人物没卡就画**：画面里有人却没角色卡/定妆照 = 同一场景里下一张就变脸，人物必须先过 Step 1.5
- **网红脸陷阱**：人物描述没写皮肤瑕疵和不完美细节 = 生出来全是 AI 假脸，十要素里的皮肤段和负约束不能省
