# AI 视频产线工作流（production-pipeline）

> 从小说/点子到多集成片的工业化流水线：每一步的产物和纪律、资产一致性、质检闭环、多平台适配。蒸馏自公开可查的 AI 短剧/漫剧产线资料。

## 1. 六步流水线总览

```
剧本分析(含合规门) → 人物/道具/资产包 → 分镜提示词 → 抽卡生视频 → 初期粗剪 → 精剪审核 + 多维质检闭环
```

- 每步产物落盘、可断点续跑；上一步不达标不进下一步
- 剧本分析自带**合规门**：版权红线、平台红线在这一步替换，不拖到出片后返工

## 2. 剧本三段式与格式规范

**三段式**：摘要（创意→立项） → 分集大纲 → 分集正文。

立项摘要的纪律：
- 忠实原创意，集数严格对齐（短篇 12–24 集 / 中篇 30–60 集）
- 一句话故事 = 主线 + 最大反转
- 人物卡的成长弧必须写成「阶段 A → 阶段 B → 阶段 C」，不许只写形容词
- 故事梗概 200–400 字走完整叙事：世界观 → 矛盾 → 结盟 → 高潮 → 结局 → 余韵

分集大纲：集数严格等于目标；集名 4–12 字概括冲突钩子；标起承转合分布；相邻集写明因果与追剧钩子。

分集正文的剧本格式（机器可解析、人可读）:

```
### 场{集}-{场}          ← 场号
日 内 灵山大雄宝殿       ← 时间 内外 景
出场人物:A、B
△ 动作行                 ← 动作
角色名(情绪/vo/os):台词  ← vo=旁白 os=内心独白
【空镜:描述】            ← 关键空镜
```

密度纪律：每集 2–4 场；每镜 1.5–3 秒，每集 25–35 镜；标准集 75–80 秒，高光集 90 秒。台词语速以实测为准：AI 配音约 3 字/秒（对白镜时长 = 字数 ÷ 3 + 0.8 秒，见短剧技能的 AI 制作卡）；原产线资料写的「8–12 字/秒」是信息密度口号，按它写台词会念不完。

## 3. 项目锚定（写第一句提示词之前）

每个项目开工前固定四件锚：
1. **美学参考配比**：如「60% A 作品 + 30% B 作品 + 10% C 作品」，风格是配出来的，不是形容词堆的
2. **节拍表**：本片种每集的节拍骨架
3. **时长与镜头规则**：上面那组数字
4. **版权红线清单**：逐项替换所有借鉴来源的独创元素（角色专属造型、专有名词、可识别桥段）,给替代写法

## 4. 资产规范（一致性的一半靠资产卡）

| 资产 | 卡片规范 | 要点 |
|---|---|---|
| 角色 | **白底全身照**：从头到脚、纯白背景、禁止半身特写 | 人物是绝对主角；配表情库/动作库/服饰库各约 6 组 |
| 场景 | **环境主体**：剥离人物，建筑/地貌/室内是绝对主角 | 配场景关键词库 |
| 镜别 | 每个资产出近/中/远景 | 分镜直接引用，不再临场描述 |

跨集一致性三板斧：
1. **ID 锁**：同一角色跨集相似度有硬指标（如 ≥0.80）,不达标重出
2. **视觉锁定符号**：每集必现的角色专属视觉锚（发型/饰品/服装花纹/配色）,写进每镜提示词
3. **妆造映射表**：同一角色不同时空的妆造对应关系，提前建表，不靠记忆

## 5. 画风锁与题材模板

每个题材一张模板，固定字段：画风锁提示词、画幅、默认集数、单集时长、分辨率、配音包、BGM 情绪、调色板（主色用数值锁定，不许「大概红」）、角色原型、场景关键词、选题库。

要点：**主色锁成具体数值**，跨集跨镜不再漂移；画风锁提示词是完整句子，拼接进每条生成请求。

## 6. 分镜→渲染的桥接纪律

分镜表字段：`镜号 / 时长 / 运镜 / 画面动作（对白、旁白、音效合并写进动作描述）`。

桥接时三条铁律：
1. 镜号、时长、运镜、动作四要素**原样保留**，不许桥接层改写
2. **禁画面内文字**：字幕、字卡全部后期叠加，不指望生成模型把字渲染对
3. 视觉锁定符号在提示词里显式出现（「她的红绳可见」）,一致性不靠运气

## 7. 抽卡与质检闭环

- 每镜生成 = 抽卡：同一提示词出多候选，按「脸一致 / 手正常 / 道具对 / 构图对」选卡
- 每镜过**多维评分**（常见 7 维：主体一致、画面质量、构图、运镜、光影、文字干净度、动作合理性）,不过 → 换引擎重生成该镜，而不是降低标准收货
- 全部镜头达标才进合成；**部分失败**的镜头保存描述与首帧，单独重出再拼，不整集重来

## 8. 声音层

- 配音按角色固定音色包；旁白与对白分轨
- BGM 按情绪段铺长音，对白段自动避让（闪避）,关键节拍踩点音效
- 成片响度归一（参考 −16 LUFS）

## 9. 多平台输出适配

一条母片 → 各平台适配包：画幅重排(9:16 / 16:9 / 1:1)、字幕样式、封面、标题文案、合规标识（AIGC 声明、水印）一次生成。

## 10. 这条产线与片种卡的关系

- 产线管**流程与一致性**（怎么不崩、怎么连发）;片种卡管**内容与审美**（怎么好看、怎么留住人）
- 两者交汇在分镜表：产线的字段约束 + 片种卡的镜语言/节奏规则，合在一起才是能执行的分镜

## 11. 其他已经跑通的产线形态

上面是短剧/漫剧的工业化产线；下面五种形态对应其他片种。

| 形态 | 流程 | 适合的片种 | 可借的做法 |
|---|---|---|---|
| **一站式工作室型** | 创意 → 剧本 → 分镜板 → 角色一致性 → 镜头级控制 → 可交付成片 | 短剧、宣传片 | 面向团队协作，每一步都可回到上一步改；一致性靠角色资产贯穿全流程 |
| **全自动对话型** | 一句话 → 脚本 → 素材 → 配音 → 成片，之后用对话迭代改片 | 科普、口播、营销短片 | 「改片」也是对话：说「第二段太慢」，只重做那一段 |
| **长视频切片型** | 长视频 → 自动挑段 → 钩子检测 → 爆款潜力打分 → 自动重新构图 → 自动字幕/表情 → 一键多平台发布 | 长视频切片 | 切片的核心是「挑段 + 钩子」，不是剪；每段打分后再决定是否发 |
| **数字人口播型** | 个人形象建模 → 脚本 → 数字人口播成片，不需要拍摄出镜 | 口播、带货口播 | 形象一次建好反复用；脚本质量决定成片上限 |
| **分镜板交互型** | 在时间线上排分镜卡 → 逐卡生成 → 延展/拼接 | 预告、MV、短片 | 素材（人物/物件/场景）作为「配料」单独管理，再在场景里组合 |

### 各形态通用的产线资产

- **分镜最小字段**：镜号、时长、运镜、动作描述（对白/旁白/音效合并写进动作）
- **质检闭环**：每镜多维打分 → 不过 → 换引擎重生成该镜 → 再评
- **一致性**：视觉锁定符号 + 人脸相似度硬指标 + 资产库复用
- **合规层**：版权替换表 + 平台红线表 + AIGC 标识/水印
- **输出适配**：一条母片导出多平台版本 + 配套营销文案
