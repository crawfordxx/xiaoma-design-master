# 创意工具与移动端：交互模式库

> 适用：设计/编辑工具、画布类产品、生成式 AI 工作台、视频编辑、移动 App。
> 关键帧来自一线创意工具与移动应用的线上样式实测。

---

## 1. 创意工具工作台

**布局**

```
┌──┬─────────────────────────────┬────────┐
│工│                             │ 参数面板 │
│具│         画布 / 预览           │        │
│栏│                             │ 滑块    │
│  │                             │ 颜色    │
│  │                             │ 生成按钮 │
└──┴─────────────────────────────┴────────┘
```

- 左工具栏 48–56px，图标 20px，激活态 accent 底 + 白图标
- 右面板 280–320px，可折叠（折叠后只留图标列）
- 面板折叠：宽度 transition 200ms，内容 opacity 0，图标居中
- 可拖拽分隔线：hover 时 2px accent 高亮

**滑块**
- 轨道 4px，圆角 pill，已完成部分 accent，剩余 `--border`
- 拖柄 14px 圆，hover scale 1.15，拖动时 scale 1.25 + shadow-md
- 数值：拖动时上方 tooltip 显示，等宽字
- 松手：拖柄回弹 `cubic-bezier(.34,1.56,.64,1)`

**生成进度**

```
[ 生成中…  ████████░░░░  67%  ]
```

- 进度条先 scaleX 入场，然后按实际进度
- 不确定进度：mask-position 100%→0 扫光，1.5s
- 生成中预览图：对角扫光覆盖
- 完成瞬间：✓ 图标弹一下 + 预览图 blur(3px) → 清晰，300ms
- 多张生成：网格 stagger 入场，每张 opacity 0 + scale(.7) → 正常

**画布交互**
- 选中框：1px accent + 8 个控制点，控制点 hover scale 1.3
- 拖拽：元素 `opacity .9` + shadow-lg，跟随无延迟
- 对齐辅助线：1px 虚线，洋红/青色，吸附时出现，松手消失
- 缩放：`⌘+滚轮`，以鼠标为中心，transform-origin 动态计算
- 平移：空格 + 拖拽，光标变抓手
- 撤销/重做 toast：底部短条，"已撤销：移动图层"，2s 消失

**图层面板**
- 拖拽排序：拖起 rotate(1deg) scale(1.02)，目标位置留 2px 空隙
- 展开/折叠：height 0 → auto，箭头 rotate
- hover：显示眼睛/锁图标，opacity 0→1
- 选中：accent-a12 背景

## 2. 实时画布 / 生成式预览

**流式渲染（逐块出现）**
- 网格分区渲染：每个 tile opacity 0→1，随机顺序，stagger 30ms
- 或模糊到清晰：blur(8px) → 0，400ms
- 刷新时：旧图 opacity 1→.3，新图覆盖淡入

**参数调整实时反馈**
- 滑块拖动 → 预览即时变化（<50ms）
- 变化中：预览边缘呼吸环（box-shadow 0→4px 白 .3，1s pulse）
- 稳定后：环消失

**多方案对比**
- 2×2 网格，每格 hover 放大 1.02
- 选中：accent 边框 + 角标 ✓
- 切换主图：translateX(-2px)→0，150ms

## 3. 视频编辑时间线

```
     0s    1s    2s    3s    4s    5s
├────┼────┼────┼────┼────┼────┼──┤
│ 视频轨  ████████████████░░░░░░░  │
│ 音频轨  ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓  │
│ 字幕轨    ████    ████    ████  │
│        ↑ 播放头（红线）           │
```

- 播放头：1px 红线，顶部倒三角，随时间 linear 移动
- 片段：圆角 4px，视频轨缩略图条，音频轨波形
- 片段选中：accent 边框 + 控制点
- 拖拽片段：ghost（opacity .5）跟随，目标位置吸附线
- 裁剪：左右控制点拖动，片段宽度实时变化
- 缩放：`⌘+滚轮`，时间刻度 fade 切换
- 播放：空格键，播放头 linear；暂停：播放头停，无动画

## 4. 移动端 App 通用

**页面转场**
- 推入：新页从右 translateX(100%) → 0，300ms，`cubic-bezier(.25,1,.5,1)`；旧页 translateX(0) → -30% + 变暗
- 弹出：translateY(100%) → 0（sheet），300ms
- 返回：反向
- 淡入：opacity 0→1，200ms（tab 切换）

**底部导航**
- 图标 24px，标签 10px
- 切换：选中项 scale 1→1.1→1，200ms
- 指示器：顶部 2px 短线，layoutId 平滑滑动到新 tab，250ms

**下拉刷新**
- 指示器：spinner，下拉时 opacity 0→1
- 触发后：spinner spin，完成后 morph ✓，收起

**列表**
- 下拉加载：底部 spinner
- 滑动操作：左滑露出删除按钮，不可删时抖动
- 新项入场：translateY(2px)→0 + opacity，150ms，stagger

**手势**
- 点击：目标 scale .96 → 1，100ms（按压反馈）
- 长按：300ms 后触发，元素 scale 1.02 + shadow
- 滑动返回：边缘右滑，页面跟手 translateX

**Toast / Snackbar**
- 底部滑入：translateY(100%) → 0，200ms
- 带"撤销"按钮：右侧文字按钮
- 2s 自动消失，上滑手势可提前关闭

**骨架屏**
- 比 spinner 好，保持布局
- shimmer 扫光，1.5s
- 内容加载完：skeleton opacity 1→0，内容 opacity .3→1

**空状态**
- 图标 64px，轻浮动
- 标题 + 说明 + CTA
- 整块可点击刷新

## 5. 键盘快捷键面板

- `?` 触发
- 分组：导航 / 编辑 / 视图
- 每行：操作名 + `<kbd>` 组合
- `<kbd>`：等宽 11px，边框 1px `--border`，圆角 4px，padding 2px 6px，底部 2px 阴影（按键感）
- 搜索框：顶部，实时过滤，不匹配的行 opacity .3

## 6. 引导 / Onboarding

**步骤引导（Tour）**
- 高亮目标：其余区域遮罩 `rgba(0,0,0,.6)` + 目标区域 `box-shadow: 0 0 0 9999px mask`
- 气泡：opacity 0 + scale(.98) translateY(5px) → 正常，150ms
- 箭头指向目标
- 步骤切换：气泡内容 opacity .3→1，位置移动用 FLIP

**进度**
- 顶部进度条：scaleX 入场，宽度按步骤
- 步骤点：完成 ✓ / 当前 pulse / 未到 ○

**空状态引导**
- 首次进入：核心按钮呼吸环（box-shadow pulse）
- 3 秒后或用户操作后停止
