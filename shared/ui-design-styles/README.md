# UI 风格库（ui-design-styles）

> 做网站 / PPT / App 之前，先在这里定风格。
> 六个原型全部来自获奖站点的真实样式数据，每个都是一套可直接落地的 token，不是形容词。

## 怎么用

1. 读 `README.md` 的决策树，锁定 **1 个主风格**
2. 打开对应风格文件，抄它的 tokens 进 `@theme` / CSS 变量
3. 按"媒体策略"决定要不要生成图/视频——风格越复杂越要生成
4. icon 和文案铁律在 `README.md` 末尾，全风格通用

## 文件

| 文件 | 一句话 | 适合 |
|---|---|---|
| `dark-studio.md` | 近黑画布，冰白字，一点青 | 创作工具、编辑器、AI 生成产品、作品集 |
| `violet-immersive.md` | 深紫宇宙，3D 漂浮，霓虹点缀 | AI 安防、游戏、沉浸式 microsite、WebGL 叙事 |
| `ink-editorial.md` | 纸白 + 墨黑 + 一点锈红，全部大写字 | 独立设计师、印刷感、作品集、文化项目 |
| `candy-playground.md` | 电紫 + 荧光绿 + 品红，超大圆角 | 创意机构、活动页、Z 世代品牌、实验项目 |
| `industrial-mono.md` | 纯黑 + 国际橙，等宽字，零圆角 | 硬科技、航天、无人机、工程、B2B 硬件 |
| `quiet-luxury.md` | 米白 + 炭黑，极小字，无圆角 | 建筑、地产、高端品牌、画廊、精品 |

## 决策树

```
产品的"内容"本身是视觉主体吗？（图片/视频/3D 作品）
├─ 是 → dark-studio（内容优先，界面退后）
└─ 否 ↓
产品要让用户"进入一个世界"（沉浸/游戏/叙事）？
├─ 是 → violet-immersive
└─ 否 ↓
产品是硬科技/工程/航天/军事风？
├─ 是 → industrial-mono
└─ 否 ↓
卖的是"品味"（建筑/时尚/艺术/高端服务）？
├─ 是 → quiet-luxury
└─ 否 ↓
品牌个性是"玩"（年轻/创意/活力）还是"手作"（独立/文化/印刷感）？
├─ 玩 → candy-playground
└─ 手作 → ink-editorial
```

## 反信号（命中就换）

| 风格 | 不适合 |
|---|---|
| dark-studio | 儿童教育、医疗、政务——黑底压得太重 |
| violet-immersive | 需要高可读性的文档/数据产品 |
| ink-editorial | 科技 SaaS——印刷感与产品感打架 |
| candy-playground | 金融、法律、B2B 企业服务 |
| industrial-mono | 消费级生活方式品牌 |
| quiet-luxury | 需要热闹转化的电商促销 |

## 通用铁律

### Icon：禁止首字母 / 首文字

- ❌ 用产品名首字母做 logo、用功能名首字做区块图标、用"AI"/"01"这种字符占位
- ✅ 每个功能点配一个**有语义的图标**：Lucide / Phosphor / Heroicons 里挑形状贴切的，或生成一个与风格同系的线性/面性图标
- 功能列表、定价表、Bento 卡片、步骤说明——**每一项都要有图标**，没图标就补，别留空白方块
- 品牌标识用抽象图形（几何/笔触/负空间），不用文字缩写

### 媒体：复杂风格必须生成图/视频

| 风格复杂度 | 必做 |
|---|---|
| violet-immersive / candy-playground | **必须**生成 hero 3D 渲染图或粒子场景图；有条件生成 6–10 秒循环背景视频 |
| dark-studio | **必须**生成 2–3 张示例作品图填充画廊/展示区，否则黑底空荡 |
| ink-editorial / quiet-luxury | 生成 1–2 张高质量摄影风图片（材质/空间/光影） |
| industrial-mono | 生成 1 张产品渲染或线稿示意图 |
| 任何风格 | 产品截图、人物头像、场景图——缺就生成，不留占位框 |

主动建议话术："这个风格靠视觉撑，建议生成一张 hero 背景图和一段 8 秒循环视频，我可以直接出。"

### 文案：不摆数据、不列依据、不说废话

- ❌ "提升了 300% 转化率，服务 500+ 客户，行业领先" —— 没人信的数据堆砌
- ❌ "我们致力于通过创新技术赋能企业数字化转型" —— 谁都能说的废话
- ❌ "功能强大 / 易于使用 / 灵活配置" —— 形容词不提供信息
- ✅ 一句话说清**做什么 + 给谁 + 凭什么不一样**，用动词和名词，删形容词
- ✅ 标题短（≤8 字），副标题一句（≤25 字），正文段落 ≤3 行
- ✅ 每句话问自己：删掉它页面少了什么？答不出就删
