# 复刻与变体方法论（clone-method）

> 怎么从已有爆款学到东西、并安全地变成自己的：拆解、改写、做变体时的十条纪律。蒸馏自「复刻爆款」类工具的公开方法论。片种卡讲「怎么写好」，这里讲「怎么从爆款学」。配套的拆解维度和带货测试设计见 `viral-breakdown.md`。

## 1. 拆解双轨制

同一条参考片，拆成两份产物，缺一不可：

| 产物 | 给谁用 | 长什么样 |
|---|---|---|
| **剧本级分析** | 给人读 | 整片的解释模型：每个创作为观众做了什么、钩子在哪、节拍怎么排、情绪怎么走 |
| **逐镜生成提示词** | 给模型吃 | 按镜组织：`[风格]/[环境]/[运镜]/[光线]/[人物] + 镜号（起止秒）`，每镜可直接投喂生成 |

只有第一份 → 学到道理但落不了地；只有第二份 → 能出片但不知道为什么这样剪。两份对齐，拆解才可复用。

## 2. 提示词挂证据链

每条可复用的生成提示词，永久绑定三样东西：

1. **源作品标识**（它从哪条片拆出来的）
2. **表现数据**（那条片的点赞/完播/评论风向）
3. **为什么这么写**（这条提示词的每个关键选择对应的意图）

没有证据链的提示词是「拍脑袋」；挂了证据链，半年后还能回答「这条为什么好用」，也能在表现变差时归因。

## 3. 改写纪律：Keep / Swap / Drop

复刻不是抄袭，是受控改写。三段纪律：

- **Keep（保留）**：钩子机制、节拍位置、镜序、节奏骨架——这些是「它为什么火」的结构原因
- **Swap（替换）**：人设、场景、台词、字幕、卖点——换成你自己的题材与资产
- **Drop（丢弃）**：一切不可证声明、原作专有素材（角色形象、专有名词、可识别桥段）

先列三列清单再动笔；Drop 列不清空就不能开工。

## 4. 单变量变体矩阵

做变体测试时，矩阵的维度通常有：受众 × 场景 × 利益点 × 开场。

**铁律：每轮只改一个变量。** 同时改两个以上，分数变了也无法归因。典型教训：两版之间同时改了画幅、约束写法、人物数量、开场结构，盲评掉了分，却说不清是哪一项的锅。

实操：固定一版「参考版」，出 N 个变体，每个变体只动一个格子；对比后再决定下一轮动哪个。

## 5. 时间锚在「词」上，不在「秒」上

写分镜时的纪律：

1. **不写死秒数，写台词锚点**：镜长由「这句词从哪个词开始、到哪个词结束」决定，秒数是推导出来的，不是设定的
2. **落地校准**：配音出来后，按词级时间戳重排全片；改一句台词、换一条配音，全片时间自动重排，而不是手工重对
3. **估算兜底**：配音前确需估时，按「约 3 字/秒」给镜长，并在分镜表标注这是估算值

对照教训：分镜表写死秒数 → 台词超长只能剪辑台事后补救；提示词里写「按 3 字/秒配镜」只是估算纪律，不是解法。解法是词锚定。

## 6. 克隆的是「响应关系」，不是时间码

学一条片，学的不是它的秒表，是**它让观众产生的反应链条**。所以拆片产出两层数据：

- **整片解释层**：每个选择为观众做了什么（为什么这里给特写、为什么这里切走）
- **逐拍实现层**：按源片时间码记录实现细节（每拍几秒、怎么切的）

并且有硬约束：**禁止编造缺失的时间戳**。拆解里不确定的地方标「未知」，不许脑补——脑补过的拆解会污染所有下游结论。判断标准：「看到的画面」和「听到的词」必须在同一个时钟上能对齐。

## 7. 场与镜之间，加「段落」层

一集不要直接切成镜列表。层级：集 → 场 → **段落（可表演的戏剧单元）** → 镜。

AI 生成的现实约束是单次 4–10 秒，一镜常常装不下一段戏。按「段落」打包生成请求，镜是段落内的切法，这样台词和动作不会被镜头边界腰斩。

## 8. format × craft 双层叠加

知识分两层，不要混：

- **format 层（片种/格式）**：注意力结构——这个片种的钩子位置、节拍表、画幅、时长
- **craft 层（手艺）**：台词、钩子写法、节奏、声音——跨片种通用

同一个 craft（比如「首镜台词叠在有动作的画面上」）可以叠在任何 format 上。技能库按这两层组织，片种卡只管 format,手艺卡全片种复用。

## 9. Playbook 不是门禁

规则库再厚，也要明写一句：**不匹配任何卡的作品照样成立**。规则是「大多数爆款满足的统计规律」，不是「不满足必死」的门禁。防止技能学成教条，把创作者框死。

## 10. Done means watched（跑完 ≠ 完成）

生成管线跑完、退出码为 0,都不算完成。完成的标准是：**人看了成片（或至少抽帧 + 读体检报告）**。自动指标（时长、响度、镜数）全绿，仍然可能整段废片——只有「看」能兜底。
