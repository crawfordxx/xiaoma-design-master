# 平台 DNA：X / Twitter（platform-dna/x）

> 三层证据模型：平台硬约束 / 可观察规范 / 运营默认值。只描述可观察行为，不做受众心理断言。

---

## 平台硬约束

| 项 | 约束 |
|---|---|
| 单帖长度 | 280 字符（免费）/ 25000（Premium 长帖） |
| URL | 一律按 23 字符计 |
| 媒体 | 1–4 图 或 1 视频 或 1 GIF（不计入字数） |
| 话题标签 | 0–2 个；3+ 被算法当垃圾信号 |
| 提及 | @用户名 计入字数 |
| 投票 | 2–4 选项，5 分钟–7 天 |
| 视频 | 2:20（免费）/ 60 分钟（Premium） |

## 可观察规范

**高表现开头模式**：
- 逆势观点："Everyone says X. Wrong."——靠分歧挣互动
- 数据开局："90% of Y. Here's why that matters:"
- 故事开局："3 years ago I X. Today Y. Here's what I learned:"
- 清单承诺："How to X in 5 steps:"
- 好奇缺口："The most underrated X is Y."

**收尾模式**：thread 最后一帖 TL;DR 一句话；CTA（关注/转发/收藏/长文链接）；**外链只放最后一帖**（中途外链被降分发）。

**引用惯例**：引用转推 > 回复带链接（互动更高）；来源截图 + 署名行；thread 内无脚注——每帖必须独立成立。

**自我推广容忍度**：中等。"build in public" 文化奖励透明式自我推广；硬广和联盟链接被降权；产品发布走个人故事线效果好；无个人背景的纯营销文案表现差。

**降权信号**：钓鱼式互动（"Am I the only one…?"）、3+ 标签、thread 中途外链、回复灌水、连发不互动。

## 运营默认值（本套件的选择）

| 场景 | 默认 |
|---|---|
| <280 字 | 单帖（一句钩子 + 一个观点） |
| 280–2000 字 | thread 3–8 帖（按段落切，每帖独立成立，编号 1/N） |
| >2000 字 | 长帖（Premium）或 thread 8+ |
| 首帖 | 钩子 + 承诺，绝不放链接 |
| 末帖 | TL;DR + CTA + 链接（如果有） |
| 图片 | 附首帖；每帖 ≤4 |
| 话题标签 | 0–2 个，放最后 |
| 发布链 | 逐帖回复自己（原生 thread 链） |

## 反模式

- thread 中途放外链（分发杀手）
- 每帖结尾都 CTA（一帖一个动作就够，放最后）
- 把长文整段粘成长帖（X 的阅读习惯是快扫，不是书页）
- 3+ 标签
- thread 超过 25 帖（完读率断崖）
