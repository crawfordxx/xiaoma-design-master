# 平台 DNA：小红书（platform-dna/xhs）

> 三层证据模型：平台硬约束 / 可观察规范 / 运营默认值。

---

## 平台硬约束

- **竖版优先**：3:4 是内容主比例（首页双列瀑布流按 3:4 裁切展示）
- **图片上限**：单帖 ≤18 张（超过自动分两篇）
- **外链**：正文不可点外链；导流靠评论区/私信/瞬间
- **标题**：≤20 字（超出折叠）；正文 ≤1000 字
- **话题标签**：# 标签参与流量分发，建议带 3–8 个相关话题

## 可观察规范（高表现内容的模式）

- **封面即卖点**：首图直接给结论/对比/清单预告，配大字（图上文字是设计元素，不是生图文字）
- **标题公式**高频出现：数字+人群+痛点（"30 岁转行，我靠这 3 个习惯"）/ 反常识（"别再 XX 了"）/ 身份认领（"给所有 XX 的人"）
- **正文结构**：emoji 做视觉分隔、短句、口语化、结尾互动引导
- **轮播叙事**：一图一观点，每张图能独立被截图传播
- **评论区运营**：置顶自评补充关键信息/引导提问

## 运营默认值（本套件的选择）

| 项 | 默认 |
|---|---|
| 图比例 | 3:4（1080×1440） |
| 图数量 | 6–12 张（少于 4 张像朋友圈，多于 15 张完读崩） |
| 首图 | 大字标题卡（设计排版，非生图文字）+ 一个钩子 |
| 内页模式 | 二选一：**原文保留式**（长文逐段搬运，零改写，适合干货）或 **摘要卡式**（每图一个观点 + 配图，适合种草/清单） |
| 超长内容 | >18 张自动拆上下篇，封面同视觉系统不同构图 |
| 标题 | 出 3 个候选（不同公式），选最具体不选最机灵 |
| 正文 | ≤800 字口语化导语 + 图轮播承担主体信息 |
| 标签 | 8–12 个：2 行业 + 3 热门 + 3 长尾 |
| 发布文档 | 交付"发布就绪包"：图序说明 + 正文文案 + 标签 + 免责声明（如引用数据） |

## 反模式

- 生图直接出带文字的封面（文字必乱码——文字层必须设计排版）
- 把公众号长文原样搬过来（横向阅读习惯 ≠ 竖向滑动习惯）
- 一张图塞三个观点（一图一义）
- 18 张全是纯文字截图（小眼睛会划走；至少 1/3 是视觉图）
- 标题写满 20 字还埋关键信息在最后（折叠=没人看见）
