# Icon 设计体系：四流派与"线即形状"的建模法

> 从 26 个产品官网和图标库的线上 SVG 实测得出（4400+ 个图标样本）。
> 回答一个问题：为什么有些 icon 看起来"厚实、有设计感"，有些看起来"细、像默认"。

---

## 一、四大流派（按技术 DNA 分，不按风格分）

| 流派 | 代表 | fill% | evenodd% | 圆角半径 | 线宽 | 建模方式 |
|---|---|---|---|---|---|---|
| **描边派** | Lucide、Tabler、Heroicons、Arc | 0–7% | 0–3% | 2–3 | stroke 1.5–2 | `stroke` 画线，圆头 |
| **实心镂空派** | 字节系创作工具、Radix、Linear、Stripe、Framer | 96–98% | **30–95%** | **1.7** | — | `fill` 形状 + `evenodd` 镂空，**线是闭合多边形** |
| **面性派** | Phosphor、Material、IconPark | 78–100% | 0–7% | 1.7–4.5 | — | 实心块，无镂空 |
| **混合派** | Hugeicons、Raycast、Iconify | 50–60% | 7–24% | 1.7–2 | 1.5 | outline + filled 双版本 |

**主流创作工具的坐标**：fill 90%、evenodd 55%、单路径 1.3 个、圆角半径 1.0、24 网格渲染 14–20px。
近亲是 Radix（eo 95%）和 Linear（eo 34%）。这是**工具类产品的 icon 语言**——精致、克制、不卖萌。

---

## 二、"线即形状"是什么意思

### 描边派（Lucide）的"开关"icon

```
<path d="M8 12h8" stroke="currentColor" stroke-width="2" stroke-linecap="round"/>
```
一条线，用 2px 描边。线端是半圆（直径 2）。**两根线交叉时，两个圆头叠在一起会出"鼓包"**，渲染到 14px 时描边边缘有抗锯齿的"毛"。

### 实心镂空派的"开关"icon

```
<path fill="currentColor" fill-rule="evenodd" d="M8.5 5.5a1 1 0 0 0-1.707-.707l-3 3A1 1 0 0 0 4.5 9.5h15a1 1 0 0 0 0-2h-11v-2Zm7 13a1 1 0 0 0 1.707.707l3-3A1 1 0 0 0 19.5 14.5h-15a1 1 0 1 0 0 2h11v2Z"/>
```
看 `a1 1 0 0 0`——**半径 1 的圆弧**。这意味着：那根"线"实际上是一个**宽 2 单位、两端半圆的闭合矩形**（胶囊形）。它是实心填充的，不是描边。

**数学上两者线宽相同**（2/24 = 8.3%），但视觉感受不同：

| | 描边派 | 实心镂空派 |
|---|---|---|
| 边缘 | 抗锯齿描边，有"毛边" | 多边形填充，边缘干净 |
| 交叉/拐角 | 圆头叠加出鼓包 | 路径并集，干净 |
| 缩放到 14px | 描边变细、发虚 | 条带按比例缩，仍实心 |
| 镂空细节 | 做不到 | `evenodd` 可以在实心块里挖出细线 |
| 色彩控制 | `stroke` | `fill`——可以做渐变、mask、多色分层 |

**这就是"加粗有设计感"的技术根源。**

## 三、实心镂空派的五个建模规则

从 93 个 icon 路径数据提炼：

### 规则 1：24 网格，整数/半格坐标
所有锚点落在 24 网格的整数或 `.5` 位置（`M8.5 5.5`、`h15`、`v6`）。不留小数坐标。网格纪律 = 缩放时像素对齐。

### 规则 2：主线宽 2，圆角 1
所有"线"是宽 2 单位的胶囊条带，端点和拐角用 `a1` 弧。这是全站统一的视觉线宽，和 Lucide 的 stroke-2 等价，但建模方式不同。

### 规则 3：大元素用 1.5–2 半径
图标里的大圆（购物车轮子 `a1.5`、文件夹圆角 `a2`、容器框 `a4.5`）用更大半径，和主线的 1.0 形成**层级**——小元素圆、大元素更圆。

### 规则 4：单路径 + evenodd 镂空
平均 1.3 个 path。细节（文件夹的折角、开关的箭头）用 `fill-rule="evenodd"` 在同一个路径里挖出来，不另开 path。好处：一个 `fill` 属性控制整个图标颜色，`currentColor` 一次到位。

### 规则 5：容器用 2.5–4.5 圆角矩形
带外框的图标（展开按钮 `M17.5 3A4.5 4.5`、设置块 `a2.5`）外框圆角是主线的 2.5–4.5 倍。外柔内刚。

## 四、四家实心镂空派的差异

同样是"线即形状"，每家的"手感"不同：

| | 工具型 A | Radix | Linear | Stripe |
|---|---|---|---|---|
| 网格 | 24 | **15** | **16** | 24 |
| 圆角半径 | 1.0 | 1.7 | 2.5 | 1.7 |
| evenodd 率 | 55% | 95% | 34% | 30% |
| 路径数 | 1.3 | 1.7 | 2.4 | 2.2 |
| 性格 | 工具感、克制 | 极简、圆头、卡通感的圆润 | **锐利、精密、工程感** | 品牌感、细节多 |
| 密度 | 中 | 低 | **高**（2.4 路径，细节多） | 高 |

**Linear 最值得学**：16 网格 + 2.5 圆角 + 2.4 路径。它的圆角半径是网格的 15.6%（工具型 A 是 4.2%），所以 Linear 的 icon 看起来**更圆润、更饱满**，但路径数多，细节也多。工具型 A 的圆角更小（1.0/24），所以更**硬朗、工具感**。

## 五、怎么用这套规则做 icon

### 5.1 决策树

```
产品是创作工具 / 专业软件 / 开发者产品？
├─ 是 → 实心镂空派（工具型 A / Linear 路线）
│        要工具感 → 24 网格，圆角 1.0（工具型 A 参数）
│        要精致感 → 16 网格，圆角 2.5（Linear 参数）
└─ 否 → 消费级 / 营销站 / 轻量产品
         ├─ 极简、留白多 → 描边派（Lucide），stroke 1.5–2
         └─ 友好、圆润 → 面性派（Phosphor fill / Material）
```

### 5.2 "线即形状"建模模板

把任意描边 icon 转成实心镂空（以 24 网格、线宽 2 为例）：

**横线** `M4 12h16` → 胶囊条带：
```
M5 11a1 1 0 0 0 0 2h14a1 1 0 0 0 0-2Z
```

**竖线** `M12 4v16` →
```
M11 5a1 1 0 0 0-2 0v14a1 1 0 0 0 2 0Z
```

**L 形拐角** `M6 6v12h12` → 外圆角 2、内圆角 1：
```
M6 8a2 2 0 0 1 2-2h10a1 1 0 0 1 0 2H9a1 1 0 0 0-1 1v9a1 1 0 0 1-2 0Z
```

**容器框**（圆角矩形描边 → 填充挖空）：
```
M5 3h14a2 2 0 0 1 2 2v14a2 2 0 0 1-2 2H5a2 2 0 0 1-2-2V5a2 2 0 0 1 2-2Z
  M5 5v14h14V5Z   ← evenodd 挖出内部
```

### 5.3 检查清单

- [ ] 所有锚点在网格整数或 `.5` 上
- [ ] 主线宽 = 网格的 8%（24 网格 → 2，16 网格 → 1.3）
- [ ] 端点/拐角用弧闭合，不用 `stroke-linecap`
- [ ] `fill="currentColor"`，一个属性控制全图标
- [ ] 细节用 `evenodd` 在同一路径挖，不另开 path
- [ ] 大元素圆角 ≥ 主线圆角 ×1.5
- [ ] 在 14px 实际渲染一次检查——边缘干净、不发虚
- [ ] 单色、不用渐变（Linear 和工具型 A 都是纯单色，渐变留给品牌 logo）

### 5.4 禁止

- ❌ `stroke` 和 `fill` 混用在同一个 icon 里（混合派看着廉价）
- ❌ 小数坐标（`M7.3 4.6`）——缩放时像素不对齐
- ❌ 多色 icon（除了状态指示）
- ❌ 在描边 icon 上用 `stroke-width="2.5"` 假装"加粗"——线还是描边，缩放还是发虚
- ❌ 首字母 / 首字 / 数字占位

| 想要 | 网格 | 主线宽 | 圆角 | 路径数 | evenodd |
|---|---|---|---|---|---|
| 工具感（硬朗） | 24 | 2 | 1.0 | 1–1.5 | 55% |
