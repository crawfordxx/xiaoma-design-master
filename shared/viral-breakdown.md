# 爆款拆解与带货测试（viral-breakdown）

> 爆款拆解维度、20 秒时间轴模板、带货内容矩阵和选品判定。蒸馏自「复刻爆款」类工具公开的方法论文章。改写纪律见 `clone-method.md`。

## 1. 先判断这条爆款值不值得学

播放高不等于值得学——热度可能来自争议、娱乐或博主个人魅力，而不是购买兴趣。值得拆的候选同时满足三条：

| 判据 | 看什么 |
|---|---|
| **产品相关** | 内容和产品互相成就，拿掉产品这条片就不成立 |
| **购买信号** | 评论区在问尺码、价格、用法，而不是只在夸人 |
| **可迁移** | 结构离开这个博主也能成立，能回答你的产品要解决的需求 |

## 2. 五层拆解法

同样的镜头和台词不保证同样的结果。可迁移的价值在下面五层，按顺序拆：

1. **受众需求**：观众是谁、遇到什么问题、产品在里面扮演什么角色。一条连衣裙视频，真正回答的可能是「小个子能不能穿长款」
2. **前 3 秒钩子机制**：归入五类之一——**提问 / 结果 / 反差 / 细节 / 情境**。迁移的是机制，不是原话
3. **每镜的角色分工**：每一镜都要有一个任务——赚注意力 / 立问题 / 演示产品 / 给结果 / 推动行动。说不出任务的镜头就是冗余
4. **视觉证据**：容量靠「往里装东西」证明，好清洗靠「冲一下」证明，合身靠「正面 + 侧面 + 走动」证明。**证明方法比声明本身更值钱**
5. **信任**：真实使用、普通细节、常见疑问、清楚的边界、自然的表达。新账号借不到博主已经积累的信任，只能靠这几样自己建

## 3. 20 秒时间轴模板

| 时间 | 任务 |
|---|---|
| 0–3 秒 | 用问题、结果或反差抓注意力 |
| 3–7 秒 | 立住真实生活里的问题 |
| 7–14 秒 | 演示解决方案 |
| 14–18 秒 | 展示结果 |
| 18–20 秒 | 收在受众、使用场景或行动上 |

## 4. 拆完落成一张模板卡

```
受众:     [谁]
问题:     [正在发生什么]
产品角色: [怎么帮上忙]
时长:     [15 / 20 / 30 秒]
0–3:      [钩子类型 + 这一镜的任务]
3–8:      [痛点 + 动作]
8–15:     [演示 + 视觉证据]
15–20:    [结果 + 收尾]
原创性:   替换人物、场景、旁白、字幕、音乐、镜头细节;不用原片素材、原声、标识和有辨识度的台词
```

## 5. 带货内容矩阵：批量测试不是批量复制

批量生成优化的是数量；内容矩阵定义的是**版本之间的关系**。每条素材都要有明确的受众、利益点、证明方式和「它和其他版本差在哪」。

### 动手前的三个决定

1. **产品解决什么问题?** 把参数翻译成看得懂的结果：「机身小」→「少占桌面/行李箱空间」。每个说法都要有产品支撑
2. **谁在经历这个问题?** 「年轻女性」给不了拍摄方向；「空间有限、常整理化妆品的租房族」直接带出场景、道具、动作和真实需求
3. **哪个利益点能被画面证明?** 优先选前后对比、完整操作、尺寸对比、整理对比、真实使用。要长篇解释才能讲清的利益点，不适合做第一轮测试

### 四个维度

| 维度 | 规则 |
|---|---|
| 受众 | 每条素材只服务一个主受众 |
| 场景 | 场景必须为价值服务，不是背景板 |
| 利益点 | 每条只讲一个主购买理由 |
| 开场 | 提问 / 结果 / 情境 / 动作 |

示例（便携风扇）:上班族 × 工位 × 个人送风 × 具体问题开场；宿舍住户 × 床边书桌 × 占地小 × 情境开场；通勤族 × 户外等车 × 便携 × 结果先行；旅行者 × 酒店房间 × 好收纳 × 第一人称体验。

第一轮可以固定主体只换开场；下一轮固定钩子再换场景或利益点。**变量清楚，结论才有用。**

### 从参考到测试素材的六步

1. 找相近的参考：产品、受众、场景、制作条件、利益点都要接近
2. 拆成模块：开场、受众、痛点、产品入场、证明、收尾
3. 写下假设：例如「结果先行能更快讲清产品」
4. 重建素材：用自有产品素材，原创或有授权的人物、场景、旁白、字幕、音乐
5. 控制变量：一轮测试只改一个主要元素
6. 规划下一轮：继续测、保留结构，或停止投入

### 常见错误

- **只换产品**：人物、场景、文案不变，既不原创也不贴合
- **一次测太多变量**：结果无法解释
- **把每个功能都讲一遍**：观众抓不住核心购买理由
- **只看播放**：要看留存、点击、加购、转化和评论区的购买提问
- **忽视产品准确性**：颜色、结构、比例、文字要逐镜检查
- **编造体验**：AI 出镜人不能冒充「长期使用的真实顾客」

### 发布前清单

- **结构**：一个受众、一个利益点、相关的开场、看得见的证据、清楚的测试差异
- **准确**：颜色、结构、文字、标识、用法、功能正确，说法可支撑
- **原创与权利**：不搬运素材、不模仿可识别的人，文案已改写，音乐和素材有授权

## 6. 选题/选品：蓝海判定

**蓝海 = 高销量 × 低内容供给。** 销量证明需求是真的；相关带货视频少，说明创作者竞争还没饱和。

- 输出短名单时同时列出价格、佣金、窗口期销量、评分、相关视频数
- 单独圈出「最值得先做的一个」并写清推理（例：周销四千多但只有一千多条相关视频，同级竞品通常三千条以上）
- 「实时搜索」能查到任何公开对象但没有销量；「历史数据集」有销量但覆盖有限——两类数据要分开标注，不混着下结论
