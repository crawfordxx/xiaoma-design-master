# UI 设计资源与媒体路由（ui-design）

> gen-ui / ppt / app 三条线共用的：风格库入口、交互模式库入口、媒体工具链路由、获奖品质标准。
> 模型名只允许出现在本文件与 prompt-library。

---

## 一、先定风格，再动手

做网站 / PPT / App，**Step 2 之前**必须走一遍 [`ui-design-styles/README.md`](ui-design-styles/README.md) 的决策树：底色 × 排版 × 表面 → 锁一个结构原型 → 挑一套调色板。

18 个结构原型在 [`ui-design-styles/cards/`](ui-design-styles/cards/)，按 **底色 × 排版 × 表面** 命名：

| 底色 | 排版 | 表面 |
|---|---|---|
| Void / Ink（深色画布）| Console / Mono（大写等宽）| Glass（毛玻璃）|
| Dusk（中灰深底）| Editorial / Literary（大写编辑 / 衬线）| Hard（零圆角）|
| Mist（中性灰）| Poster（极端字阶）| Pill（超大圆角）|
| Daylight（亮色画布）| Fluid（流式字号）| Mute / Pop / Soft |

每个原型 = 簇共性结构规格 + 6 套真实调色板（各自来自一个获奖/提名站点）。
**结构与色彩解耦**：先定结构，再挑一套色。README 有决策树和产品匹配列。

每个风格文件 = 完整 tokens + 组件规格 + 媒体策略 + 动效 + icon 规则。**抄 tokens，不抄形容词。**

用户没说风格 → 按产品品类走决策树，给出推荐 + 一句理由，直接开做。
用户说了风格词 → 映射到最近的原型（如"高级黑"→ void-*-mute，"赛博"→ void-*-glass），保留原话作参考。

**PPT 适配**：只借色彩系统 + 字体气质 + 版式密度。动效不适用，改入场层级。
**App 适配**：借色彩/圆角/字阶/文案语气，触控目标 ≥44px，底部导航优先。

## 二、媒体工具链路由（缺就生成，不留占位）

| 需求 | 工具 | 调用 |
|---|---|---|
| 网页配图（hero / 产品图 / 氛围图 / 展示画廊） | **gpt-image-2** | `$S/toolkit/gen image --prompt "<提示词>" --ratio 16:9 --tier draft` → 确认后 `--tier final` |
| **人物**（头像 / 团队 / 用户故事） | **midjourney** | 按 [`character-design.md`](character-design.md) 出角色卡；无通道降级 gpt-image-2 |
| **场景 / 3D 主视觉**（沉浸式 hero、星球、抽象几何） | **midjourney** | 氛围与艺术性优先；文字层后期加 |
| **网页视频**（hero 背景 / 产品演示 / 循环动效） | **seedance** | `$S/toolkit/gen video --prompt "<导演式提示词>" --duration 8 --tier draft` → final |
| 网页 DOM 动画 | **Motion** | 不用视频模型 |
| 3D 交互场景 | **three.js** | 不用视频替代 |

生成纪律沿用 [`runtime-rules.md`](runtime-rules.md)：draft 先行、final 需确认、批量先报预估。

### 主动推媒体，不等用户要

风格越复杂，视觉资产越不能空。交付前对照：

| 风格 | 不生成就是半成品 |
|---|---|
| 表面 Glass / Pill / Poster | hero 视觉图 + 2–3 张场景图，有条件加循环视频 |
| 底色 Void / Ink | hero 拼贴图 + 3–4 张示例作品（深底空荡最致命） |
| 其余原型 | 至少 1–3 张风格匹配图 |

页面里出现空占位框、灰色方块、`<img src="">`——**必须**生成填充，不能交付。
话术："这个风格靠视觉撑，建议生成一张 hero 背景图和一段 8 秒循环视频，我可以直接出。"——直接建议，不等用户开口。

## 三、Icon：先选流派，再建模

**完整方法论见 [`icon-design.md`](icon-design.md)**——四流派对比、"线即形状"建模模板、参数速查表。

### 选流派（按产品）

| 产品类型 | 流派 | 参数 |
|---|---|---|
| 创作工具 / 专业软件 / Agent / 开发者 | **实心镂空派** | 24 网格，线宽 2，圆角 1.0，`fill` + `evenodd` |
| 精致 SaaS（Linear 那种手感） | 实心镂空派 | 16 网格，线宽 1.3，圆角 2.5 |
| 轻量消费级 / 营销站 | 描边派（Lucide） | stroke 1.5–2，round cap |
| 友好圆润 / 教育 / 生活 | 面性派（Phosphor fill） | 圆角 4+ |

### 为什么"线即形状"更有设计感

主流创作工具、Linear、Radix、Stripe 的 icon 看起来厚实精致，不是因为线粗，是因为**每根线是一个闭合多边形**（宽 2、圆角 1 的胶囊条带），`fill` 填充而非 `stroke` 描边。缩放到 14px 边缘仍干净，交叉处是并集不是鼓包，细节能用 `evenodd` 在同一路径里挖出来。

### 铁律

- ❌ 首字母 / 首字 / "01" / "AI" / 空方块占位
- ❌ 同一 icon 混用 stroke 和 fill
- ❌ 小数坐标、多色、用 `stroke-width=2.5` 假装加粗
- ✅ 每个功能点、Bento 卡、定价档、步骤都有语义图标
- ✅ `fill="currentColor"` 一个属性控色
- ✅ 14px 实际渲染检查一次

## 四、文案纪律：不摆数据、不列依据、不说废话

**删掉这些**：
- 任何百分比 / 倍数 / 客户数 / 市场排名——"提升 300%"、"服务 500+ 企业"——没人信，还显得廉价
- "致力于 / 赋能 / 打造 / 助力 / 引领 / 一站式 / 全方位"
- "功能强大 / 易于使用 / 灵活 / 高效 / 专业"
- 三段式排比、对仗口号、押韵标语
- "在当今快速发展的数字时代"

**只写这些**：
- 做什么（动词 + 名词，一句话）
- 给谁（具体人群，不是"广大用户"）
- 凭什么不一样（一个具体的差异点，不是"更好"）
- 标题 ≤8 字，副标题 ≤25 字，段落 ≤3 行
- 每句话自问：删掉它页面少了什么？答不出就删

好的例子："把录音变成纪要，发给没来开会的人。" / "给独立开发者的支付工具，不抽成。"
坏的例子："智能高效的会议纪要解决方案，助力企业提升协作效率。"

## 六、获奖品质标准（自检锚）

**四维打分**（gen-ui Step 7 依据）：

1. **Design 40%** —— 层级清晰？留白是设计还是空旷？像模板还是有自己的脸？
2. **Usability 30%** —— 首屏 5 秒明白是什么给谁？可点的东西看起来可点？移动端真适配？
3. **Creativity 20%** —— 有一个让人记住的瞬间？还是每个区块都"标准实现"？
4. **Content 10%** —— 文案在对受众说话？有没有占位废话、数据堆砌？

**及格线**：Design ≥9、Usability ≥9、Creativity ≥8、Content ≥8。

**硬指标先过**（不过不打分）：
- 375px 无横向滚动，触控目标 ≥44px
- 正文对比度 ≥4.5:1，大字 ≥3:1
- 控制台零报错；依赖纪律通过
- 动画尊重 `prefers-reduced-motion`；首屏图有宽高
- **每个功能点都有语义图标，没有首字母/文字占位**
- **没有空占位框，所有视觉位都有真实资产**
- **文案里没有百分比/客户数/形容词堆砌**
- **状态动效四种齐全**（进行中/成功/失败/等待），流式输出有 `aria-live`

**自检方法**：真实跑起来 → 桌面/移动全页截图 → 逐屏对照四维 + 硬指标 → 问题具体到可执行 → 修 → 重评。最多 3 轮。
