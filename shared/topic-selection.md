# 选题方法论（topic-selection）

> 文章在选题时就赢了或输了。平庸话题上的好文章，打不过好话题上的过得去的文章。
> 最常见的浪费：为一个今天没人需要读的东西磨两千字。

---

## 唯一铁律

**一个话题值得写，当且仅当你能回答**："这篇文章能给读者什么，是搜索引擎前三名给不了的？"

答案是"写得更好"——不够。答案是"一个他们没遇到过的视角、数据点或洞察"——继续。

## 评分前的三道硬门

1. **转发句是什么？** 读者转发时会配哪一句话？想不出来就没发育好。
2. **为什么是现在？** 这周读和 someday 读有什么区别？
3. **主要转化目标是什么？** 收藏 / 评论 / 关注 / 下一步阅读——选一个。

任何一道空白，这个话题再热也没写好。

## 五维评分模型

### 1. 热度（权重 20%）

| 分 | 信号 |
|---|---|
| 9–10 | 全网级热点，人人都在谈 |
| 7–8 | 跨平台刷屏，2 个以上平台在热 |
| 5–6 | 行业内热，大众还没感觉 |
| 3–4 | 常青话题，稳定搜索量无紧迫性 |
| 1–2 | 小圈子话题 |

时效衰减：热点 >24h → -2 分；>72h → 没有独家角度就别写。

### 2. 受众匹配（权重 25%）

| 分 | 信号 |
|---|---|
| 9–10 | 正中靶心，受众主动搜索的核心话题 |
| 7–8 | 相邻话题，他们没想要但会要 |
| 5–6 | 需要搭桥的相关性 |
| 3–4 | 牵强，信息流里会觉得突兀 |
| 1–2 | 无关 |

### 3. 角度价值（权重 25%）

| 分 | 信号 |
|---|---|
| 9–10 | 独家——只有你能写的数据/经历/内部视角 |
| 7–8 | 差异化——能更深或带证据挑战主流叙事 |
| 5–6 | 新包装——不独家但有新数据或更好框架 |
| 3–4 | 饱和——同类文章几十篇 |
| 1–2 | 纯重复。别写 |

### 4. 互动潜力（权重 15%）

| 分 | 信号 |
|---|---|
| 9–10 | 两极化，读者必须表态 |
| 7–8 | 触及身份认同（"这说的不就是你吗"） |
| 5–6 | 有用，会收藏不一定转发 |
| 3–4 | 读完即忘 |
| 1–2 | 零个人相关性的纯信息 |

### 5. 洞察潜力（权重 15%）

| 分 | 信号 |
|---|---|
| 9–10 | 有一个没人点破的不舒服真相，能感觉到它在那 |
| 7–8 | 多层可挖，第一性原理拆解会有惊喜 |
| 5–6 | 挖一挖至少有一个非显然角度 |
| 3–4 | 表面即全部 |
| 1–2 | 话题就是它看起来的样子 |

## 评分公式

```
总分 = 热度×0.20 + 匹配×0.25 + 角度×0.25 + 互动×0.15 + 洞察×0.15
```

**修正项**：与近 7 天已发主题重叠 → **-2** 并标"近期已覆盖"；知识库有支撑素材 → **+1** 并标"有素材"。

## 输出：10 个候选话题

每个必须包含：

| 字段 | 要求 |
|---|---|
| 草拟标题 | 移动优先，主体+收益前置 |
| 总分 | 0–10，展示加权过程 |
| 五维明细 | 各维分数 |
| CTR 预测 | 高/中/低 |
| 推荐框架 | 六大框架之一 + 一句理由 |
| 去重标记 | 对照近 7 天历史 |
| **原子洞察草稿** | 1–2 句：这篇文章能交付什么洞察？**最重要的字段** |
| 转发理由 | 读者会把它转给哪一个具体的人，为什么 |
| 转化匹配 | 支撑哪个主要转化目标 |

30 秒内写不出原子洞察草稿 → 这个话题大概率没有洞察，换下一个。

## 选题锐化五步

大多数话题生下来是泛的。工作是磨到能割手。

1. **说出泛版**："AI 对职场的影响"
2. **加人群——具体是谁？**："AI 对 30 岁以上中层管理者的影响"
3. **加张力——不舒服的真相是什么？**："AI 不会先干掉基层员工，会先干掉中层——因为中层的核心价值是信息传递和协调，而这正是 AI 最擅长的"
4. **加时效——为什么是现在？**："上周某大厂裁撤了一整个中层序列，理由是'AI 已经能做周报汇总和跨部门对齐了'"
5. **写出原子洞察**："你以为 AI 在替代执行层，其实它在替代协调层。月薪 5 万的人比月薪 5 千的人更危险。"

这才值得 2000 字。最初那句不值得。

### 更多锐化示例

| 泛（别写） | 锐（写这个） |
|---|---|
| 如何提高工作效率 | 为什么你越努力越低效——以及真正高效的人从不告诉你的一件事 |
| AI 的未来趋势 | AI 不会取代你的工作，但会取代你工作中你最引以为傲的那部分 |
| 年轻人的焦虑 | 25 岁焦虑是因为选择太多。35 岁焦虑是因为发现选择已经做完了 |
| 副业赚钱 | 你的副业不是在帮你赚钱，是在帮你逃避主业的真实问题 |
| 读书的好处 | 我去年读了 60 本书，然后意识到——我记住的不到 5 本的内容 |
| 创业心得 | 创业第三年我才明白：最大的成本不是钱，是你用来犹豫的那些月份 |

## 七个选题透镜

1. **内容缺口**："大家都在谈但没人讲明白的是什么？"——20 篇都是表面总结的热点，深处留白。
2. **受众痛点**："我的读者这周在为什么发愁？"——通用话题 + 具体人群 = 金子。
3. **信息不对称**："我知道什么而大多数读者不知道？"——出爆文概率最高，但需要真实的信息优势。没有就别硬写。
4. **情绪共鸣**："什么话题会让读者转发时配'说的就是我'？"——身份、人生转折、职业焦虑、代际张力。
5. **晚宴测试**："聪明朋友聚餐时抛出这个话题，讨论会升温吗？"——会，就有天然的辩论能量；礼貌点头换话题，就太平了。
6. **不舒服的真相**："这个圈子里大家在假装看不见什么？"——每个行业都有房间里的大象。点破的文章被转发不是因为写得好，是因为读者松了口气：终于有人说了。
7. **反转视角**："这个话题的反面立场，有没有被低估的道理？"——所有叙事都有反面，多数没人认真辩护过。

## 排序规则

1. 按总分降序
2. 平分先比洞察潜力（深度>表面）
3. 再平分比 SEO 可行性
4. "近期已覆盖"标记的话题垫底，无论分数

## 选题陷阱

- **最高热度陷阱**：1000 篇已发的 10 分热度，不如角度 9 分的 7 分热度。
- **相关性拉伸**：需要超过一句话解释为什么相关，大概率不相关。诚实打分。
- **常青借口**："这是常青话题"不是今天写的理由。触发点是什么？没有触发点就存着。
- **安全牌**：默认选最容易的而不是最有趣的。有趣但难 > 安全但无聊，每次都是。读者闻得出你在滑水。
- **委员会式选题**：auto 模式选最高分就走。反复自我怀疑浪费时间还引入偏差。
