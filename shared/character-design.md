# 人物设计逻辑（character-design）

> 做图做视频需要人物、用户又没提供照片时，用这套逻辑**先设计人物、再生成画面**。
> 核心口诀：**骨相、五官、皮肤、神态，一样一句。**
> 真实感来自不完美：痣、疤、痘印、皱纹、干裂、脱皮——每个角色至少两三处"缺陷"，缺了就是网红假脸。

---

## 角色卡十要素（生成人物的提示词标准结构）

按固定顺序组装，一段话写成：

```
[类型定位]，[地点]的[身份]，[性别]，[年龄]。
骨相：[脸型、颧骨、下颌，一句]。
五官：[眼(眼皮/形状/细节)、眉、鼻、嘴，一句]。
皮肤：[质感+颜色+瑕疵(晒斑/痘印/红血丝/毛孔)，一句]。
头发：[发型+当下状态(被压扁/花白/碎发)]。
神态：[正在做的动作 + 情绪，合成一句]。
穿着：[具体服装 + 磨损/使用细节(洗白/沾泥/袖口粉笔灰)]。
环境与光：[地点 + 光线方向与性质(低角度冷蓝侧光/正午硬光/屏幕冷光)]。
[镜头]：50mm 镜头，胸像，竖幅构图。
保留真实皮肤纹理和毛孔，不磨皮，不要网红脸，五官不要完美对称，不要浓妆，画面里不要文字。
```

**十要素各自的作用**：
| 要素 | 作用 | 缺了会怎样 |
|---|---|---|
| 类型定位 | 锁定摄影语言和真实感基调 | 风格漂移 |
| 骨相 | 决定"这是张什么脸"的底层结构 | 换个角度就变脸 |
| 五官 | 辨识度的主要来源 | 千人一面 |
| 皮肤 | 真实感的命门 | AI 网红脸 |
| 头发 | 年龄/状态的廉价信号 | 人物失真 |
| 神态 | 让人物"活着"而不是摆拍 | 蜡像感 |
| 穿着 | 身份的物证，细节要磨损感 | 广告片群演感 |
| 环境与光 | 情绪氛围 + 光影逻辑 | 平光假片 |
| 镜头 | 构图纪律 | 随机裁切 |
| 负约束 | 反 AI 假脸五连 | 全部白做 |

## 匹配逻辑：用户没给人物，怎么"根据需求匹配"

**第一步：从需求里提取四元组** —— 身份（职业/角色）、年龄段、地域/族群、气质（坚韧/疲惫/自豪/松弛…）。用户只说"需要一个人"时，问一句或从内容主题推断（写外卖骑手的文章 → 骑手；科技产品 → 程序员/产品经理）。

**第二步：身份反推细节**（十要素的素材库思维）：
- 职业 → 皮肤状态（渔把头=冻伤红血丝；骑手=头盔印+晒黑；程序员=屏幕冷光+浮肿）
- 职业 → 穿着磨损（厨师服沾油点；工装褪色；白大褂口袋插笔）
- 地域 → 光环境（查干湖=冰面冷蓝；夜市=炭火红光；医院=日光灯冷白）
- 年龄 → 皮肤证据（20 岁雀斑痘印；50 岁晒斑皱纹；80 岁老年斑+深纹）
- 民族/地域 → 头饰发型（苗族银角；藏族辫子缠红绳；惠安斗笠头巾）

**第三步：植入 2–3 处"不完美"**（从池子里选）：痣 / 旧疤 / 缺牙 / 银牙 / 痘印 / 干裂嘴唇 / 脱皮 / 眉毛断一截 / 牙缝 / 抬头纹。**这是去 AI 味的核心**。

**第四步：神态写成动作+情绪**：不写"微笑的老人"，写"手托刚出炉的馕，自豪地笑"、"刚摘下口罩，靠墙闭眼休息一秒"。

## 范例（六张参考角色卡）

**查干湖渔把头 · 男 · 62**（职业→皮肤+环境的典型）
> 纪实人像摄影，吉林查干湖冬捕的渔把头，男，62 岁。骨相：方长脸，颧骨外扩，下颌宽而硬。五官：细长单眼皮，眼角下垂、鱼尾纹很深；眉毛粗而稀疏、眉尾发白；鼻梁短、鼻头宽、冻得发红；嘴唇薄、嘴角向下。皮肤：常年风吹，脸颊有冻伤后的红血丝和晒斑，胡茬灰白。头发：狗皮帽压着，鬓角花白。神态：眯眼看冰面，呼出白气。穿着：旧军绿棉大衣，领口结霜。环境与光：清晨冰湖，低角度冷蓝侧光。50mm 镜头，胸像，竖幅构图。保留真实皮肤纹理和毛孔，不磨皮，不要网红脸，五官不要完美对称，不要浓妆，画面里不要文字。

## 角色复用（一致性）

角色一旦确认，就是**项目的资产**：

1. **定妆照**：角色卡先 draft 生成一张定妆照（正面胸像），用户确认后 final 存档 `workspace/projects/<slug>/characters/<名字>.png`
2. **后续画面**：同一角色的所有图/视频，要么把定妆照作为 `--ref` 参考图传入，要么在每条提示词里**原样复述角色卡的骨相+五官+皮肤段**（文本锚定）
3. **多角度**（需要时）：用同一角色卡生成"正面/侧面/全身"三视图，存为角色资产包
4. **改名不改卡**：用户只说"换个表情/换个场景"时，角色描述段一字不动，只改神态和环境段

## 角色卡自查

- [ ] 十要素齐全且顺序正确
- [ ] 骨相/五官/皮肤/神态各一句，没写成小作文
- [ ] 至少 2 处不完美细节
- [ ] 神态 = 动作 + 情绪
- [ ] 穿着有磨损/使用细节
- [ ] 光有方向和性质
- [ ] 负约束五连在场（不磨皮/非网红脸/不对称/不浓妆/无文字）
- [ ] 与需求四元组（身份/年龄/地域/气质）匹配
