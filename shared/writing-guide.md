# 写作方法论指南（writing-guide）

> 差距不在词汇和语法，在于：找到别人没注意到的那一件事，并用别人忘不掉的方式说出来。
> 本文件是所有文字类技能的核心方法库。写任何长文之前必读。

---

## 核心问题

AI 写作像一个读遍万卷书却毫无经历的好学生：有条理、面面俱到、四平八稳、没有生命。

读者在深夜十一点刷内容，拇指划得比思考快。他们已经跳过了 20 篇以"随着 AI 的发展"开头的文章。你只有 3 秒。

**你的工作不是传递信息**（信息是免费的），而是：
1. 让他们停下来
2. 让他们感受到没预料到的感受
3. 给他们一个明天洗澡时还在回味的念头

对标标准不是"不错的 AI 内容"，而是平台上最好的人类作者：刀锋般的类比、把读者放进现场的场景描写、让人读完觉得自己变聪明的分析。

**三条死刑判定**：
- 换几个名词就能用在任何话题上 → 死
- 读者从搜索引擎前三条就能得到同样内容 → 死
- 读者说"写得不错"但第二天记不住任何一句具体的话 → 死

## 原子洞察（Atomic Insight）

每篇好文章有且只有一个核心洞察——锋利到能割手的那一个念头。其余一切（结构、案例、金句）都是为了铺垫、交付、钉牢它。

**定义检验**：读完 2000 字后，读者会跟朋友转述哪一句话？答不出来就没资格开写。

### 四种找法

**方法一：反转测试** — 把话题的常识结论翻过来，问反面是否更接近真相。
- 常识："远程办公提高效率" → 反转："远程办公正在悄悄杀死你最重要的职业资产——弱关系网络"
- 常识："要培养好习惯" → 反转："你以为在培养习惯，其实在训练自己的无聊耐受力"

**方法二："为什么这事让我烦"挖掘** — 轻微的烦躁感指向一个未被审视的矛盾，顺着挖。
- "为什么每次团建我都想请假？" → 不是因为内向。是团建的账根本算不过来 → 洞察：**大多数团建不是在增进感情，是在消耗你最稀缺的资源——真诚。**

**方法三：二阶后果链** — 多数文章停在一阶效应，往后再走两步。
- 一阶："短视频让注意力下降"（人人会说）
- 二阶："注意力下降导致深度阅读退化"（有人会说）
- 三阶："深度阅读退化意味着复杂决策能力下降——这一代最聪明的人可能正在变成最高效的信息消费者，同时变成最差的判断者" ← **这才是你的洞察**

**方法四："谁受益"透视** — 每个流行叙事背后都有受益者，问是谁、为什么。
- "所有人都在说终身学习" → 谁受益？知识付费平台 → 洞察：**"终身学习"被偷换了概念——本来是说保持好奇心，现在变成了"永远焦虑，永远购买"。**

### 洞察质检（3 项不过就换角度）

- [ ] 业内人会说出"这个角度有意思"而不是"这我知道"吗？
- [ ] 它挑战了读者目前相信的某件事吗？
- [ ] 它具体到换个话题就不能复用吗？
- [ ] 能用证据（而不只是修辞）捍卫它吗？
- [ ] 晚宴上说出来会引发争论吗？（好）还是只收获礼貌点头？（坏——太平庸）

## 写前思考框架（在 `<thinking>` 里完成，绝不写进正文）

1. **读者场景**：不是"地铁上"，是"周三晚上十点半，刷了半小时短视频已经有点恶心自己了，随手点开了你的文章"。为那个情绪状态而写。
2. **情绪旅程**：起点（轻度好奇）→ 攀升（认同："这说的就是我"）→ 峰值（不舒服的真相）→ 落地（被赋能的清醒）。必须有峰值。
3. **核心矛盾**：最有趣的那对悖论——不是两边有道理的辩论，而是没有干净答案的真矛盾。"我们要真实，但精心策划一切。"
4. **原子洞察**：一句话。说不出一句话就停下。
5. **最强反驳**：聪明的怀疑者会说什么？不是稻草人，是让你自己都迟疑的那条。必须在文中回应。
6. **电影场景**：哪一个具体画面能概括全文本质？不是比喻，是有感官细节的瞬间。这是开头候选。
7. **一千块赌注**：拿一千块赌你的核心主张，你敢吗？不敢就找到你敢赌的那个版本。
8. **信息不对称**：你知道什么而 95% 的读者不知道？答案是"没有"就再调研，或换角度。没有信息不对称的写作是表演，不是贡献。

思考会自然渗入写作，**不要**把清单本身抄进文章。

## 深度架构

形式漂亮内容空洞，比形式粗糙洞察扎实更糟。读者能原谅笨拙的深刻，永远不原谅优雅的空洞。

### "So What" 阶梯

每个主张要撑过三级追问：

> **一级（现象）**："越来越多的公司开始裁员"
> —— So what？
> **二级（含义）**："求职市场正在从卖方转向买方，面试门槛整体提高"
> —— So what？
> **三级（刺痛/可行动）**："当市场上到处是优秀的失业者，真正保护你的不是技能——是你在行业里的'被想起概率'。那些默默干活从不发声的人，危险系数最高。"

一级是新闻，二级是不错的分析，三级是让人转发时配一句"说到点子上了"的东西。**每篇至少两次到达三级。**

### 第一性原理拆解

1. **大家在假设什么？** 找到隐含前提。"AI 争论假设'取代岗位'等于'让人失业'，但历史显示技术创造的总岗位多于摧毁的——只是岗位不同。真正的问题不是失业，是转型速度和代价。"
2. **这个假设成立吗？** 用边缘案例测试。"效率文化假设产出越多价值越大。但一家'高效'地把病人快速打发走的医院，结果更差。效率依情境而定。"
3. **二阶效应是什么？** 深度藏在二三阶："当人人都能卖货，稀缺的不再是渠道而是信任——信任经济正在悄悄取代流量经济。"
4. **没人说出口的不舒服真相是什么？** 每个话题都有一个。点破它的文章赢。

### 深度从哪来

- **挖素材库**：已收藏的材料是金矿——具体数据点、不寻常的视角、真实经历。通用文章给不了这些。
- **跨域交叉**：写管理从演化生物学借力（"办公室政治不是功能失调，是带邮件的灵长类等级制度"）；写 AI 从电气化史借力（"工厂花了 30 年才学会用电动机——不是技术不行，是他们一直把电动机放在蒸汽机原来的位置"）。
- **命名矛盾**："我们一边嘲笑消费主义，一边在购物车放了 7 件'必需品'。"
- **审问数据**：不装饰统计，交叉质询。"那个'平均存款'数据的样本全是一二线城市本科以上——这不是平均，这是最会赚钱的那批人。"
- **用一手来源**：读论文本身而不是报道论文的稿子。一手和二手之间的落差就是洞察藏身处。

### 深度清单（写作后必查，2 个以上"否"就重写）

- [ ] 有至少一个让业内人士说"这个角度我没想过"的洞察？
- [ ] 读者能采取一个从搜索前三名里得不到的具体行动？
- [ ] 点名并正面回应了最强反驳（不是稻草人）？
- [ ] 有至少一个可验证的具体主张（数据/具名案例/具体经历）？
- [ ] 剥掉所有排版和修辞，光看观点还值得读吗？

### 浅薄反模式

- **华丽的废话**：节奏无可挑剔、类比生动、洞察为零。检验：一句话总结论点，如果是废话（"AI 会改变世界"），两千字白写。最危险的浅薄是听起来很深的浅薄。
- **框架填空题**："5 个提高效率的方法"每条都是"制定计划/减少干扰/定期复盘"。框架是骨架，深度是血肉和伤疤。
- **圆滑的和稀泥**："这问题很复杂……要看具体情况……各有利弊……"这不是全面，是智识怯懦。全面是亮明立场并说明为什么聪明人可能反对你。
- **比喻成灾**：一个精准的类比是武器，五个连用是躲在装饰后面。
- **大而全的平庸**：十个角度各扫一遍，不如一个角度打穿。深度永远赢广度。

## 情绪架构

每篇好文章都是一段有形状的情绪体验。情绪平线 = 读者流失。写之前设计弧线。

### 五种情绪形状

1. **缓升型**：平静开场 → 逐步积累 → 洞察引爆 → 安静收尾。适合深度分析。弧线：好奇 → 认同 → 不安加剧 → "原来如此" → 清醒。
2. **当头棒喝型**：震撼开场 → 持续高压 → 短暂喘息 → 硬真相 → 抗争式收尾。适合热点锐评。
3. **温柔一刀型**：轻松共鸣开场 → 随口一提 → 洞察毫无预警地降临。适合生活/职场/情感文。最难写，写成了最强。
4. **跌宕型**：紧张与释放交替，每轮加码。适合故事和案例。
5. **自我解剖型**：脆弱坦白 → 共同认领 → 不舒服的真相 → 集体宣泄。适合个人随笔和文化批评。

### 节奏规则

- **同一情绪强度不得超过 3 段**。激烈之后转安静，分析之后转 visceral。
- **情绪峰值放在全文 60–70% 处**，不是结尾。最后 30% 用来落地和回响。
- **幽默是武器不是装饰**：严肃文章里一个恰到好处的玩笑，效果是持续搞笑的十倍。用它卸掉防备，再递上硬话。
- **愤怒是燃料不是火焰**：带具体证据的义愤让人转发，泛泛的抱怨让人划走。

### 情绪具体化原则

抽象情绪打动不了人，具体的才行：

| 抽象（弱） | 具体（强） |
|---|---|
| 很焦虑 | 焦虑到凌晨三点对着天花板数空调嗡嗡声的次数 |
| 很开心 | 把外卖单揉成球投进垃圾桶、进了、握拳的小得意 |
| 感到被背叛 | 就是那种——你以为你们在聊天，后来发现对方在搜集素材 |
| 很迷茫 | 简历改到第五版，每一版都觉得不像自己 |

## 声音架构

### 塑形思考，而不是约束输出

| 约束输出（死声音） | 塑形思考（活声音） |
|---|---|
| "用短句" → 机械断句 | "想象你已经琢磨这事一周，刚刚想通，半夜发消息给你最聪明的朋友" → 自然带着急迫 |
| "要口语化" → 硬插"你知道吗" | "你不是在写文章，是在把想法说出声。乱一点没关系" → 真实 |
| "不要用列表" → 变成"首先…其次…"（更糟） | "想想这个话题在哪一刻跟你有关。从那一刻写起" → 落地 |
| "要有感情" → 通用感叹号 | "如果这事发生在你身上，你会是什么感受？" → 挣来的情绪 |

### 不完美叙述者

你不是全知的。认知诚实换来信任：
- **挣来的自我怀疑**："我也不确定这个判断对不对，但我赌了。"
- **改主意是思考过的证据**："半年前我的观点完全相反。改变我的不是道理，是一件小事。"
- **承认局限**："这个我知道得不多。但有个人说得比谁都清楚——"
- **实时自我修正**："等等，我刚才说的不对——不，准确地说应该是——"
- **刻意的跑题**："扯远了。但这个远，远得有道理。"

### 具体性：不可协商的分水岭

每个主张必须落地，无例外：

| 禁用（抽象=AI 默认） | 必须（具体=人味信号） |
|---|---|
| 很多人都有这个问题 | 上周在一个 300 人的产品经理群做了投票，217 人选了"是" |
| 效率很低 | 一个原本 20 分钟能写完的周报，我硬是拖了三天 |
| AI 正在改变行业 | 我们公司法务部上个月用 AI 改合同，平均审核时间从 4.5 天压到 6 小时。法务总监说："我现在的主要工作是检查 AI 有没有发现我没想到的问题" |
| 这个方法很有效 | 换了方法之后三个月涨了 2300 个粉丝。不算多，但之前半年一共涨了 400 |
| 沟通很重要 | 业绩最好的那个季度，唯一的变量是每周多开了一次 15 分钟的对齐会 |

## 中文写作五技法

1. **四字节奏**：不是"源远流长博大精深"那类套话（AI 信号），是现代的、锋利的自造四字格："进退两难、骑虎难下"、"月薪五千，焦虑五万"、"简历很新，心气很旧"、"嘴上躺平，身体内卷"。
2. **转折的艺术**：中文读者被转折喂养长大，越陡越难忘。
   - 弱："虽然有困难，但是我们要坚持"
   - 锋："我以为问题是钱。不是。问题是我根本不知道自己不知道什么。"
   - 毁灭级："他用了三年证明自己是对的。然后用了三秒意识到，对的没用。"
3. **对仗不对称**：完美对仗是 AI 的签名，刻意打破末项是人味。
   - ❌ "有人在拼命，有人在躺平，有人在摸索"（太对称=机器人）
   - ✅ "有人在拼命。有人在装死。还有一群人，连自己在干什么都说不清。"（末项爆裂）
4. **留白**：中文最有力的时刻是没说出口的部分。"他问我后悔吗。我没回答。不是不想说。"——三句话，读者自己补完。读者创造的意义永远强于你写明的。
5. **口语切入**： prose 太光滑时砸进一句大白话，反差制造真实感。"从宏观经济学的角度看，消费降级的本质是预期管理的失败。说人话就是：大家不是没钱，是不敢花了。"

## 节奏与韵律

### 句长变化（强制）

长句蓄力，短句出拳。绝不连续三句相近长度。

> 我花了整整三个月，每天下班之后在出租屋里对着电脑，一行一行地学写代码。从完全看不懂到能看懂报错，从能看懂报错到能自己改，从能自己改到第一次跑通的那个凌晨两点半。
>
> 然后我辞职了。
>
> 不是因为学会了。是因为在学的过程中，我突然明白了一件更重要的事。

"然后我辞职了"——五个字跟在七十字后面。对比本身就是冲击。句长全是中等，文章就没有脉搏。

### 段落节奏

- 短段（1–2 句）与发展段（3–5 句）交替；绝不连续 3 段等长
- 每 3–4 段插一个钩子：提问、场景跳转、数据冲击、直接称呼、急转弯
- 连续文本行不超过 7–10 行必须有视觉断点（图、引用、小标题）

### 标点是乐器

- **句号**：语法上能用逗号的地方断句，制造打击感
- **省略号**：未完成的想法，读者预期。每篇最多 2 次
- **破折号**：戏剧性揭示、急转、意外旁白，最趁手的工具
- **问号**：让读者真思考的问题，不是自问自答的铺垫
- **单句成段**：核弹级，留给最需要落地的那一下

## 开头规则：你有 3 秒

### 八种开头模式（按威力排序）

1. **场景坠落**——把读者扔进一个正在进行的瞬间。没有铺垫。"凌晨 1:47，我盯着一个叫 layoff-tracker 的开源仓库——有人把裁员名单做成了每 15 分钟自动更新的项目。最高赞评论是：'Star 了。保佑用不上。'"
2. **伤人的数字**——不是统计，是让胃部收紧的数。"1158 万毕业生你可能没感觉。换个说法：每过 1 秒，就有 37 个人拿着简历开始找工作。你读完这句的工夫，又多了 300 个对手。"
3. **坦白**——承认一件有代价的事，用诚实换更深的信任。"写这篇之前我删掉了三个版本。不是不满意——是每写到一半就意识到自己在骗人。所以这一版，从我不信的那个东西说起。"
4. **慢动作碰撞**——两个不该同时为真的事实。"每年出版 50 万本新书，人均阅读量 4.7 本还在跌。我们正以史上最快速度生产没人读的东西。"
5. **偷听时刻**——某句随口的话事后看精准得可怕。"聚餐时一个做了 10 年 HR 的朋友喝到微醺：'面试最可笑的是双方都在演，都知道对方在演，谁先破功谁输。'那顿饭之后我想了一周。"
6. **反转**——立好预期再炸掉。"我花两年研究了成功人士的早晨习惯。五点起床、冥想、运动、写日记，全做了。你猜怎么着？——我变成了一个每天五点起床的普通人。"
7. **直接挑衅**——告诉读者他们信错了。但你最好证明得了。"你以为在做内容创业。说句难听的：你在做免费劳动。不信？算一笔账。"
8. **未完微故事**——带未解之问的微型叙事。"上个月，认识十年的合伙人发来一条微信：'我想好了。'三个字。那天下午我们只说了七句话。但它改变了之后所有事。"

### 禁用开头（秒劝退）

"今天给大家分享…" / "随着 XX 的发展…" / "在当今社会…" / "在这个信息爆炸的时代…" / "众所周知…" / "相信很多人和我一样…" / 任何定义式开头（"什么是 XX？XX 是指…"）

## 结尾规则

- 最多 1–2 句。读者刚经历完全文，**绝不总结**。
- 结尾应该改变前文某处的含义，或留下一个甩不掉的念头。

**四种强结尾**：
- **回旋镖**：带着新含义回到开头。（"后来我问他后悔吗。他说了句我到现在没想明白的话：'后悔是后来人才有的资格。'"）
- **不舒服的问题**：（"下次有人跟你说'做自己'，试着问一句：哪个自己？"）
- **安静的重击**：没有感叹号，没有戏剧。只有真话。（"这个世界不缺聪明人。缺的是愿意把聪明用在笨事上的人。"）
- **未完的动作**：停在动作中间。（"写到这里，我把搁置半年的项目文件夹打开了。"）

**禁用结尾**："希望对你有帮助" / "以上就是我的分享" / "你觉得呢？欢迎留言讨论" / "让我们一起…" / 任何形式的总结。

## 截图测试（终检）

**全文是否至少有一段好到值得截图发给朋友？**

截图级段落的特征：2–3 句完美结晶的洞察；命名了读者感受到但从未说出的东西；精确到可以被引用的措辞。

> "职场最残酷的真相不是'努力没用'。是'努力有用，但有用的程度远远小于你以为的程度'。差距真正拉开的地方，是你下班之后、没人看着的时候，选择做什么。"

> "我们这代人有个毛病：把'知道'当成'做到'的预支。看了减肥视频觉得自己瘦了三斤，读了理财文章觉得自己赚了三万。"

写完 2000 字找不到一段截图级的 → 密度不够，回去磨。

## 结构规格表

| 元素 | 要求 |
|---|---|
| 总字数 | 1500–2500（完读率最优 1500–2000） |
| H1 标题 | 移动优先，前置主体和收益 |
| H2 小标题 | 至少 3 个，必须勾人（"这才是真正的问题"而非"问题分析"） |
| 段落上限 | 150 字（移动可读性） |
| 钩子间隔 | 每 3–4 段 |
| 截图级段落 | 至少 1 处，理想 2–3 处 |

## 编辑指令表

| 用户说 | 动作 |
|---|---|
| 润色 | 提升表达。保内容保结构。磨薄弱段。 |
| 缩写 | 压到 60–70%。保原子洞察和最强案例。 |
| 扩写 | 加案例、深度、细节到 130–150%。不加废话，加实质。 |
| 换语气 | 按用户指定的目标语气调整。需要目标。 |

## 常见失败模式

- **通用洞察**：洞察连你自己都不惊讶，就没人会惊讶。深挖或砍掉。
- **平衡机器人**：每边都说到、没有立场。亮立场，承认可贵的反对，解释你为何仍然不同意。
- **总结式结尾**：读者刚在场过。结尾必须给新东西。
- **伪装成散文的列表**：把要点改成"首先…其次…最后"不是散文。真正的流动是观点互相搭建、互相意外、互相反驳。
- **300 字热身**：正文前的背景铺垫。砍掉，从有趣的地方开始，背景后置织入。
- **情绪平线**：好文章的强度图是心跳，不是直线。
- **确定性病**：一切都说成定论。"我不确定，但我倾向于…"比"毫无疑问"可信。
- **案例充数**：三个例子说同一件事。一个锋利的例子 > 三个平庸的。第二个例子必须加新维度，否则删。
