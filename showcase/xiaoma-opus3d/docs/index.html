乌镇西栅 · 可交互模型

由 xiaoma-opus3D skill 生成：没有用任何 3D 模型、贴图或照片，几何、材质、纹理全部是代码生成的。全屏打开

下面这块是嵌在普通网页里的 3D 模型：左键拖动旋转，滚轮缩放，右键拖动平移；手机上单指旋转、双指缩放。

方式一：iframe（最省事）

<iframe src="wuzhen.html?quality=auto&time=55" style="width:100%;height:540px;border:0"></iframe>

方式二：script 挂到任意 div

同一页面里嵌多个时，iframe 互相隔离更稳；想和页面脚本交互（比如自己做按钮切画质）用这种。

<div data-wuzhen='{"quality":"auto","time":55}' style="height:540px"></div>
<script src="wuzhen-embed.js"></script>

<!-- 或者手动挂载 -->
<script>
  WuzhenScene.mount(document.getElementById('scene'), { quality: 'medium' })
    .then((viewer) => { /* viewer.setQuality('low'); viewer.dispose(); */ });
</script>

参数：quality = auto / high / medium / low（auto 会在帧率不够时自动降档）；time = 0~70，0 是日落前，70 是华灯初上；hint = false 关掉左下角的操作提示。
