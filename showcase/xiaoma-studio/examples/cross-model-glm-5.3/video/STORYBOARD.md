# STORYBOARD

Logline：一个买了烂片电影票的人想要止损离场，但「票钱已经花了」不断把他按回座位，所以他必须先看清一件事——花掉的钱和接下来的决定，根本是两件事。
原型：theme-editorial（编辑部数据叙事）    画幅：1920×1080    时长：58s    BPM：90
钩子（0–2s）：三枚硬币依次落下、弹跳、摞成一叠（物件在动，不是标题淡入）
母题：一枚硬币（开场落下摞起 → 中途沉入水面之下 → 结尾再落一枚、沉没、变暗）
色彩弧线：编辑部黑（#0a0a0a + 蓝 #4a6cff）→ 22s 亮纸底翻转（#f2f2ef + 墨色，数据章节）→ 36s 回黑（水面隐喻 + 收尾）
声音：纯音乐（pad/bass/kick/hat/pluck 合成，BPM 90）+ 卡点音效；无旁白，字幕即旁白
叙事结构：B 反常识数据（具体场景 → 问题 → 常见解释 → 亮底翻转 → 数据 → 隐喻 → 新结论）
